# 막혔을 때

먼저 **오류 메시지를 그대로 복사해서 AI에게 붙여넣고** "이거 왜 이래? 뭘 하려던 거냐면 ○○야"라고 물어보세요. 대부분 여기서 풀립니다.
그래도 안 되면 아래를 보고, 그래도 안 되면 운영진을 부릅니다.

## 저장소가 안 보여요

- 로그인한 계정이 초대받은 계정인지 확인합니다 (오른쪽 위 동그란 프로필 사진 클릭).
- 이메일에 온 **초대 메일의 "View invitation" 버튼**을 눌렀는지 확인합니다. 안 눌렀으면 저장소가 안 보입니다.
- 메일이 없으면 https://github.com/notifications 에서 초대를 찾을 수 있습니다.
- 그래도 없으면 운영진에게 GitHub 아이디를 알려 주세요. 다시 초대합니다.

## 웹에서 파일을 만들었는데 저장이 안 돼요

- 파일 이름 끝에 `.md`가 있는지 확인합니다.
- 초록색 **Commit changes…** 버튼을 두 번 눌러야 합니다 (한 번은 열기, 한 번은 저장).
- 같은 이름의 파일이 이미 있으면 만들어지지 않습니다. 이름을 바꾸거나, 그 파일이 내 것이면 **Edit**로 고칩니다.

## AI가 clone을 못 해요

- 저장소 주소를 정확히 붙여넣었는지 봅니다: `https://github.com/selfishclub/baemin-ops-os-camp`
- 비공개 저장소라서 **내 컴퓨터가 내 GitHub 계정으로 로그인되어 있어야** 합니다. AI에게 "GitHub 로그인부터 도와줘"라고 말합니다. 브라우저가 열리면 거기서 로그인합니다.
- 이미 같은 이름의 폴더가 있으면 "이미 있어"라고 나옵니다. 그 폴더를 열어서 pull 하면 됩니다.

## push가 안 돼요

**"rejected" 또는 "behind"라고 나옴**
→ 다른 사람이 먼저 올린 게 있어서입니다. AI에게 "먼저 pull하고 다시 push해 줘"라고 말합니다.

**"permission denied" 또는 "403"**
→ 로그인 계정이 다르거나 초대 수락이 안 된 것입니다. 위 "저장소가 안 보여요" 확인.

**"nothing to commit"**
→ 바꾼 게 없거나 이미 올라간 것입니다. GitHub 웹에서 내 폴더를 열어 확인합니다.

## 충돌(conflict)이 났대요

같은 파일의 같은 부분을 두 사람이 다르게 고치면 생깁니다.
이 캠프에서는 **자기 폴더만 고치면 생기지 않습니다.**
만약 났다면 AI에게 "충돌 난 파일 보여 줘. 내 내용을 남기고 싶어"라고 말하고, 확신이 없으면 운영진을 부릅니다.
**"강제로 push해 줘"는 절대 하지 않습니다.** 남의 작업이 지워집니다.

## 실수로 비밀번호나 키를 올렸어요

1. 즉시 운영진에게 알립니다.
2. 그 키는 **새로 발급**합니다 (Supabase, Vercel 등 해당 서비스에서). 파일만 지우는 것으로는 부족합니다. 기록에 남기 때문입니다.
3. AI에게 "방금 올린 키를 기록에서 지우고 .gitignore에 넣어 줘"라고 말합니다.

## 내 파일을 남이 고쳤어요 / 내가 남의 파일을 고쳤어요

- 되돌릴 수 있습니다. GitHub은 기록이 남습니다. 운영진에게 말하면 이전 버전으로 되돌립니다.

## 그냥 무서워요

- 이 저장소에서 **되돌릴 수 없는 일은 거의 없습니다.** 기록이 남는 게 GitHub의 존재 이유입니다.
- 딱 하나, 비밀번호·키를 올리는 것만 조심하면 됩니다.
