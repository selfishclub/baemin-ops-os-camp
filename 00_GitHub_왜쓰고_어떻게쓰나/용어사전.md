# 용어사전 — 화면에 나오는 말, 한 줄 뜻

## 기본 개념

| 말 | 한 줄 뜻 |
|---|---|
| **GitHub** (깃허브) | 내 프로젝트를 보관하고 기록하는 온라인 금고 서비스 |
| **Git** (깃) | 그 기록을 남기는 기술 이름. GitHub은 Git을 쓰는 웹사이트 |
| **Repository / Repo** (저장소, 레포) | 프로젝트 하나를 담는 금고 한 칸. "저장소 = 프로젝트 폴더" |
| **Private** (비공개) | 초대받은 사람만 볼 수 있는 저장소 |
| **Public** (공개) | 링크만 있으면 누구나 볼 수 있는 저장소. 이 공동 저장소와 완성 후에 만들 내 개인 저장소 둘 다 이것. 보는 건 누구나, 올리는 건 초대받은 사람만 |
| **main** (메인) | 저장소의 기본 작업 줄기. 이번 캠프는 전부 main에 바로 저장 |
| **Branch** (브랜치) | 작업 줄기를 따로 하나 더 내는 것. 이번 캠프에서는 안 씀 |
| **Collaborator** (협업자) | 저장소에 초대되어 같이 쓰는 사람 |

## 동작 네 개

| 말 | 한 줄 뜻 | 비유 |
|---|---|---|
| **Clone** (클론) | 저장소를 내 컴퓨터에 처음 복사 | 금고에서 노트 복사본 받아오기 |
| **Pull** (풀) | 저장소의 최신 내용을 내 컴퓨터에 반영 | 남이 고친 페이지 받아오기 |
| **Commit** (커밋) | 고친 내용에 설명을 붙여 기록 | "오늘 급여표 추가"라고 메모 붙여 저장 |
| **Push** (푸시) | 기록을 GitHub에 올리기 | 노트를 다시 금고에 넣기 |

## 화면 버튼

| 화면에 보이는 말 | 뜻 |
|---|---|
| **Add file** | 파일 추가 |
| **Create new file** | 새 문서 만들기 |
| **Upload files** | 내 컴퓨터 파일 올리기 |
| **Preview** | 미리 보기 |
| **Commit changes…** | 설명 붙여 저장 |
| **Commit directly to the main branch** | 기본 줄기에 바로 저장 (이걸 고름) |
| **Edit** 또는 연필 모양 | 내용 수정 |
| **Code** (초록 버튼) | 저장소 주소 복사, 다운로드 |
| **Settings** | 저장소 설정 (공개/비공개 바꾸는 곳) |
| **Fork** (포크) | 남의 저장소를 내 계정으로 복사. 오늘은 안 씀 |
| **Star** (별) | 즐겨찾기. 눌러도 아무 일 안 생김 |

## 배포 관련

| 말 | 한 줄 뜻 |
|---|---|
| **배포** (Deploy) | 내가 만든 걸 인터넷 주소로 만들어 누구나 열어보게 하는 것 |
| **Vercel** (버셀) | GitHub 저장소를 읽어서 인터넷 주소를 만들어 주는 서비스 |
| **Supabase** (수파베이스) | 데이터를 저장하는 온라인 창고(데이터베이스) 서비스 |
| **환경변수** (Environment Variable) | 코드에 직접 적으면 안 되는 값(키, 주소)을 따로 넣어 두는 칸 |
| **anon key** | Supabase의 "공개해도 되는 열쇠". 화면에서 쓰는 용도 |
| **service_role key** | Supabase의 "절대 공개하면 안 되는 열쇠". GitHub·코드에 넣지 않음 |

## 파일

| 말 | 한 줄 뜻 |
|---|---|
| **.md** (마크다운) | 글을 적는 문서 파일. GitHub에서 예쁘게 보여 줌 |
| **README.md** | 폴더를 열면 자동으로 보이는 안내문 |
| **.gitignore** | "이 파일은 올리지 마"를 적어 두는 목록. 비밀 파일 보호용 |
| **PRD** | Product Requirements Document. 무엇을 왜 만들지 적은 기획안 |
