# 실습 ① 우리 가게 소개 올리기

**네 줄만 적고 저장하면 끝입니다. 설치도, 명령어도 없습니다. GitHub 웹사이트에서 합니다.**

목표는 두 가지입니다. 서로 어느 가게인지 알기, 그리고 "GitHub에 뭔가 올려 봤다"는 경험 하나 만들기.

## 1. 아래 링크를 누릅니다

GitHub에 로그인한 상태에서 누르세요.

### 👉 [우리 가게 소개 작성하기](https://github.com/selfishclub/baemin-ops-os-camp/new/main/01_GitHub%EC%8B%A4%EC%8A%B5_%EC%9A%B0%EB%A6%AC%EA%B0%80%EA%B2%8C%EC%86%8C%EA%B0%9C?filename=%EA%B0%80%EA%B2%8C%EC%9D%B4%EB%A6%84_%EC%9D%B4%EB%A6%84.md&value=%23%20%EC%9A%B0%EB%A6%AC%20%EA%B0%80%EA%B2%8C%20%EC%86%8C%EA%B0%9C%0A%0A-%20%EC%9A%B0%EB%A6%AC%20%EA%B0%80%EA%B2%8C%20%EC%9D%B4%EB%A6%84%3A%0A-%20%EC%9A%B0%EB%A6%AC%20%EA%B0%80%EA%B2%8C%20%EC%9E%90%EB%9E%91%ED%95%98%EA%B8%B0%3A%0A-%20%EB%82%B4%EA%B0%80%20%EC%98%A4%EB%8A%98%20%EB%A7%8C%EB%93%A4%EA%B3%A0%20%EC%8B%B6%EC%9D%80%20%EA%B2%83%3A%0A-%20%EC%99%9C%20%EA%B7%B8%EA%B1%B8%20%EB%A7%8C%EB%93%A4%EA%B3%A0%20%EC%8B%B6%EC%9D%80%EC%A7%80%3A%0A)

누르면 새 파일 만드는 화면이 열리고, 네 줄 양식이 **미리 채워져** 있습니다.

## 2. 파일 이름을 바꿉니다

맨 위 파일 이름 칸에 `가게이름_이름.md`라고 되어 있습니다. 자기 것으로 바꿉니다.

- 예: `부찌대학_이범례.md`, `빈숲카페_양진서.md`, `해모닉_김민혁.md`
- 끝의 `.md`는 그대로 둡니다. (`.md`는 "글 문서"라는 이름표입니다)
- 폴더 이름(`01_GitHub실습_우리가게소개/`)이 이미 앞에 보이면 다시 적지 않습니다.

## 3. 네 줄을 채웁니다

```markdown
# 우리 가게 소개

- 우리 가게 이름:
- 우리 가게 자랑하기:
- 내가 오늘 만들고 싶은 것:
- 왜 그걸 만들고 싶은지:
```

한 줄씩 짧게 적어도 됩니다. 예를 들면 이렇게요. (가상의 가게입니다)

```markdown
# 우리 가게 소개

- 우리 가게 이름: 함흥물냉면 서초점
- 우리 가게 자랑하기: 육수를 매일 새벽에 직접 끓입니다. 배민 별점 4.9
- 내가 오늘 만들고 싶은 것: 알바 근무표를 넣으면 주급이 자동으로 계산되는 표
- 왜 그걸 만들고 싶은지: 매주 일요일 밤에 계산기 두드리는 30분을 없애고 싶어서
```

## 4. 저장합니다

1. 오른쪽 위 초록색 **Commit changes…** 버튼을 누릅니다.
2. 작은 창이 뜨면 첫 칸에 `우리 가게 소개 추가`라고 적습니다.
3. **Commit directly to the main branch**가 선택되어 있는지 봅니다.
4. 초록색 **Commit changes** 버튼을 한 번 더 누릅니다.

화면이 바뀌고 내가 쓴 글이 보이면 **완료**입니다. 웹에서 저장했으니 이미 GitHub에 올라갔습니다.

## 화면에 나오는 영어 버튼

| 화면에 보이는 말 | 뜻 |
|---|---|
| Add file | 파일 추가 |
| Create new file | 새 문서 만들기 |
| Preview | 미리 보기 |
| Commit changes… | 설명 붙여 저장하기 |
| Commit directly to the main branch | 기본 줄기에 바로 저장 (이걸 고름) |
| Edit 또는 연필 모양 | 내용 수정 |

## 잘 안 될 때

- **링크를 눌렀는데 404가 떠요** → 로그인이 안 됐거나 초대 수락을 안 한 것입니다. [막혔을 때](../00_GitHub_왜쓰고_어떻게쓰나/막혔을때.md)를 보세요.
- **링크 없이 직접 하고 싶어요** → 이 폴더에서 **Add file → Create new file**을 누르고 [_양식.md](_양식.md) 내용을 복사해 붙입니다.
- **저장했는데 고치고 싶어요** → 내 파일을 열고 연필 모양(**Edit**)을 누릅니다. 몇 번이고 고쳐도 됩니다.
- **같은 이름 파일이 이미 있대요** → 내가 아까 만든 것입니다. 그 파일을 열어 **Edit**로 고칩니다.

다 됐으면 [첫 화면](../README.md)으로 돌아가 다음 순서로 갑니다.
