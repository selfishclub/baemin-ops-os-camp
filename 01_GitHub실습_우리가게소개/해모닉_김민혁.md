# 우리 가게 소개

- 우리 가게 이름: 해모닉 대게 킹크랩 전문점
- 우리 가게 자랑하기: 대게와 킹크랩을 중심으로, 가족 외식부터 소중한 사람과의 특별한 식사까지 함께하고 싶은 전문점입니다.
- 내가 오늘 만들고 싶은 것: ‘대게와 킹크랩, 어떤 걸 고르면 좋을까?’를 주제로 맛과 식감의 차이, 취향별 선택 팁을 쉽게 알려주는 인스타그램 캐러셀 콘텐츠
- 왜 그걸 만들고 싶은지: 대게와 킹크랩을 처음 접하는 고객의 메뉴 선택 고민을 덜어주고 싶습니다. 유용해서 저장하고 함께 먹을 사람에게 공유하는 콘텐츠로 해모닉을 알리고, 방문으로 이어지게 만들고 싶습니다.
