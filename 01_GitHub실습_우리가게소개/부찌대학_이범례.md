# 우리 가게 소개

- 우리 가게 이름: 소문난의정부부대찌개 고대본점 (부찌대학) · since 2013, 고려대 정문 앞 2분
- 우리 가게 자랑하기: 채소와 남해 다시마로 매일 2시간 우린 채수, 직접 담가 숙성한 찌개전용김치로 담백하고 개운한 부대찌개를 끓입니다. 하루 300장 직접 굽는 들기름 김구이, 배달도 노란 보온가방에 담아 대접받는 밥상처럼 보냅니다.
- 내가 오늘 만들고 싶은 것: 직원 출퇴근 시간만 넣으면 근무시간·휴게시간·주휴수당까지 계산해 직원별 급여가 바로 나오는 급여 산정표
- 왜 그걸 만들고 싶은지: 급여날마다 근무표 펴놓고 계산기 두드리는 시간이 길고, 휴게시간·주휴수당 계산이 헷갈려 혹시 틀릴까 늘 마음이 쓰여서요. 계산은 도구에 맡기고, 저는 확인만 하고 싶습니다.
