# 운영자용 · 참가자 초대하기

## 1. 이메일 취합

체크인 시트의 "GitHub 이메일" 열을 확인합니다. 기한은 9/14였고, 미제출자는 카톡으로 독려합니다.
이메일 대신 **GitHub 아이디**를 받아도 초대됩니다. (아이디가 더 확실합니다)

## 2. Collaborator 초대

저장소 https://github.com/selfishclub/baemin-ops-os-camp
→ **Settings → Collaborators and teams → Add people** → 이메일 또는 아이디 입력 → **Write** 권한 → Add.

명령어로 한 번에:
```bash
gh api -X PUT repos/selfishclub/baemin-ops-os-camp/collaborators/<GitHub아이디> -f permission=push
```

## 3. 수락 확인

**Settings → Collaborators** 에서 "Pending invite"가 남아 있으면 미수락입니다.
- 초대 메일은 GitHub 가입 이메일로 갑니다. 스팸함 확인.
- 메일이 없으면 https://github.com/notifications 또는 저장소 주소를 직접 열면 수락 배너가 뜹니다.

## 비상 통로 — 당일 초대가 안 된 분

저장소가 공개(Public)라서, 초대를 못 받은 분도 **fork → Pull Request**로 제출할 수 있습니다. 운영진이 merge하면 폴더에 들어갑니다.

사장님에게 안내할 말:
1. 실습 ① 링크를 누르면 "Fork this repository"라는 초록 버튼이 나옵니다. 누릅니다. (내 계정에 복사본이 생깁니다)
2. 파일 이름 바꾸고 네 줄 채웁니다. 똑같습니다.
3. 초록 버튼이 **Propose changes**로 보입니다. 누르고, 다음 화면에서 **Create pull request**를 두 번 누릅니다.
4. 운영진에게 "PR 보냈어요"라고 말합니다.

AI로 할 때:
> 이 저장소를 내 계정으로 fork하고 받아 줘. 내 폴더에 PRD를 넣고, 원본 저장소로 Pull Request를 보내 줘.

운영진: 저장소 **Pull requests** 탭 → 열어 보고 → **Merge pull request** → **Confirm**. 그 뒤 그분을 협업자로 초대해서 다음부터는 직접 push하게 합니다.
