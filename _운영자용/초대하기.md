# 운영자용 · 참가자 초대하기

## 1. 이메일 취합

체크인 시트의 "GitHub 이메일" 열을 확인합니다. 기한은 9/14였고, 미제출자는 카톡으로 독려합니다.
이메일 대신 **GitHub 아이디**를 받아도 초대됩니다. (아이디가 더 확실합니다)

## 2. Collaborator 초대

저장소 https://github.com/selfishclub/baemin-ops-os-camp
→ **Settings → Collaborators and teams → Add people** → 이메일 또는 아이디 입력 → **Write** 권한 → Add.

명령어로 한 번에:
```bash
gh api -X PUT repos/selfishclub/baemin-ops-os-camp/collaborators/<GitHub아이디> -f permission=push
```

## 3. 수락 확인

**Settings → Collaborators** 에서 "Pending invite"가 남아 있으면 미수락입니다.
- 초대 메일은 GitHub 가입 이메일로 갑니다. 스팸함 확인.
- 메일이 없으면 https://github.com/notifications 또는 저장소 주소를 직접 열면 수락 배너가 뜹니다.
