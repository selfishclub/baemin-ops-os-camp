## 자주 생기는 일과 대응

| 상황 | 대응 |
|---|---|
| 저장소 404 | 초대 미수락. notifications에서 수락 |
| 실습 ① 링크 눌렀는데 양식이 안 채워짐 | 01 폴더 → Add file → Create new file, `_양식.md` 복사 |
| AI가 clone 못 함 | "GitHub 로그인부터 도와줘" → 브라우저 로그인 |
| push rejected | "먼저 pull하고 다시 push해 줘" |
| PRD가 없는 분 | 02 README 실습 ② 3번 "없을 때" 프롬프트로 즉석 작성. 완성 안 돼도 push |
| 시간이 남는 조 | "같은 조 PRD 읽고 참고할 점" 프롬프트 |
| v1을 일찍 끝낸 분 | **오늘 v2 시작해도 된다고 안내.** "v1/프로젝트를 v2/프로젝트로 복사하고 v2/PRD.md 기능을 하나씩 추가해 줘" |
| 내 폴더 안에서 git init 해 버림 | AI에게 "방금 만든 .git 폴더를 지워 줘. 상위 저장소를 쓸 거야" |
| 내 폴더 밖에 파일이 생김 (루트에 package.json 등) | AI에게 "내 폴더 밖에 만든 파일을 내 폴더 v1/프로젝트으로 옮겨 줘" |
| push가 너무 큼 / 느림 | node_modules나 영상이 들어간 것. "node_modules와 영상 파일을 기록에서 빼고 .gitignore 확인해 줘" |
| GitHub에서 프로젝트 폴더가 회색 화살표로 보이고 안 열림 | 복사해 온 폴더 안에 `.git`이 있었던 것. "v1/프로젝트 안의 .git 폴더를 지우고, 그 폴더를 다시 추가해서 push해 줘" |
| 앱의 `data/` 폴더가 GitHub에 안 올라감 | 캠프 `.gitignore`가 예전엔 `data/` 전체를 제외했음(지금은 세션 파일만). "pull 받고 data 폴더를 다시 추가해서 push해 줘" |
| Vercel 배포가 안 됨 | 로그인 창이 안 뜨면 "npx vercel login 해 줘". 빌드 실패면 오류 그대로 AI에게. 프로젝트 이름 한글·대문자 확인 |
| 구경하기 표가 비어 있음 | 운영진이 `python3 _운영자용/도구/build_gallery.py` 실행 후 push. 사장님 제출서에 도구 이름·한 줄 설명이 있고 결과물/첫화면.png가 있어야 채워짐 |

## 말할 때 쓰지 않는 말
