코드는 **내 GitHub 저장소(공개)**에, 화면은 **Vercel 주소**로, 이 저장소에는 **기획안(PRD) + 두 링크가 적힌 제출서 + 스크린샷**을 올립니다.

## 꼭 지킬 것 세 가지

1. **내 폴더만 고칩니다.** 다른 사장님 폴더는 보기만 합니다.
2. **비밀은 올리지 않습니다.** 비밀번호, API 키, 로그인 파일, 직원·손님 실명, 실제 매출 파일.
3. **강제로 덮어쓰지 않습니다.** 막히면 혼자 해결하지 말고 운영진을 부릅니다.
