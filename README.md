## 제출은 이렇게

**오늘은 만든 것을 통째로 이 저장소에 올립니다.** 내 폴더 안 `v1/프로젝트/`에서 만들고, 코드·프롬프트 기록·이미지·문서까지 그대로 push합니다.
12명이 한곳에 두면 "저런 것도 되는구나" 하고 서로 **힌트**를 얻고 끌어다 쓸 수 있기 때문입니다. 써 보는 건 각자 **Vercel 주소**로 합니다. → [구경하기](02_실전캠프_Day2_실습제출/README.md#구경하기)

## 꼭 지킬 것 네 가지

1. **내 폴더만 고칩니다.** 다른 사장님 폴더는 보기만 합니다. 끌어다 쓸 때도 내 폴더로 복사해서 씁니다.
2. **내 폴더 안에서 `git init`을 따로 하지 않습니다.** 이 폴더는 이미 저장소 안입니다. AI에게 "git init은 하지 마"라고 말합니다.
3. **비밀은 올리지 않습니다.** 비밀번호, API 키, 로그인 파일, 직원·손님 실명, 실제 매출 파일. `node_modules`와 `.env`는 자동으로 빠집니다.
4. **강제로 덮어쓰지 않습니다.** 막히면 혼자 해결하지 말고 운영진을 부릅니다.
