# 0단계 · 공동 저장소에서 내 앱 옮기기

완성한 앱은 공동 저장소 `02_실전캠프_Day2_실습제출/내폴더/v2/프로젝트/` 안에 있습니다.
이걸 **복사해서 독립된 프로젝트**로 만든 뒤, 1단계에서 내 개인 저장소에 올립니다. 5분.

## AI에게 이렇게 말합니다

> 공동 저장소 `baemin-ops-os-camp` 안의 `02_실전캠프_Day2_실습제출/[1조_이범례_부찌대학]/v2/프로젝트` 폴더를 홈 폴더 아래 `[staff-schedule]` 이라는 새 폴더로 복사해 줘.
> `node_modules`와 `.env.local`은 빼고 복사하고, 복사본에서 `npm install`(또는 필요한 설치)을 해서 실행되는지 확인해 줘.
> 공동 저장소 쪽 폴더는 그대로 두고, 복사본에서만 `git init`을 해 줘.

## 직접 확인하기

1. 새 폴더에서 앱이 실행되는지 봅니다. (AI에게 "실행해서 주소 알려 줘")
2. `.env.local`이 필요한 앱이면 새 폴더에 다시 만듭니다. 값은 Supabase에서 다시 복사합니다.
3. 공동 저장소의 내 폴더는 **지우지 않습니다.** 캠프 기록으로 남깁니다.

## 왜 복사인가

공동 저장소 안에서 바로 개인 저장소로 올리면 두 저장소가 꼬입니다.
복사본은 "내 것"이고, 공동 저장소의 원본은 "캠프 기록"입니다. 둘을 나눠 두면 안전합니다.
