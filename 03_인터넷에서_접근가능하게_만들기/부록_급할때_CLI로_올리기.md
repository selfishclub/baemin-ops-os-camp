# 부록 · 급할 때 AI가 내 폴더에서 바로 Vercel에 올리기

> **정식 방법은 [1단계 개인 저장소 → 3단계 Vercel 연결](README.md)입니다.** 그러면 push만 해도 자동으로 올라갑니다.
> 이 문서는 GitHub 연동이 당장 안 될 때 **임시 주소**를 만드는 방법입니다. 나중에 정식 방법으로 바꾸면 됩니다.

지금 만든 폴더에서 바로 인터넷 주소를 만듭니다. AI가 Vercel 도구(CLI)로 올려 줍니다. 10분.

## 1. Vercel 가입 (사장님이 직접, 1분)

https://vercel.com → **Sign Up** → **Continue with GitHub**. GitHub 접근 허용 화면이 나오면 **Authorize**.
무료(Hobby) 플랜이면 됩니다.

## 2. AI에게 올려 달라고 하기

내 폴더 `v1/프로젝트`가 열린 상태에서:

> 이 프로젝트를 Vercel에 배포해 줘. `npx vercel`을 써서. 로그인하라고 하면 브라우저가 열릴 테니 내가 할게. 프로젝트 이름은 `[staff-schedule]`(영어 소문자), 나머지 설정은 기본값으로. 끝나면 인터넷 주소를 알려 줘.

- 브라우저가 열리면 Vercel에 로그인하고 확인 버튼을 누릅니다. 한 번만 하면 됩니다.
- AI가 `https://staff-schedule-xxxx.vercel.app` 같은 주소를 알려 줍니다. **이 주소를 제출서에 적습니다.**
- 내 폰에서 열어 봅니다. 열리면 성공. 옆 사장님 폰에서도 열리면 진짜 성공.

## 3. Supabase를 쓰는 앱이면 — 열쇠도 넣어 주기

내 컴퓨터의 `.env.local`은 Vercel이 못 봅니다. 같은 값을 Vercel에도 넣습니다.

> Vercel에 넣어야 할 환경변수 이름을 표로 알려 줘. `.env.local` 기준으로. service_role 키는 빼 줘.

Vercel 웹 화면 → 내 프로젝트 → **Settings → Environment Variables** → 이름과 값을 붙여넣고 Save. 그다음:

> 환경변수 넣었어. 다시 배포해 줘.

## 4. 고칠 때마다

이 방식은 내 컴퓨터에서 직접 올리는 것이라, GitHub에 push해도 주소가 저절로 바뀌지 않습니다.
화면을 고쳤으면 AI에게 한마디:

> 다시 배포해 줘.

같은 주소에 새 버전이 올라갑니다. v2도 같은 방식입니다.

## 실패했을 때 (빨간 글씨)

> Vercel 배포가 실패했어. 오류는 이거야: [붙여넣기]. 원인을 찾아 고치고 다시 배포해 줘.

자주 나오는 원인: 환경변수 빠짐, 내 컴퓨터에서는 되는데 빌드 오류, 프로젝트 이름에 한글·대문자.

## 알아 둘 것

- `.vercel` 폴더가 내 폴더 안에 생깁니다. 자동으로 GitHub에는 안 올라갑니다.
- 무료 플랜은 개인·비상업용입니다. 캠프 실습과 시연은 충분합니다.
- 개인 저장소를 만든 뒤 Vercel 프로젝트 **Settings → Git**에서 그 저장소를 연결하면, 같은 주소로 push 자동 배포가 됩니다.
