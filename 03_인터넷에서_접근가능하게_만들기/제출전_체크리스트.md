# 제출 전 체크리스트

제출서를 커밋하기 전에 여섯 개만 확인합니다. AI에게 "이 체크리스트대로 확인해 줘"라고 시켜도 됩니다.

- [ ] **1. 내 GitHub 저장소가 Public인가** — 저장소 페이지 이름 옆에 `Public`이 보인다
- [ ] **2. 비밀이 안 올라갔나** — 저장소에서 `.env`, 키, 비밀번호가 보이지 않는다
- [ ] **3. Vercel 주소가 열리나** — 내 폰에서, 그리고 옆 사람 폰에서 열린다
- [ ] **4. 제출서에 두 링크를 다 적었나** — 개인 저장소 주소 + Vercel 주소 (+ 아티팩트 링크)
- [ ] **5. 스크린샷을 넣었나** — `결과물/` 폴더에 1장 이상
- [ ] **6. 공동 저장소에 push 했나** — GitHub 웹에서 내 폴더를 열어 제출서가 보인다

AI에게 마지막으로:
> 공동 저장소 내 폴더의 `v1/제출서.md`와 `v1/결과물/`이 바뀌었는지 확인하고, "v1 제출"이라고 커밋해서 push해 줘.

여섯 개 다 체크되면 **v1 제출 완료**입니다. 수고하셨습니다.
