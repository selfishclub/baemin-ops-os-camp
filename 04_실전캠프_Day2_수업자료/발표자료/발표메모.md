## 01 · GitHub, 왜 쓰고 어떻게 쓰나 (16장)

| 장 | 말할 것 |
|---|---|
| 1 표지 | "오늘 GitHub 시간엔 딱 하나만 가져가시면 됩니다. 끝낼 때 push." |
| 2 공감 | Day 1에 만든 것 어디 있는지 물어본다. 손 드는 분 없으면 그게 답. |
| 3 한 줄 | 금고 + 노트. "노트"가 핵심. 저장만 아니라 기록. |
| 4 네 가지 | 04 "같이 본다"를 강조. 이 캠프는 같은 주제를 각자 만들고 서로 보는 방식. |
| 5 저장소 둘 | **제일 헷갈리는 부분.** 공동 = 게시판, 개인 = 작업실. 두 번 말한다. |
| 6 그림 | 지금은 왼쪽 두 칸만. Vercel은 v1 만들고 나서. |
| 7 네 단어 | Clone 한 번, 나머지 셋은 매일. Commit ≠ Push. |
| 8 한 줄 | 따라 읽게 한다. "시작할 때 풀, 끝낼 때 커밋 푸시." |
| 9 AI에게 | 명령어 화면 안 보여 줌. 문장 세 개만. 저장소 프롬프트 문서 위치 안내. |
| 10 실습 ① | 이 장에서 카톡 링크 올림. 시범은 실습 시작 때. |
| 11 실습 ② | 실습 ② 때 다시 자세히. 지금은 "v1 만들기 전에 PRD가 올라간다"만. |
| 12 규칙 | 비밀 이야기. "실수로 올리면 지우는 게 아니라 키 재발급." |
| 13~16 | **실습 ①과 이범례 발표가 끝난 뒤** 이어서. 13 사례 연결 → 14 v1/v2 → 15 정리 → 16 실습 ② 시작 |

실습 ①: 화면 공유로 링크 클릭 → 파일명 바꾸기 → 네 줄 → 초록 버튼 두 번 시범 1회. 그 뒤 01 폴더 새로고침해서 파일 늘어나는 걸 보여 준다.

## 02 · 제출은 어디에 무엇을 (7장)

| 장 | 말할 것 |
|---|---|
| 2 폴더 | 폴더는 이미 있다. 채우기만. 내 폴더만. |
| 3 다섯 가지 | **"만든 폴더 통째로 여기 올려요 — 내 폴더 v1/프로젝트"** 두 번. git init 금지, 가져올 땐 .git 빼기. 첫화면.png가 구경하기 표에 올라간다. |
| 4 v1/v2 | 오늘 안에 되는 것만 v1. 욕심내면 아무것도 안 나온다. |
| 5 다섯 마디 | 화면에 띄워 두고 실습. 3번 PRD 없는 분은 "없을 때" 프롬프트. |
| 6 남의 것 | 일찍 끝난 분에게. |

실습 ②: 조별 운영진 배치. clone 실패(로그인) 케이스 먼저 잡는다.

## 03 · v1 만들기 — 내 폴더에, 같이 (8장)

| 장 | 말할 것 |
|---|---|
| 2 오늘 목표 | 전체 PRD → v1·v2 → v1 구현 → push. 여기까지가 오늘. |
| 3 어디에 | **내 폴더 v1/프로젝트.** git init 금지. node_modules·.env는 자동으로 빠진다. 세 번 말한다. |
| 4 같이 | 자주 pull. 남의 앱은 읽고 복사만. 그 폴더는 안 고친다. |
| 5 열쇠 | 공개 저장소다. anon은 공개용, service_role은 절대. |
| 6 네 개 | 제출서 맨 아래 네 칸으로 셀프 체크. |
| 7 완성 후 | 개인 저장소·Vercel은 10/17 이후. 오늘 안 한다. |

v1 만들기 진행: 각자 v1 → 운영진은 조별 순회(내 폴더 밖 파일 생겼는지 확인) → push → 제출서 → 조별 공유.
