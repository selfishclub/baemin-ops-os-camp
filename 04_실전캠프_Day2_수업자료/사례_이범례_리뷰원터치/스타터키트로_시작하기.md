# 스타터 키트로 시작하기 — 리뷰 원터치

**리뷰 관리 도구를 만들 분**은 처음부터 만들지 않고 이 키트에서 시작합니다.
저장소: https://github.com/selfishclub/review-onetouch-starter (공개)

키트는 완성품이 아닙니다. **뼈대 + 안전장치 + AI에게 시킬 순서**입니다.
가게마다 쓰는 플랫폼·컴퓨터·목적이 달라서, 마지막 조립은 내 가게에 맞게 AI와 합니다.

## 들어 있는 것

| 무엇 | 설명 |
|---|---|
| 뼈대 화면 | 가짜 리뷰 5건이 카드로 뜨는 웹페이지 (0단계 완성본) |
| 로그인 | 창을 띄우고 **사람이 직접** 로그인 |
| 수집 도구 | Playwright + 어드민 쓰기 차단(읽기 전용) |
| 답글칸 채우기 | 에이전트 브라우저로 초안을 넣고 **멈춤** |
| 시키는 순서 | 설문 → PRD → 0~5단계 프롬프트 (`docs/PROMPTS.md`) |
| 함정 모음 | 플랫폼마다 실제로 부딪힌 것 (`docs/PITFALLS.md`) |
| AI 규칙 | Claude Code가 이 폴더에서 지킬 선 (`CLAUDE.md`) |

플랫폼별 수집 코드는 **일부러 없습니다.** 어드민 화면이 자주 바뀌어서, AI가 내 가게 것을 그때그때 만듭니다.

## 1. 받기 — AI에게

> https://github.com/selfishclub/review-onetouch-starter 를 홈 폴더에 받아서 열어 줘. 맥이면 바탕화면·문서·다운로드 폴더는 피해 줘.

(맥에서 그 세 폴더 안에 두면 밤 예약 실행이 파일을 못 읽습니다.)

## 2. 첫 프롬프트 — 그대로 붙여넣기

받은 폴더에서 Claude Code를 열고:

```
【 S · 상황 】
- 나는 (가게 이름) 사장이야. 배달앱 · 네이버에 리뷰가 흩어져 있고, 답글은 지금 내가 하나씩 달아.
- 이 폴더는 리뷰 원터치 스타터 키트야. 나는 코딩을 잘 몰라.

【 T · 할 일 】
1. 내 상황을 물어봐 — 한 번에 1~4개, 번호 보기로 고를 수 있게.
   (쓰는 플랫폼 · 맥/윈도우 · 목적 우선순위 · 리뷰 양 · 지금 답글 방식과 걸리는 시간 · 예산)
2. 내 답에 맞게 준비는 네가 알아서 해줘.
   - 빠진 게 있으면 설치하고, 에이전트 브라우저가 필요하면 다운로드 페이지를 열어줘.
   - 쓰는 플랫폼의 로그인 창을 하나씩 띄워줘. 비밀번호는 내가 창에서 입력할게.
   - 가게 번호 같은 설정은 로그인된 화면에서 네가 찾아서 채워줘.
3. 내 말투(최근 답글 3개)와 절대 자동화하면 안 되는 것까지 더 물어본 뒤, 기획서(PRD)를 써줘.

【 I · 의도 】
- 모은 고객이 떠나지 않게 빠짐없이 답하고, 리뷰를 데이터로 쓰고, 관리 시간을 줄이려는 거야.
- 가게마다 상황이 달라서, 만들기 전에 내 상황에 맞는 범위와 순서부터 정하고 싶어.

【 C · 주의할 점 】
- 아직 구현하지 마. 이번엔 준비와 PRD까지만.
- 아이디 · 비밀번호는 묻지도, 입력하지도 마. 로그인은 내가 창에서 직접 해.
- 로그인 창은 한 번에 하나씩. "보호조치" · "비정상 동작" 이 뜨면 바로 멈추고 알려줘.
- 답글 등록 버튼은 내가 누른다. PRD 의 "안 만들 것"에 넣어줘.
- 모르는 건 지어내지 말고 "확인 필요"로. 돈이 드는 건 먼저 물어봐.
```

그러면 AI가 **묻고 → 준비하고 → 로그인 창 띄우고 → PRD**까지 씁니다. 사장님은 고르고, 창에서 비밀번호만 칩니다.

## 3. 그 다음 — 한 단계씩

키트 안의 `docs/PROMPTS.md`에 1단계부터 5단계 프롬프트가 있습니다. PRD대로 한 단계씩 시킵니다.

- **오늘 v1**: 0단계(뼈대 화면) + 1~2단계(내 플랫폼 하나 수집)까지가 현실적입니다.
- **v2 (10/2)**: 답글 초안 생성, 답글칸 채우기, 인사이트

## 넘지 않는 선 — 키트가 이미 막아 둔 것

| 선 | 이유 |
|---|---|
| 등록 버튼은 사람이 누른다 | 올라가면 손님에게 바로 보이고, 못 고치는 플랫폼도 있다 |
| 로그인은 사람이 창에서 | 코드가 아이디를 넣으면 봇으로 막힌다 |
| 수집은 읽기 전용 | 조회 아닌 요청은 네트워크에서 막는다 |
| 제한 문구가 뜨면 멈춘다 | 무시하고 다시 하면 계정이 잠긴다 |
| 한 건씩, 간격을 두고 | 연달아 돌리면 막힌다 |
| 비밀은 올리지 않는다 | `.env.local`, `data/`(세션), `docs/PRD.md`는 `.gitignore`에 있다 |

## 내 가게에 맞게 고치는 예

- 별점 1~2점 리뷰는 아침까지 안 기다리고 바로 카톡 알림
- 월요일 아침 주간 리포트 한 장
- 신메뉴 리뷰만 따로 모아 보기
- "품절 사과는 이렇게", "재방문 손님은 이렇게" 우리 가게 답글 규칙

필요 없는 기능은 안 붙이면 됩니다.

## 이 키트를 내 저장소로 올릴 때

키트를 고쳐서 **내 개인 저장소(Public)**에 올리기 전에 AI에게:
> `git status`로 `.env.local`, `data/`, `docs/PRD.md`가 빠져 있는지 확인해 줘. 로그인 세션 파일은 절대 올리면 안 돼.
