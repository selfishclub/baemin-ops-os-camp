# 피드백 주고받기 — 10/2 점검 시간에

10/2 온라인 중간 점검 시간에 **다른 사장님 도구를 직접 써 보고 피드백을 남깁니다.** 서로 써 보는 건 이날 한 번입니다. 10/2부터 10/14까지는 받은 피드백을 반영하고 내 가게에서 더 써 보며 최종본을 만드는 기간입니다.
피드백은 **캠프에서 같이 쓰는 공동 스프레드시트**에 적습니다. 링크는 운영진이 단톡방에 올려 둔 것을 씁니다. GitHub 파일을 고치는 게 아니라서 남의 폴더를 건드릴 일이 없습니다.

## 10/2 순서

1. 한 사람씩 5분 — Vercel 주소로 **결과물 시연** + `중간점검_1002.md`로 **만든 과정** 공유
2. **개인 저장소로 흩어지기** — 내 폴더 앱을 옆 폴더로 복사 → 개인 저장소(Public) → Vercel 연결 → 제출서에 두 링크 ([03 폴더](../03_인터넷에서_접근가능하게_만들기/README.md))
3. 그 Vercel 주소로 서로 써 보고 **스프레드시트에 피드백 적기** (아래)

## 얼마나

- 점검 시간 안에 같은 조 사장님 도구 **2개 이상**. 시간이 남으면 다른 조도.
- 한 줄에 도구 하나. 길게 안 써도 됩니다. 칸마다 한두 문장이면 충분합니다.
- 점검 전에 내 Vercel 주소가 열리는지 한 번 확인해 둡니다.

## 써 보는 방법 — Vercel 주소로

1. [구경하기](../02_실전캠프_Day2_실습제출/README.md#구경하기) 표에서 사장님을 고릅니다.
2. 그 칸의 **열어 보기(Vercel 주소)**를 누릅니다. 설치도 실행도 없습니다. 폰으로 열어도 됩니다.
3. 그분 `중간점검_1002.md` 5번 "봐 줬으면 하는 것"을 먼저 읽습니다.
4. 실제로 눌러 봅니다. 폰과 컴퓨터 둘 다 보면 좋습니다.

폴더(코드)는 "어떻게 만들었나" 힌트용입니다. 써 보는 데는 열 필요가 없습니다.

## 피드백 적는 방법 — 스프레드시트에 한 줄

공동 스프레드시트의 **피드백 칸**에 도구 하나당 한 줄씩 적습니다.

| 칸 | 적는 것 | 예시 |
|---|---|---|
| 남긴 사람 | 내 가게 · 이름 | 부찌대학 · 이범례 |
| 써 본 도구 | 가게 이름 · 도구 이름 | 빈숲카페 · 레시피북 |
| 어떤 상황으로 써 봤나 | 무엇을 넣고 눌러 봤는지 | 신메뉴 레시피 하나 등록해 봄 |
| 좋았던 것 | 지켜야 할 점 | 사진이 크게 나와 주방에서 보기 편함 |
| 불편했던 것 | **상황과 함께** | 재료가 10개 넘으니 화면이 잘림 |
| 있었으면 하는 것 | 하나만 | 재료 원가가 같이 나오면 좋겠음 |

## 받은 피드백 보는 방법

- 스프레드시트에서 **"써 본 도구"가 내 가게인 줄**을 찾습니다. 필터를 쓰면 편합니다.
- 고맙다는 답이나 질문은 그 줄 옆 칸이나 단톡방에 남깁니다.
- 점검 당일 `중간점검_1002.md` 6번에 **받은 피드백과 내가 남긴 피드백**을 옮겨 적고, 10/14까지 반영해 `피드백_반영_1014.md`에 정리합니다.

## 좋은 피드백 세 가지

1. **상황을 적는다.** "불편해요"보다 "근무표에 알바 셋을 넣으니 화면이 잘려요".
2. **좋은 것도 적는다.** 그게 지켜야 할 것을 알려 줍니다.
3. **바라는 것 하나.** "이게 있으면 우리 가게에서도 쓸 것 같아요".

스프레드시트에는 실제 직원·손님 이름, 비밀번호, 매출 숫자를 적지 않습니다.
