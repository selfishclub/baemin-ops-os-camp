## 9/17 ~ 10/2 — v1 써 보고, v2 만들기

- v1을 실제로 쓸 때마다 내 폴더 `v1/사용메모.md`에 한 줄.
- `v1/프로젝트`를 `v2/프로젝트`로 복사해 v2 기능(API·외부 데이터 등) 추가. v1이 일찍 끝났으면 9/17 당일에 시작해도 됩니다.

## 10/2 (금) — v2 1차 마감 + 온라인 중간 점검 + 서로 피드백

- **마감:** `v2/프로젝트/`, `v2/PRD.md`, `v2/제출서.md`(Vercel 주소 갱신), `v2/결과물/첫화면.png` push
- **전날까지** `중간점검_1002.md`를 채우고 push. 점검 때 그 파일을 보며 v2 상태·막힌 것·봐 줬으면 하는 것 확인
- **점검 시간에** 같은 조 사장님 도구 2개 이상 써 보고 GitHub Issue로 쪽지 → [피드백 주고받기](피드백_주고받기.md). 서로 써 보는 건 이날만.
