# 사전 과제 안내

캠프 전에 세 가지를 합니다. 아직 안 했으면 **지금** 하면 됩니다.

## 1. GitHub 가입 + 이메일 제출

- https://github.com 에서 가입합니다. (무료)
- 가입한 **이메일 주소**를 체크인 시트에 적습니다. 운영진이 그 이메일로 이 저장소에 초대합니다.
- 이메일을 모르겠으면 GitHub 오른쪽 위 프로필 → **Settings → Emails**에서 확인. 또는 Claude에게 "내 GitHub 이메일 확인하는 법 알려 줘".
- 초대 메일이 오면 **View invitation → Accept**.

## 2. 과제 6 — 운영 OS 기획안(PRD)을 MD 파일로

- 내 가게 운영에서 힘든 일 하나를 골라 기획안을 씁니다.
- 양식: [PRD 양식](../02_실전캠프_Day2_실습제출/_양식/PRD.md)
- AI에게:
  > 내가 하는 일은 [가게 종류]인데 매번 [힘든 일]이 힘들어. 이 양식대로 기획안을 써 줘. 오늘 안에 만들 수 있는 v1과 나중에 더할 v2를 나눠 줘. 질문은 한 번에 하나씩.
- 결과를 `PRD.md` 파일로 저장합니다. 캠프 당일 내 폴더 `v1/PRD.md`에 옮깁니다.

## 3. 과제 7 — PRD를 Claude 아티팩트로 웹 게시

- Claude에게:
  > 이 PRD를 누구나 볼 수 있는 웹페이지(아티팩트)로 만들어 줘. 사장님이 보기 쉽게 표와 그림으로.
- 만들어진 아티팩트를 **게시(Publish)**하고 링크를 복사합니다.
- 링크를 체크인 시트와 캠프 당일 `v1/제출서.md`의 "PRD 아티팩트 링크" 칸에 적습니다.

## 왜 코드가 아니라 PRD인가

참가자마다 AI 사용 수준이 달라서, 미리 만들어 오면 편차가 큽니다.
대신 **무엇을 만들지**를 문서로 정해 오면 당일에 모두 같은 출발선에서 시작합니다.
