# 가영이네 외국인 메뉴 선택 도우미 — PRD v2

작성: 박가영 · 2026-10-02 KST · 실제 구현 범위 기준

## 문제와 목표
외국인 고객이 메뉴명만으로 음식과 재료·맵기를 이해하기 어렵고, 직원의 반복 설명이 필요하다. 사진·가격·확인된 식재료 아이콘과 한국어 메뉴명 병기로 고객이 기기 주문 전에 메뉴를 고를 수 있도록 돕는다.

## 사용자와 핵심 흐름
영어·일본어·중국어(간체) 사용 고객이 언어 선택 → 메뉴 사진/가격/설명 확인 → 맵기와 나라별 추천으로 찾기 → 상세 정보 또는 직원에게 보여주기 → 매장 주문 기기에서 주문한다.

## 확정된 v2 범위
- 실제 메뉴 32개, 원본 사진 18장. M008 오뎅만 떡볶이와 M033 재주문100% 단무지는 제외.
- 떡볶이·라볶이 / 튀김 / 김밥·식사 / 순대 / 사이드 / 빙수 / 음료 순서.
- 사장님 추천: 떡볶이, 라볶이, 참치김밥, 가영이네 김밥, 김치볶음밥, 갈비만두, 떡꼬치. 메뉴명 옆 오렌지 별과 각 언어 추천 문구.
- 메인 오렌지 #FF6600, 귀엽고 단순한 식재료 아이콘, 공식 원본 로고, 원본 비율을 유지한 메뉴 사진.
- WithGreen/SORENA의 빠른 정보 파악 방식을 참고한 큰 사진/가격/설명/재료 구조. PC 좌측 카테고리, 모바일 접는 카테고리와 세로 배열.
- 맵지 않음·미확인에는 고추 없음, 약간 매움 1개, 매움 2개. 맵기 선택은 정확히 해당 단계로 찾는다.
- 나라별 추천과 맵기의 교집합, 결과 수, 빈 결과 안내와 초기화. 언어 변경 시 필터 유지.
- 메뉴 / 이용 방법 / 매장 정보의 세 영역. 결제·셀프 서비스·식기 반납·영업시간 안내.

## 데이터 규칙
Google Sheets 입력 정보를 수동 검토해 dist/data.js에 반영한 스냅샷이다. 자동 동기화는 없다.
재료는 contains / absent_verified / unknown으로 구분한다. 전체 레시피에서 미포함이 검증된 메뉴가 없어 재료 제외 버튼 11개는 비활성화하고 이유를 표시한다. 소스/가공품의 성분이나 교차 접촉을 추정하지 않는다. 아이콘 부재는 미포함의 증거가 아니다.

## 제외 및 후속 범위
주문·결제·장바구니·고객정보 수집·Supabase·매출 대시보드·실시간 품절 관리·시트 자동 동기화는 이번 버전에 없다. 최초 7개 언어 계획은 사용자 요청에 따라 3개 언어로 좁혔다.
미등록 사진 14장, M018/M019 동일 사진, 전체 레시피 확인, 원어민 검수와 실매장 사용 검증은 후속 항목이다.
