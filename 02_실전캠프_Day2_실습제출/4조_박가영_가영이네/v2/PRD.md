# 기획안(PRD) — Gayoungene Menu Finder · v2

> 초안 — v1을 써 본 뒤 고칩니다

- 가게 / 이름: 가영이네 / 박가영
- 조 주제: AI면접관 (개인 주제: 외국인 손님용 다국어 메뉴 선택 도우미)
- 이 버전의 목표 한 줄: **사장님이** **메뉴·번역·사진·매장 안내가 바뀔 때** **시트에 써서 점검하고 게시하는 일을**, **외국인 손님이** **자기 언어로 검수된 메뉴 정보를 보는 일을** 편하게 처리하는 도구

## 1. 무엇을 왜 만들고 싶나요?

v1은 영어 기본·샘플 데이터·JSON 직접 교체로 돌아갑니다. 실제 손님에게 쓰려면 ① 실제 메뉴 값을 한 번에 올리고 ② 6개 언어를 검수하고 ③ 사진을 넣고 ④ 품절·가격 변경을 코드 없이 반영해야 합니다. (v1 사용메모를 보고 이 칸을 다시 씁니다)

## 2. 누가 언제 쓰나요?

- **사장:** 메뉴·가격·재료·번역·매장 안내가 바뀔 때 구글 시트에 쓰고, 미리보기 확인 후 게시. 품절이면 켜고 끔.
- **손님:** v1과 같음. 자기 언어(7개)로 검수된 정보를 봄. 방문 전엔 구글 비즈니스 링크로, 매장에선 QR로.

## 3. 지금은 어떻게 하고 있나요?

(v1을 써 본 뒤) 값을 바꾸려면 JSON 파일을 직접 고쳐 다시 올려야 함. 번역은 초안 표시. 사진은 회색.

## 4. 도구를 쓰면 어떤 일이 달라지나요?

| | 넣는 것 | 나오는 것 |
|---|---|---|
| 1 | 사장님이 구글 시트에 메뉴·매장·추천·번역 입력 | 점검 결과: 번호 중복·빈 값·미확인 재료·연결 안 된 추천 |
| 2 | 언어별 미리보기 확인 → 게시 | 사이트 데이터 교체, 직전 버전 보관 |
| 3 | 품절 켜기 | 목록엔 품절 표시, 추천에서 빠짐 |

## 5. v2에서 만들 것 — 10/17까지 (API 연동·외부 데이터 등 v1에서 미룬 것)

**꼭 할 것**
- 기능 1: **구글 시트 → 점검 → 미리보기 → 게시** — 시트를 읽어 JSON으로 만들고, 번호 중복·빈 값·`draft`·연결 안 된 추천을 잡아 보여 준 뒤 게시. 직전 버전 복구.
- 기능 2: **실제 데이터·사진 채우기 + 언어 검수 흐름** — 사장님이 한 번에 올린 실제 메뉴(20~30개)·사진·매장 안내를 게시. 언어별 `draft/approved` 상태를 두고 검수 끝난 언어만 "초안" 표시를 뗌.

**여유 있으면**
- 품절 켜고 끄기 (사장님 로그인 화면 하나)
- 나라별 손님 추천 — 베트남 순대·몽골 오뎅·일본 갈비만두·김밥 관찰을 실제 메뉴에 연결. "가영이네를 찾은 ○○ 손님들이 좋아했던 메뉴" 문구. 조건 필터 적용.
- 구글 비즈니스에 링크 등록, QR 인쇄물
- 번역 초안 자동 생성 (사람 검수 전제)

**준비물**
- 구글 시트 항목 보완: 메뉴 번호·재료 3상태·맵기·공개 상태·언어별 검수 상태·추천 연결
- 시트 읽기 권한 (서비스 계정 또는 공개 읽기) — 키는 `.env`에만
- 6개 언어 검수자 (직접 못 읽는 언어)
- 메뉴 사진, 키오스크·테이블오더 번호 붙이기 (매장에서 사람이)
- 공개 주소(Vercel) — 완성 후 개인 저장소로 옮긴 뒤

- **이번에 하지 않을 것:** 관리자 화면에서 직접 편집(시트로 충분한지 먼저 봄) · 온라인 주문·결제 · 실시간 AI 추천 · 배민 리뷰 연동

## 6. 완성됐다는 걸 어떻게 확인하나요?

- 시연할 예시 입력: 시트에서 메뉴 하나의 가격을 바꾸고 다른 메뉴를 `sold_out`으로 → 반영 실행
- 기대하는 결과: 점검 화면에 변경 2건 표시 → 게시 → 사이트에서 가격 바뀜, 품절 메뉴는 목록에 품절 표시·추천에서 빠짐. 직전 버전으로 되돌리기 가능
- 잘못 입력했을 때: 번호 중복·빈 이름·`unknown`인데 `approved` → 게시 막고 어느 줄인지 표시. 시트 저장만으로는 공개되지 않음
- 다시 열었을 때 남아 있어야 할 것: 게시된 버전과 직전 버전. 검수 상태.

- 필요한 데이터나 외부 연결: 배민 리뷰(외국인 리뷰 모아 보기)
- 사람이 직접 판단·확인해야 할 부분: v1 8번과 같음

- 검수 안 된 번역을 "완료"로 표시하지 않음.
