# 가영이네 메뉴 사이트 AI 작업 규칙

AGENTS.md의 현재 사용자 승인 범위와 디자인·검증 지침을 읽고 적용한다.

- 가격·성분·맵기는 사용자 확인 데이터만 사용한다. 추정값을 운영 데이터로 쓰지 않는다.
- 미확인 성분은 unknown이다. 아이콘 부재를 성분 미포함으로 해석하지 않는다.
- 영어·일본어·중국어(간체) 3개 언어와 한국어 메뉴명 병기를 유지한다.
- 공식 로고 원본, 오렌지 #FF6600, 사진 원본 비율을 보존한다.
- 실제 검증·배포·매장 사용 여부를 과장하지 않는다.
- API 키·환경변수·고객정보는 커밋하지 않는다.
- 원격 최신 상태 확인 → 수정 → npm test → 변경/민감정보 검토 → 커밋 → 승인된 대상에 일반 push 순서로 작업한다.
- 다른 수강생 폴더, 이전 v1 제출물, 별도 선결제/포트폴리오 프로젝트를 수정하지 않는다.
