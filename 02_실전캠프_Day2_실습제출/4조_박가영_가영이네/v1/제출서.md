# v1 제출서 — 가영이네 / 박가영

## 만든 것

- 도구 이름: Gayoungene Menu Finder
- 한 줄 설명: 외국인 손님이 피하는 재료·맵기·음식 종류를 고르면 맞는 메뉴만 보여 주고, 메뉴 번호·한국어 이름으로 키오스크·테이블오더에서 찾게 돕는 사이트
- 코드 위치: `v1/프로젝트/`
- 실행 방법:
  1. `v1/프로젝트/index.html`을 브라우저로 엽니다 (더블클릭). 설치·서버 없음.
  2. 언어를 고르고 (기본 English), 피하는 재료·맵기·종류를 누르면 목록이 바뀝니다.
  3. 카드 → 상세 → "Find this dish in store"로 번호·한국어 이름을 크게 봅니다.
- 스크린샷: `결과물/첫화면.png` (추가 예정) · 참고: GPT로 만든 MVP 화면 https://gayoungene-menu-finder.ghghgh0704.chatgpt.site/
- PRD 아티팩트 링크 (사전 과제로 만든 웹페이지, 있으면): 원본 PRD는 `../PRD_원본_GPT_v1.2.md`

## 이번 버전에서 되는 것

- 조건 필터: 피하는 재료 6종(여러 개) · 맵기 상한 5단계 · 음식 종류 4종. 첫 화면에 펼쳐져 있고 누르면 바로 반영
- 재료 3상태(포함 / 없음 확인됨 / 미확인) 판정. 미확인은 결과에서 빠지고 안내, 고르지 않은 재료의 미확인은 영향 없음
- 조건 모순(치킨 종류 + 닭 제외) → 결과 없음 안내, 조건을 임의로 풀지 않음
- 메뉴 상세: 재료별 상태, 맵기, 충족한 조건, 알러지 면책 문구
- 매장에서 찾기: 번호·한국어 이름 크게 + "키오스크·테이블오더에서 주문·결제" 안내. 주문 버튼 없음
- 사장님 추천 (조건 필터가 추천에도 적용), 나라별 추천은 자리만
- How to order · Visit 화면 (값은 "To be confirmed")
- 언어 7개 선택. 영어 기본, 영어 외는 "Draft translations" 띠 + 없는 문구는 영어로 대체. 언어를 바꿔도 조건 유지
- 상세에서 뒤로 가면 조건·스크롤 위치 유지. 잘못된 주소는 목록으로 안내
- 데이터는 `data/*.js` 4개 파일에 분리. 사장님이 값을 채우면 화면이 바뀜 (채우는 법: `프로젝트/README.md`)
- 320·375·430px 폭에서 가로 스크롤 없음, 버튼 44px 이상
