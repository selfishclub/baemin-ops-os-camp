# v1 만들 때 AI에게 한 말 — 기록

다른 사장님이 "어떻게 만들었나" 볼 수 있게 남깁니다. 2026-09-17, Claude Code(데스크톱 앱) 사용.

## 1. 기획 (baemin-ops-prd 스킬)

- `/baemin-ops-prd` 실행 → 사전 과제 v1 PRD를 읽고 PRD_전체 초안을 채움
- GPT에서 만든 PRD v1.2 파일과 MVP 사이트 링크를 붙여 넣고: "이거 내가 기획한 사이트 prd인데 gpt에서 작업했고 첫번째 버전 mvp사이트도 이미 개발한 상태야. 수정보완해야할 점이 있다면 ask your question 통해서"
- AI가 MVP 사이트를 폰 화면으로 직접 눌러 보고, 캠프 v1 PRD(질문 3개 추천형)와 GPT PRD(조건 필터형)가 다른 제품임을 발견 → "GPT PRD + MVP가 기준"으로 결정
- 인터뷰 답: 매장 1곳·어머니와 둘 / 키오스크+테이블오더 둘 다 / MVP 코드는 없음 / 영어권 손님이 제일 많음 / 주 3~5팀·팀당 3~5분 / 전체 20~30개 중 v1은 10개 / 사진은 나중 / "모든 데이터 값은 나중에 한 번에 업로드"
- "우리 4조는 조별 주제가 없고 개인주제로 진행할거야"
- GPT PRD 원본을 별도 파일(`PRD_원본_GPT_v1.2.md`)로 두고 v1/PRD.md에서 참조하기로 함

## 2. 구현

- "만든 prd를 바탕으로 화면 구현하고싶어" → AI가 화면 구성(S01~S06)을 글로 먼저 보여 줌 → "이대로 만들자"
- 기술: 설치 없는 정적 웹(HTML·CSS·JS). 처음엔 JSON + ES module로 만들었다가, 이 컴퓨터에 Python·Node가 없어 **index.html 더블클릭으로 열리도록** 데이터를 `data/*.js`로 바꿈
- 확인: PRD 6번 시나리오(Pork 제외 + Not spicy → 2개, 모순 조건 → 결과 없음, 상세→매장 찾기→뒤로, 잘못된 주소, 언어 전환, 320px 폭)를 AI가 브라우저에서 직접 눌러 확인

## 3. 데이터 채울 때 (예정)

- "store.js에 주소·영업시간·주문 순서를 넣고 confirmed를 true로"
