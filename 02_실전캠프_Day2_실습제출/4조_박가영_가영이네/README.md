## 이 폴더는 어떻게 쓰나

```
4조_박가영_가영이네/
├── README.md        ← 이 파일 (체크리스트)
├── PRD_전체.md      ← 전체 기획안. 여기서 v1·v2로 나눕니다
├── 중간점검_1002.md ← 10/2 v2 1차 마감·점검용
├── 최종제출_1010.md ← 10/10 최종 제출용
(10/2부터 코드는 내 개인 저장소에. 여기 프로젝트/ 폴더는 캠프 기록)
├── v1/  PRD.md · 제출서.md · 사용메모.md · 결과물/ · 프로젝트/  ← 만든 폴더 통째로
└── v2/  PRD.md · 제출서.md · 결과물/ · 프로젝트/
```
