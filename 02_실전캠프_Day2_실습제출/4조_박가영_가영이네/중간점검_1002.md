## 2. 만든 과정
기존 7개 언어 계획을 3개로 줄이고 실제 시트 데이터와 사진 중심으로 바꾸었다.
1. 사장님이 시트와 메뉴 포함/제외·제공 방식·추천 목록을 확인했다.
2. AI가 다국어 메뉴 UI와 필터를 구현하고 사장님 피드백에 따라 정보 순서와 아이콘을 수정했다.
3. 데이터 11개 검사와 DOM 상호작용 검사를 실행하고, 최종 소스·문서·검수 한계를 정리했다.

실제로 사용한 요청 예시:
> 언어는 우선 영어, 일본어, 중국어 이 3개만 진행해보자.

> 외국인들에게 순대는 인기가 없는편이라 3번에 김밥 식사류 넣어줘.

> 추천 메뉴는 떡볶이, 라볶이, 참치김밥, 가영이네 김밥, 김치볶음밥, 갈비만두, 떡꼬치

막힌 점: 전체 원재료가 확인되지 않아 재료 제외 기능을 안전하게 제공할 수 없었다. 해당 버튼을 비활성화하고 확인된 포함 아이콘만 제공했다. 미리보기 접근은 제한됐으나, 승인된 브라우저 작업으로 GitHub 연결과 Vercel 배포를 완료하고 실제 공개 사이트를 확인했다.

## 3. 사용해본 결과
현재 확인 가능한 사용은 사장님 리뷰, AI의 자동 코드/DOM 시뮬레이션과 실제 공개 사이트 PC 브라우저 검증이다. 실제 외국인 고객 사용 횟수와 효과는 기록하지 않았으므로 사용 완료나 시간 절감 수치를 제시하지 않는다.
사장님 피드백으로 추천 아이콘의 어색함과 고추/Not spicy의 혼동을 발견했다. 실제 직원 설명 시간·고객 메뉴 선택 시간을 측정하는 것은 다음 단계다.
수동 작업: 시트 변경 검토와 데이터 반영, 사진 추가, 번역 확인, 배포.

## 4. 아직 막힌 부분
- Vercel 연결 문제는 GitHub 본인 인증 및 저장소 권한 승인 후 해결했다. 기존 주소에서 최신 버전을 확인했다.
- 실제 PC 화면과 첫화면 PNG는 확보했다. 실제 휴대폰 화면 확인은 남아 있다.
- 사진 14장 없음, 가영이김밥/참치김밥 원본 사진 중복, 원어민 번역 및 전체 레시피 확인 대기.
