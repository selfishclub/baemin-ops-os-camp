- 가게 / 이름: 가영이네 / 박가영
- 조 주제: AI면접관 (개인 주제: 외국인 손님용 다국어 메뉴 선택 도우미)
- 한 줄 목표: **외국인 손님이** **키오스크·테이블오더 앞에서 뭘 시킬지 모르는 순간에** **피하는 재료·맵기에 맞는 메뉴를 고르고 번호로 찾아 주문하는 일을** 편하게 처리하는 도구
- 마지막 수정: 2026-09-17
- 원본 기획: GPT로 작성한 [`PRD_원본_GPT_v1.2.md`](PRD_원본_GPT_v1.2.md) + MVP 사이트(chatgpt.site, 코드 없음). 이 문서는 그것을 캠프 양식으로 옮기고 v1/v2로 나눈 것. 세부 요구사항(화면·문구·필터 규칙·데이터 구조·검수)은 원본이 기준

## 1. 배경 — 최근 실제로 있었던 한 장면

- 장면: 외국인 손님이 키오스크 앞에서 한참 서 있음. "이거 고기 들어가요? 맵나요?"를 몸짓·번역기로 물어봄. 직원이 답하고, 육수·소스 재료는 주방에 확인하러 갔다 옴. 매운 걸 못 먹는 손님이 떡볶이를 시켰다가 거의 남긴 적 있음. 순대·어묵은 뭔지 몰라서 주문이 안 들어옴. 겨우 골라도 키오스크 한글 화면에서 그 메뉴를 다시 못 찾아 직원이 옆에서 눌러 줌.
- 얼마나 자주: 외국인 손님 주 3~5팀 (영어권이 제일 많음)
- 한 번에 걸리는 시간: 팀당 설명 3~5분 (바쁜 시간엔 다른 손님 응대가 밀림)
- 실수·빠뜨림: 맵기·재료 설명이 안 통해 잘못 시키고 남김 · 육수·소스 속 재료(돼지고기 등)를 겉만 보고 "없다"고 답할 위험

## 3. 흐름 — 지금 vs 도구를 쓰면

| 단계 | 지금 (쓰는 앱·파일) | 도구를 쓰면 |
|---|---|---|
| 1 | 키오스크 한글 화면·종이 메뉴판을 봄 | 사이트 열면 바로 "피하는 재료·맵기·종류" 선택이 펼쳐져 있음 |
| 2 | 손짓·번역기 앱으로 재료·맵기를 물음 | 조건 고르면 맞는 메뉴만 남고, 미확인 메뉴는 빠졌다고 안내 |
| 3 | 직원이 주방에 재료 확인하고 다시 나와 답함 | 상세에서 재료별 "포함 / 없음 확인됨 / 미확인"과 맵기를 봄 |
| 4 | 직원이 키오스크에서 대신 눌러 줌 | "매장에서 찾기" 화면의 번호·사진·한국어 이름으로 키오스크·테이블오더에서 직접 찾아 주문 |

## 7. 예외 — 잘못 넣거나 평소와 다를 때

- 조건이 서로 모순(음식 종류 "치킨" + 피하는 재료 "닭")이면 → 임의로 풀지 않고 "조건에 맞는 메뉴가 없어요" + 조건 고치기·전체 보기 링크
- 고른 재료가 `미확인`인 메뉴는 → 조건 결과에서 빠지고, "미확인이라 빠진 메뉴가 있어요" 안내. 고르지 않은 재료의 미확인은 영향 없음
- 맵기 "안 매움"을 고르면 → 맵기 0만. 미확인(null)은 빠짐
- 번역이 빈 칸이면 → 영어로 대체하고 "초안" 표시. 빈 문구·코드 이름을 그대로 보이지 않음
- 데이터 파일에 번호 중복·`draft`·`inactive`가 있으면 → 화면에 안 보임 (v2: 게시 전 점검에서 잡음)
- 잘못된 메뉴 주소로 들어오면 → 목록으로 돌아가는 안내
- 상세에서 뒤로 가면 → 고른 조건·목록 위치 유지. 언어를 바꿔도 조건 유지

## 8. 사람이 꼭 직접 해야 하는 것 (자동화 금지)

- 알러지·안전 판정 — 화면은 "이 재료가 포함/미포함 확인됨"까지. "안전합니다"라고 단정하지 않음. 교차 접촉은 직원에게 묻도록 안내
- 재료 `없음 확인됨` 표시 — 육수·소스·가공 재료까지 사람이 확인한 뒤에만
- 번역 문구 확정 — 검수 전 언어는 "초안" 표시 유지
- 실제 주문·결제 — 키오스크·테이블오더에서. 사이트는 아무것도 보내지 않음
- 가격·품절·메뉴 게시 — 사장님이 확인하고 반영
- 손님 개인정보·국적 추정 — 저장·추정하지 않음. 언어 선택 ≠ 국적

## 9. 성공 기준 — 숫자로

- 지금: 외국인 주 3~5팀 × 설명 3~5분 = 주 10~25분. 잘못 시켜 남기는 일 가끔
- 목표: 손님이 직원 도움 없이 조건 고르고 번호로 키오스크에서 찾음. 재료·맵기 반복 설명 0~1분/팀. 맵기 때문에 남기는 일 0건
- 시연할 예시 입력 → 기대하는 결과: English → 피하는 재료 "Pork" → 맵기 "Not spicy" → 돼지고기 `없음 확인됨` + 맵기 0인 메뉴만 남고 개수가 맞음. 미확인 메뉴 빠짐 안내. 카드 → 상세 → "Find this dish in store" → 번호·한국어 이름 큰 화면

| 구글 시트 | 메뉴·매장·추천·번역 원본 읽기 → 점검 → 게시 | 시트 항목 보완(번호·재료 3상태·승인 상태), 읽기 권한 | [v2] |
| 구글 비즈니스 | 프로필에 사이트 링크 | 공개 주소(Vercel) | [v2] |
| 번역 초안 자동 생성 | 새 메뉴 설명 초안 (사람이 검수) | 번역 API 키 | [v2] 여유 있으면 |
| 배민 리뷰 | 외국인 리뷰 모아 보기 | 배민 데이터 접근 방법 확인 | [나중] |

## 11. 아직 정하지 못한 것

- `[가정]` 사장님 추천 메뉴 목록과 이유 — 데이터 업로드 때 같이
- 나라별 추천을 v1에 넣을지 — v2로 둠. 관찰(베트남 순대·몽골 오뎅·일본 갈비만두·김밥)은 초안으로 보관
- How to order·Visit의 실제 값(주문 순서·주소·영업시간) — 데이터 업로드 때
- 테이블오더에서 메뉴 이름·사진·번호를 바꿀 수 있는지 (키오스크는 가능 확인됨)
- 첫 수록 메뉴 10개를 무엇으로 할지 — 외국인이 자주 묻는 것 위주, 사장님이 정함
- 몽골어 키릴·중국어 간체 표기 — 검수 때 확인
- 조 주제(AI면접관)와 별개인 개별 주제로 진행함 — 운영진 확인 필요하면 알림
