# 통장 내역 자동으로 가져오기 — 숯불에닭 강상구 사장님용

> 2026-10-06 기준. 10/2 중간 점검 때 드린 말씀을 웹에서 다시 확인하고, 사장님 도구(Windows)에 맞춰 정리했습니다.
> 사장님 질문: "은행 엑셀을 받아 앱에 넣고 있는데, 자동화하려니 팝빌 같은 유료 API(월정액)뿐인가요?"

## 한 줄 답

**팝빌만 있는 건 아닙니다. 그리고 팝빌 월정액도 생각보다 쌉니다(계좌조회 월 5,000원부터).**
길은 세 가지이고, 아래 순서로 해 보시길 권합니다.

| | 방법 | 돈 | 사장님이 하는 일 | 추천 |
|---|---|---|---|---|
| A | **브라우저 에이전트**가 은행 화면에서 엑셀 받기까지 대신 클릭 | 0원~ | 로그인만 직접 | ★ 먼저 10분 테스트 |
| B | **팝빌 계좌조회 API** — 은행 대신 팝빌이 거래내역을 보내 줌 | 월 5,000원~ | 최초 1회 계좌 등록 | A가 막히면 |
| C | 지금처럼 손으로 받기 + 앱의 "어디까지 받았나" | 0원 | 로그인·기간 선택·다운로드 | 이미 하고 계심 |

## 1. 사실 점검 — 10/2에 드린 말씀, 그대로 해도 되나

| # | 드린 말씀 | 확인 결과 | 판정 |
|---|---|---|---|
| 1 | "카드사 웹 내역을 자동으로 가져올 수 있다(리뷰 수집과 비슷)" | 기술적으로 가능. 단 은행·카드사는 공동인증서·간편인증·OTP가 필요하므로 **로그인은 사람이 직접** 해야 하고, 은행 보안프로그램 때문에 자동화 브라우저에서 화면이 안 열리는 곳이 있을 수 있음. 은행·카드사 약관의 자동화 금지 여부는 이번에 확인하지 못함 | △ 방향은 맞음, **먼저 테스트** |
| 2 | "체크카드는 통장 내역으로 증빙" | 이미 사장님 앱이 그렇게 함(체크카드 74건 중 영수증과 맞음 31·필요 없음 18·취소 3) | ○ |

| 5 | "Aside, Playwright 같은 에이전트 브라우징 서비스로 가능" | 아래 표 참고. **Aside는 Windows에서 지금 설치되는지 불확실** | △ |
| 6 | (오늘 확인) 사장님 우려 "팝빌은 월정액 결제" | 팝빌 계좌조회 정액제는 **월 5,000원**(공식 요금 페이지). 계좌당·조회주기에 따라 요금제가 갈리고, VAT 포함 여부와 개인사업자 계좌 지원은 페이지에 명시가 없어 **가입 전 문의 필요**. 연동 신청하면 1개월 무료 테스트 | ○ 부담은 작음 |

### 도구별 Windows 사용 가능 여부

| 도구 | Windows | 근거 | 비고 |
|---|---|---|---|
| **Claude in Chrome** (크롬 확장) | 가능 | Claude 공식 문서: Chrome·Edge 지원(WSL 제외). 유료 플랜(Pro 이상) 필요 | 내 크롬에서 이미 로그인한 화면을 그대로 씀 |
| **Playwright** | 가능 | 일반적으로 알려진 사실(이번에 웹으로 재확인하지는 않음) | 코드가 필요. 사장님은 Claude Code가 짜 주니 문제없음 |
| **Aside** | **불확실** | 9/7 기사: Windows는 비공개 베타·공개 다운로드 없음. 9/14 기사: Windows 출시. aside.com 에서는 상태를 확인하지 못함 | 설치가 되는지 먼저 확인. 안 되면 위 둘 중 하나 |

> 참고: 제가(젬마쌤) 쓰는 Aside 연결 도구는 Mac 전용입니다. 사장님은 Windows 앱을 직접 열어 쓰셔야 합니다.

## 2. 안전 규칙 — 은행 화면에서는 이것만은

- **비밀번호·공동인증서·OTP는 AI에게 알려 주지 않습니다.** 로그인은 사장님이 직접 하고, 그다음부터 AI가 이어받습니다.
- AI는 **조회·엑셀 다운로드까지만.** 이체·송금·결제 메뉴는 누르지 않게 프롬프트에 못 박아 둡니다.
- 은행에 **조회 전용 아이디/서비스**가 있으면 그걸로 로그인하면 더 안전합니다(은행마다 다름).
- 로그인 정보가 담긴 브라우저 폴더는 GitHub에 올라가지 않게 `.gitignore`에 넣습니다.
- 처음 한두 번은 AI가 하는 걸 **화면으로 지켜봅니다.**

## 3. 사장님 앱의 어디에 붙이나

- **올리기 탭 → "통장을 ○월 ○일까지 받아 뒀어요"**: 에이전트가 이 날짜 다음날부터 어제까지를 알아서 받아 오게 하면 "앞 날짜 빠뜨림"이 구조적으로 없어집니다.
- **겹치는 기간은 새 줄만 추가**(이미 구현됨): 자동으로 몇 번 돌려도 중복이 안 생겨서 자동화하기 좋은 구조입니다.
- **쿠팡이츠·요기요·땡겨요 정산 자료**(중간 점검에서 "파일이 없거나 손으로 넣어야 함"): 파트너센터에 사장님이 로그인해 두면 정산내역 엑셀 받기를 같은 방식으로 맡길 수 있습니다.
- **네이버·쿠팡 주문내역(영수증 대신)**: 아래 프롬프트 4번.

## 4. 프롬프트 (Windows용 · Claude Code에 그대로 붙여 넣기)

### 프롬프트 1. 먼저 10분 테스트 — 우리 은행 화면이 자동화로 열리나

```
숯불에닭 장부 앱 폴더에서 작업해 줘. 코드는 건드리지 말고 테스트만 하자.

목표: 내가 쓰는 은행 인터넷뱅킹 화면이 Playwright로 연 브라우저에서 정상적으로 열리고, 거래내역 엑셀 받기까지 갈 수 있는지만 확인한다.

조건:
- 내 PC는 Windows야. 명령은 PowerShell 기준으로 알려 줘.
- 별도 폴더 `tools\bank-fetch\` 를 만들고 Playwright를 설치해 줘. 내 PC에 설치된 Chrome을 써 줘(channel: "chrome").
- 로그인 정보가 저장되는 브라우저 폴더(`tools\bank-fetch\.profile\`)는 .gitignore에 반드시 추가해 줘.
- 브라우저를 눈에 보이게 띄워서 은행 로그인 페이지까지만 열고 멈춰. 로그인은 내가 직접 한다.
- 비밀번호·인증서·OTP를 코드나 파일에 쓰지 마. 나한테 입력해 달라고 하지도 마.
- 내가 "로그인했어"라고 하면, 거래내역 조회 화면까지 이동해서 엑셀 받기 버튼이 보이는지만 확인하고 멈춰. 이체·송금 메뉴는 절대 누르지 마.
- 보안프로그램 설치 창, 화면이 안 뜨는 것, 오류가 나면 그대로 알려 줘. 임의로 우회하지 마.

끝나면: 된다 / 안 된다 / 일부 된다 로 결론 내고, 안 되면 이유와 다음 선택지(Claude in Chrome 확장, 팝빌 계좌조회 API)를 알려 줘.
```

### 프롬프트 2. 엑셀 받기 자동화 (테스트가 통과했을 때)

```
프롬프트 1에서 만든 tools\bank-fetch 를 이어서 작업해 줘.

만들 것: 내가 은행에 직접 로그인한 뒤 `npm run bank` 를 실행하면 아래를 해 주는 스크립트.
1. 앱이 기억하는 "통장을 받아 둔 마지막 날짜"의 다음 날부터 어제까지를 기간으로 입력한다. (마지막 날짜를 못 읽으면 나에게 물어봐)
2. 거래내역 엑셀을 받아 `C:\Users\<내 사용자 이름>\Downloads\숯불에닭\통장\` 에 `통장_YYYYMMDD-YYYYMMDD.xlsx` 이름으로 저장한다.
3. 몇 건이 들어 있는지, 기간이 맞는지 한 줄로 알려 준다.

지킬 것:
- 로그인·인증은 항상 내가 한다. 저장된 비밀번호를 쓰지 않는다.
- 하는 일은 조회와 엑셀 받기뿐. 이체·송금·결제·계좌 설정 화면은 누르지 않는다.
- 처음 보는 화면이나 팝업이 나오면 멈추고 나에게 물어본다.
- 세션이 끊겨 있으면 "다시 로그인해 주세요"라고만 하고 끝낸다.
- 완성되면 내가 보는 앞에서 한 번 돌려 보고, 앱의 올리기 탭에서 받은 파일이 새 줄만 추가되는지까지 같이 확인해 줘.
```

### 프롬프트 3. 받은 파일을 앱에 자동으로 올리기

```
tools\bank-fetch 가 받아 둔 통장 엑셀을 앱에 올리는 단계를 줄이고 싶어.

- 앱의 "통장 올리기"가 쓰는 파싱 함수를 그대로 재사용해서, 새로 받은 파일을 한 번에 올리는 명령(`npm run bank:import`)을 만들어 줘. 내가 화면에서 파일을 고르는 단계가 없어지면 돼.
- 겹치는 기간은 새 줄만 추가하는 기존 규칙을 그대로 따른다. 몇 줄 추가됐고 몇 줄 건너뛰었는지 알려 줘.
- 올린 뒤 "통장엔 들어왔는데 매출에 없는 날" 카드가 새로 뜨면 날짜를 같이 알려 줘.
- 내 실제 데이터를 쓰는 건 내 PC 모드에서만. 시연용 데모 배포(Vercel)에는 이 기능과 실제 거래내역이 올라가지 않게 해 줘.
- 어떤 파일을 고쳤는지, 어떻게 확인했는지 마지막에 정리해 줘.
```

### 프롬프트 4. 쿠팡·네이버 주문내역을 영수증 대신 가져오기

```
영수증이 없는 쿠팡·네이버 결제를 주문내역으로 대신하고 싶어. tools\bank-fetch 와 같은 방식으로 해 줘.

- 로그인은 내가 직접 한다. 쿠팡은 QR 로그인으로 내가 휴대폰에서 승인할 거야.
- 로그인 후에는 지정한 기간의 주문내역(날짜·상품명·금액)만 읽어서 `영수증_주문내역_YYYYMM.csv` 로 저장해 줘. 주소·전화번호 같은 개인정보 칸은 읽지도 저장하지도 마.
- 쿠팡이 자동화 접속을 막거나 화면이 달라서 안 되면 억지로 우회하지 말고 멈춰서 알려 줘. 그땐 주문 목록 화면을 캡처해서 AI에게 읽히는 방법으로 바꾸자.
- 저장한 CSV는 앱의 매입 영수증 올리기 형식에 맞춰 줘.
```

### 프롬프트 5. 코딩 없이 — 브라우저 에이전트 앱(Aside·Claude in Chrome)에 말로 시키기

은행에 **먼저 직접 로그인**해 둔 뒤, 에이전트 창에 붙여 넣습니다.

```
지금 열려 있는 은행 거래내역 조회 화면에서 작업해 줘.
- 조회 기간을 [시작일]부터 [종료일]까지로 설정하고, 거래내역 엑셀을 내려받아 줘.
- 내려받은 파일 이름을 통장_[시작일]-[종료일].xlsx 로 바꿔 줘.
- 조회와 엑셀 받기 말고는 아무것도 누르지 마. 이체·송금·결제·설정 화면은 열지도 마.
- 로그인이 풀렸거나 처음 보는 화면이 나오면 멈추고 나한테 알려 줘. 비밀번호·인증번호는 입력하지 마.
```

### 프롬프트 6. (B안) 팝빌 계좌조회로 가기 전에 따져 보기

```
팝빌 계좌조회 API를 숯불에닭 장부 앱에 붙이는 걸 검토해 줘. 코드는 아직 고치지 마.

- 팝빌 개발자 문서(developers.popbill.com)의 계좌조회(EasyFinBank)를 읽고, 우리 앱(Next.js + Supabase + Vercel)에서 어떻게 붙이는지 설계만 정리해 줘.
- API 키·비밀값은 서버 환경변수에만 두고 브라우저 코드에 노출되지 않게. `.env`는 커밋 금지.
- 사업자 대표 개인 통장이 지원되는지, 은행에 빠른조회 신청이 필요한지, 월 요금이 계좌당 얼마인지(VAT 포함 여부 포함)를 문서에서 못 찾으면 "확인 불가"라고 적고, 팝빌에 물어볼 질문 목록으로 만들어 줘.
- 지금 쓰는 엑셀 올리기와 비교해서, 월 비용 대비 줄어드는 시간이 얼마인지 내가 판단할 수 있게 표로 정리해 줘.
```

## 5. 권하는 순서

1. **오늘~내일**: 프롬프트 1로 10분 테스트. 은행 화면이 열리는지만 본다.
2. 열리면 프롬프트 2 → 3. 안 열리면 프롬프트 5(Claude in Chrome 등)로 시도.
3. 둘 다 안 되면 프롬프트 6으로 팝빌 검토. 월 5,000원부터이니 시간 절약이 크면 충분히 합리적입니다.
4. **10/10 제출 전에는** 시연용 가짜 데이터에 영향이 없는지만 확인하세요. 이 자동화는 "개선한 점 / 앞으로"에 한 줄로 넣기에 좋은 주제입니다(실제 계좌 데이터가 공개 저장소·데모 주소에 올라가지 않게 주의).
