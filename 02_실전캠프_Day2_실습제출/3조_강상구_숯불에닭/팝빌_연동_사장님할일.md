# 팝빌 자동 가져오기 — 사장님이 하실 일

작성: 2026-10-05 새벽 (코드 쪽은 다 만들어 뒀습니다)

통장 거래내역과 전자세금계산서를 **버튼 한 번으로** 가져오는 기능입니다.
앱 쪽은 끝났고, **팝빌 가입과 농협 신청만 하시면** 바로 됩니다.

---

## 1단계 — 농협 빠른조회 신청 (10분)

통장을 가져오려면 농협에서 "빠른조회"를 먼저 켜야 합니다. **공동인증서로 로그인은 필요하지만, 팝빌에 인증서를 넘기지는 않습니다.**

1. 농협 개인뱅킹 `banking.nonghyup.com` 접속 → 공동인증서 로그인
2. **MY뱅크 → 뱅크서비스관리 → 빠른조회**
3. 조회용 계좌로 **351-1335-4499-93** (가게 통장) 등록
4. 등록할 때 만든 **빠른조회 아이디·비밀번호**를 적어 두세요 → 2단계에서 씁니다

> 기업뱅킹을 쓰시면 메뉴 이름이 조금 다를 수 있습니다. 못 찾으시면 농협 고객센터(1661-3000)에 "빠른조회 서비스 등록"이라고 물어보시면 됩니다.

## 2단계 — 팝빌 가입 (15분)

1. `popbill.com` 가입 — 사업자번호 **267-14-02423**
2. **사업자 인증** (사업자등록증 올리기)
3. **계좌조회** 서비스 신청 → 1단계에서 만든 빠른조회 아이디로 계좌 등록
4. **홈택스 세금계산서** 서비스도 같이 신청 (매입분 가져오기용)

### 요금은 가입하실 때 꼭 확인해 주세요
- 계좌조회: 계좌당 월 정액 + 건당 요금 구조입니다. **한 달 무료 테스트**가 있다고 조사해 뒀습니다
- 홈택스 세금계산서: 별도 요금
- 생각보다 비싸면 **통장만 먼저** 하고 세금계산서는 미뤄도 됩니다

## 3단계 — 저한테 알려 주실 것

팝빌 **연동 관리 → 연동정보** 에서 두 개를 복사해 주세요.

| 항목 | 어디서 |
|---|---|
| 링크아이디 (LinkID) | 팝빌 연동정보 |
| 비밀키 (SecretKey) | 팝빌 연동정보 |

> **비밀키는 카톡·단톡방에 올리지 마세요.** 이 대화창에 바로 붙여 주시면 제가 `.env.local`에 넣겠습니다. 그 파일은 GitHub에 안 올라갑니다.

## 제가 이미 만들어 둔 것

- 통장 거래내역 가져오기 → 자동 분류 → 중복 거르기 (엑셀 올릴 때와 똑같은 길)
- 한 번에 1개월씩 쪼개서 요청 (팝빌 제한), 3개월보다 오래된 건 막아 둠
- 매입 전자세금계산서 → 영수증 초안 (국세청 승인번호로 같은 계산서 두 번 안 들어가게)
- 올리기 탭 **"통장 자동 가져오기"**, 매입 영수증 **"전자세금계산서 가져오기"** 단추
- 테스트 22개 (전체 311개 통과)

### 안전하게 해 둔 것
- 팝빌 열쇠는 **사장님 PC에만** 둡니다. 시연 주소(Vercel)에는 안 넣습니다
  → 시연 주소는 누구나 열 수 있어서, 거기 열쇠를 두면 남이 사장님 통장을 조회할 수 있습니다
- 그래서 시연 주소에서는 이 단추가 **아예 안 보입니다**
- 장부 숫자(매출·손익)는 서버로 **안 나갑니다**. 팝빌에서 받아온 줄만 오갑니다

## 처음 돌릴 때 같이 봐야 할 것

통장 거래처 이름이 농협 엑셀과 똑같이 나오는지 한 번 맞춰 봐야 합니다.

- 지금 엑셀로는 `NH체크 쿠팡(주)` 처럼 들어옵니다 (거래내용 + 거래기록사항)
- 팝빌은 그 둘을 `remark1~4` 중 어디에 담아 주는지 **은행마다 다릅니다**
- 그래서 첫 수집 결과를 보고 순서를 맞춰야 합니다. 안 맞으면 자동 분류 규칙이 안 걸립니다
- 고치는 건 한 줄(`lib/popbill/bank.ts`의 `REMARK_ORDER`)이라 금방 됩니다

**처음에는 테스트 서버(`POPBILL_IS_TEST=true`)로 돌려 보고**, 모양이 맞으면 실제로 바꾸겠습니다.
