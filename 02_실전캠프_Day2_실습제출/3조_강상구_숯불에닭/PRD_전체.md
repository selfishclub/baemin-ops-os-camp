# 전체 기획안(PRD) — 숯불에닭 한눈 손익 장부

- 가게 / 이름: 숯불에닭 / 강상구
- 조 주제: 날씨 기반 가게 운영 준비
- 한 줄 목표: 사장님이 매달 초 정산할 때(나중에는 매일 마감할 때) 통장 내역과 배달앱 실매출을 넣으면, 임대료·수수료까지 다 들어간 "이번 달 실제로 남은 돈"을 한 장으로 보는 도구
- 마지막 수정: 2026-09-22 (중간 점검 준비)

> **이 문서는 "다 만들었을 때의 모습"입니다.** 먼저 여기에 전체를 그린 뒤, 4번 기능 목록에 꼬리표를 붙여
> 오늘 만들 것은 `v1/PRD.md`로, 나중에 더할 것은 `v2/PRD.md`로 나눕니다.
> v1을 써 본 뒤에는 `v1/사용메모.md`를 보고 이 문서와 v2를 다시 고칩니다.
>
> 핵심 흐름 한 줄: **사장님이 은행 거래내역 엑셀을 올리고 배달앱별 실매출을 넣으면 → 자동 분류된 손익 한 장(임대료 포함 순수익·앱별 수수료율)이 나오고 → 월별로 남는다.**

## 1. 배경 — 최근 실제로 있었던 한 장면

- 장면: 매달 초, 사장님이 지난달 정산을 한다. 은행 사이트에서 통장 거래내역을 엑셀로 내려받고 → 한 줄씩 보면서 "이건 재료비, 이건 수수료" 하고 분류한 뒤 → 따로 만들어 둔 정리용 엑셀(월별 금전출납부 + 손익계산서)에 거래처별 금액을 옮겨 적는다. 홀 매출은 포스에 찍힌 숫자로, 배달 매출은 **통장에 들어온 돈(수수료가 이미 빠진 금액)**으로 적는다. 그래서 배달앱 4곳에서 손님이 실제 결제한 금액이 얼마인지, 그중 수수료로 얼마가 나갔는지는 집계가 안 된다. 나간 돈도 전부 통장 내역으로만 본다.
- 막힌 지점: ① 거래 한 줄씩 분류하는 게 제일 오래 걸린다. ② 실매출 대비 수수료가 안 보인다. ③ 맞게 했는지 확인할 기준이 없다.
- 얼마나 자주: 월 1회 (매달 초)
- 한 번에 걸리는 시간: 1~2시간
- 실수·빠뜨림: 거의 매달 1~2건을 나중에 발견. 분류를 잘못 넣음 / 통장에 안 보이는 지출(현금·다른 카드)이 빠짐 / 합계를 옮겨 적다 틀림 / 틀렸는지 확인할 방법이 없음.
- 지금 쓰는 엑셀을 살펴보니: 손익계산서 수식에 **임대료 합계가 빠져 있어** 영업이익이 월세·관리비만큼 크게 나오고, 누적 수식이 **초기 9개월만** 합산한 채 끊겨 있었다. 새 달 시트를 만들 때마다 수식을 손으로 이어 줘야 하는 구조라서 생긴 일이다. 수입도 "매출액(카드)·기타매출(현금)" 두 줄뿐이라 홀/배달/앱별 구분이 없다.

## 2. 쓰는 사람과 역할

가게: 청주율량점 1곳. 화덕 2명(사장님 + 시급제 1명) · 주방 1명(고정 월급제) · 홀 알바 1~2명(시급제). **도구는 사장님만 쓴다. 직원은 보지 않는다.**

| 누가 | 언제 여나 | 무엇을 보나 | 무엇을 누르나 | 어떤 기기로 |
|---|---|---|---|---|
| 사장 | 매달 초 정산할 때 | 자동 분류된 거래 목록, 분류 안 된 줄, 입금 대조 결과 | 은행 엑셀 올리기, 분류 고르기, 앱별 실매출 입력, **이번 달 마감** | 매장/집 PC |
| 사장 | 수시로 (마감 후, 집에서) | 이번 달 손익 한 장, 앱별 수수료율, 월별 추이 | 달 바꿔 보기 | 폰 |
| 사장 | 매일 마감 때 1분 ([v2]) | 오늘 입력 칸, 이번 달 누적·예상 | 채널별 매출 5칸, 시급제 직원 별칭 + 근무시간 | 폰 |
| 직원 | 열지 않음 | — | — | — |

## 3. 흐름 — 지금 vs 도구를 쓰면

| 단계 | 지금 (쓰는 앱·파일) | 도구를 쓰면 |
|---|---|---|
| 1 | 은행 사이트에서 거래내역 엑셀 내려받기 | 같음 (내려받은 파일을 도구에 올린다) |
| 2 | 엑셀에서 한 줄씩 보며 머릿속으로 분류 (제일 오래 걸림) | 거래처 이름 규칙으로 **자동 분류**. 처음 보는 거래처·애매한 줄만 모아서 보여 주고, 한 번 고르면 다음 달부터 기억 |
| 3 | 정리용 엑셀 월별 시트에 거래처별 금액을 손으로 옮겨 적기 | 옮겨 적기 없음. 분류가 끝나면 대분류·소분류 합계가 바로 나온다 |
| 4 | 홀 매출은 포스 숫자, 배달 매출은 통장 입금액으로 적기 | 홀 매출 + **배달앱별 주문금액·정산금액·건수**를 넣는다 — 주문이 발생한 달 기준 (v1: 사장님 사이트 화면 보고 월 합계 입력) |
| 5 | 수수료가 얼마인지는 모르고 넘어감 | 앱별 수수료액·수수료율(%) 비교표. 통장 입금은 입금일 기준이라 따로 맞춰 보고(지난달 말 미입금 + 이 달 정산금액 − 이 달 말 미입금), 안 맞으면 빨간색으로 표시 |
| 6 | 손익계산서 시트 수식이 알아서 계산 (임대료 빠짐, 새 달은 수식을 손으로 이어야 함) | 손익 한 장: 매출 → 매출원가 → 가맹수수료 → 영업비·**임대료**·세금과공과·노무관리비 → 영업이익, 항목마다 매출 대비 %. 달이 늘어도 손댈 수식이 없다 |
| 7 | 맞는지 확인할 기준 없음 | 사장님이 확인하고 **이번 달 마감** 버튼 → 확정·저장. 마감 뒤 고치면 기록이 남는다 |

## 4. 전체 기능 목록

|---|---|---|---|

## 7. 예외 — 잘못 넣거나 평소와 다를 때

- 같은 기간의 은행 파일을 두 번 올리면 → "이미 올린 기간이에요"라고 알리고 중복 저장하지 않는다.
- 자동 분류가 틀릴 수 있는 줄(처음 보는 거래처, 금액이 큰 줄, 마트처럼 재료비/생활비가 애매한 곳)은 → 확인 표시를 띄우고 사장님이 직접 고른다. 확인 표시가 남아 있으면 마감 버튼을 누를 때 한 번 더 알린다.
- 숫자가 이상하면(매출이 평소의 10배, 정산금액이 주문금액보다 큼, 월말 미입금액이 정산금액보다 큼, 금액이 0이나 음수) → 저장 전에 "맞나요?" 하고 묻는다.
- 통장에 들어온 돈이 "들어와야 할 돈"(지난달 말 미입금 + 이 달 정산금액 − 이 달 말 미입금)과 안 맞으면 → 차이를 빨간색으로 보여 준다(막지는 않음). 월말 미입금액을 안 넣었으면 정산 시차가 섞인 숫자라 회색 "시차 포함"으로 보여 준다.
- 올린 파일이 은행 거래내역 모양이 아니면 → 저장하지 않고 "날짜·내용·금액 열을 찾지 못했어요"라고 안내한다.
- [v2] 일별 매출을 빠뜨린 날은 → 달력에 빈 날로 표시하고 나중에 채울 수 있게 한다.

## 8. 사람이 꼭 직접 해야 하는 것 (자동화 금지)

- 월 정산 확정(마감) 버튼 — 사장님이 눌러야 확정. 마감 뒤 수정은 기록이 남는다.
- 애매한 거래의 분류 — 처음 보는 거래처, 재료비/생활비가 갈리는 거래.
- 급여·주휴수당 확정, 세금 금액 확정 — 도구는 어림값과 "확인 필요"만 보여 준다. 판단은 사장님과 세무사·노무사.
- 세무사에게 파일 보내기 — 도구는 파일만 만든다.
- 데이터 삭제 — 한 달 치 지우기처럼 되돌릴 수 없는 일.

## 9. 성공 기준 — 숫자로

- 지금: 월 정산에 1~2시간. 거의 매달 실수 1~2건을 나중에 발견. 배달앱 수수료율은 0곳 파악. 손익계산서에 임대료가 빠져 있었음.
- 목표: 월 정산 20분 이내 [가정]. 옮겨 적기 실수 0건, 분류 누락은 "확인 필요 줄"에서 다 걸러짐. 배달앱 4곳 수수료율이 한 표에 보임. 임대료가 들어간 영업이익이 나옴.
- 시연할 예시 입력 → 기대하는 결과: 가짜 은행 엑셀 한 달 치(약 60줄)를 올리고, 채널 5곳(홀 + 앱 4곳)의 가짜 월 실매출을 넣는다 → 50줄 이상 자동 분류되고 나머지만 "확인 필요"로 뜬다 → 3줄을 직접 고르면 규칙으로 저장된다 → 손익 한 장에 총매출, 대분류별 금액과 %, 임대료 포함 영업이익·이익률, 앱별 수수료율 4개가 나온다 → 마감 버튼 → 폰에서 다시 열어도 그대로 보인다 → 같은 파일을 또 올리면 막힌다.

- 배달앱 네 번째가 정확히 어디인지(땡겨요 등) — 채널 이름은 설정에서 고칠 수 있게 한다.
- 실제 은행 엑셀의 열 모양(은행마다 다름) — v1은 가짜 파일 모양으로 만들고, 실제 파일을 쓸 때 열 맞추기를 한 번 한다.
- 가맹수수료를 손익에서 어디에 둘지 — 지금 엑셀은 "매출총이익 − 가맹수수료 = 경영주수입" 순서. 그대로 따른다.
- 세금 어림 계산 방식 — 세무사에게 확인한 뒤 v2에서 정한다.
- 기준 시점 — 매출·배달앱 수수료는 "주문이 발생한 달", 비용은 "통장에서 돈이 나간 날"(지금 엑셀과 같음). 다른 달에 결제한 비용(후불 주류, 다음 달에 나가는 급여·부가세)의 귀속 월을 고치는 기능은 v2 후보.
- 각 배달앱 사장님 사이트에서 "주문일 기준" 월 합계와 정산금액을 어느 메뉴에서 보는지, 포스에 카드사(매입사)별 매출 집계가 있는지 확인 — v2의 정산 주기·카드사별 수수료율에 필요.
- 사장님 전용 로그인 — v1은 로그인 없이 "내 PC 모드"(실제 숫자는 이 컴퓨터에만)와 "시연 모드"(웹, 가짜 데이터만)로 나눴다. 폰에서 실제 손익을 보려면 로그인이 필요 → v2 후보.
- 지금 쓰는 정리용 엑셀(최신본)의 손익계산서에도 임대료 누락·수식 끊김이 있는지 사장님이 확인.
