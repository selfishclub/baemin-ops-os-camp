# 폰에서 쓰기 · 다른 사장님과 나눠 쓰기 — 준비 순서

손익장부를 인터넷(Supabase + Vercel)에 올려서 폰에서도 열고, 다른 가게 사장님도 자기 이메일로 로그인해 **자기 가게 장부**를 쓰게 하는 순서입니다.
공유되는 것은 **기본판**(손익·오늘·올리기·정산·원가율·규칙)만입니다. 리뷰·상권·자동 가져오기는 사장님 PC에만 있습니다.

비밀번호는 없습니다. 이메일로 온 링크를 누르면 로그인됩니다. 가게마다 이메일 하나 = 장부 하나. 서로의 자료는 보이지 않습니다.

## 1. Supabase 대시보드에서 (한 번만) — 2026-10-17 숯불에닭 프로젝트(sootdak-ledger)는 완료

https://supabase.com/dashboard 에 로그인 → 캠프 때 만든 프로젝트를 고릅니다.

1. **SQL Editor** → New query → 이 폴더의 `supabase/schema_v2.sql` 내용을 통째로 붙여 넣고 **Run**.
   - 시연용 표(가짜 자료)를 지우고 가게별 표로 다시 만듭니다. "Success. No rows returned" 가 나오면 됩니다.
2. **Authentication → Providers → Email**: `Enable Email provider` 켜기. `Confirm email` 은 꺼도 됩니다(링크 자체가 확인). 저장.
3. 로그인 메일 문구는 **그대로 둔다**. Supabase 기본 메일에는 링크만 있고, 문구를 바꾸려면 메일 서버(SMTP)를 따로 붙여야 한다.
   - 아이폰 홈 화면 앱은 링크를 누르면 사파리가 열리므로, 앱 로그인 화면의 **"메일 링크 붙여넣기"** 칸을 쓴다 (링크를 길게 눌러 복사).
4. **Authentication → URL Configuration**:
   - Site URL: `https://sootdak-ledger.vercel.app`
   - Redirect URLs 에 추가: `https://sootdak-ledger.vercel.app/**`
5. (확인 필요) 기본 메일 서버는 **시간당 몇 통**만 보냅니다. 여러 가게가 같은 시간에 로그인하면 메일이 늦을 수 있어요.
   여러 사장님이 쓰기 시작하면 **Project Settings → Authentication → SMTP** 에 메일 서비스(예: Resend 무료)를 붙이는 것을 생각합니다. 돈이 드는 선택은 먼저 묻습니다.

열쇠(Project Settings → API 의 Project URL · anon public)는 Vercel 에 이미 들어 있습니다(2026-09 시연 때). `service_role` 키는 어디에도 넣지 않습니다.

## 2. 올리기 (Vercel)

이 폴더(`v2/프로젝트`)에서:

```bash
npx vercel deploy --prod
```

Vercel 환경변수(Production)에 `NEXT_PUBLIC_STORAGE=supabase`, `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` 가 이미 있으므로 인터넷 모드·기본판으로 뜹니다. `NEXT_PUBLIC_EDITION` 은 비워 둡니다(= 기본판).

## 3. 폰에 앱처럼 붙이기

1. 폰 브라우저로 https://sootdak-ledger.vercel.app 열기 → 이메일 넣고 **로그인 메일 보내기** → 메일의 링크 누르기.
2. 안드로이드(크롬): 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**.
   아이폰(사파리): 공유(⬆) → **홈 화면에 추가**.
3. 홈 화면 아이콘으로 열었는데 로그인 화면이 다시 나오면(아이폰은 저장 공간이 따로라 그래요): 그 화면에서 메일을 다시 보내고, 메일의 링크를 **누르지 말고 길게 눌러 "링크 복사"** → 앱의 "메일 링크 붙여넣기" 칸에 붙여 넣고 "링크로 로그인". 한 번 들어가면 계속 유지됩니다.

## 4. 내 PC 장부를 인터넷으로 옮기기 (사장님만)

1. PC 장부(내 PC 모드) 규칙 탭 → **백업 파일 저장** (.json).
2. 인터넷 사이트에 로그인 → 규칙 탭 → **내 PC 장부를 여기로 옮기기** → 그 파일 고르기 → 요약 확인 → **넣기**.
   - 리뷰·상권 자료는 기본판에 없어서 빼고 넣습니다. 거래·매출·근무·직원·규칙·원가율 설정은 다 들어갑니다.
   - 영수증 사진은 백업 파일에 없어서 옮겨지지 않습니다.
3. PC 는 그대로 **내 PC 모드·전체판**으로 씁니다. 인터넷 장부와 자동으로 맞춰지지는 않습니다 — 둘 다 쓰면 한 달에 한 번 백업으로 다시 옮기는 식이 됩니다. (자동 맞춤은 다음 단계)

## 5. 다른 사장님에게 나눠 주기

주소 하나만 보내면 됩니다: https://sootdak-ledger.vercel.app
그 사장님이 자기 이메일로 로그인하면 빈 장부가 새로 생깁니다. 규칙 탭 맨 위 "처음이세요? 사용법"부터 보시라고 알려 주세요.
우리 가게 자료는 그 사장님에게 보이지 않고, 그 사장님 자료도 우리에게 보이지 않습니다(표의 잠금이 막습니다).

## 잘 안 될 때

| 보이는 것 | 뜻 | 할 일 |
|---|---|---|
| "인터넷 저장소에 표가 아직 없어요" | 1-1 을 안 했다 | schema_v2.sql 실행 |
| 로그인 메일이 안 온다 | 스팸함, 또는 시간당 한도 | 스팸함 확인 → 몇 분 뒤 다시 |
| "로그인이 풀렸어요" | 세션 만료 | 다시 로그인 (자료는 그대로) |
| 홈 화면 앱에서 계속 로그인 화면 | 아이폰 저장 공간 분리 | 메일 링크를 복사해 붙여넣기 |
