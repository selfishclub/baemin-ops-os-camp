## 1. 무엇을 왜 만들고 싶나요?

v1은 매달 초에 "지난달 얼마 남았나"를 빠르고 정확하게 보는 도구다. 하지만 결과를 **달이 끝난 뒤에야** 안다. 월 합계만 있어서 요일별·날씨별·채널별 패턴도 안 보이고, 시급제 직원(화덕 1명 + 홀 알바 1~2명)을 하루에 몇 명 부르는 게 맞는지 판단할 근거가 없다. 배달앱 실매출도 v1에서는 사장님 사이트 화면을 보고 손으로 옮겨 적어야 한다.

## 2. 누가 언제 쓰나요?

사장님 혼자 쓴다.

- 매일 마감 때 1분: 폰으로 오늘 채널별 매출과 시급제 직원 근무시간 입력
- 수시로: 폰으로 이번 달 누적·예상 손익, 일별 인건비율 확인
- 매달 초: PC로 v1의 월 정산 + 배달앱 정산 파일 올리기

## 3. 지금은 어떻게 하고 있나요?

(v1을 쓰고 있다는 전제) 월 1회 은행 엑셀을 올려 손익을 본다. 일별 매출은 포스와 각 배달앱 사이트에 흩어져 있고 따로 모으지 않는다. 시급제 직원 근무시간은 도구 밖에서 챙기고, 인건비는 월말 통장 이체액으로만 본다. 배달앱 실매출은 앱 4곳의 화면을 돌며 월 합계를 손으로 입력한다.

## 4. 도구를 쓰면 어떤 일이 달라지나요?

하루 기준: **채널별 매출 5칸 + 시급제 직원 별칭과 근무시간**을 넣으면 → 그날 매출 합계, 어림 인건비, **인건비율**이 나오고 → 이번 달 누적과 "이 속도면 이번 달 이만큼 남는다"는 예상이 갱신된다.

한 달 기준: 배달앱 정산 파일을 올리면 주문금액·수수료·입금액이 자동으로 채워지고, 월말에는 도구가 계산한 시급제 인건비와 통장에서 실제 나간 급여를 나란히 보여 준다.

## 6. 완성됐다는 걸 어떻게 확인하나요?

- 시연할 예시 입력: 가짜 일별 데이터 2주 치(채널별 매출 + 화덕A·홀A·홀B 근무시간), 가짜 은행 엑셀(카드사·앱별 입금이 정산 주기대로 찍힌 것), 정산 규칙 5개, 가짜 포스 상품ABC분석 엑셀 + 가짜 레시피·기준단가
- 기대하는 결과: 날짜별 매출·인건비·인건비율 표가 나오고 빈 날 2일이 달력에 표시됨 → 채우면 누적이 바뀜 → 규칙을 등록하면 통장 입금이 날짜 주문분에 자동으로 짝지어져 채널별 실제 수수료율이 나오고, 짝이 안 맞는 입금 1건이 따로 뜸 → 월말 미입금액이 자동 계산되어 v1의 대조표와 일치 → (원가율 탭) 포스 엑셀을 올리면 이론 재료비·이론 원가율과 실제 재료비가 나란히 보이고 메뉴별 원가율 순위가 나옴
- 잘못 입력했을 때: 평소의 10배인 매출이나 하루 24시간이 넘는 근무시간 → 저장 전에 "맞나요?" / 같은 날을 두 번 입력 → 덮어쓸지 묻기 / 모양이 다른 포스·정산 파일 → 저장하지 않고 안내 / 포스 엑셀의 합계 행과 읽은 합이 다르면 → 올리기 막음 / 레시피가 없는 메뉴 → "미등록"으로 따로 표시(원가율에서 빠졌다고 알림)
- 다시 열었을 때 남아 있어야 할 것: 일별 채널 매출, 일별 시급제 근무(별칭·시간·시급), 정산 주기 규칙, 입금 짝 맞춤 결과, 메뉴·레시피·기준단가, 올린 포스 파일의 기간, 고정비, v1의 모든 데이터

## 8. 절대 자동화하면 안 되는 것

- 월 정산 확정(마감) 버튼
- 애매한 거래의 분류
- 급여·주휴수당 확정, 세금 금액 확정 — 도구는 근무시간 × 시급의 어림값과 "확인 필요"만 보여 준다. 실제 이체는 사장님이.
- 세무사에게 파일 보내기, 직원·손님에게 가는 모든 메시지 전송
- 데이터 삭제
