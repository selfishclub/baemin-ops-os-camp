## 이번 버전에서 되는 것 (v1에 더한 것)

- **오늘 탭** — 마감 때 채널별 매출(홀 카드·홀 현금·배달앱 4곳)과 시급제 직원(별칭) 근무시간 입력 → 어림 인건비·일별 인건비율, 달력에 빈 날 표시, 이번 달 누적·하루 평균. 직원 별칭·시급, 채널(카드사별 추가 가능) 설정. 주 14시간 이상이면 "확인 필요"
- **정산 탭** — 채널마다 정산 규칙("매출일 + N영업일" / "주 단위 요일", 공휴일) 등록 → 통장 입금 한 건 한 건을 어느 날짜 주문분인지 자동으로 짝지음 → 채널별 실제 수수료액·수수료율을 **정산금액 입력 없이** 집계. "예정 / 미입금 / 차이" 상태, 짝이 안 맞는 입금 표시. 규칙이 없는 채널만 v1 방식으로 직접 입력
- **손익 탭** — 월 합계를 직접 넣지 않아도 일별 합계 + 정산 결과로 매출·배달앱 수수료를 자동 계산
- **원가율 탭** — 포스(오케이포스) "상품ABC분석" 엑셀을 올리면(합계 행으로 검산) 메뉴별 판매량 × 레시피 원가 = 이론 재료비·이론 원가율. 통장의 실제 재료비(매출원가)와 나란히 놓고 차이(%p)를 표시. 메뉴별 원가율·1개 마진 순위, 레시피 없는 메뉴 표시, 품목별 이론 사용량. 품목·기준단가·메뉴·레시피 설정(계산 로직은 `ai-store-manager`에서 가져옴)
- **사용법 페이지** — 규칙 탭 맨 위 "처음이세요?" → 처음 한 번 / 매일 마감 / 매달 초에 어디에 무엇을 넣고 어느 화면에서 숫자를 가져오는지. 화면마다 "?" 안내 줄
- 지출 추가는 올리기 탭 안으로 합침. 가짜 예시: 9/1~9/17 일별 자료·직원 3명, 정산 주기대로 입금이 찍힌 9월 은행 엑셀, 9월 포스 엑셀, 품목 11·메뉴 12·레시피 10
- 금액 입력 칸 버그(타이핑한 숫자가 0으로 바뀜) 수정 — v1에도 반영·재배포
