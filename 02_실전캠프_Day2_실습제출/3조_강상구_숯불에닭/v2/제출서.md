## 이번 버전에서 되는 것 (v1에 더한 것)

- **오늘 탭** — 마감 때 채널별 매출(홀 카드·홀 현금·배달앱 4곳)과 시급제 직원(별칭)의 출근·퇴근 시각 입력 → 근무시간 자동 계산(자정 넘김 처리, 전날 시각 미리 채움) → 어림 인건비·일별 인건비율, 달력에 빈 날 표시, 이번 달 누적·하루 평균. 직원 별칭·시급 설정. **카드사별 입력(선택)**: 카드 칸에서 "+ 카드사 추가"를 누르면 포스 마감정산서의 "카드사별 매출내역"과 같은 이름(BC·국민·신한·삼성·현대·롯데·하나(구외환)·NH·우리·간편결제) 목록이 나오고, 고른 카드사 옆에 금액을 넣음 → 아래에 카드 합계. 다음 날엔 전날 쓴 카드사 줄이 미리 나옴. 저장하면 그 카드사의 정산 규칙(+2영업일)과 통장 입금 분류 규칙이 자동으로 생겨 카드사별 입금·수수료율이 정산 탭에 나옴. 주 14시간 이상이면 "확인 필요"
- **정산 탭** — 채널마다 정산 규칙("매출일 + N영업일" / "주 단위 요일", 공휴일) 등록 → 통장 입금 한 건 한 건을 어느 날짜 주문분인지 자동으로 짝지음 → 채널별 실제 수수료액·수수료율을 **정산금액 입력 없이** 집계. "예정 / 미입금 / 차이" 상태, 짝이 안 맞는 입금 표시. 규칙이 없는 채널만 v1 방식으로 직접 입력
- **손익 탭** — 월 합계를 직접 넣지 않아도 일별 합계 + 정산 결과로 매출·배달앱 수수료를 자동 계산
- **원가율 탭** — 포스(오케이포스) "상품ABC분석" 엑셀을 올리면(합계 행으로 검산) 메뉴별 판매량 × 레시피 원가 = 이론 재료비·이론 원가율. 통장의 실제 재료비(매출원가)와 나란히 놓고 차이(%p)를 표시. 메뉴별 원가율·1개 마진 순위, 레시피 없는 메뉴 표시, 품목별 이론 사용량. 품목·기준단가·메뉴·레시피 설정, 레시피 JSON 가져오기/내보내기(매장관리자에서 뽑은 실제 레시피는 내 PC 모드에서만 가져옴). 실제 오케이포스 상품ABC분석 .xls 파일(1~16일치·하루치)이 읽히는 것 확인(계산 로직은 `ai-store-manager`에서 가져옴)
- **날씨 × 매출** — 오늘 탭에 넣은 일별 매출 옆에 그날 청주 날씨(Open-Meteo, 무료·키 없음)를 자동으로 붙임. 날씨별 하루 평균(홀/배달/배달 비율/인건비율), 요일×날씨 표, "비 오는 날 배달 +○%", 30℃ 이상 날, 이번 주 예보와 같은 요일·같은 날씨 과거 평균으로 예상 매출(참고값). 조 주제 "날씨 기반 가게 운영 준비"의 첫 화면. 오늘 탭 아래 요약 카드 → /weather
- **사용법 페이지** — 규칙 탭 맨 위 "처음이세요?" → 처음 한 번 / 매일 마감 / 매달 초에 어디에 무엇을 넣고 어느 화면에서 숫자를 가져오는지. 화면마다 "?" 안내 줄
- 지출 추가는 올리기 탭 안으로 합침. 가짜 예시: 9/1~9/17 일별 자료·직원 3명, 정산 주기대로 입금이 찍힌 9월 은행 엑셀, 9월 포스 엑셀, 품목 11·메뉴 12·레시피 10
- 금액 입력 칸 버그(타이핑한 숫자가 0으로 바뀜) 수정 — v1에도 반영·재배포
