# 10월 말 재고 세기 — 숯불에닭 청주율량점

**왜 세나** — 9월 원가율 차이 5.2%p(253만원)가 **로스**인지 **재고**인지 갈라내려고요.
세고 나면 `산 것 − 남은 것 = 실제로 쓴 것`이 나오고, 거기서 레시피 기준과 얼마나 벌어지는지가 로스입니다.

**언제** — 10월 31일 영업 끝나고 (또는 11월 1일 오픈 전)
**얼마나 걸리나** — 아래 14개만 세면 20~30분

---

## 세는 법

- **포장 안 뜯은 것**은 개수만 세고, **뜯은 것**은 눈대중으로 "반 봉" "3분의 1통"처럼 적으세요
- 정확하지 않아도 됩니다. **10% 안팎이면 충분**합니다
- 주류는 **병 수**만 세면 됩니다 (박스는 ×20병 / 소주는 ×30병)
- 냉장고·냉동고·창고·홀 뒤쪽까지 한 바퀴

## 적으실 때

종이에 **품목 · 남은 양**만 적으시면 됩니다. 사진으로 찍어 보내 주셔도 돼요.

```
닭갈비 원육   32kg
카스          140병
참이슬        90병
비장탄        포대 3개 (27kg)
...
```

## 제가 할 일

받으면 이렇게 계산합니다.

1. **실제 사용량** = 10월 매입 − 10월 말 재고 (+ 9월 말 재고)
2. **레시피 기준 사용량**과 견주기
3. 품목마다 **"몇 kg 더 나갔나"** → 그게 로스
4. 원가율 차이에서 재고 몫을 걷어내고 **진짜 로스만** 남기기

> 9월 말 재고를 안 세서 첫 달은 어림이 섞입니다. **11월 말에 한 번 더 세면 그때부터 정확해집니다.**
