## 이번 버전에서 되는 것

- 은행 거래내역 엑셀 올리기 → 거래처 이름 규칙으로 자동 분류 (지금 쓰는 엑셀의 8개 대분류 그대로). 처음 보는 거래처·큰 금액·마트처럼 애매한 곳만 "확인 필요"로 모아 보여 주고, 한 번 고르면 규칙으로 기억
- 이번 달 손익 한 장: 매출액 → 매출원가 → 매출총이익 → 가맹수수료 → 경영주수입 → 영업비·**임대료**·세금과공과·노무관리비·기타 → 영업이익. 항목마다 매출 대비 %, 지난달 대비, 줄을 누르면 소분류. 생활비는 "내가 가져간 돈"으로 따로
- 채널 5곳(홀 + 배달앱 4곳) 월 실매출 입력 → 앱별 수수료액·수수료율 비교. **기준은 "주문이 발생한 달"**(주문금액·정산금액). 주문일과 입금일이 달라서 통장 입금은 따로 맞춰 봄: 지난달 말 미입금 + 이 달 정산금액 − 이 달 말 미입금 = 들어와야 할 돈 → 통장과 다르면 빨간색, 월말 미입금액을 안 넣었으면 회색 "시차 포함"
- 통장에 안 보이는 지출(현금·다른 카드) 직접 추가
- 월 마감 버튼(확인 필요 줄이 남았으면 한 번 더 물음), 마감 뒤 고치면 수정 기록이 남음. 같은 기간 파일을 또 올리면 막음. 은행 파일이 아니면 안내. 이상한 숫자(정산금액 > 주문금액, 월말 미입금 > 정산금액, 지난달의 10배, 0·음수)는 저장 전에 "맞나요?"
- 저장 모드 두 가지: **내 PC 모드**(기본 — 이 컴퓨터 브라우저에만 저장, 백업 파일 저장/불러오기)와 **시연 모드**(Supabase, 가짜 데이터 전용). 실제 숫자는 내 PC 모드에서만 씁니다
- 계산 로직 테스트 19개 통과 (`npm test`)

## 아직 안 되는 것 / 다음에 할 것

- 시연 모드(Supabase) 연결은 코드와 테이블 SQL(`v1/프로젝트/supabase/schema.sql`)까지 준비됨. Supabase 가입·열쇠 붙여넣기는 아직 안 함 → 연결한 뒤 가짜 데이터로 한 번 더 확인 필요
- 로그인이 없어서 실제 숫자는 폰에서 볼 수 없음(내 PC에서만). 사장님 전용 로그인은 v2 후보
- 실제 은행 엑셀은 아직 안 올려 봄. 머리줄(거래일시·기재내용·출금액·입금액 등)을 자동으로 찾지만, 은행 양식에 따라 열 이름을 더 넣어야 할 수 있음
- "지난달의 10배" 경고는 지난달 데이터가 있어야 동작
- 비용은 통장에서 나간 날 기준. 다른 달에 결제한 비용의 귀속 월 고치기는 v2 후보
- v2: 오늘 마감 입력(일별 채널 매출 + 시급제 직원 인별 근무시간), 카드사·배달앱별 정산 주기 규칙으로 입금 짝 맞추기(월말 미입금 자동 계산·실제 수수료율 추정), 배달앱 정산 파일 올리기, 추이 그래프, 세금 미리 보기, 세무사용 내보내기, 날씨 붙이기
