# v1 제출서 — 본노엘 / 손성필

## 만든 것

- 도구 이름: 본노엘 신입 직원 매뉴얼북
- 한 줄 설명: 4개 매장 신입이 매장폰으로 필수 매뉴얼을 사진·영상과 함께 보고 "확인했어요"를 남기면, 사장님·매니저가 누가 첫 주 안에 다 봤는지 진행률로 확인하는 웹사이트
- 프로젝트 폴더: `v1/프로젝트/` (만든 폴더 통째로. 코드·프롬프트 기록·이미지·문서 전부. 10/2까지 여기)
- 실행 방법:
  1. 아래 Vercel 주소를 폰이나 컴퓨터 브라우저에서 열면 바로 됩니다 (설치 없음).
  2. 직원 화면: 검색하거나 "신입 필수" 필터를 눌러 매뉴얼을 열고, 맨 아래에서 매장 → 이름을 고른 뒤 "확인했어요".
  3. 관리자 화면: 오른쪽 위 "관리자" → 비밀번호 입력 → 매뉴얼·매장·직원 관리, 신입 진행률, 확인 현황.
- 첫 화면 스크린샷: `결과물/첫화면.png` (구경하기 표에 올라갑니다)
- 다른 스크린샷: 없음
- 영상이 있으면 링크로 (파일은 올리지 않습니다): 없음
- PRD 아티팩트 링크 (사전 과제로 만든 웹페이지, 있으면): 없음
- Vercel 배포 주소: https://bakery-manual-book.vercel.app

## 이번 버전에서 되는 것

- 띄어쓰기·대소문자 무시 검색 ("컵 홀더"로 쳐도 "컵홀더 스티커 붙이는 법"이 나옴), 카테고리별 보기, "신입 필수" 모아 보기
- 매뉴얼 상세: 사진 여러 장, 유튜브 영상, 단계별 설명, 태그
- 확인했어요: 매장 → 본인 이름을 고르고 누르면 누가 언제 봤는지 기록. 같은 사람이 두 번 누르면 "이미 확인했어요(날짜)". 명단에 없으면 매니저에게 등록 요청 안내
- 관리자(비밀번호): 매뉴얼 추가·수정·삭제, "신입 필수" 지정, 사진 업로드, 유튜브 링크, 카테고리·매장·직원 명단 관리
- 신입 진행률: 매장별 → 직원별 "필수 N개 중 M개 확인", 남은 매뉴얼 이름, 마지막 확인 날짜, 등록 며칠째. 등록 7일이 지났는데 남은 게 있으면 빨간 표시
- 확인 현황: 매뉴얼 하나 기준으로 누가 봤고 누가 안 봤는지
- 데이터는 Supabase에 저장되어 어느 기기에서 열어도 같은 매뉴얼·확인 기록이 보임

## 아직 안 되는 것 / 다음에 할 것

- 카톡·문자 알림은 만들지 않음 (사장님 결정: 직원 개인폰으로 자료가 퍼지는 게 싫어서, 당분간 매장폰 한 대로만 씀)
- 매장별 매니저 권한 (지금은 사장님·매니저가 같은 비밀번호로 모든 매장을 봄) → v2
