# 기획안(PRD) — 본노엘 매뉴얼북 · v1

- 가게 / 이름: 본노엘 베이커리 (서울 직영 4곳, 직원 60~70명) / 
- 주제(영역): 교육 — 직원 매뉴얼 온라인 북 + 신입 숙지 체크
- 이 버전의 목표 한 줄: 신입이 입사 첫 주에 매장폰으로 필수 매뉴얼을 다 보고 자기 이름으로 확인을 남기고, 사장님·매니저는 신입별로 몇 개 남았는지 한눈에 보는 도구

> 전체 그림은 `../PRD_전체.md`. 이 문서는 그중 [v1]만 옮긴 것.
> 이미 만들어진 `index.html`(검색·카테고리·매뉴얼·관리자·확인 기록·매장) 위에 **오늘 새로 3가지**를 얹는다.

## 1. 무엇을 왜 만들고 싶나요?

사장님이 매장에 들렀는데 배달 커피 컵홀더 스티커가 정위치가 아닌 곳에 붙어 있었다. 예전처럼 말로 알려주고·매니저에게 묻고·단톡방에 올리는 걸 수년간 반복했는데도 같은 일이 계속 생겨서 이번엔 아무 말도 하지 않았다. 원인은 사람이 아니라 **교육이 덜 된 것** — 현장 교육(OJT)이라 첫 며칠 그 일이 안 생기면 아예 못 배우고, 매뉴얼은 단톡방에 흩어져 있어 찾지 않는다. 신입은 월 3~5명씩 계속 들어온다. 영상·사진 매뉴얼을 보고 "확인했어요"를 남기게 해서, 나중에 "못 들었어요"라는 말이 안 나오게 만든다.

## 2. 누가 언제 쓰나요?

- **신입 직원** — 입사 첫 주, 매장 공용폰으로 "신입 필수" 매뉴얼을 하나씩 보고, 매장 명단에서 자기 이름을 고른 뒤 "확인했어요"
- **기존 직원** — 일하다 궁금할 때 매장폰에서 검색
- **매니저 (매장당 1명)** — 신입 오면 명단에 등록, 자기 매장 신입 진행률 확인, 필요하면 매뉴얼 추가 (관리자 비밀번호 공유)
- **사장님** — 매뉴얼 만들고 "신입 필수" 지정, 4개 매장 진행률 확인. 폰·PC

## 3. 지금은 어떻게 하고 있나요?

1. 신입 입사 → 매니저가 일하다 만나는 업무를 말로 알려줌 (별도 교육 시간 없음)
2. 그날 안 생긴 일은 못 배움. 궁금하면 단톡방 스크롤을 뒤지거나 다시 물어봄
3. 봤는지 안 봤는지 아무도 모름 → 틀린 걸 사장님이 발견 → 말·단톡방 반복
4. 이미 만든 `index.html`에는 검색·카테고리·매뉴얼(사진·유튜브·단계)·관리자·"확인했어요"(이름 타이핑)·매장별 확인 현황이 있음. 다만 "컵 홀더"로 치면 안 나오고, 이름을 타이핑해서 기록이 갈릴 수 있고, 신입이 뭘 다 봐야 하는지·몇 개 남았는지가 없음

## 4. 도구를 쓰면 어떤 일이 달라지나요?

한 명 기준: 매니저가 신입을 명단에 등록 → 신입이 매장폰 홈에서 "신입 필수" 목록을 열고 하나씩 봄 → 매뉴얼 끝에서 [매장 → 이름 → 확인했어요] → 사장님·매니저는 진행률 화면에서 "알바 A: 필수 8개 중 5개 확인, 남은 것: 컵홀더 스티커·마감 청소·…"를 봄. 일하다 궁금하면 "컵 홀더"라고 띄어 쳐도 바로 나옴.

## 5. 이번 버전에서 만들 것 (v1이면 하루 안에 되는 것만)

- 기능 1: **띄어쓰기 무시 검색** — 검색어와 매뉴얼 제목·태그·단계에서 공백을 빼고 비교. "컵 홀더" → "컵홀더 스티커 붙이는 법" 나옴
- 기능 2: **확인할 때 이름 고르기** — 매뉴얼 상세 맨 아래에서 매장 고르기 → 그 매장 직원 명단에서 이름 고르기 → "확인했어요". 이름 타이핑 칸은 없앰. 명단에 없으면 "매니저에게 등록을 요청하세요" 안내. 같은 사람이 두 번 누르면 "이미 확인했어요(날짜)"
- 기능 3: **필수 매뉴얼 지정 + 신입별 진행률** — 관리자 매뉴얼 폼에 "신입 필수" 체크. 홈에 "신입 필수" 필터·표시. 관리자 안에 진행률 화면: 매장별 → 직원별 "필수 N개 중 M개 확인", 남은 매뉴얼 이름, 마지막 확인 날짜, 직원 등록일
- 유지: 검색·카테고리·매뉴얼(사진·유튜브·단계·태그)·관리자 CRUD·매뉴얼별 확인 현황 — 이미 있음
- **이번에 하지 않을 것:** 카톡·문자 알림 [v2] · 로그북 연결 [v2] · 매장별 매니저 권한 [v2] · 직원 로그인 [나중] · 영상 직접 업로드 [나중] · 앱 [나중] · 매뉴얼 수정 시 재확인 (안 만듦, 사장님 결정)

## 6. 완성됐다는 걸 어떻게 확인하나요?

- 시연할 예시 입력: 관리자에서 매장 "성수점", 직원 "알바 A"(성수점) 등록 → 매뉴얼 "컵홀더 스티커 붙이는 법"(사진 2장, 유튜브 링크, 단계 3개, 태그 포장·컵홀더·배달)을 **신입 필수**로 저장 → 홈에서 "컵 홀더" 검색 → 상세에서 성수점 → 알바 A → 확인했어요
- 기대하는 결과: 검색에 매뉴얼이 나옴 · 상세에 "알바 A님이 2026-09-17에 확인함" · 관리자 진행률에 "성수점 / 알바 A: 필수 1개 중 1개 확인" · 필수 매뉴얼을 하나 더 추가하면 "1개 중… → 2개 중 1개, 남은 것: ○○"로 바뀜
- 잘못 입력했을 때: 알바 A가 같은 매뉴얼을 또 누르면 저장 안 하고 "이미 확인했어요(9/17)" · 명단에 없는 사람은 확인 버튼 자체가 안 됨(안내만) · 매뉴얼·직원 삭제는 한 번 더 묻고 지움 · 필수 매뉴얼을 지우면 진행률 분모에서 빠짐
- 다시 열었을 때 남아 있어야 할 것: 매뉴얼·필수 여부·매장·직원 명단(등록일)·확인 기록 전부 (Supabase). 매뉴얼을 고쳐도 확인 기록은 그대로

## 7. 다음 버전에서 더할 것 (v2: API·외부 데이터 등)

- 다음에 추가할 기능 하나: 카톡·문자 알림 — 신입 등록하면 매뉴얼 링크 보내기, 등록 7일 지났는데 미확인이 있으면 사장님·매니저에게 알림
- 필요한 데이터나 외부 연결: 카카오 비즈니스 채널(알림톡) 심사 또는 문자 API, 직원 연락처 저장(개인정보라 다시 결정) · 매니저 로그북(같은 Supabase) 연결 · 매장별 매니저 권한(로그인)
- 사람이 직접 판단·확인해야 할 부분: 알림 조건을 켤지, 누구에게 보낼지는 사장님이 정함

## 8. 절대 자동화하면 안 되는 것

- "확인했어요"는 **본인이 직접** 누른다. 매니저가 대신 눌러주지 않는다
- 매뉴얼·직원 삭제는 사람이 한 번 더 확인하고 누른다
- 필수 매뉴얼 지정은 사장님이 정한다
