# 기획안(PRD) — 신입 직원 매뉴얼북 · v1

- 가게 / 이름: 본노엘 / 손성필
- 조 주제: 직원 교육 매뉴얼 온라인 북 — 직원 매뉴얼
- 이 버전의 목표 한 줄: **신입 직원이** **일하다 막힌 순간에** **폰으로 검색해서 포장·기계·서류 방법을 스스로 확인하고**, 사장은 **누가 아직 안 봤는지** 한눈에 보는 도구

## 1. 무엇을 왜 만들고 싶나요?

2014년부터 운영한 수제 베이커리로, 서울에 직영 매장 4곳이 있습니다. 매장이 여러 곳이다 보니 직원마다 업무 방식이 달라지고, 컵홀더 접는 법·빵 포장·기계 사용법·근로계약서 같은 서류 처리를 신입이 올 때마다 매장마다 반복해서 교육해야 합니다. 누구한테 알려줬고 누구는 빠뜨렸는지도 기억에 의존하고 있습니다.

## 2. 누가 언제 쓰나요?

- **신입 직원**: 근무 중 막혔을 때 폰에서 열어 검색 → 사진·영상·단계 설명을 보고 따라 함 → "확인했어요"를 누름
- **사장/관리자(나)**: 새 매뉴얼을 올릴 때, 그리고 직원별 확인 현황을 볼 때
- 직원과 같이 씁니다. 4개 매장 직원 모두 같은 주소로 접속합니다.

## 3. 지금은 어떻게 하고 있나요?

매장에서 직접 시범을 보여주거나 카톡으로 사진·설명을 보냅니다. 자료가 매장별 카톡방에 흩어져 있어 나중에 찾기 어렵고, 매장마다 방식이 조금씩 달라지며, 누가 봤는지는 물어봐야 압니다.

## 4. 도구를 쓰면 어떤 일이 달라지나요?

한 건 기준:
- **넣는 것**: 관리자가 매뉴얼 1개 등록 — 제목, 카테고리(포장/매장 운영/기계/서류·행정/손님 응대), 사진 몇 장, 유튜브 링크, 단계별 설명, 태그
- **나오는 것**: 직원이 "컵홀더"라고 검색하면 그 매뉴얼이 바로 뜨고, 이름 입력 후 "확인했어요"를 누르면 관리자 화면에 **매장별로 본 사람/안 본 사람 표**가 나옵니다

## 5. v1에서 만들 것 — 오늘(9/17) 안에 되는 것만

- 기능 1: 매뉴얼 검색 + 카테고리별 목록 + 상세 보기(사진·유튜브·단계별 설명)
- 기능 2: 직원 "확인했어요" 기록 → 관리자 화면에서 매뉴얼별·매장별 확인 현황(안 본 사람 표시)
- 기능 3: 관리자(PIN) 화면에서 매뉴얼·카테고리·매장·직원 명단 등록/수정/삭제, 폰 홈화면에 앱처럼 설치(PWA)
- **이번에 하지 않을 것:** 직원 개인 로그인, 퀴즈/테스트, 카톡 알림, 매출·근태 연동

## 6. 완성됐다는 걸 어떻게 확인하나요?

- 시연할 예시 입력: 관리자로 "컵홀더 접는 방법" 매뉴얼(사진 2장 + 3단계 설명) 등록 → 직원 화면에서 "컵홀더" 검색 → 이름 "홍길동"(가상) 입력 후 확인했어요
- 기대하는 결과: 검색 결과에 바로 뜨고, 관리자 "확인 현황"에서 홍길동은 ✅, 나머지 직원은 "안 봄"으로 표시
- 잘못 입력했을 때: 이름 없이 확인 누르면 저장 안 되고 안내 메시지, 틀린 PIN이면 관리자 화면 안 열림
- 다시 열었을 때 남아 있어야 할 것: 등록한 매뉴얼·사진·확인 기록 전부 (다른 폰·다른 브라우저에서 열어도 동일)

## 7. v2에서 더할 것 (10/17까지 · API·외부 데이터 등)

- 다음에 추가할 기능 하나: 새 매뉴얼 등록 시 / 일정 기간 안 본 직원에게 **알림** 보내기 (카카오 알림톡 또는 문자)
- 필요한 데이터나 외부 연결 (API, 배민 데이터, 날씨 등): 카카오 알림톡 API 또는 문자 발송 API, 직원 연락처(동의 받은 것만)
- 사람이 직접 판단·확인해야 할 부분: 알림을 누구에게 언제 보낼지는 관리자가 버튼을 눌러 결정. 매뉴얼 내용의 정확성(특히 기계·안전 관련)은 사장이 검수

## 8. 절대 자동화하면 안 되는 것

- 직원에게 가는 메시지 자동 전송 (반드시 관리자가 확인 후 발송)
- 직원 명단·확인 기록 삭제
- 근로계약서 등 서류의 내용 확정 (매뉴얼은 "방법 안내"까지만)
