# 전체 기획안(PRD) — 본노엘 매뉴얼북

- 가게 / 이름: 본노엘 베이커리 (서울 직영 4곳, 직원 60~70명) / 
- 주제(영역): 교육 — 직원 매뉴얼 온라인 북 + 신입 숙지 체크
- 한 줄 목표: 신입·기존 직원이 "이거 어떻게 하지?" 싶은 순간에 매장폰으로 검색해서 사진·영상·글로 똑같이 따라 하고, 신입은 입사 첫 주에 필수 매뉴얼을 다 보고 확인을 남겨 "못 들었어요"가 없어지게 하는 도구
- 마지막 수정: 2026-09-17

> **이 문서는 "다 만들었을 때의 모습"입니다.** 먼저 여기에 전체를 그린 뒤, 4번 기능 목록에 꼬리표를 붙여
> 오늘 만들 것은 `v1/PRD.md`로, 나중에 더할 것은 `v2/PRD.md`로 나눕니다.
> v1을 써 본 뒤에는 `v1/사용메모.md`를 보고 이 문서와 v2를 다시 고칩니다.

## 1. 배경 — 최근 실제로 있었던 한 장면

- 장면: 사장님이 매장에 들렀는데, 배달로 나가는 커피의 종이컵 홀더에 스티커가 정해진 위치가 아닌 아무 데나 붙어 있었다. 예전 같으면 ① 그 자리에서 직원에게 말로 다시 알려주고 ② 매니저에게 왜 안 가르쳤는지 묻고 ③ 사진 찍어 단톡방에 올렸을 텐데, 이 세 가지를 수년째 반복해도 같은 일이 계속 생겼다. 그래서 이번엔 아무 말도 하지 않았다(에너지를 쏟기 싫어서). 원인은 "그 사람이 잘못한 것"이 아니라 **교육이 덜 된 것**이고, 영상·매뉴얼을 보고 숙지했다고 체크하게 만들어서 재발을 막기로 결심했다.
- 지금 매뉴얼이 있는 곳: 단톡방에 예전에 올린 사진·글. 찾으려면 스크롤을 뒤져야 해서 결국 안 찾고 물어보거나 대충 한다.
- 교육 방식: 별도 교육 시간 없이 **현장 교육(OJT)** — 일하다 그 업무를 만날 때 옆에서 알려줌. 그래서 첫 며칠 동안 그 일이 안 생기면 아예 못 배우고, 나중에 틀리게 한다.
- 얼마나 자주: "배운 대로 안 하는" 일이 눈에 띄는 것만 4개 매장 통틀어 **한 달에 몇 번** (안 보이는 데선 더 많을 것)
- 신입 입사: **한 달에 3~5명** (연 40~60명). 4개 매장이 늘 신입을 돌리고 있음
- 실수·빠뜨림: 매니저마다 설명이 달라 매장마다·사람마다 결과물이 달라짐. 나중에 "저 그거 못 들었어요"라고 하면 확인할 방법이 없음

## 2. 쓰는 사람과 역할

| 누가 | 언제 여나 | 무엇을 보나 | 무엇을 누르나 | 어떤 기기로 |
|---|---|---|---|---|
| 신입 직원 | 입사 첫 주에 필수 매뉴얼 볼 때 · 일하다 궁금할 때 | 필수 매뉴얼 목록(남은 개수), 매뉴얼 상세(사진·영상·단계) | 검색, 매장 명단에서 내 이름 고르기, "확인했어요" | 매장 공용폰 |
| 기존 직원 | 일하다 "이거 어떻게 하지?" 싶을 때 | 검색 결과, 매뉴얼 상세 | 검색 | 매장 공용폰 |
| 매니저 (매장당 1명) | 신입이 왔을 때 · 신입 진행률 볼 때 · 매뉴얼 올릴 때 | 자기 매장 신입별 진행률(누가 몇 개 남았나), 관리자 화면 | 직원 등록, 매뉴얼 추가·수정, 진행률 보기 | 매장 공용폰 |
| 사장 (관리자) | 매뉴얼 만들 때 · 필수 매뉴얼 정할 때 · 4개 매장 진행률 볼 때 | 매뉴얼 목록, 매장별 신입 진행률, 매뉴얼별 확인 현황 | 추가·수정·삭제, 사진 올리기, 영상 링크, 필수 지정, 카테고리·매장·직원 명단 관리 | 사장님 폰·PC |

관리자 화면은 사장님과 매니저가 **같은 비밀번호**로 들어간다(v1). 매장별로 권한을 나누는 건 로그인이 필요해서 v2.

## 3. 흐름 — 지금 vs 도구를 쓰면

| 단계 | 지금 (쓰는 앱·파일) | 도구를 쓰면 |
|---|---|---|
| 1 | 신입 입사 → 매니저가 일하다 만나는 업무를 말로 알려줌 | 매니저가 관리자 화면에서 신입을 매장 명단에 등록 |
| 2 | 그날 안 생긴 일은 못 배움 | 신입이 매장폰에서 "필수 매뉴얼" 목록을 열고 첫 주 안에 하나씩 봄 (사진·영상·단계) |
| 3 | 봤는지 안 봤는지 아무도 모름 | 매뉴얼 끝에서 매장 명단 중 내 이름 고르고 "확인했어요" → 이름·시각 기록 |
| 4 | 나중에 궁금하면 단톡방 스크롤 뒤지거나 다시 물어봄 | 검색창에 "컵홀더" → 바로 나옴 ("컵 홀더"로 쳐도 나옴) |
| 5 | 틀린 걸 사장님이 발견 → 말·단톡방 반복 | 사장님·매니저가 신입별 "몇 개 남았는지" 보고, 다 본 뒤 틀리면 매뉴얼 다시 보게 함. "못 들었어요"는 기록으로 반박 |

## 7. 예외 — 잘못 넣거나 평소와 다를 때

- 신입이 확인하려는데 명단에 이름이 없을 때 → 매니저가 관리자 화면에서 그 자리에서 등록한 뒤 확인 (비밀번호 공유). 이름 직접 타이핑은 막음
- 같은 사람이 같은 매뉴얼을 두 번 확인 → 첫 기록만 남기고 "이미 확인했어요(9/17)"라고 보여줌
- 매뉴얼 내용을 고쳤을 때 → 기존 확인 기록 그대로 유지. 재확인 없음 (확인 = 입사 때 들었다는 증거)
- 필수 매뉴얼을 삭제하면 → 진행률의 분모에서 빠짐. 삭제는 되돌릴 수 없으니 한 번 더 묻고 지움
- `[가정]` 퇴사자 → 명단에서 지우면 진행률 목록에서 사라짐. 확인 기록은 남겨 둠
- 검색어에 띄어쓰기·대소문자가 달라도 찾음 ("컵 홀더", "Cup holder")

## 8. 사람이 꼭 직접 해야 하는 것 (자동화 금지)

- "확인했어요"는 **본인이 직접** 누른다. 매니저가 대신 눌러주지 않는다 (증거 효력이 없어짐)
- 매뉴얼·직원 삭제는 사람이 한 번 더 확인하고 누른다
- 필수 매뉴얼 지정은 사장님이 정한다 (v2 알림도 사장님이 조건을 켠 것만 나감)

## 9. 성공 기준 — 숫자로

- 지금: 배운 대로 안 하는 일이 눈에 띄는 것만 월 몇 번 · 신입 월 3~5명이 매니저마다 다르게 배움 · "못 들었어요" 반박 불가 · 매뉴얼 찾기 = 단톡방 스크롤
- 목표: 신입 **입사 7일 안에 필수 매뉴얼 100% 확인** (매장별 진행률 화면에서 확인) · 필수 매뉴얼에 있는 일로 "못 들었어요"라는 말 **0건** · "컵홀더" 검색 → 3초 안에 매뉴얼 열림
- 시연할 예시 입력 → 기대하는 결과: 관리자에서 "컵홀더 스티커 붙이는 법"을 신입 필수로 등록 → 매장폰 홈에서 "컵 홀더" 검색 → 상세에서 성수점 → 알바 A 고르고 확인 → 진행률 화면에 "알바 A: 필수 1개 중 1개 확인" 표시

- 매니저에게 관리자 비밀번호를 공유하면 삭제도 가능해짐. 문제가 되면 v2 권한 나누기를 앞당김
