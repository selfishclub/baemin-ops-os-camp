## 1. 배경 — 최근 실제로 있었던 한 장면

### 장면 A — 매뉴얼북 (9/17, v1 완료)
- 사장님이 매장에 들렀는데 배달 커피 컵홀더 스티커가 정위치가 아닌 곳에 붙어 있었다. 말로 알려주고·매니저에게 묻고·단톡방에 올리는 걸 수년간 반복해도 같은 일이 계속 생겼다. 원인은 사람이 아니라 **교육이 덜 된 것**. 현장 교육(OJT)이라 첫 며칠 그 일이 안 생기면 못 배우고, 매뉴얼은 단톡방에 흩어져 찾지 않는다. 신입은 월 3~5명씩 들어온다.
- → 사진·영상 매뉴얼을 보고 "확인했어요"를 남기고, 사장님·매니저가 신입별 진행률을 보는 웹사이트를 만들어 배포함 (bakery-manual-book.vercel.app).

### 장면 D — 고객응대 (환불·컴플레인, 월 1~2번)
- 손님이 환불·교환을 요청하는데, 직원(특히 신입)이 얼마까지 자기가 처리해도 되는지 몰라 판단을 못 함. 손님을 계산대 앞에 세워 둔 채로 매장 뒤에서 매니저에게 전화해서 물어보고, 매니저가 알려주면 그제서야 응대함.
- 인사·주문 받기·품절 안내처럼 매일 하는 응대도 정해진 말이 없어 사람마다 다르고, 신입은 현장에서 그 상황이 생겨야만 배움(포장·제조 매뉴얼과 같은 문제).
- 얼마나: 이런 "판단 못 해 멈추는" 응대는 4개 매장 합쳐 **월 1~2번**. 손님을 기다리게 하는 시간 자체는 몇 분이지만, 그 사이 손님 표정이 굳거나 재차 항의로 번지는 게 진짜 문제.

### 장면 E — 배달 주문(배민·쿠팡) 검수·전화·품절 대체 (거의 매일)
- 배민·쿠팡 주문이 오면 영수증(주문서)을 보고 메뉴별 수량을 맞게 챙겼는지 대조하고, 컷팅/비컷팅 같은 옵션이 있는 품목은 옵션대로 준비해야 한다. 정해진 확인 방법(수량은 동그라미, 옵션은 v체크, 하단에 총 개수 합계)이 매뉴얼로 정리돼 있지 않아 사람마다 확인하는 방식이 다르고, 빠뜨리는 일이 **거의 매일** 생긴다.
- 빵을 미처 품절 처리하지 못한 채 주문이 들어오면 대체 상품으로 안내해야 하는데, 이때도 "동일 가격대 추천 → 없으면 최대 1000원까지는 본노엘이 부담해서라도 대체 상품으로 유도"라는 규칙이 있지만 정리된 문서가 없어 직원마다 다르게 대응한다.
- 배달앱 주문 전화를 받을 때 그냥 "본노엘입니다"라고 하면 손님이 무슨 가게인지 바로 못 알아듣는다. "빵 주문주신 본노엘입니다"라고 해야 바로 이해한다는 걸 사장님은 알지만, 신입은 모른 채 그냥 매장 인사말대로 받는다.
- 손님이 주문 시 요청사항 칸에 "서비스로 빵 주세요", "리뷰 이벤트 1개 제한인데 그 이상 달라"는 요청, 제품·포장/구성품·배송/도착 관련 요청을 쓰는데, 뭐라고 답해야 할지 정해진 게 없어 직원이 그때그때 판단한다.
- 얼마나: 배달 주문 검수·전화 응대 관련 문제는 4개 매장 합쳐 **거의 매일**. 포장 매뉴얼(장면 A)·응대 카드(장면 D)와 같은 문제 — 정리된 게 없어 사람마다 다르고, 신입은 겪어봐야 배운다.

### 장면 F — 가게 소개(신념·철학) 없음
- 신입·알바가 입사해도 "본노엘이 왜 이 이름인지, 어떤 마음으로 빵을 만드는지, 손님을 왜 이렇게 대하는지"를 알 기회가 없다. 지금까지 정리된 매뉴얼(포장·응대·배달 검수)은 전부 "어떻게 하는지"(방법)이고, "왜 이렇게 하는지"(신념)는 어디에도 없다.
- 사장님이 직접 원문을 작성해 확정함 (2014년 12월 창업, 직접 생산·당일 생산 당일 판매·기본을 지키는 것이 실력이라는 3원칙, 매뉴얼·시스템을 만드는 이유, 함께 일하고 싶은 사람 7가지, "힘들되 지치지는 말자"). 전체 원문은 `../v1/가게소개_원문.md`.

### 장면 B — 휴무·대타 (9월 둘째 주)
- 답십리점 알바 A가 9/9 아침 문자로 "9/24(목) 휴무 요청"을 했고, 기차표 문제로 9/23(수)까지 하루 더 요청. 사장님은 "하루도 매장을 닫아야 할 상황이라 불가. 원래 휴무는 **본인이 대타를 구해야 하고, 못 구하면 출근**"이라고 답.
- 같은 주, 성수점 알바 B가 낮 12시 19분에 "오늘 독감 진단, 근무 어려움" 문자. 사장님은 "네이버에서 본노엘 검색해 매장에 전화하고 매니저와 통화하라"고 안내. 알바는 매니저와 통화 후 "앞으로 대타 구하는 방법 숙지하겠다"고 답.
- 지금 대타 흐름(매장 벽 종이 안내문 기준): ① 근무자가 사장님께 문자로 휴무 요청 → ② 사장님 수락 → ③ 본인이 오픈채팅 단체방에서 대타를 구함 (전화번호는 개인정보라 사장님이 공유 안 함) → ④ 대타 가능한 사람이 사장님께 문자로 여쭤봄 (겹침 여부는 사장님이 판단) → ⑤ 되면 종이 **대타일지**에 "빠지는 사람 / 날짜·시간 / 대타 이름" 쓰고 사장님이 O 컨펌 → ⑥ 사장님이 그 종이를 보고 **엑셀 근무표(매장별·주간·30분 단위 색칠 표)**를 직접 고침.
- 규칙: 대타 못 구하면 출근. 파트너가 1인 근무 가능하면 파트너 컨펌 받고 빠질 수 있음.
- 얼마나: 4개 매장 합쳐 **거의 매일** 한 건, 한 건에 사장님 시간 **20분 넘게** (문자 받기 → 컨펌 → 엑셀 수정) → **주 2~3시간**. 사장님이 다 해서 제일 피곤한 일.

### 장면 C — 비품 재고·발주 (매주)
- 왕십리점 근무자가 주 1회 코팅된 종이 **비품리스트**(식빵봉투·손잡이·빵봉투·스티커·컵·테이프… 약 60품목)에 매직으로 현재고를 씀 ("2묶음", "0.5box+3봉", "2.5포대").
- 적정재고를 외워서 **암산**으로 부족분을 계산해 "주문요청" 칸에 O. 근무자가 바뀌면 적정재고를 몰라 **감으로** → 실수.
- 그걸 다시 카톡방에 텍스트로 **한 번 더** 타이핑: "<왕십리점 비품요청> 치아바타봉투(재고 2묶음), 깜빠뉴봉투(재고 1묶음), …".
- 사장님이 온라인 주문 → 주문 화면 **캡처**해서 방에 올리고 "1,2,3장 모두 성수 완료", "손잡이 봉투 중 7일 소요"를 손으로 씀.
- 점간 이동(예: "왕→중 소독 알코올 2개 @왕십리점 챙겨주세요")도 카톡에 손으로.
- 도착하면 근무자가 수량을 **대충** 확인해서, 잘못 와도 못 걸러내 손해 볼 때가 있음.
- 얼마나: 사장님 **주 2시간**, 잘못 주문(빠뜨림·중복·과다) **월 2번**.

## 2. 쓰는 사람과 역할

| 누가 | 언제 여나 | 무엇을 보나 | 무엇을 누르나 | 어떤 기기로 |
|---|---|---|---|---|
| 근무자 (알바·직원) | 휴무 필요할 때 · 대타 지원할 때 · 주 1회 비품 셀 때 · 비품 도착했을 때 · 매뉴얼 볼 때 | 내 근무표, 우리 매장 대타 구하는 목록, 비품 현재고 입력 화면, 도착 예정 목록 | 휴무 신청, 대타 지원, 현재고 입력, 도착 확인, 확인했어요 | 자기 폰 (이름 고르기 + 개인 비밀번호 4자리) · 매뉴얼은 매장 공용폰 |
| 매니저 (매장당 1명) | 대타 컨펌할 때 · 우리 매장 근무표 볼 때 · 비품 부족 볼 때 | 우리 매장 근무표, 대타 요청·지원 목록, 부족 목록 | 대타 컨펌, 점간 이동 기록, 직원 등록 | 매장폰·자기 폰 |
| 사장 (관리자) | 대타 컨펌 · 4개 매장 부족 목록 보고 주문할 때 · 근무 패턴 바꿀 때 | 홈(4개 매장 요약), 전체 근무표, 전체 부족 목록, 주문·도착 현황 | 대타 컨펌, "주문함·N일 소요", 적정재고 설정, 근무 패턴 편집 | 사장님 폰·PC |

권한: v1 매뉴얼북은 사장님·매니저가 같은 비밀번호. 새 모듈부터는 역할(근무자/매니저/사장)이 필요하므로 **이름 고르기 + 개인 비밀번호** 방식으로 통일 `[가정: 4자리 숫자, 사장님·매니저가 초기 설정]`.

## 3. 흐름 — 지금 vs 도구를 쓰면

### 3-1. 휴무·대타

| 단계 | 지금 (쓰는 앱·파일) | 도구를 쓰면 |
|---|---|---|
| 1 | 근무자가 사장님께 문자로 휴무 요청 | 근무자가 폰에서 [휴무 신청: 날짜·시간(내 근무 패턴에서 자동), 사유] |
| 2 | 사장님이 문자로 수락/거절 | 사장님·매니저 홈에 "휴무 신청 1건" → 수락하면 자동으로 "대타 구하는 중"이 됨 |
| 3 | 본인이 오픈채팅에서 대타 구함 | 같은 매장 근무자 화면에 "9/24 목 17:00~21:00 대타 구함" 표시 → 가능한 사람이 [대타 지원] |
| 4 | 대타 가능자가 사장님께 문자, 사장님이 겹침 판단 | 도구가 그 시간에 이미 근무 중이면 지원 버튼을 막음. 지원자 목록이 사장님·매니저에게 보임 |
| 5 | 종이 대타일지에 이름 쓰고 O 컨펌 | 사장님 또는 매니저가 [컨펌] → 신청자·대타 둘 다에게 화면 표시 |
| 6 | 사장님이 엑셀 근무표 수정 | **근무표에 자동 반영** (그 칸이 대타 이름으로 바뀜, 색으로 "대타" 표시) |
| 7 | 대타 못 구하면 출근 (문자로 다시 알림) | 근무 시작 전까지 컨펌된 대타가 없으면 자동으로 "출근"으로 표시 `[가정]` |

### 3-2. 비품 재고·발주

| 단계 | 지금 (쓰는 앱·파일) | 도구를 쓰면 |
|---|---|---|
| 1 | 주 1회 종이에 매직으로 현재고 | 근무자가 폰에서 품목별 현재고 입력 (지난주 값이 미리 보임) |
| 2 | 적정재고 외워서 암산 → O 표시 | 도구가 "적정 5, 현재 3 → **2 부족**" 자동 계산. 적정재고는 사장님이 품목마다 정해 둠 |
| 3 | 카톡에 텍스트로 다시 정리 | 저장하면 끝. 사장님 홈에 **4개 매장 부족 목록** 한 화면 |
| 4 | 사장님 주문 → 캡처 → "완료·7일 소요" 타이핑 | 사장님이 부족 줄마다 [주문함 · 도착 예정 N일] → 매장 화면에 "도착 예정" 표시 |
| 5 | 점간 이동 카톡에 손으로 | 매니저·사장님이 [점간 이동: 왕십리→중계, 알코올 2개] → 양쪽 재고에 반영, 받는 매장에 표시 |

### 3-3. 고객응대

## 7. 예외 — 잘못 넣거나 평소와 다를 때

- 휴무 신청한 시간이 내 근무 패턴에 없을 때 → 신청 못 함. "근무 패턴을 매니저에게 확인" 안내
- 대타 지원자가 그 시간에 이미 근무 중이면 → 지원 버튼 비활성 + "겹쳐요" 표시
- 지원자가 둘 이상이면 → 사장님·매니저가 한 명 골라 컨펌. 나머지는 자동 취소
- 근무 시작 전까지 컨펌이 없으면 → "출근"으로 표시 `[가정: 자동. 사장님이 수동으로 '휴무 승인(1인 근무)'으로 바꿀 수 있음]`
- 당일 신청(병가)이면 → "매장에 전화해서 매니저와 통화하세요" 문구를 크게. 신청 자체는 됨
- 컨펌 뒤에 대타가 못 오게 되면 → 대타가 "취소" 누르면 다시 "구하는 중"으로, 사장님·매니저에게 빨간 표시 `[가정]`
- 비품 현재고를 안 넣은 품목 → "미입력"으로 표시 (감으로 채우지 않음)
- 현재고를 적정보다 많이 넣으면 → 부족 0, 목록에 안 뜸. 숫자 대신 글자 넣으면 저장 안 됨
- 도착 수량이 다르면 → 실제 수량으로 재고 반영 + 사장님 홈에 빨간 표시 (반품·문의는 사람이)
- 점간 이동 수량이 보내는 매장 재고보다 많으면 → 경고만 하고 저장은 됨 (종이 재고가 틀릴 수도 있어서) `[가정]`
- 퇴사자 → 근무 패턴 끄면 근무표에서 사라짐. 기록은 남김
- 검색·띄어쓰기 등 매뉴얼북 예외는 v1 그대로
- 손님 응대 중 카드에 없는 상황(메뉴판·카드에 안 나온 요청)을 만나면 → 직원이 스스로 판단하지 않고 **무조건 책임자(매니저·사장님) 호출**. 카드마다 이 안내 문구를 고정으로 넣음
- 품절 대체 상품의 가격 차이가 **1000원을 넘으면** → 직원이 그대로 진행하지 않고 책임자 호출. 1000원 이내면 직원 재량으로 바로 대체 진행
- 배달 주문 검수에서 수량·옵션이 영수증과 안 맞으면 → "미확인"으로 표시하지 않고 그 자리에서 다시 확인(체크리스트 형태라 자동 저장·기록은 하지 않음, 매뉴얼만 제공)

## 8. 사람이 꼭 직접 해야 하는 것 (자동화 금지)

- 휴무 **수락**과 대타 **컨펌**은 사장님·매니저가 누른다. 도구가 자동으로 승인하지 않는다
- 대타 지원은 **본인이** 누른다. 매니저가 대신 넣지 않는다
- 비품 **주문**은 사장님이 직접 한다. 도구는 목록만 만든다 (자동 주문·결제 없음)
- 적정재고·근무 패턴은 사장님(매니저)이 정한다
- 도착 수량이 틀렸을 때 반품·문의는 사람이 한다
- "확인했어요"(매뉴얼)는 본인이 직접 (v1 그대로)
- 환불·교환, 손님이 화를 내거나 언성이 높아지는 상황, 메뉴판·카드에 없는 요청은 **모두 책임자(매니저·사장님)가 처리**한다. 직원 혼자 판단해 결정하지 않는다
- 품절 대체 상품의 차액이 1000원을 넘는 결정은 책임자가 한다. 1000원 이내는 직원이 그대로 진행해도 된다
- 급여·근무시간 확정은 도구 숫자를 참고만 하고 사람이 확인한다

## 9. 성공 기준 — 숫자로

- 지금: 대타 처리에 사장님 주 2~3시간(거의 매일 20분+) · 비품 주문에 주 2시간 · 잘못 주문 월 2번 · 도착 오류는 못 걸러냄 · 고객응대 중 판단 못 해 매니저 호출 월 1~2번 · 배달 주문 검수·전화 응대 문제 거의 매일
- 목표: 대타 한 건에 사장님 손 **2분 안쪽**(컨펌 한 번) · 엑셀 근무표 수정 **0번** · 비품 주문 정리 **주 30분 안쪽** · 잘못 주문 **월 0~1번** · 도착 오류 **당일 발견** · 신입이 응대 카드를 미리 본 뒤엔 "판단 안 서서 손님 기다리게 하는" 호출이 **월 0~1번**으로 · 배달 주문 수량·옵션 누락, "본노엘입니다" 오해로 인한 재문의는 **주 1번 이하**로
- 시연할 예시 입력 → 기대하는 결과:
  - 대타: 알바 A(성수, 수·목·금 16:30~21:00)가 9/24(목) 휴무 신청 → 매니저 수락 → 알바 C(성수, 월·화)가 지원 → 매니저 컨펌 → 9/24 성수 근무표 16:30~21:00 칸이 "알바 C(대타)"로 바뀜. 알바 B(그 시간 근무 중)는 지원 버튼이 안 눌림
  - 비품: 왕십리 알바 E가 "치아바타 봉투 현재고 2" 입력(적정 4) → 사장님 부족 목록에 "왕십리 치아바타 봉투 2 부족" → [주문함·7일] → 왕십리 도착 확인 목록에 뜸 → 알바 E가 "틀림, 실제 3" → 사장님 홈에 빨간 표시, 재고 5

## 11. 아직 정하지 못한 것

- `[가정]` 개인 비밀번호 4자리 방식 — 잊어버리면 매니저가 초기화. 더 간단히 "이름만 고르기"로 갈지
- `[가정]` 못 구하면 자동 "출근" 표시 시점 — 근무 시작 시각? 전날 밤?
- `[가정]` 컨펌 뒤 대타 취소 처리
- `[가정]` 점간 이동이 재고보다 많을 때 경고만
- 매장별 근무 패턴 60~70명을 도구에 옮기는 방법 — 엑셀 가져오기 vs 손으로 (v2 만들 때 엑셀 파일 보고 결정)
- 비품 체크 요일 — 매장마다 다른지
- 적정재고 첫 값 — 사장님이 품목 60개 × 4매장을 한 번에 넣어야 함. 먼저 한 매장(왕십리)만으로 시작할지
- 다른 매장 근무자의 대타 허용 여부
- 매뉴얼북을 홈에 "링크"로 둘지, 같은 사이트 안으로 합칠지 (v2에선 링크)
- 9/17에 v2로 뒀던 "카톡·문자 알림"과 "매장별 매니저 권한": 알림은 제출서 결정대로 [나중], 권한은 새 모듈의 역할 구분으로 자연스럽게 해결
- 고객응대 카드 문구를 사장님이 직접 쓸지, 참고 이미지처럼 기본 틀만 만들고 문구는 사장님이 나중에 채울지 — v1은 4개 상황에 대해 사장님이 실제 문구를 채운다고 가정 `[가정]`
- v2로 미룬 나머지 고객응대 상황(퇴점 인사·메뉴 추천·알레르기·대기 지연) 문구는 언제 채울지 — v1을 매장에서 써 본 뒤 결정
- "리뷰 이벤트 1개 제한 초과 요청" 등 배달 요청사항 답변 문구의 정확한 표현(예: 어디까지 거절하고 어디까지 들어줄지)은 사장님이 정책을 정해서 채운다고 가정 `[가정]`
- 배달 주문 검수 매뉴얼에 실제 영수증·메뉴 사진을 넣어야 하므로, 시연은 가짜 영수증 이미지로 하고 실제 사진은 나중에 사장님이 교체
