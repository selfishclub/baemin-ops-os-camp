## 2. 만든 과정 — 다른 사장님이 따라 할 수 있게

1. 계획을 어떻게 고쳤나요? (예: 사용메모에서 "마감 때 체크를 까먹음" → 완료 버튼 추가)
   - 사용메모 "이름 선택뿐이라 진짜 이해했는지 약함" → 이해도 퀴즈 추가 (다른 조 사장님의 빈숲 OS에서 본 퀴즈를 보고 떠올림)
   - 사용메모 "진행률을 매번 열어 보지 않아도 눈에 띄었으면" → 화면 배지 추가. 처음 v2로 잡았던 카톡·문자 알림과 매니저 권한 나누기는 [나중]으로 내림 (심사·비용 없이 화면만으로 되는 것부터)
   - 10/2에 계획과 실제 앱을 다시 비교 → AI 문제 제안은 [나중]으로, 배지 기준 고치기·퀴즈 결과 보기·한 매장 실사용을 10/14까지 할 일로 나눔
2. 만든 순서 (세 줄 안팎):
   - 9/16~17: 검색·매뉴얼·"확인했어요"를 먼저 만들고, 기획안 인터뷰 뒤 "신입 필수 지정 + 진행률 + 이름 고르기"를 더함
   - 9/19~24: 실제 매뉴얼 10개를 올리면서 매장 4곳 나누기, 포장 비품 사진, 홈 화면 타일, 홈페이지와 같은 색·글꼴, 회사 소개를 그때그때 붙임
   - 9/26~27: 사용메모로 v2 계획을 고친 뒤 퀴즈와 배지를 만들고, Supabase에 표를 더하고(SQL 실행), push해서 Vercel에 반영
3. **AI에게 한 말 중 결과를 크게 바꾼 것** (원문 그대로 두세 개):
   > "PRD 전체 버전과 버전 1을 비교해 보고 내가 이미 구현한 부분에서 어떤 점을 더 고도화하고 디벨롭할 수 있을지 계획을 먼저 세워서 가져와줘." (9/17) — 바로 만들지 않고 차이부터 보게 해서, 필수 매뉴얼 지정과 진행률이 v1에 들어옴

   > "비품 사진방에 내가 쓰는 비품 사진들을 올려놓고, 필요한 비품을 비품 폴더가 아닌 제조나 커피타기 폴더 처럼 그 폴더에서 비품 폴더 사진을 골라서 넣을 수 있으면 좋겠어" (9/19) — 포장 비품 사진을 한 번만 올리고 매뉴얼마다 골라 붙이게 됨

   > "신입 메뉴얼북을 조금더 고도화 하고 싶어 아주 전문적으로 하고 싶어서 너가 prd 먼저 제안해조" (9/26) — 만들기 전에 계획부터 받아서 v2가 퀴즈와 배지 두 가지로 좁혀짐
4. 막혔다가 푼 것과 푼 방법:
   - 사진을 완성/제조 두 칸으로 나눴다가 오히려 헷갈림 → 써 본 그 자리에서 한 칸으로 되돌림
   - 포장 비품 사진을 잘못 올리면 지우거나 바꿀 버튼이 없었음 → 화면에서 막힌 곳을 그대로 말해 삭제(×) 버튼을 추가

## 4. 아직 막힌 것 — 점검 때 같이 풀 것

- 만들어 놓았지만 매장에서 아직 안 씀. 직원이 매장폰으로 매뉴얼북을 열게 하려면 언제, 누가, 어떻게 시키는 게 좋을지
- 배지에서 '신입'을 어떻게 가려낼지. 입사일이 적힌 직원이 54명 중 30명뿐
- 다른 사람이 써 볼 때 이름 고르기 목록에 실제 직원 이름이 보임. 시연용 매장·직원을 따로 둘지

## 5. 다른 사장님이 써 볼 때 봐 줬으면 하는 것

- **먼저 부탁드려요:** 매뉴얼 찾기와 퀴즈 풀기까지만 써 봐 주세요. 맨 아래 매장·이름 고르기와 "확인했어요"는 실제 직원 명단과 기록이라 누르지 말아 주세요.
- 퀴즈가 있는 매뉴얼은 두 개예요 — "파운드 케이크 컷팅 방법"(다 맞혀야 확인 가능), "바질 잠봉 포카치아 샌드위치"(참고용). 검색창에 "파운드"라고 치면 나와요.
