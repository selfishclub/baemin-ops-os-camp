# 기획안(PRD) — 본노엘 매뉴얼북 · v2

> 초안 — v1을 써 본 뒤 고칩니다

- 가게 / 이름: 본노엘 베이커리 (서울 직영 4곳, 직원 60~70명) / 
- 주제(영역): 교육 — 직원 매뉴얼 온라인 북 + 신입 숙지 체크
- 이 버전의 목표 한 줄: 사장님이 진행률 화면을 매번 열어 보지 않아도, 신입 등록과 첫 주 미완료를 카톡·문자로 알려주고, 매니저는 자기 매장만 관리하는 도구

## 1. 무엇을 왜 만들고 싶나요?

v1은 신입이 매장폰에서 필수 매뉴얼을 보고 확인을 남기고, 사장님·매니저가 진행률을 **직접 열어서** 보는 것까지. 매장이 4곳이고 신입이 월 3~5명이면 "누가 첫 주 안에 못 끝냈는지"를 매번 들어가 보는 게 빠지기 쉽다. v1을 써 보고 실제로 얼마나 자주 열어 보게 되는지, 매니저 비밀번호 공유가 문제가 되는지에 따라 아래를 고른다.

## 2. 누가 언제 쓰나요?

- 사장님 — 알림을 받고 필요할 때만 진행률 화면을 엶
- 매니저 — 자기 매장 알림을 받음. 자기 매장 직원·진행률만 보고 고침
- 신입 — 등록되면 카톡·문자로 매뉴얼 링크를 받음 (매장폰 말고 자기 폰으로도 볼 수 있음)

## 3. 지금은 어떻게 하고 있나요? (v1 기준)

사장님·매니저가 관리자 화면에 들어가 진행률을 눈으로 확인. 첫 주 기준도 등록일을 보고 사람이 셈. 매니저는 사장님과 같은 비밀번호로 모든 매장을 볼 수 있음.

## 4. 도구를 쓰면 어떤 일이 달라지나요?

신입 등록 → 자동으로 매뉴얼 링크 발송 → 등록 7일째 미확인이 남아 있으면 사장님·해당 매니저에게 "성수점 알바 A: 필수 8개 중 3개 남음" 알림 → 매니저가 챙김. 로그북에서도 "이번 주 신입 교육 진행"이 보임.

## 5. 이번 버전에서 만들 것

**꼭 할 것** (1~2개)
- 기능 1: **첫 주 미완료 알림** — 직원 등록일 + 7일에 필수 매뉴얼이 남아 있으면 사장님·해당 매장 매니저에게 카톡(알림톡) 또는 문자. 보낼 조건·시간은 관리자 알림 설정 화면에서 사장님이 켬
  - 준비물: 카카오 비즈니스 채널 개설·알림톡 템플릿 심사(며칠 걸림) 또는 문자 API(가입·건당 비용). 사장님·매니저 연락처 저장
- 기능 2: **신입 등록 시 링크 발송** — 등록하면 그 신입에게 매뉴얼 사이트 링크 + "첫 주 안에 필수 매뉴얼 확인" 안내
  - 준비물: 직원 연락처 저장 → 개인정보라 동의·보관 기간을 먼저 정함

**여유 있으면**
- 매장별 매니저 권한 — 매니저 로그인(매장별 비밀번호 또는 계정)으로 자기 매장 직원·진행률만 보기. 삭제는 사장님만
- 로그북 연결 — 같은 Supabase의 매니저 로그북에 "신입 교육 진행률" 카드 표시
- 첫 주 자동 계산 — 등록일 기준 D+7을 진행률 화면에 자동 표시 (알림 없이 화면만)

**이번에 하지 않을 것:** 직원 로그인 [나중] · 영상 직접 업로드 [나중] · 앱 [나중] · 매뉴얼 수정 시 재확인 (안 만듦)

## 6. 완성됐다는 걸 어떻게 확인하나요?

- 시연할 예시 입력: 알바 A를 등록일 8일 전으로 등록, 필수 매뉴얼 3개 중 1개만 확인 → 알림 조건 켬
- 기대하는 결과: 사장님·성수점 매니저 폰에 "성수점 알바 A: 필수 3개 중 2개 남음 (컵홀더 스티커, 마감 청소)" 알림 도착. 알림 발송 기록이 관리자에 남음
- 잘못 입력했을 때: 연락처가 없는 사람은 알림 건너뛰고 관리자 화면에 "연락처 없음" 표시 · 알림 조건이 꺼져 있으면 아무것도 안 보냄
- 다시 열었을 때 남아 있어야 할 것: 알림 설정, 발송 기록, 연락처

## 7. 다음 버전에서 더할 것

- v1 사용메모를 보고 정함. 후보: 매뉴얼 조회수·검색어 기록(뭘 자주 찾는지 → 매뉴얼 우선순위), 퀴즈형 확인(보기만 하고 누르는 걸 막음)

## 8. 절대 자동화하면 안 되는 것

- "확인했어요"는 본인이 직접 누른다
- 알림은 사장님이 켠 조건으로만 나간다. 직원에게 가는 문구는 사장님이 정한다
- 연락처 저장·삭제는 사람이 한다
