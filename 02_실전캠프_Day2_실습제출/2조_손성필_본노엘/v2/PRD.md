# 기획안(PRD) — 본노엘 매장 운영 시스템 · v2 (홈 + 비품·발주 + 휴무·대타·근무표)

> 초안 — v1을 써 본 뒤 고칩니다

- 가게 / 이름: 본노엘 베이커리 (서울 직영 4곳, 직원 60~70명) / 
- 주제(영역): 운영 전반 — 홈 화면에 아이콘별 모듈. v1 매뉴얼북(완료) 위에 **비품 재고·발주**와 **휴무·대타·근무표**를 얹음
- 이 버전의 목표 한 줄: 사장님이 문자·카톡·종이·엑셀로 손으로 하던 대타 처리(주 2~3시간)와 비품 주문(주 2시간)을, 근무자가 폰에서 넣고 사장님·매니저는 컨펌·주문만 누르게 만든다

## 1. 무엇을 왜 만들고 싶나요?

9/17 v1(매뉴얼북)을 만들고 나서, 다른 사장님의 "홈 화면 + 아이콘별 도구" 앱을 보고 본노엘도 같은 구조로 키우기로 했다. 지금 사장님 시간을 제일 많이 먹는 두 가지가 다음이다.

- **대타**: 근무자가 문자로 휴무 요청 → 사장님 수락 → 본인이 오픈채팅에서 대타 구함 → 대타 가능자가 사장님께 문자 → 종이 대타일지에 이름 → 사장님 O 컨펌 → **사장님이 엑셀 근무표(30분 단위 색칠 표)를 직접 수정**. 4개 매장 합쳐 거의 매일, 한 건 20분 넘게. 주 2~3시간.
- **비품**: 주 1회 근무자가 종이에 매직으로 현재고 → 적정재고를 외워 암산(근무자 바뀌면 감으로) → 카톡에 텍스트로 다시 정리 → 사장님 주문 → 캡처 + "완료·7일 소요" 타이핑 → 점간 이동도 손으로 → 도착 수량은 대충 확인해 잘못 와도 못 걸러냄. 사장님 주 2시간, 잘못 주문 월 2번.

## 2. 누가 언제 쓰나요?

- **근무자** — 자기 폰에서 매장 → 이름 → 비밀번호 4자리. 휴무 신청, 우리 매장 대타 지원, 주 1회 비품 현재고 입력, 비품 도착 확인
- **매니저 (매장당 1명)** — 우리 매장 휴무 수락·대타 컨펌, 근무표 보기, 점간 이동 기록, 직원·근무 패턴 등록
- **사장님** — 홈에서 4개 매장 요약, 대타 컨펌, 부족 목록 보고 "주문함·N일", 적정재고·근무 패턴 설정. 폰·PC
- 매뉴얼북은 지금처럼 매장 공용폰 (홈에서 링크)

## 3. 지금은 어떻게 하고 있나요? (v1 기준)

- 매뉴얼북만 있음 (bakery-manual-book.vercel.app). 대타·비품은 위 1번처럼 전부 문자·카톡·종이·엑셀
- 매니저 로그북은 따로 있음 (bonnoel-manager-logbook.vercel.app)

## 4. 도구를 쓰면 어떤 일이 달라지나요?

- **대타 한 건**: 알바 A가 폰에서 9/24(목) 휴무 신청 → 매니저 [수락] → 성수점 근무자 화면에 "9/24 목 16:30~21:00 대타 구함" → 알바 C [지원] (그 시간 근무 중인 알바 B는 버튼이 안 눌림) → 매니저 [컨펌] → 9/24 성수 근무표 그 칸이 "알바 C(대타)"로 바뀜. 사장님은 홈에서 보기만. 엑셀 안 고침. 근무 시작까지 컨펌이 없으면 "출근"으로 표시
- **비품 한 주**: 왕십리 알바 E가 폰에서 품목별 현재고 입력(지난주 값이 보임) → "치아바타 봉투 적정 4, 현재 2 → 2 부족" 자동 → 사장님 홈 부족 목록에 4개 매장이 한 화면 → [주문함·7일] → 왕십리 도착 확인 목록에 뜸 → 도착하면 알바 E가 "맞음 / 틀림(실제 3)" → 틀리면 사장님 홈에 빨간 표시. 점간 이동은 매니저가 "왕십리→중계 알코올 2" 한 줄

## 5. 이번 버전에서 만들 것

**꼭 할 것** (1~2개)

- 기능 1: **홈 + 비품 재고·발주** (목표 9/22~9/26)
  - 홈 화면: 아이콘 묶음(매일 하는 일 / 직원 관리 / 설정), 매뉴얼북·로그북은 링크. 매장 → 이름 → 비밀번호 4자리로 들어가고 역할(근무자/매니저/사장)이 정해짐
  - 비품 설정(사장): 품목·단위(묶음/box/포대/개)·적정재고·분류, 매장별 켜고 끄기. 종이 리스트 순서 그대로. 주방 요청 품목도 같은 목록
  - 비품 체크(근무자): 우리 매장 품목 목록, 지난주 값, 현재고 입력, 저장. 안 넣은 품목은 "미입력"
  - 부족 목록(사장·매니저): 적정 − 현재 > 0인 것만. 매장·품목·부족 수량·현재고. 줄마다 [주문함 · 도착 예정 N일]. 카톡 복사 버튼(병행용)
  - 도착 확인(근무자): 우리 매장 도착 예정 목록 → 수량 맞음 / 틀림(실제 N) → 틀리면 실제 수량으로 재고 반영 + 사장님 홈 빨간 표시
  - 점간 이동(사장·매니저): 보내는 매장·받는 매장·품목·수량 → 양쪽 재고 반영, 받는 매장에 표시
  - 준비물: 종이 비품리스트 4장(매장별) 사진 → 품목·단위 옮기기. 적정재고 첫 값은 사장님이 정함 (먼저 한 매장부터 해도 됨)
- 기능 2: **휴무·대타·근무표** (목표 9/27~10/1 기본, 10/14까지 다듬기)
  - 근무 패턴(사장·매니저): 사람별 매장·요일·시작~끝·역할. 퇴사는 끄기
  - 주간 근무표: 매장별 한 주 30분 단위 표(엑셀 모양), 대타·휴무 색 표시, 주 이동. 사장님은 4개 매장 전부
  - 휴무 신청(근무자): 날짜 고르면 내 시간 자동, 사유 → 상태(신청/수락/대타 구하는 중/확정/출근). 당일이면 "매장에 전화해서 매니저와 통화" 문구 크게
  - 수락/거절(사장·매니저) → 수락하면 "대타 구하는 중"
  - 대타 지원(근무자, 같은 매장): 목록에서 [지원]. 그 시간에 이미 근무면 비활성 + "겹쳐요"
  - 컨펌(사장·매니저): 지원자 중 한 명 → 근무표 자동 반영. 나머지 지원은 자동 취소
  - 1인 근무 OK: 파트너가 "그날 혼자 가능" → 대타 없이 확정 가능
  - 못 구하면 출근: 근무 시작 시각까지 컨펌 없으면 "출근" 표시 `[가정]`. 사장님이 수동으로 바꿀 수 있음
  - 대타 기록: 월별로 누가 누구 대신, 누가 컨펌
  - 준비물: 매장별 엑셀 근무표 4개 → 근무 패턴으로 옮기기 (60~70명). 엑셀 양식이 같으면 가져오기 기능으로, 아니면 손으로

**여유 있으면**

- 엑셀 근무표 가져오기 (지금 엑셀 파일을 읽어 근무 패턴 자동 생성)
- 홈 요약 카드: "휴무 신청 1 · 대타 구하는 중 2 · 부족 비품 6 · 도착 확인 필요 1"
- 컨펌 뒤 대타 취소 → 다시 "구하는 중" + 빨간 표시 `[가정]`
- 매뉴얼북을 링크가 아니라 같은 사이트 안으로 합치기
- (9/22 추가) 고객응대 카드 나머지 4개 상황(퇴점 인사·메뉴 추천·알레르기 성분 문의·대기가 길어질 때) 내용 채우기 — 카드 구조 자체는 v1에서 이미 만들어져 있어 문구만 추가하면 됨. 자세한 배경은 `../v1/PRD.md` 기능 4

**이번에 하지 않을 것:** 카톡·문자 알림 [나중] · 다른 매장 근무자 대타 [나중] · 근무 조회·시간 합계(급여 참고) [나중] · 주문 사이트 자동 주문 [나중] · 사용량으로 적정재고 추천 [나중] · 로그북과 데이터 창고 합치기 [나중] · 오픈·마감 체크리스트·폐기 기록·근로계약서 [나중] · 매뉴얼 수정 시 재확인 (안 만듦)

## 6. 완성됐다는 걸 어떻게 확인하나요?

- 시연할 예시 입력:
  - 직원: 성수점 알바 A(수·목·금 16:30~21:00), 알바 B(목 16:30~21:00), 알바 C(월·화 16:30~21:00), 매니저 M. 왕십리점 알바 E
  - 비품: 왕십리 "치아바타 봉투" 묶음, 적정 4. 알바 E가 현재고 2 입력 → 사장님 [주문함·7일] → 알바 E "틀림, 실제 3"
  - 대타: 알바 A가 9/24(목) 휴무 신청 → 매니저 M 수락 → 알바 C 지원 → 매니저 M 컨펌
- 기대하는 결과:
  - 부족 목록에 "왕십리 · 치아바타 봉투 · 2 부족(현재 2)" → 주문 후 왕십리 도착 확인에 뜸 → "틀림 3" 뒤 사장님 홈에 빨간 표시, 재고 5
  - 알바 B는 [지원] 버튼이 비활성("겹쳐요"). 컨펌 뒤 9/24 성수 근무표 16:30~21:00 칸이 "알바 C(대타)". 대타 기록 9월에 한 줄
  - 다른 휴무 신청을 컨펌 없이 두고 근무 시작 시각이 지나면 "출근" 표시
- 잘못 입력했을 때: 내 패턴에 없는 날 휴무 신청 → 안 됨 + 안내 · 현재고에 글자 → 저장 안 됨 · 미입력 품목은 "미입력"으로 남음 · 점간 이동이 재고보다 많으면 경고만 `[가정]` · 삭제(직원·품목)는 한 번 더 묻고, 기록은 남김
- 다시 열었을 때 남아 있어야 할 것: 직원·비밀번호·근무 패턴·휴무 신청·지원·컨펌·1인 근무 OK·품목·적정재고·재고 체크·주문·도착 확인·점간 이동 전부 (Supabase)

## 8. 절대 자동화하면 안 되는 것

- 휴무 수락과 대타 컨펌은 사장님·매니저가 누른다
- 대타 지원은 본인이 누른다. 매니저가 대신 넣지 않는다
- 비품 주문은 사장님이 직접 한다. 도구는 목록만 만든다 (자동 주문·결제 없음)
- 적정재고·근무 패턴은 사람이 정한다
- 도착 수량이 틀렸을 때 반품·문의는 사람이 한다
- 급여·근무시간 확정은 도구 숫자를 참고만 한다
