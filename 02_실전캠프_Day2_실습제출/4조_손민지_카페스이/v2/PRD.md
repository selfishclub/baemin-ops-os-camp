## 1. 무엇을 왜 만들고 싶나요?

v1은 **적고 체크하는 것**까지입니다. 써 보면 두 가지가 아쉬울 것으로 봅니다.

**하나 — 적어 놓기만 하고 모아 볼 곳이 없습니다.** DAY 1·2·3에 답을 다 적어도 그건 탭 세 개에 흩어져 있습니다. 누구에게 보여 주거나 스스로 다시 읽으려면 탭을 옮겨 다니며 찾아야 합니다. 원래 워크북의 결과물이 "브랜드 북 한 권"이었던 이유가 이것입니다.

**둘 — 숫자를 손으로 계산해야 합니다.** v1에서는 판매가·원가를 적는 칸만 있고 원가율은 직접 계산해서 적어야 합니다. 2018년에 제가 가장 힘들었던 게 비용인데, 계산을 손으로 하면 또 틀립니다.

## 2. 누가 언제 쓰나요?

v1과 같습니다. **카페를 준비하는 사람 혼자.** 여기에 두 순간이 더해집니다.

| 언제 | 무엇을 하나 |
|---|---|
| 브랜드를 다 정한 뒤 | 「브랜드 북 보기」를 눌러 한 권으로 읽고, 인쇄하거나 PDF로 저장 |
| 가격을 정할 때 | 판매가·원가를 넣으면 원가율이 색으로 나오고, 월 손익이 바로 계산됨 |

## 3. 지금은 어떻게 하고 있나요?

v1을 쓰는 상태 기준입니다.

| 하는 일 | v1에서는 |
|---|---|
| 적은 답 모아 보기 | DAY 탭 3개를 옮겨 다니며 찾아 읽는다 |
| 원가율 계산 | 계산기로 직접 나눠서 칸에 적는다 |
| 월 손익 | 따로 엑셀을 열거나 암산한다 |
| 소상공인365·데이터랩 열기 | 주소를 기억해 직접 검색한다 |
| 내 상황에 없는 항목 | 그냥 비워 둔다 (지울 수 없음) |

## 4. 도구를 쓰면 어떤 일이 달라지나요?

**한 건 기준** — DAY 2에서 "이달의 과일 케이크" 판매가 `7500`, 1개 원가 `2600`을 넣으면:

- 원가율 **34.7%**가 자동으로 나오고 **초록색**으로 표시됩니다 (35% 이하 초록 · 45% 이하 노랑 · 그 위 빨강)
- 아래 월 손익 칸에 월매출 9,000,000 · 월세 1,500,000 · 인건비 2,500,000 · 공과금 600,000을 넣으면 → 재료비·수수료·**남는 돈**과 각 비율, **하루에 몇 명이 와야 하는지**가 나옵니다

**브랜드 북 기준** — 「브랜드 북 보기」를 누르면 DAY 1·2·3에 적은 답이 표지 → 콘셉트와 고객 → 상권 → 메뉴와 가격 → 비주얼 → SNS → 30일 계획 순으로 **한 권**이 됩니다. 빈 칸은 "아직 작성 전"으로 표시되고 깨지지 않습니다.

## 5. v2에서 만들 것 — 10/14까지 (API 연동·외부 데이터 등 v1에서 미룬 것)

### 꼭 할 것

- **기능 1 — 브랜드 북 보기**: DAY 1·2·3에 적은 답을 한 권으로 모아 보기. 표지(카페 이름·콘셉트 한 줄·날짜) → 7개 장. 빈 칸은 "아직 작성 전". **인쇄·PDF 저장** 버튼. A4 세로, 장마다 페이지가 끊기지 않게
- **기능 2 — 원가율·월 손익 자동 계산**: 판매가·1개 원가를 넣으면 원가율 자동(35% 초록·45% 노랑·그 위 빨강). 월 손익 4칸(월매출·월세·인건비·공과금)을 넣으면 재료비·카드 수수료·남는 돈과 비율, 하루 필요 손님 수

### 여유 있으면

- **AI 프롬프트 만들어 주기**: 내가 적은 답이 들어간 프롬프트를 항목마다 자동으로 만들어 복사 버튼 제공 (워크북 18개 기준). 도구 안에서 AI를 부르지 않고, 복사해서 챗GPT·클로드에서 대화
- **참고 링크 모음**: 소상공인365·네이버 데이터랩·카카오맵·네이버 지도를 해당 항목 옆에. 적어 둔 동네 이름으로 지도 검색. 원가계산표·손익계산서 빈 양식 내려받기
- **항목 추가·삭제·순서 바꾸기**: 내 상황에 맞게 고침. 이미 적은 답·체크·비용은 그대로 둠
- **비용을 예산과 비교**: 총 예산을 정해 두면 남은 돈과 초과 여부 표시

### 준비물 (미리 해 둘 것)

| 무엇 | 왜 | 언제까지 |
|---|---|---|
| 원가계산표·손익계산서 빈 양식 파일을 올려 둘 곳 | 내려받기 링크가 필요 | 참고 링크 만들기 전 |
| 인쇄용 CSS (A4 세로, 페이지 끊김 방지) | 브랜드 북 PDF 저장 | 기능 1과 함께 |
| 프롬프트 18개 문구 다듬기 | 답이 들어갈 자리를 정해야 함 | AI 프롬프트 만들기 전 |
| 원가율 색 기준 확정 (35%/45%) | 카페스이 실제 비율로 바꿀지 | 기능 2 만들기 전 |

**이번에 하지 않을 것:**
- **사진·파일 붙이기** (계약서·상권 캡처·시제품 사진) → 저장 공간과 비용이 들고, 메모로 대신할 수 있음
- **기존 워크북 사이트(cafe-brandbook)에서 답 가져오기** → 사이트 교시 구조를 이 7단계에 맞춘 뒤에야 가능
- **여러 사람이 각자 쓰기** → 권한 나누기가 필요. 이 도구는 혼자 쓰는 것으로 정함

## 6. 완성됐다는 걸 어떻게 확인하나요?

**시연할 예시 입력**

1. DAY 2 → 메뉴 1: 판매가 `7500`, 1개 원가 `2600` / 메뉴 2: `6800`, `2400` / 메뉴 3: `4500`, `1200`
2. 월 손익 4칸: 월매출 `9000000` · 월세 `1500000` · 인건비 `2500000` · 공과금 `600000`
3. DAY 1·2·3 답을 절반쯤 채운 상태에서 「브랜드 북 보기」 누르기
4. 브랜드 북에서 인쇄(PDF로 저장) 누르기

**기대하는 결과**

1. 원가율 **34.7% (초록) · 35.3% (초록) · 26.7% (초록)** 이 자동으로 나온다
2. 재료비 비율이 세 메뉴 평균으로 잡히고, **남는 돈**과 비율, **하루 필요 손님 수**가 나온다
3. 적은 답은 그대로, 안 적은 칸은 **"아직 작성 전"**으로 나오고 화면이 깨지지 않는다. 맨 아래에 "아직 비어 있는 곳" 안내
4. A4 세로로 저장되고, 장 중간에서 페이지가 끊기지 않는다

**잘못 입력했을 때**

- 판매가·원가에 글자나 음수 → 저장하지 않고 "숫자만 넣어 주세요" 안내
- **1개 원가가 판매가보다 클 때** → 원가율을 빨강으로 표시하고 "원가가 판매가보다 큽니다" 안내 (계산은 막지 않음)
- 판매가만 있고 원가가 없을 때 → 원가율 칸은 "—" (0%로 표시하지 않음)
- 월매출이 0이거나 비어 있을 때 → 비율 계산을 하지 않고 "월매출을 먼저 넣어 주세요"

**다시 열었을 때 남아 있어야 할 것**

- v1에서 남던 것 전부(답·체크·비용) + 판매가·1개 원가·월 손익 4칸 + 총 예산

## 7. 그 다음에 더하고 싶은 것

- **다음에 추가할 기능 하나**: 기존 워크북 사이트(cafe-brandbook)에 이미 적어 둔 3일치 답을 **자동으로 가져오기**. 두 번 적지 않아도 됩니다
- **필요한 데이터나 외부 연결**: 워크북 사이트의 데이터 창고 접근 방법 · 파일을 올려 둘 곳
- **사람이 직접 판단·확인해야 할 부분**: 원가율·월 손익 숫자가 나와도 **가격을 올릴지 레시피를 줄일지는 사람이 정합니다.** 도구는 "35% 넘음"까지만 말하고 "비싸다/싸다"를 말하지 않습니다

## 8. 절대 자동화하면 안 되는 것

- **가격 결정.** 원가율과 색 표시는 참고일 뿐, 얼마에 팔지는 사람이 정합니다
- **항목 "완료" 판단.** 도구가 알아서 완료 처리하지 않습니다
- **도구 안에서 AI를 부르지 않습니다.** 프롬프트를 만들어 줄 뿐, 대화는 본인이 챗GPT·클로드에서 합니다
- **브랜드 북 내용을 AI가 대신 채우지 않습니다.** 빈 칸은 "아직 작성 전"으로 두고, 채우는 것은 본인입니다
- **계약·신고 같은 결정을 대신하지 않습니다**
