## 3. 시연 소개 흐름 — 링크를 열고 카테고리를 짚어 가며

| 순서 | 화면 (카테고리·탭) | 누르는 것 | 나오는 것 | 할 말 |
|---|---|---|---|---|
| 1 | 매장 운영 시스템 · 근무표 | 「근무표」 탭, 이번 달 | 직원별 오픈 · 미들 · 마감과 휴무가 채워진 달력 | "직원이 휴무도 여기서 신청해요. 매장 컴퓨터와 휴대폰에서 같은 화면을 봐요." |
| 2 | 매장 운영 시스템 · 오늘 할 일 | 「오늘 할 일」 → 오픈 · 미들 · 마감 | 맨 위 "근무 내내 지키기"와 시간대별 체크 항목 | "제가 늘 말로 하던 기준이에요. 누가 체크했는지 이름이 남아요." |
| 3 | 매장 운영 시스템 · 고객 응대 · 일지 | 「고객 응대」 → 「일지」 | 상황별 응대 말과 마감 일지 칸, 보고서 미리보기 | "놓친 일을 감정 섞지 않고 데이터로 바로 이야기해요." |
| 4 | 1차 면접 · 지원자 화면 | 「시작하기」 → 질문 몇 개 답하기 → 제출 | 한 화면에 한 질문, 답이 자동 저장 | "지원자에게 링크 하나만 보내요. AI 사용료는 0원이에요." |
| 5 | 1차 면접 · 사장님 화면 | 「사장님 화면」 → PIN 0000 → 지원자 김하늘 | 20개 답과 예시 리포트, 「리포트용 복사」 | "답을 복사해 AI에 붙이면 2차 면접 전에 리포트가 나와요." |
| 6 | 리뷰 모음소 · 대시보드 → 자동 답글 → 한달 분석 | 탭 세 개 차례로 | 리뷰 숫자, 미답변 리뷰의 답글 초안, 월간 손님 리포트 | "네이버 · 배민 · 쿠팡이츠 리뷰를 한곳에 모으고, 제 답글 말투로 초안을 만들어요. 올리는 건 사람이 승인해요." |

| 방향 | 받은 것 · 찾은 것 | 그래서 고친 것 |
|---|---|---|
| 젬마쌤 피드백 | 개인정보 · 매출 · 시급을 뺀 데모 링크를 가상 데이터로 생생하게 / 캡처의 개인정보 · 매출은 가리기 / "카페스이의 1차 면접 자동화를 GitHub에 올려 주시면 좋습니다" | 매장 운영 시스템 · 1차 면접 · 리뷰 모음소를 가짜 데이터 데모로 새로 만들었습니다. 1차 면접은 예시 지원자 3명과 예시 리포트를 넣어 다른 사장님이 바로 써 볼 수 있게 했습니다. 발표 캡처의 경영노트는 숫자가 빈 화면으로 찍었습니다 |
| 다른 사장님 저장소 | 김씨육면 리뷰 원터치의 「콘텐츠」 구조 · 대시보드 | 리뷰 모음소에 우리에게 없던 칸(이번 주 vs 지난주, 오늘 먼저 볼 것, 한달 분석)을 더했습니다 |
| AI 대화 기반 인사이트 | [아직 안 함 — 하면 적기] | |
| QA (가상 페르소나 · 실제 사용자) | 실제 사용자: 매장 운영 시스템을 직원 전원이 매일 사용. 직원들이 동시에 쓰기 어려웠고, 저장이 안 돼 기록이 날아갈 때가 많았음. 화면을 고치는 동안 내용이 달라지기도 함 | 경영노트 수수료처럼 날아간 칸은 칸별로 따로 저장하게 고침. 여러 명이 동시에 써도 안 날아가는 공용 저장은 다음 과제 |

- 반영하지 않은 의견과 이유:
  - 카카오톡 알림 — 공식 지원이 없어 불안정하다는 공통 피드백대로, 마감 보고는 텔레그램(단톡방)을 그대로 씁니다

## 5. 써 보니 — 전과 후

| 같은 일 | 전 | 후 | 어떻게 알았나 (직접 잼 · 느낌 · 예상 · 아직 안 잼) | 기간 · 횟수 |
|---|---|---|---|---|
| 마감 보고 확인 | 하루 종일 (수시로 메시지 · 노션 · 파일 확인) | 30분 (마감 일지 한 화면에서 확인) | 느낌 (직접 재지 않음) | 9월 중순 매장 운영 시스템 도입 후 매일 |
| 직원에게 할 일 · 기준 설명 | 하루 N번 (수시로) | 하루 2~3번 | 느낌 (직접 재지 않음) | 매일 영업일 |
| 리뷰 확인 · 답글 달기 | 30분 | 15분 (모아 둔 리뷰 + 답글 초안) | 느낌 (직접 재지 않음) | 리뷰 모음소 사용 후 |

- 누가, 어떤 일에, 얼마나 써 봤나요? (실제 사용 / 예시 시험): 실제 사용 — 매장 운영 시스템은 직원 전원(매니저 1 · 직원 2)과 사장이 매일 씁니다. 오늘 할 일 · 업무 일지 · 발주를 이 화면에서 봅니다
- 줄어든 시간에 한 일: 직원 교육 내용, 미래 예측 보고서, 트렌드 분석처럼 가게 기획을 AI와 함께 하는 데 씁니다 (사장님 말)
- 직원 반응 (사장님이 말한 것): 오늘 할 일 · 업무 일지 · 발주를 한눈에 봐서 번잡스러움이 줄었고 만족도가 높아졌습니다. 데이터로 피드백하니 직원들이 부족한 점을 훨씬 빨리 깨닫습니다
