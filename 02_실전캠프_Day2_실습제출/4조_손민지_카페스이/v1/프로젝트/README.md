# 브랜드에서 오픈까지 — v1

카페를 준비하는 사람이 **브랜드를 정하는 3일(DAY 1·2·3)부터 오픈까지** 한 화면에서 챙기는 도구입니다.

## 실행 방법

1. 이 폴더의 `index.html`을 **더블클릭**합니다. (브라우저가 열립니다)
2. 설치·서버·회원가입이 필요 없습니다.
3. 처음 열면 비어 있습니다. 오른쪽 위 **「예시 채우기」**를 누르면 시연용 가짜 데이터가 들어갑니다.

## 화면

- **오른쪽 — DAY 1·2·3 탭**: 눌러서 들어가 답을 적습니다. 답을 다 적으면 그 항목이 자동으로 완료됩니다.
- **왼쪽 — 창업 준비 체크리스트**: 32항목. DAY 탭을 옮겨도 늘 떠 있습니다. 체크하면 완료되고 날짜가 남습니다.
- **맨 위 — 여정 막대**: 7칸(앞 3칸 DAY, 뒤 4칸 준비). 49항목을 하나의 진행으로 봅니다.
- **앞의 답이 뒤로 따라갑니다**: DAY 1 키워드 → DAY 2, 콘셉트 → DAY 3, "내일부터 할 세 가지" → 왼쪽 첫 항목.

## 저장

적은 내용은 **이 브라우저 안에만**(localStorage) 저장됩니다. 서버로 보내지 않습니다.
다른 기기에서는 보이지 않고, 브라우저 데이터를 지우면 함께 지워집니다.

## 파일

| 파일 | 무엇 |
|---|---|
| `index.html` | 화면 틀과 디자인 |
| `data.js` | **항목 49개와 시연용 예시 데이터** — 항목을 고치려면 여기만 |
| `app.js` | 저장·진행률·완료 판단 |

## 만든 것 / 아직 아닌 것

v1은 **적고 체크하는 것**까지입니다. 브랜드 북 보기·원가율 자동 계산·월 손익 미리보기·AI 프롬프트는 v2입니다.
자세한 것은 [v1/PRD.md](../PRD.md)와 [v2/PRD.md](../../v2/PRD.md)에 있습니다.
