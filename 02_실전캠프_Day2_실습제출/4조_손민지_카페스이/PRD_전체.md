- 가게 / 이름: 카페스이 / 손민지
- 조 주제: 창업 체크리스트 (창업의 모든 것) / AI면접관 / AI고객응대 트레이닝

## 1. 배경 — 최근 실제로 있었던 한 장면

- 장면: 2018년 카페스이 준비 때 — 메뉴·레시피 확정 → 상가 매물 → 창업 비용 계산 → 사업자등록·인허가 순서로 했다. 할 일은 수첩에 손으로 적고 나머지는 머릿속과 검색. 상가·인허가·관리 전부 힘들었지만 **비용이 가장 힘들었다**: 간판·소방 같은 항목이 뒤늦게 튀어나와 예산을 넘겼다.
  수첩은 흩어지고 무엇을 했는지 다시 찾기 어려웠다. 브랜드를 정하는 단계와 오픈 준비 단계가 머릿속에서 섞여, 지금 무엇을 해야 하는지 매번 다시 생각해야 했다.
- 얼마나 자주: 창업 준비 기간 내내, 거의 매일
- 한 번에 걸리는 시간: "다음에 뭐 하지"를 다시 정리하는 데 한 번에 30분~1시간
- 실수·빠뜨림: 비용 항목 빠뜨림(간판·소방·전기 증설), 해 놓고도 기록이 없어 다시 확인

(배경 맥락) 카페스이가 진행하는 카페 창업 브랜딩 과정의 결과물은 브랜드 북과 30일 실행계획이다. 그 뒤 실제 오픈까지 이어서 챙기는 도구가 없다.

## 2. 쓰는 사람과 역할

| 누가 | 언제 여나 | 무엇을 보나 | 무엇을 누르나 | 어떤 기기로 |
|---|---|---|---|---|
| 카페를 준비하는 사람 (혼자) | 할 일 하나 끝냈을 때, 다음에 뭘 할지 볼 때, 비용을 가늠할 때 | 7단계 체크리스트 한 장, 맨 위에 진행률, 단계마다 예상 비용 합계 | 항목 체크, 메모·예상 비용 입력, 항목 추가 | 휴대폰 |

혼자 쓰는 도구다. 다른 사람이 내 기록을 보거나, 내가 남의 진행을 보는 기능은 두지 않는다.

## 3. 흐름 — 지금 vs 도구를 쓰면

| 단계 | 지금 (쓰는 앱·파일) | 도구를 쓰면 |
|---|---|---|
| 1 | 브랜드를 정한 결과물(씨앗 카드·상품구성표·브랜드 북·30일 계획)이 따로 흩어져 있다 | 그 결과물이 1~3단계 체크 항목이 되고, 30일 계획은 4단계에 옮겨 적는다 |
| 2 | 그 뒤 준비: 수첩에 손으로, 나머지는 머릿속·검색 | 7단계 목록에서 체크하고, 메모와 예상 비용을 적는다 |
| 3 | 비용은 따로 계산하다 항목을 빠뜨린다 | 빠뜨리기 쉬운 항목이 기본으로 들어 있고, 단계별·전체 합계가 바로 나온다 |
| 4 | 무엇이 남았는지 다시 훑어야 안다 | 진행률과 "다음에 할 것"이 첫 화면에 보인다 |

|---|---|---|---|
| 단계별 체크리스트 | **7단계 49항목** — DAY 1 브랜드 씨앗 → DAY 2 대표 상품 → DAY 3 브랜드 만들기 → 첫 판매 실험(30일) → 상권·상가 계약 → 비용·예산 → 인허가·홍보·오픈. 기본 항목은 아래 「① 기본 항목」 | [v1] | 본체. 이게 없으면 아무것도 안 됨 |

| 진행률 표시 | 단계별·전체 % + "다음에 할 것" 한 줄 — 첫 화면 맨 위 | [v1] | 첫 화면에 보이기로 정함. 계산만 하면 되어 비용 낮음 |
| 세부 항목 접기·펴기 | 필수 항목 아래 세부 항목(진행률에는 안 들어감)을 접었다 폄 | [v1] | 49항목이 한 번에 다 보이면 부담스러움. 표시만 하면 되어 쉬움 |
| 30일 계획 칸 | 브랜드 북 마지막에 정리한 30일 계획과 "내일부터 할 세 가지"를 적는 전용 칸 | [v2] | 전용 칸이 없어도 메모로 적을 수 있음. 자동 연결과 함께 만드는 게 나음 |
| 참고 링크 모음 | 소상공인365·네이버 데이터랩·지도 등 자주 쓰는 링크를 해당 단계 옆에 | [v2] | 없어도 한 바퀴가 돎. 단계마다 링크를 정리할 시간이 따로 필요 |
| 항목 추가·삭제·순서 바꾸기 | 내 상황에 맞게 항목을 고침 (이미 체크한 기록은 그대로) | [v2] | 처음엔 기본 49항목으로 충분. 써 보고 나서 고칠 것이 보임 |
| 비용을 예산과 비교 | 총 예산을 정해 두면 남은 돈·초과 여부를 보여 줌 | [v2] | 합계가 먼저. 예산 비교는 그다음 |
| 브랜드 북 사이트 자동 연결 | cafe-brandbook에서 "세 가지"·정리한 답을 자동으로 가져옴 | [v2] | 외부 자동 연결. 사이트 구조를 이 7단계에 맞춘 뒤에만 가능 |
| 사진·파일 붙이기 | 항목에 계약서·상권 캡처·시제품 사진을 붙임 | [나중] | 저장 공간과 비용이 들고, 지금은 메모로 충분 |

**핵심 흐름 한 줄**: 항목을 체크하고 메모·예상 비용을 적으면 → 진행률과 비용 합계가 나오고 → 다음에 할 것이 보이고 → 다시 열어도 그대로 남아 있다.
**v1 5개** · **v2 5개** · **나중 1개**. 자른 게 아니라 v2로 옮긴 것.

### ① 기본 항목 (7단계)

굵은 항목 = 꼭 해야 할 것(필수 체크). 그 아래 들여쓴 것 = 세부 항목(진행률에는 안 들어감).
1~3단계는 브랜드를 정하는 DAY 1·2·3, 4~7단계는 그 뒤 실제 창업 준비다. 두 갈래의 항목을 모두 담았다.

**1. DAY 1 · 브랜드 씨앗**
- **내가 만들고 싶은 카페 적어 두기** (나중에 비교해 보려고)
- **창업자 자원: 잘하는 것 × 좋아하는 것 × 돈 낼 가능성**
  - 트렌드 키워드 10개 뽑고 네이버 데이터랩에서 1년 검색량 확인
  - 내가 좋아하는 것·추구하는 것 적기
- **사람들이 돈을 내는 순간(장면) 찾기** (출근 전·하원 후·선물·주말 간식…)
- **핵심 고객 4가지: 누구 + 언제 + 왜 + 무엇을**
  - 대표 고객 1명(가명·나이대·하는 일·주문·객단가)
- **브랜드 씨앗 카드 완성** ("나는 __한 사람에게 / __한 순간에 / __을 제공하는 브랜드")
  - 콘셉트 키워드 3개 · 콘셉트 한 줄 · "굳이 와야 할 이유" 한 문장

**2. DAY 2 · 대표 상품**
- **대표상품 1개 + 함께 팔 상품 2~4개** (기준 5가지: 원하는가·잘하는가·구분되는가·반복 생산·남는가)
  - 시그니처 조건 4가지 점검: 콘셉트 보임·사진 찍고 싶음·매일 같은 품질·재료 손실 적음
- **메뉴 아이디어 10개 → 하나씩 제외**
- **원가와 1개당 남는 돈 계산** (재료·포장 → 인건비·월세·수수료·폐기 연결)
  - 시그니처 3개 원가율 표 — 35% 안
  - 월 손익 미리보기 4칸: 예상 월매출·월세·인건비·공과금
- **대표상품 가격 확정** (지불의사·경쟁가·구성·브랜드 느낌·판매 장소)
  - 메뉴명 + 25자 설명 (재료·시간·크기가 보이게)
- **음료·곁들임 메뉴를 5가지 안으로 줄이기** (재료 손실 막기)
- **지인 10명 시식 — 반응 받기**
- **첫 상품구성표(미니 메뉴판) 완성**
  - 메뉴판 카테고리 순서 · 전체 메뉴 12개 안팎

**3. DAY 3 · 브랜드 만들기**
- **브랜드 이름: 내용 → 이름, 10 → 3 → 1** (기억·발음·검색·의미·확장성)
- **무드보드 1장** (색·사진·글씨·패키지·공간·말투 한 방향)
  - 대표 컬러 3개(색 코드) · 폰트 느낌 · 로고 방향 키워드
- **브랜드 한 문장 + 소개 + 대표상품 설명 + 인스타 프로필·메뉴 문구**
  - 입소문 문장 · 계정명 · 소개글 150자 · 하이라이트 4~5개
- **첫 판매 실험 설계** (예약판매·팝업·플리마켓·공유주방·SNS·지인 테스트 중 택)
- **브랜드 북(8~12p) 완성**
  - 콘셉트 한 줄 최종 · "내일부터 할 세 가지"

**4. 첫 판매 실험 (시작 후 30일)**
- **30일 계획과 "내일부터 할 세 가지"를 여기 옮겨 적기** (기능 ⑥)
- **실험 방식·날짜·장소 정하기**
- **준비** — 시제품·포장·안내
  - 먼저 찍을 사진 5장(무엇·시간·각도) · 홍보 문구 1개 · 릴스 아이디어 1개
- **실행**
- **결과 기록** — 몇 개 팔렸나, 반응, 다음에 바꿀 것

**5. 상권 · 상가 계약**
- **들어갈 동네 정하기** (시·구까지)
- **소상공인365 — 유동인구 특징 · 주요 고객층 캡처**
- **직접 상권 걷기 — 평일 저녁·주말 오후 각 30분씩 지나가는 사람 세기**
- **경쟁 카페 3곳 리뷰 읽기** (프랜차이즈 1 + 개인 2)
- **이 상권의 장점·단점 적기**
- **권리금·보증금·월세 확인**
- **주차·간판 자리·전기 용량 확인**
- **계약 전 등기부등본 확인**
- **임대차 계약**

**6. 비용 · 예산** (기능 ③ 비용 합계는 이 단계)
- **보증금**
- **인테리어·공사**
- **장비** (오븐·쇼케이스·냉장)
- **간판·소방·전기 증설** ← 2018년에 빠뜨렸던 항목
- **초도 재료·포장재**
- **예비비** (총액의 10%)
  - 월세는 매출의 15% 안인지 확인

**7. 인허가 · 홍보 · 오픈**
- **위생교육 수료**
- **영업신고** (구청 위생과)
- **사업자등록** (홈택스)
- **배달앱·통신판매 신고** (필요할 때)
- **인스타 계정 만들고 소개글 올리기** (DAY 3에서 정한 계정명·소개글로)
- **스마트플레이스 등록 — 소개 문구 3~4줄 + 검색 키워드 5~8개**
- **콘텐츠 주제 3개 정하기**
- **오픈 4주 전 홍보 계획** (주 단위)
- **이웃 20명 시식 초대**
- **리뷰·단골이 생기게 할 장치 1개**
- **오픈**
- **오픈 후 첫 한 달 홍보 계획** (손님 사진·리뷰 요청·다음 달 예고)

## 7. 예외 — 잘못 넣거나 평소와 다를 때

- 비용 칸에 글자나 음수를 넣으면 → 저장하지 않고 "숫자만 넣어 주세요" 안내
- 완료한 항목을 다시 누르면 → 바로 풀지 말고 "완료를 취소할까요?" 한 번 확인
- 항목을 지우려 하면 → 적어 둔 메모·비용이 함께 사라진다고 알리고 확인
- 연결이 끊겼을 때 → 폰에 임시로 두고 연결되면 다시 저장

## 8. 사람이 꼭 직접 해야 하는 것 (자동화 금지)

- 항목 "완료" 판단은 본인이 한다 — 도구가 알아서 완료 처리하지 않는다
- 비용이 적정한지 판단은 사람이 한다 — 도구는 합계만 내고 "비싸다/싸다"를 말하지 않는다
- 계약·신고 같은 결정은 도구가 대신하지 않는다. 체크리스트는 빠뜨림을 막을 뿐이다

## 9. 성공 기준 — 숫자로

- 지금: "다음에 뭐 하지"를 다시 정리하는 데 한 번에 30분~1시간, 비용 항목 빠뜨림으로 예산 초과
- 목표: 폰을 열면 **10초 안에** 다음 할 일이 보임 · 비용 항목 빠뜨림 0 · 오픈까지 한 번도 수첩으로 돌아가지 않음
- 시연할 예시 입력 → 기대하는 결과: 1~3단계 항목 몇 개 체크 → 진행률이 오르고, 6단계에 간판·소방 2,500,000과 보증금 10,000,000을 넣으면 6단계 합계 12,500,000·전체 합계가 나온다 → 완료한 항목을 다시 누르면 확인창 → 폰을 닫고 다시 열어도 그대로
