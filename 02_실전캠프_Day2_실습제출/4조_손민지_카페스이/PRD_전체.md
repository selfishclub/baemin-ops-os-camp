- 가게 / 이름: 카페스이 / 손민지
- 조 주제: 창업 체크리스트 (창업의 모든 것) / AI면접관 / AI고객응대 트레이닝
- 한 줄 목표: [예비창업자(수강생)가] [3일 수업이 끝난 뒤 실제 창업을 준비하는 동안] [단계별 할 일·예상 비용·진행 상황을 한곳에서 챙기고, 강사(카페스이)는 누가 어디까지 했는지 한눈에 보는] 도구
- 마지막 수정: 2026-09-17

## 1. 배경 — 최근 실제로 있었던 한 장면

- 장면: 2018년 카페스이 준비 때 — 메뉴·레시피 확정 → 상가 매물 → 창업 비용 계산 → 사업자등록·인허가 순서로 했다. 할 일은 수첩에 손으로 적고 나머지는 머릿속과 검색. 상가·인허가·관리 전부 힘들었지만 **비용이 가장 힘들었다**: 생각 못 한 항목이 뒤늦게 튀어나와 예산을 넘겼다.
  지금은 반대 자리 — 베이킹 클래스·강의 수강생 중 창업하려는 분들이 수업 직후 카톡·전화로 준비 과정을 물어 온다. 각자 어디까지 했는지 기록이 없어서 **같은 질문을 또 받고, 서로 어디까지 했는지 모른다.**
- 얼마나 자주: 클래스 기수마다 수업 직후 몇 명씩
- 한 번에 걸리는 시간: 한 사람당 30분~1시간 (카톡·전화로 자세히)
- 실수·빠뜨림: 물어봤던 걸 다시 물어봄 — 진행 상황을 서로 모름. 비용 항목 빠뜨림은 창업자 공통(민지님 본인 경험)

(배경 맥락) 2026-09-28~30 부산 청년잡 「디저트 카페 창업 브랜딩」 3일 수업(강의계획안 15교시). 결과물은 3일차 BRAND LAUNCH DAY 발표 + MY FIRST BRAND BOOK(8~12p) + 30일 실행계획. 수업 중 답은 워크북 사이트(cafe-brandbook)에 적는다(교시 구조가 계획안과 달라 맞추는 일은 11번). 그 뒤의 실제 창업 준비는 정해진 도구가 없다.

## 2. 쓰는 사람과 역할

| 누가 | 언제 여나 | 무엇을 보나 | 무엇을 누르나 | 어떤 기기로 |
|---|---|---|---|---|
| 예비창업자 (수강생, 기수당 20명) | 수업 끝난 뒤 창업 준비 중, 할 일 하나 끝낼 때·막힐 때 | 전체 체크리스트 한 장(스크롤), 그 안에 진행률·단계별 예상 비용 합계. 다른 수강생은 **진행률만** 보임 | 항목 체크, 비용·메모 입력, 막힌 항목에 질문 남기기 | 휴대폰 |
| 강사 (카페스이 손민지) | 수업 중 시연할 때, 수강생이 카톡으로 물어 올 때 | 수강생 20명 표(진행률·마지막 체크한 날·막힌 단계) + 수강생 질문 모아 보기 | 이름 눌러 그 사람 체크리스트 열기, 질문에 답 적기, 항목 추가·순서 바꾸기 | 노트북 |

카페스이 운영 직원은 쓰지 않는다.

## 3. 흐름 — 지금 vs 도구를 쓰면

| 단계 | 지금 (쓰는 앱·파일) | 도구를 쓰면 |
|---|---|---|
| 1 | 3일 수업: 15교시 결과물(씨앗 카드·상품구성표·브랜드 북) + 30일 계획 발표 | Day 1·2·3 교시 결과물이 체크 항목(수업 중 진도표), 발표한 30일 계획은 4단계 첫 항목으로 옮겨 적는다 |
| 2 | 수업 뒤 각자 준비: 수첩·머릿속·검색. 막히면 강사에게 카톡·전화(30분~1시간) | 단계별 목록에서 체크하고, 비용·메모를 적는다. 막힌 항목에 질문을 남긴다 |
| 3 | 강사: 누가 어디까지 했는지 기록 없음 → 같은 질문을 또 받음 | 강사 화면에서 수강생별 진행률과 막힌 단계를 보고, 질문 모아 보기에서 답한다 |

꼬리표: **[v1]** 오늘 만듦 · **[v2]** 써 본 뒤 더함 · **[나중]** 아직 아님

| 기수 진행률 보기 (수강생끼리) | 같은 기수 다른 사람의 진행률만 보임 (비용·메모·질문은 안 보임) | | |

| 알림 | 오래 멈춘 수강생에게 카톡·문자 | | |

### ① 기본 항목 (7단계 · 강의계획안 15교시 뼈대 + 워크북 칸)

굵은 항목 = 교시 결과물(필수 체크). 그 아래 들여쓴 것 = 워크북 칸에서 온 세부 항목(진행률에는 안 들어감). 계획안·워크북 어느 쪽에도 없는 항목은 넣지 않았다.

**1. DAY 1 · 씨앗 (9/28)**
- **1교시 — 내가 만들고 싶은 카페 적어 두기** (3일 뒤 비교용)
- **2교시 — 창업자 자원: 잘하는 것 × 좋아하는 것 × 돈 낼 가능성**
  - 트렌드 키워드 10개 뽑고 네이버 데이터랩에서 1년 검색량 확인 (워크북 D1-1)
  - 내가 좋아하는 것·추구하는 것 적기 (워크북 D1-1)
- **3교시 — 사람들이 돈을 내는 순간(장면) 찾기** (출근 전·하원 후·선물·주말 간식…)
- **4교시 — 핵심 고객 4가지: 누구 + 언제 + 왜 + 무엇을**
  - 대표 고객 1명(가명·나이대·하는 일·주문·객단가) (워크북 D1-2)
- **5교시 — 브랜드 씨앗 카드 완성** ("나는 __한 사람에게 / __한 순간에 / __을 제공하는 브랜드")
  - 콘셉트 키워드 3개 · 콘셉트 한 줄 · "굳이 와야 할 이유" 한 문장 (워크북 D1-1·4·5)

**2. DAY 2 · 상품 (9/29)**
- **1교시 — 대표상품 1개 + 함께 팔 상품 2~4개** (기준 5가지: 원하는가·잘하는가·구분되는가·반복 생산·남는가)
  - 시그니처 조건 4가지 점검: 콘셉트 보임·사진 찍고 싶음·매일 같은 품질·재료 손실 적음 (워크북 D2-1)
- **2교시 — 메뉴 아이디어 10개 → 하나씩 제외**
- **3교시 — 원가와 1개당 남는 돈 계산** (재료·포장 → 인건비·월세·수수료·폐기 연결)
  - 시그니처 3개 원가율 표 — 35% 안 (워크북 D2-3)
  - 월 손익 미리보기 4칸: 예상 월매출·월세·인건비·공과금 (워크북 D2-3)
- **4교시 — 대표상품 가격 확정** (지불의사·경쟁가·구성·브랜드 느낌·판매 장소)
  - 메뉴명 + 25자 설명 (재료·시간·크기가 보이게) (워크북 D2-2)
- **5교시 — 첫 상품구성표(미니 메뉴판) 완성**
  - 메뉴판 카테고리 순서 · 전체 메뉴 12개 안팎 (워크북 D2-4)

**3. DAY 3 · 브랜드 (9/30)**
- **1교시 — 브랜드 이름: 내용 → 이름, 10 → 3 → 1** (기억·발음·검색·의미·확장성)
- **2교시 — 무드보드 1장** (색·사진·글씨·패키지·공간·말투 한 방향)
  - 대표 컬러 3개(색 코드) · 폰트 느낌 · 로고 방향 키워드 (워크북 D2-4)
- **3교시 — 브랜드 한 문장 + 소개 + 대표상품 설명 + 인스타 프로필·메뉴 문구**
  - 입소문 문장 · 계정명 · 소개글 150자 · 하이라이트 4~5개 (워크북 D3-1)
- **4교시 — 첫 판매 실험 설계** (예약판매·팝업·플리마켓·공유주방·SNS·지인 테스트 중 택)
- **5교시 — BRAND LAUNCH DAY 발표 + MY FIRST BRAND BOOK 완성**
  - 콘셉트 한 줄 최종 · "내일부터 할 세 가지" (워크북 D3-5)

**4. 첫 판매 실험 (수업 뒤 30일)**
- **30일 계획과 "내일부터 할 세 가지"를 여기 옮겨 적기** (기능 ⑥)
- **실험 방식·날짜·장소 정하기**
- **준비** — 시제품·포장·안내
  - 먼저 찍을 사진 5장(무엇·시간·각도) · 홍보 문구 1개 · 릴스 아이디어 1개 (워크북 D3-3)
- **실행**
- **결과 기록** — 몇 개 팔렸나, 반응, 다음에 바꿀 것

**5. 상권 · 상가 계약**
- **들어갈 동네 정하기** (시·구까지) (워크북 D1-3)
- **소상공인365 — 유동인구 특징 · 주요 고객층 캡처** (워크북 D1-3)
- **경쟁 카페 3곳 리뷰 읽기** (프랜차이즈 1 + 개인 2) (워크북 D1-3)
- **이 상권의 장점·단점 적기** (워크북 D1-3)
- **권리금·보증금·월세 확인** (2018)
- **주차·간판 자리·전기 용량 확인** (2018)
- **계약 전 등기부등본 확인** (2018)
- **임대차 계약**

**6. 비용 · 예산** (기능 ③ 비용 합계는 이 단계)
- **보증금** · **인테리어·공사** · **장비(오븐·쇼케이스·냉장)** · **간판·소방·전기 증설** · **초도 재료·포장재** · **예비비(총액의 10%)**
  - 월세는 매출의 15% 안인지 확인 (워크북 D2-3)

**7. 인허가 · 홍보 · 오픈**
- **위생교육 수료** · **영업신고(구청 위생과)** · **사업자등록(홈택스)** (2018)
- **스마트플레이스 등록 — 소개 문구 3~4줄 + 검색 키워드 5~8개** (워크북 D3-2)
- **콘텐츠 주제 3개 정하기** (워크북 D3-2)
- **오픈 4주 전 홍보 계획** (주 단위) (워크북 D3-4)
- **이웃 20명 시식 초대** (워크북 D3-4)

## 7. 예외 — 잘못 넣거나 평소와 다를 때

- 비용 칸에 글자나 음수를 넣으면 → 저장하지 않고 "숫자만 넣어 주세요" 안내
- 완료한 항목을 다시 누르면 → 바로 풀지 말고 "완료를 취소할까요?" 한 번 확인
- 같은 이름 + 같은 뒤 4자리가 두 명이면 → 두 번째 사람에게 "다른 4자리로" 안내 (워크북과 같은 방식)
- 강사가 기수 항목을 바꾸면 → 이미 체크한 기록은 그대로 두고, 새 항목만 추가됨
- 연결이 끊겼을 때 → 폰에 임시로 두고 연결되면 다시 저장 (워크북과 같은 방식)

## 8. 사람이 꼭 직접 해야 하는 것 (자동화 금지)

- 항목 "완료" 판단은 수강생 본인만 — 도구가 알아서 완료 처리하지 않는다
- 수강생에게 가는 알림·메시지는 강사가 내용을 보고 직접 보낸다 (나중에 알림이 생겨도 보내기 버튼은 사람)
- 질문에 대한 답은 강사가 적는다 (자동 답변 없음)

## 9. 성공 기준 — 숫자로

- 지금: 기수마다 몇 명 × 한 사람당 30분~1시간 상담, 같은 질문 반복. 비용 빠뜨림으로 예산 초과(액수는 사람마다)
- 목표: 물어 오면 강사가 표를 열어 **10분 안**에 답. 같은 질문 반복 0. 수강생이 비용 항목을 빠뜨리는 일 0 (기본 항목에 다 있음)
- 시연할 예시 입력 → 기대하는 결과: 가짜 수강생 3명(가명)이 입장 → 각자 항목 몇 개 체크 + 비용 입력 + 질문 1개 → 내 화면에 진행률·단계 비용 합계 → 강사 화면에 3명 표와 질문 1개 → 강사가 답 적으면 수강생 화면에 보임 → 폰을 닫고 다시 열어도 그대로
