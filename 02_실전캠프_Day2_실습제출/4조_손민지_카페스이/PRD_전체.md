# 전체 기획안(PRD) — 카페 창업 준비 체크리스트 (가칭)

- 가게 / 이름: 카페스이 / 손민지
- 조 주제: 창업 체크리스트 (창업의 모든 것) / AI면접관 / AI고객응대 트레이닝
- 한 줄 목표: [창업 준비자가] [실제 창업을 준비하는 동안] [단계별 할 일·예상 비용·진행 상황을 한곳에서 챙기고, 멘토(카페스이)는 누가 어디까지 했는지 한눈에 보는] 도구
- 마지막 수정: 2026-09-17

> **이 문서는 "다 만들었을 때의 모습"입니다.** 먼저 여기에 전체를 그린 뒤, 4번 기능 목록에 꼬리표를 붙여

## 1. 배경 — 최근 실제로 있었던 한 장면

- 장면: 2018년 카페스이 준비 때 — 메뉴·레시피 확정 → 상가 매물 → 창업 비용 계산 → 사업자등록·인허가 순서로 했다. 할 일은 수첩에 손으로 적고 나머지는 머릿속과 검색. 상가·인허가·관리 전부 힘들었지만 **비용이 가장 힘들었다**: 생각 못 한 항목이 뒤늦게 튀어나와 예산을 넘겼다.
  지금은 반대 자리 — 베이킹 클래스·강의를 들은 분들 중 창업하려는 분들이 카톡·전화로 준비 과정을 물어 온다. 각자 어디까지 했는지 기록이 없어서 **같은 질문을 또 받고, 서로 어디까지 했는지 모른다.**
- 얼마나 자주: 한 그룹마다 몇 명씩
- 한 번에 걸리는 시간: 한 사람당 30분~1시간 (카톡·전화로 자세히)
- 실수·빠뜨림: 물어봤던 걸 다시 물어봄 — 진행 상황을 서로 모름. 비용 항목 빠뜨림은 창업자 공통(민지님 본인 경험)

(배경 맥락) 카페스이가 진행하는 카페 창업 브랜딩 과정. 결과물은 브랜드 북(8~12p)과 30일 실행계획이고, 정리는 브랜드 북 사이트(cafe-brandbook)에 한다. 그 뒤의 실제 창업 준비는 정해진 도구가 없다.

## 2. 쓰는 사람과 역할

| 누가 | 언제 여나 | 무엇을 보나 | 무엇을 누르나 | 어떤 기기로 |
|---|---|---|---|---|
| 창업 준비자 (한 그룹 20명) | 창업 준비 중, 할 일 하나 끝낼 때·막힐 때 | 전체 체크리스트 한 장(스크롤), 그 안에 진행률·단계별 예상 비용 합계. 다른 이용자은 **진행률만** 보임 | 항목 체크, 비용·메모 입력, 막힌 항목에 질문 남기기 | 휴대폰 |
| 멘토 (카페스이 손민지) | 이용자가 카톡으로 물어 올 때 | 이용자 20명 표(진행률·마지막 체크한 날·막힌 단계) + 이용자 질문 모아 보기 | 이름 눌러 그 사람 체크리스트 열기, 질문에 답 적기, 항목 추가·순서 바꾸기 | 노트북 |

카페스이 운영 직원은 쓰지 않는다.

## 3. 흐름 — 지금 vs 도구를 쓰면

| 단계 | 지금 (쓰는 앱·파일) | 도구를 쓰면 |
|---|---|---|
| 1 | DAY 1~3으로 브랜드 정하기: 씨앗 카드 · 상품구성표 · 브랜드 북 · 30일 계획 | 그 결과물이 DAY 1~3 체크 항목이 되고, 30일 계획은 4단계 첫 항목으로 옮겨 적는다 |
| 2 | 각자 준비: 수첩·머릿속·검색. 막히면 멘토에게 카톡·전화(30분~1시간) | 단계별 목록에서 체크하고, 비용·메모를 적는다. 막힌 항목에 질문을 남긴다 |
| 3 | 멘토: 누가 어디까지 했는지 기록 없음 → 같은 질문을 또 받음 | 멘토 화면에서 이용자별 진행률과 막힌 단계를 보고, 질문 모아 보기에서 답한다 |

## 4. 전체 기능 목록

꼬리표: **[v1]** 오늘 만듦 · **[v2]** 써 본 뒤 더함 · **[나중]** 아직 아님

| 기능 | 설명 | 꼬리표 | 그렇게 나눈 이유 |
|---|---|---|---|
| 단계별 체크리스트 | **7단계** — DAY 1 브랜드 씨앗 → DAY 2 대표 상품 → DAY 3 브랜드 만들기 → 첫 판매 실험(30일) → 상권·상가 계약 → 비용·예산 → 인허가·홍보·오픈. 기본 항목은 아래 「① 기본 항목」 | [v1] | 본체. 이게 없으면 아무것도 안 됨 |
| 항목 체크·메모 | 끝낸 항목 체크(본인만), 항목마다 한 줄 메모 | [v1] | 한 바퀴에 필수. 30일 계획·세 가지도 당분간 메모로 대신 |
| 예상 비용 입력 → 합계 | 항목마다 예상 비용을 적으면 단계별·전체 합계. 빠뜨리기 쉬운 항목(간판·소방·초도 재료 등)은 기본 항목으로 들어 있음 | [v1] | 2018년에 가장 힘들었던 것(빠뜨린 비용). 이 도구의 이유 |
| 진행률 표시 | 단계별·전체 % — 첫 화면 위에 | [v1] | 첫 화면에 보이기로 정함. 계산만 하면 되어 비용 낮음 |
| 막힌 항목에 질문 남기기 | 항목 옆 "질문" 칸. 멘토가 답을 적으면 그 자리에 보임 | [v1] | 목표 "같은 질문 반복 0"의 핵심. 이용자→멘토 한 바퀴 |
| 30일 계획·세 가지 넣기 | 마지막에 정리한 30일 계획과 "내일부터 할 세 가지"를 4단계 첫 항목에 옮겨 적기 (처음엔 직접 입력, 나중엔 브랜드 북 사이트에서 자동) | [v2] | 전용 칸이 없어도 메모로 적을 수 있음. 브랜드 북 사이트 자동(⑫)과 함께 만드는 게 나음 |
| 참고 링크 모음 | 소상공인365·네이버 데이터랩·지도 등 자주 쓰는 링크를 해당 단계 옆에 | [v2] | 없어도 한 바퀴가 돎. 단계마다 링크를 정리할 시간이 따로 필요 |
| 멘토 현황 표 | 이용자 20명 — 진행률·마지막 체크한 날·막힌 단계. 이름 누르면 그 사람 체크리스트 | [v1] | 멘토 쪽 한 바퀴. 이름 눌러 열고 질문에 답하는 것까지 v1 |
| 멘토 질문 모아 보기 | 모든 이용자의 질문을 한 곳에, 답 안 한 것 먼저 | [v2] | 현황 표에서 이름 눌러 답할 수 있어 v1은 대체 가능. 사람이 늘면 필요 |
| 멘토 항목 편집 | 그룹마다 항목 추가·삭제·순서 바꾸기 (이미 체크한 기록은 그대로) | [v2] | 첫 그룹는 항목을 미리 넣어 두고 시작. 그룹가 늘면 필요 |
| 그룹 진행률 보기 (이용자끼리) | 같은 그룹 다른 사람의 진행률만 보임 (비용·메모·질문은 안 보임) | [v2] | 남의 것을 보이게 하려면 권한 나누기가 필요 → v1 범위 밖 |
| 브랜드 북 사이트 자동 연결 | cafe-brandbook에서 "세 가지"·정리한 답을 자동으로 가져옴 — 브랜드 북 사이트 구조를 맞춘 뒤에만 가능 | [v2] | 외부 자동 연결. 브랜드 북 사이트 구조를 맞춘 뒤에만 가능 |
| 알림 | 오래 멈춘 이용자에게 카톡·문자 | [나중] | 카톡 채널 개설·심사·비용이 들고, 지금은 필요가 낮음 |

**핵심 흐름 한 줄**: 이용자가 항목을 체크하고 비용·질문을 적으면 → 진행률과 비용 합계가 나오고 → 멘토 화면에 보여 답을 달 수 있고 → 다시 열어도 남아 있다.
**v1 6개**(체크리스트·체크/메모·비용 합계·진행률·질문·멘토 현황) · **v2 6개** · **나중 1개**. 자른 게 아니라 v2로 옮긴 것.

### ① 기본 항목 (7단계)

굵은 항목 = 꼭 해야 할 것(필수 체크). 그 아래 들여쓴 것 = 세부 항목(진행률에는 안 들어감).
1~3단계는 브랜드를 정하는 DAY 1·2·3, 4~7단계는 그 뒤 실제 창업 준비다. 두 갈래의 항목을 모두 담았다.

**1. DAY 1 · 브랜드 씨앗**
- **내가 만들고 싶은 카페 적어 두기** (나중에 비교해 보려고)
- **창업자 자원: 잘하는 것 × 좋아하는 것 × 돈 낼 가능성**
  - 트렌드 키워드 10개 뽑고 네이버 데이터랩에서 1년 검색량 확인
  - 내가 좋아하는 것·추구하는 것 적기
- **사람들이 돈을 내는 순간(장면) 찾기** (출근 전·하원 후·선물·주말 간식…)
- **핵심 고객 4가지: 누구 + 언제 + 왜 + 무엇을**
  - 대표 고객 1명(가명·나이대·하는 일·주문·객단가)
- **브랜드 씨앗 카드 완성** ("나는 __한 사람에게 / __한 순간에 / __을 제공하는 브랜드")
  - 콘셉트 키워드 3개 · 콘셉트 한 줄 · "굳이 와야 할 이유" 한 문장

**2. DAY 2 · 대표 상품**
- **대표상품 1개 + 함께 팔 상품 2~4개** (기준 5가지: 원하는가·잘하는가·구분되는가·반복 생산·남는가)
  - 시그니처 조건 4가지 점검: 콘셉트 보임·사진 찍고 싶음·매일 같은 품질·재료 손실 적음
- **메뉴 아이디어 10개 → 하나씩 제외**
- **원가와 1개당 남는 돈 계산** (재료·포장 → 인건비·월세·수수료·폐기 연결)
  - 시그니처 3개 원가율 표 — 35% 안
  - 월 손익 미리보기 4칸: 예상 월매출·월세·인건비·공과금
- **대표상품 가격 확정** (지불의사·경쟁가·구성·브랜드 느낌·판매 장소)
  - 메뉴명 + 25자 설명 (재료·시간·크기가 보이게)
- **음료·곁들임 메뉴를 5가지 안으로 줄이기** (재료 손실 막기)
- **지인 10명 시식 — 반응 받기**
- **첫 상품구성표(미니 메뉴판) 완성**
  - 메뉴판 카테고리 순서 · 전체 메뉴 12개 안팎

**3. DAY 3 · 브랜드 만들기**
- **브랜드 이름: 내용 → 이름, 10 → 3 → 1** (기억·발음·검색·의미·확장성)
- **무드보드 1장** (색·사진·글씨·패키지·공간·말투 한 방향)
  - 대표 컬러 3개(색 코드) · 폰트 느낌 · 로고 방향 키워드
- **브랜드 한 문장 + 소개 + 대표상품 설명 + 인스타 프로필·메뉴 문구**
  - 입소문 문장 · 계정명 · 소개글 150자 · 하이라이트 4~5개
- **첫 판매 실험 설계** (예약판매·팝업·플리마켓·공유주방·SNS·지인 테스트 중 택)
- **브랜드 북(8~12p) 완성**
  - 콘셉트 한 줄 최종 · "내일부터 할 세 가지"

**4. 첫 판매 실험 (시작 후 30일)**
- **30일 계획과 "내일부터 할 세 가지"를 여기 옮겨 적기** (기능 ⑥)
- **실험 방식·날짜·장소 정하기**
- **준비** — 시제품·포장·안내
  - 먼저 찍을 사진 5장(무엇·시간·각도) · 홍보 문구 1개 · 릴스 아이디어 1개
- **실행**
- **결과 기록** — 몇 개 팔렸나, 반응, 다음에 바꿀 것

**5. 상권 · 상가 계약**
- **들어갈 동네 정하기** (시·구까지)
- **소상공인365 — 유동인구 특징 · 주요 고객층 캡처**
- **직접 상권 걷기 — 평일 저녁·주말 오후 각 30분씩 지나가는 사람 세기**
- **경쟁 카페 3곳 리뷰 읽기** (프랜차이즈 1 + 개인 2)
- **이 상권의 장점·단점 적기**
- **권리금·보증금·월세 확인**
- **주차·간판 자리·전기 용량 확인**
- **계약 전 등기부등본 확인**
- **임대차 계약**

**6. 비용 · 예산** (기능 ③ 비용 합계는 이 단계)
- **보증금**
- **인테리어·공사**
- **장비** (오븐·쇼케이스·냉장)
- **간판·소방·전기 증설** ← 2018년에 빠뜨렸던 항목
- **초도 재료·포장재**
- **예비비** (총액의 10%)
  - 월세는 매출의 15% 안인지 확인

**7. 인허가 · 홍보 · 오픈**
- **위생교육 수료**
- **영업신고** (구청 위생과)
- **사업자등록** (홈택스)
- **배달앱·통신판매 신고** (필요할 때)
- **인스타 계정 만들고 소개글 올리기** (DAY 3에서 정한 계정명·소개글로)
- **스마트플레이스 등록 — 소개 문구 3~4줄 + 검색 키워드 5~8개**
- **콘텐츠 주제 3개 정하기**
- **오픈 4주 전 홍보 계획** (주 단위)
- **이웃 20명 시식 초대**
- **리뷰·단골이 생기게 할 장치 1개**
- **오픈**
- **오픈 후 첫 한 달 홍보 계획** (손님 사진·리뷰 요청·다음 달 예고)

## 7. 예외 — 잘못 넣거나 평소와 다를 때

- 비용 칸에 글자나 음수를 넣으면 → 저장하지 않고 "숫자만 넣어 주세요" 안내
- 완료한 항목을 다시 누르면 → 바로 풀지 말고 "완료를 취소할까요?" 한 번 확인
- 같은 이름 + 같은 뒤 4자리가 두 명이면 → 두 번째 사람에게 "다른 4자리로" 안내 (브랜드 북 사이트와 같은 방식)
- 멘토가 그룹 항목을 바꾸면 → 이미 체크한 기록은 그대로 두고, 새 항목만 추가됨
- 연결이 끊겼을 때 → 폰에 임시로 두고 연결되면 다시 저장 (브랜드 북 사이트와 같은 방식)

## 8. 사람이 꼭 직접 해야 하는 것 (자동화 금지)

- 항목 "완료" 판단은 이용자 본인만 — 도구가 알아서 완료 처리하지 않는다
- 이용자에게 가는 알림·메시지는 멘토가 내용을 보고 직접 보낸다 (나중에 알림이 생겨도 보내기 버튼은 사람)
- 질문에 대한 답은 멘토가 적는다 (자동 답변 없음)

## 9. 성공 기준 — 숫자로

- 지금: 그룹마다 몇 명 × 한 사람당 30분~1시간 상담, 같은 질문 반복. 비용 빠뜨림으로 예산 초과(액수는 사람마다)
- 목표: 물어 오면 멘토가 표를 열어 **10분 안**에 답. 같은 질문 반복 0. 이용자가 비용 항목을 빠뜨리는 일 0 (기본 항목에 다 있음)
- 시연할 예시 입력 → 기대하는 결과: 가짜 이용자 3명(가명)이 입장 → 각자 항목 몇 개 체크 + 비용 입력 + 질문 1개 → 내 화면에 진행률·단계 비용 합계 → 멘토 화면에 3명 표와 질문 1개 → 멘토가 답 적으면 이용자 화면에 보임 → 폰을 닫고 다시 열어도 그대로
