# 최종 제출 — ReTi AI 데모 (2026-10-10)

> 데모는 **가상 매장·가상 데이터**만 써요. 실제 매장·직원·금액·연락처는 없어요. 실제 앱 주소·자료와 완전히 분리된 별도 사이트예요.

- 알림·문자·이메일은 실제로 보내지 않고, AI 결과는 예시 문구로 보여요.

## 3. 시연 소개 흐름 — 시연 장면 3개

첫 화면 ‘데모입니다 · 가상 데이터’ → **데모 시작** → 대시보드 (오늘 할 일·이번 달 매출·‘여기부터 눌러 보세요’) 에서 시작해요.

### 장면 1. AI 월간 계획이 오늘 할 일이 되기까지
- **누를 곳:** 월간 마케팅 AI → 다음 달 계획 → ‘주말 가족 포장 세트(에어프라이어 재가열 안내 포함)’ 실행 카드 → **하기로 함** → 오늘 업무 → 전체 예정
- **전:** 다음 달 계획의 ‘주말 가족 포장 세트’가 아직 ‘후보’예요.
- **후:** ‘하기로 함’을 누르면 실행 카드가 진행 상태가 되고, 준비 업무(안내문 준비·가격·원가 다시 보기·사진·공지·시작·점검)가 날짜별로 오늘 업무에 이어져요.
- **한 줄:** “AI 가 제안하고, 사장님이 고르면, 준비할 일이 날짜별로 따라와요.”
- 사진: `발표자료_이미지/장면1_전_휴대폰.png`(후보) · `장면1_후_휴대폰.png`(하기로 함 · 준비 중) · `장면1_후_할일_휴대폰.png`(관련 할 일 7개) · `장면1_후_오늘업무_휴대폰.png` (패드 크기도 같은 이름 `_패드`) · 움직임 `장면1_움직임_휴대폰.gif`

### 장면 2. 새는 돈 찾기 — 배달 정산 미입금·수수료 차이
- **누를 곳:** 매출·성과 → 통장·카드 → **정산 맞추기** (지난달) → 쿠팡이츠 줄의 **이유를 알아요 (확인함)**
- **전:** 지난달 쿠팡이츠 정산이 2주치 덜 들어와 ‘확인 필요’, 배민은 예정보다 조금 적게 들어와 ‘조금 달라요’, 포스 카드 매출은 수수료 1.5% 차이라 ‘맞음’.
- **후:** 사장님 포털에서 확인한 내용을 ‘확인함’으로 남기면 그 달에는 다시 알리지 않아요.
- **한 줄:** “매출 파일과 통장을 맞춰서, 덜 들어온 돈을 먼저 알려 줘요.”
- 사진: `장면2_전_휴대폰.png` · `장면2_후_휴대폰.png` (+ `_패드`) · 움직임 `장면2_움직임_휴대폰.gif`

### 장면 3. 현장 문제 → 개선 업무 → 다시 확인
- **누를 곳:** 업무 → 체크리스트 → **미흡 · 재점검** → ‘마감 기록 — 마감 점검표 작성·서명’ → 기한·권고안 → **저장하고 ‘담당·기한·권고안 정함’으로** → **오늘 업무에 추가**
- **전:** 현장 점검에서 찾은 문제 4개(마감 점검표 빠짐·알레르기 안내 없음·메뉴판 가격 다름·튀김기름 기록 없음)가 ‘발견’ 상태예요.
- **후:** 담당·기한·권고안을 정하면 다음 단계로 넘어가고 오늘 업무에 들어가요. 지난달에 고친 원산지 표시판은 ‘다시 확인 통과’로 종결돼 있어요.
- **한 줄:** “현장에서 찾은 문제를 업무로 만들고, 다음 점검에서 다시 확인해 끝내요.”
- 사진: `장면3_전_휴대폰.png` · `장면3_후_휴대폰.png` (+ `_패드`) · 움직임 `장면3_움직임_휴대폰.gif`

왼쪽 메뉴의 매출·원가·손익·직원·급여·리뷰·네이버 플레이스 관리·성장캠퍼스를 짧게 짚어요. 모두 같은 가상 매장 자료로 이어져 있어요.

### (함께 보여 줄 때) 가게체크 — 매일 할 일이 빠진 날을 한눈에
- **누를 곳:** 오늘 탭(오픈 3개 완료 · 마감 남음) → 달력 탭(6일 전 마감 점검표·가스 빠짐, 4일 전 튀김기름 확인 빠짐, 월요일 휴무) → 리포트 탭(자주 빠뜨리는 항목)
- 사진: `가게체크_오늘_휴대폰.png` · `가게체크_달력_휴대폰.png` · `가게체크_리포트_휴대폰.png` (+ `_패드`)
