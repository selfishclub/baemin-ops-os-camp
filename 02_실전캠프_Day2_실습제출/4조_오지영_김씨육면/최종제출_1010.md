## 3. 시연 소개 흐름 — 링크를 열고 카테고리를 짚어 가며

만든 것 9가지 중 **추리고 연결해서 완결한 3가지**를 순서대로 보여 줍니다. 본부 → 손님 목소리 → 콘텐츠로 이어집니다.

| 순서 | 화면 (카테고리·탭) | 누르는 것 | 나오는 것 | 할 말 |
|---|---|---|---|---|
| 1 | 본부 · 홈 → 업무 지도 | 왼쪽 메뉴 「업무 지도」 | 영규(운영·고객) / 지영(마케팅·재무)이 맡은 일과 쓰는 도구가 한 장에 | "흩어진 도구를 한눈에 보이게 모았고, 꼭 필요한 일만 남겼어요." |
| 2 | 직원용 · 마감 보고 | 육수·우삼겹·재고 숫자 넣고 「보내기」 | 본부에 보고가 쌓이고 발주 목록이 자동 정리 · 텔레그램 알림 | "직원은 핸드폰으로 숫자만 넣으면 끝이에요. 마감하면 알림이 와요." |
| 3 | 만족도 조사 · 손님 화면 | 「시작하기」 → 표정 고르기 | 초로기가 묻고 30초 만에 응답 · 식사권 추첨 자동 응모 | "구글 폼에 쌓이기만 하던 응답을 테이블 오더에서 바로 받아요." |
| 4 | 관리자 · 대시보드 → 인사이트 | 상단 「인사이트」 | "또 올게요" 95%, 혼밥 손님 재방문 의향이 가장 낮음, 가장 감동적인 말 | "쌓아 둔 응답에서 다음 할 일이 나와요." |
| 5 | 디자인 메이커 · 디자인 작업 | 템플릿 고르고 사진·문구 바꾸기 | 틀이 고정된 캐러셀이 바로 완성 (영상도 넣을 수 있음) | "인사이트가 그대로 콘텐츠가 돼요. 캐러셀 한 편이 하루에서 1시간 이내로." |

| 방향 | 받은 것 · 찾은 것 | 그래서 고친 것 |
|---|---|---|
| 젬마쌤 피드백 | 페이히어 매출을 1년 단위로 · 카드에 뭘 샀는지 안 나오는 결제는 구매 내역과 대조 · 완성된 화면으로 피드백 받기 | 손익관리가 페이히어 파일의 시트를 전부 읽고 메뉴별 판매를 보여 주게 고침 · 쿠팡 전표를 승인번호로 카드 내역에 1:1로 붙임 · 만든 것을 허브 한 장에 모아 공유 |
| 다른 사장님 저장소 | 캠프에서 공유된 매장 운영 사이트 코드 · 다른 사장님 발표자료(시연 범위를 먼저 정하고 "직접 눌러 보세요"로 마무리) | 매장 운영 관리 시스템을 김씨육면에 맞게 고쳐 씀 · 발표를 시연 3가지로 좁히고 마지막 장에 체험 링크를 둠 |
| AI 대화 기반 인사이트 | "하고 싶은 게 많을수록 추리고 연결하는 게 중요하다" · 운영 서비스에 다 넣으려다 손이 안 갔다 | 9가지 중 3가지(본부·만족도 조사·디자인 메이커)를 골라 서로 잇고 완결 · 본부는 당장 필요한 마감 보고부터 만듦 |
| QA (가상 페르소나 · 실제 사용자) | 영규 사장님(실사용): "마감 보고, 매번 요청해야 하니까 불편해" | 직원 마감 보고를 숫자 입력 + 텔레그램 자동 알림으로 바꿈. 가상 페르소나 QA는 아직 못 했고, 데모판을 폰·패드 화면으로 열어 빈 화면을 점검함 |

- 반영하지 않은 의견과 이유: 손익관리 자동 분류는 두세 달 손으로 분류해 쌓은 뒤에 정리하기로 해서 이번엔 넣지 않았습니다. 알림은 카카오톡 대신 텔레그램으로 했습니다(젬마쌤 말씀대로 카톡 연동은 불안정해서).
