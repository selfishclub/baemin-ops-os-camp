# v2 제출서 — 김씨육면 / 오지영

## 만든 것

- 도구 이름: **김씨육면 손익관리**
- 한 줄 설명: **카드·통장·매출 파일을 올리면 1일부터 말일까지 펼쳐 놓고 손으로 분류하며, 그 분류가 쌓여 다음 달부터 저절로 붙는 손익 도구**
- 프로젝트 폴더: `v2/프로젝트/` (코드·문서·시연용 가짜 파일 전부)
- **바로 열기(설치 없이)**: https://kimssi-profit.vercel.app — 폰·다른 PC 어디서나. 자료는 각자 브라우저에 저장됩니다
- 실행 방법 (내 컴퓨터에서 돌릴 때):
  1. `cd v2/프로젝트` 에서 `npm install`
  2. `npm run dev` — http://localhost:3177
  3. 월 정산 → 불러오기에서 카드·통장 CSV를, 매출에서 페이히어 xlsx를 올립니다. 시연용 가짜 파일은 `fixtures/`에 있습니다
- 첫 화면 스크린샷: `결과물/첫화면.png` · `결과물/월정산.png`
  > **스크린샷의 숫자는 시연용 가짜 자료입니다.** 실제 금액이 공개 저장소에 남지 않도록 `fixtures/`의 가짜 파일로 다시 찍었습니다. 화면 구성은 실제와 같습니다
- Vercel 배포 주소: **https://kimssi-profit.vercel.app**

> **실제 자료는 저장소에 올리지 않았습니다.** 카드 내역·통장 거래내역·페이히어 매출표·쿠팡 전표는
> 전부 개인 금융 자료라 `data/` 폴더를 통째로 뺐습니다. 받아서 돌려 보실 때 비어 있는 게 정상이고,
> `fixtures/`의 가짜 파일로 시연할 수 있습니다.

## v1을 써 보고 바꾼 것

v1은 **기존 가계부에서 쓰던 대분류·소분류를 그대로 들고 와서**, 카드 파일을 올리면 자동으로 분류되게 만들었습니다.
7월 실제 자료를 넣어 보니 그게 맞지 않았습니다.

| v1을 써 보고 나온 불편 | v2에서 고친 것 |
|---|---|
| **카드사마다 읽는 방식이 달랐고, 체크카드는 또 달랐다.** 국민체크카드는 열어 보니 카드 내역서가 아니라 통장 입출금 내역이었다 | 통장용 해석기를 따로 만들었다. 통장은 '적요'가 거래처가 아니라 돈이 오간 방식이라, 적요를 읽으면 154건이 전부 `전자금융`으로만 보인다. **보낸분/받는분 칸**을 읽게 고쳤다 |
| **기존 분류 체계로는 카드 전표만 넣었을 때 100% 분류되지 않았다** | 코드에 박아 둔 기본 규칙을 걷어내고 **사장이 가르친 것만** 쓰게 했다. 백지에서 시작해 손으로 분류한 것이 쌓인다 |
| **분류한 것이 그 달 안에 갇혀 있었다.** 7월에 가르친 걸 8월이 몰랐다 | 배운 규칙을 **달 밖(전역)으로** 꺼냈다. 7월에 한 번 가르치면 8·9·10월 파일에 바로 붙는다 |
| **고정비를 따로 넣으니 카드·통장과 대조가 어렵고 이중으로 집계됐다** | **고정비 단계를 없앴다.** 임대료는 이미 통장에 찍혀 있다. 고정/변동은 계정 플래그로 계산하므로 따로 받을 이유가 없었다 |
| **분류하는 데 손이 너무 많이 갔다** (7월 통장만 거래 56건, 카드까지 230건) | 1일~말일 **일자별 표**로 펼치고, **검색·체크박스·한꺼번에 지정**을 넣었다. '토스'로 검색해 3건을 한 번에 확정할 수 있다 |
| 개인지출이 매장 지출에 섞였다 | 대분류 `개인` 하나로 빼고, **3단계에 따로 모아** 거기서 소분류를 정한다 |
| 가맹점명이 `쿠팡(쿠페이)`·`CJ올리브네트웍스PG인증 - …`처럼 무엇인지 알 수 없었다 | 쿠팡 전표 PDF를 **승인번호로 1:1** 붙여 상품명을 가져오고, 긴 이름은 **표시 이름**으로 줄인다. 원문은 그대로 둔다(대조에 쓰는 열쇠라서) |
| 매출이 통장 입금밖에 없어 홀·배달이 안 갈렸다 | **페이히어 매출표(xlsx)**를 읽어 매출 캘린더를 채운다. 홀·배민·쿠팡이츠가 갈린다 |
| 12개월 할부가 산 달에 전액 잡혀 그 달만 손익이 무너졌다 | 저장은 전액 그대로 두고 **집계할 때만 12달로 나눈다.** 카드 파일과 대조는 그대로 된다 |
| 화면이 한눈에 안 들어왔다 | 벤토 구조로 다시 짜고, 사이드바를 상단 바로 합쳤다. 메뉴 아래 1~12월 줄을 두어 달을 눌러 오간다 |

## 이번 버전에서 되는 것

**1. 불러오기**
- **카드 CSV** — 카드사마다 다른 머리글을 이름으로 찾는다(날짜·가맹점명·금액·취소일·할부개월·승인번호). EUC-KR, 머리글 줄바꿈, 한글 날짜 처리
- **통장 거래내역 CSV** — 카드와 열 구조가 달라 따로 읽는다. 적요·보낸분/받는분·송금메모·출금·입금
- **쿠팡 전표 PDF** — 브라우저에서 읽어 **승인번호로 카드 한 줄에 상품명을 붙인다**. 7월 전표 49장을 0.5초에 읽어 누락 0건
- **페이히어 매출표 xlsx** — 엑셀 라이브러리 없이 zip을 직접 풀어 읽는다. 배달앱 열을 읽어 배민·쿠팡이츠를 가른다
- 같은 파일을 두 번 올려도 **카드 구분+승인일+승인번호**로 걸러져 건수가 안 늘어난다
- 파일이 적어둔 합계와 대조한다. 정답을 코드에 박지 않고 파일이 스스로 검산한다

**2. 지출 분류 · 검수**
- 1일~말일 표. 거래가 없는 날도 줄로 남긴다(빠진 날이 보여야 파일이 제대로 들어왔는지 안다)
- 하루 안은 카드별로 묶어 종이 내역서와 한 줄씩 대조한다
- **제안 / 확정 두 단계** — 앱이 붙인 건 제안일 뿐, 사장이 확정해야 인정된다
- 검색·체크박스·전체 선택·한꺼번에 확정. `미분류만`·`미확정만`·날짜·대분류·소분류 필터
- 분류하는 동안 목록이 발밑에서 움직이지 않는다. 다 하면 `↻ 새로고침`으로 처리한 것을 걷는다
- 계정과목·소분류를 **그 자리에서 만든다**. 설정까지 다녀오지 않아도 된다

**3. 개인 지출** — 개인으로 뺀 것을 모아 소분류를 정한다. 잘못 넣었으면 대분류를 바꿔 되돌린다

**4. 입금 내역** — 통장 입금을 매출/기타수입/**지영 생활비**/제외로 가른다. 카드 결제대금과 대출 쌍은 자동으로 뺀다(카드 내역서에서 이미 잡힌 것이라 두 번 세면 안 된다)

**매출** — 판 날 기준 캘린더. 홀/배달 비중, 그 해 월별 막대

**월 요약 · 대시보드** — 매출·비용·영업이익·**실제로 남은 돈**(영업이익−개인지출)·프라임코스트, 계정과목 전월 대비, 비용 구성, 고정·변동

**설정** — 카테고리 설정, 표시 이름(붙여넣기·수정·삭제·내보내기), 고정비 템플릿, 데이터 초기화

## 아직 안 되는 것 / 다음에 할 것

- **자동 분류가 아직 안 된다.** 지금은 손으로 분류하고 그게 쌓이는 단계다. 7·8·9·10월을 쌓은 뒤 분류 체계를 다시 잡는 것이 목표다
- **분류 결과가 브라우저에만 있다.** 브라우저를 정리하면 날아간다. 내보내기·되불러오기가 없다
- **쿠팡은 매달 전표가 필요하다.** 상품의 80%가 매달 새것이라 한 번 배운 걸로 다음 달이 해결되지 않는다
- 현대카드 7월 파일에 거래 1건이 빠져 있는 것으로 보인다. 카드사 쪽 확인 필요
- 소분류가 거래처 축(투웰브·모노마트)과 품목 축(고기·새우)으로 섞여 있다. 두세 달 쌓은 뒤 정리하기로 했다
