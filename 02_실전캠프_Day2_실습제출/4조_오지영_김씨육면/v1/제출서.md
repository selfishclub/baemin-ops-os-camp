## 만든 것

- 도구 이름: **김씨육면 손익관리**
- 한 줄 설명: 카드 내역서를 올리면 계정과목별로 분류해 그 달 손익이 바로 보이는 도구
- 프로젝트 폴더: `v1/프로젝트/` (만든 폴더 통째로. 코드·설정·시연용 가짜 CSV·문서 전부. 10/2까지 여기)
- 실행 방법:
  1. `cd v1/프로젝트` 에서 `npm install`
  2. `npm run dev` — http://localhost:3177
  3. 월 정산 → 불러오기에서 카드 CSV를 올립니다. 시연용 가짜 파일은 `fixtures/`에 있습니다
- 첫 화면 스크린샷: `결과물/첫화면.png`
- 다른 스크린샷: `결과물/` 폴더
- Vercel 배포 주소 (오늘은 있으면. 만드는 법 → [부록](../../../03_인터넷에서_접근가능하게_만들기/부록_CLI로_바로_올리기.md)):
- 영상이 있으면 링크로 (파일은 올리지 않습니다):

> **실제 카드 내역은 저장소에 올리지 않았습니다.** 개인 금융 자료라 `data/` 폴더를 통째로 뺐습니다.

## 이번 버전에서 되는 것

- **카드 CSV 불러오기** — 카드사마다 다른 머리글을 이름으로 찾습니다(날짜·가맹점명·금액·취소일·할부개월·승인번호). 현대카드·국민카드 실제 파일로 확인
  - EUC-KR로 저장된 파일, 머리글 칸 안의 줄바꿈, `2026년 07월 31일` 같은 한글 날짜 처리
  - 취소 건은 집계에서 빼고 따로 보관, 할부는 원본 금액 그대로 두고 표시만
  - 머리글을 못 찾으면 **열을 직접 고르는 화면**이 뜹니다
  - 같은 파일을 두 번 올려도 **승인일+승인번호**로 걸러져 건수가 안 늘어납니다
- **파일 합계와 대조** — 카드사가 파일에 적어둔 합계와 파서 집계를 맞춰봅니다. 정답을 코드에 박지 않고 매달 파일이 스스로 검산합니다
  - 현대카드 파일: 파일이 적어둔 합계와 파서 집계가 1건 차이 → **파일 쪽에 빠진 거래가 있음**을 툴이 발견
  - 국민카드 파일: 건수는 맞는데 금액만 어긋남 → 엑셀 열 너비 때문에 `########`로 깨진 칸을 찾아내고 **그 금액까지 역산**
- **분류·검수** — 계정 → 소분류 → 거래처 → 건, 4단 트리. 거래처를 여러 개 골라 한 번에 계정을 주고 `거래처 기억`으로 다음 달 자동 적용
  - 금액 3만원 미만은 접되 **눌러서 펼치면 그대로 분류**됩니다 (건수로 접으면 1건짜리 큰 지출이 숨습니다)
  - 소분류 이름 바꾸기, 고른 건을 새 소분류로 묶기, 소분류·건별 메모
  - 쿠팡·세븐일레븐·배민은 계정이 채워져 있어도 [매장]/[집]을 묻습니다
- **고정비 템플릿 · 매출 입력** — 전월 복사 후 달라진 금액만 수정, 범위 밖이면 표시만. 채널별 매출액·입금액을 넣으면 수수료가 자동 계산됩니다
- **월 요약** — 매출·비용·영업이익, 프라임코스트·식재료비율·인건비율·임차료율과 전월 대비 %p, 계정과목 전월 대비, 지난달에 있었는데 이번 달 없는 고정비 경고
- **연간 대시보드** — 누적 KPI 5개, 월별 매출·비용 막대, 연간 비용 구성, 월별 정산 표
- **설정** — 계정과목·소분류 추가·수정·삭제, 고정비 템플릿, 인건비 소분류별 고정·변동 플래그, 월별 데이터 초기화(계정과목 설정은 남김)

### 기존 시트 대조로 확인한 것

7월 구글시트 가계부를 그대로 넣어 대조했습니다. 계정과목별 합계는 시트의 소계와 전부 일치했고, **시트가 ○○○,○○○원을 덜 잡고 있는 것**을 찾았습니다 — 변동비 소계에 지방세 ○○○,○○○원과 종소세 ○○○,○○○원이 빠져 있었습니다. 바로잡은 값은 매출 ○○○,○○○,○○○원 / 비용 ○○○,○○○,○○○원 / 영업이익 781,383(3.4%) / 프라임코스트 54.1%입니다.

```
npm run verify              # 기존 시트 대조 (자료가 있을 때)
npm run verify:card <파일>   # 카드 파일 대조
```
