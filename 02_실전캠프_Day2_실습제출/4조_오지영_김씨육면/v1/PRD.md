# 기획안(PRD) — 김씨육면 손익관리 · v1

- 가게 / 이름: 김씨육면 / 오지영
- 조 주제: 매장 월말정산 (인건비 계산, 손익관리)
- 이 버전의 목표 한 줄: **사장이 월말에 카드 내역 파일을 넣으면, 분류만 하고 그 달 손익이 바로 보이는 도구**

> 전체 그림은 `../PRD_전체.md`. 이 문서는 그중 **[v1]** 만 옮긴 것입니다.
> v1은 9/14~16에 이미 만들어 7월 실데이터로 검증까지 마쳤습니다. 코드는 개인 저장소(`accounts`)에 있습니다.

## 1. 무엇을 왜 만들고 싶나요?

구글시트 가계부에 카드 내역을 한 줄씩 옮겨 적는 월말 정산이 **반나절 이상** 걸렸고, 6개월 하는 동안 이런 일이 생겼다.

- 처음 두 달은 날짜를 다 채웠는데 여름엔 **거의 안 채우게 됐다.** 손입력은 반드시 무너진다
- `판관비`라고 잘못 적은 건들이 마케팅비에서 빠져 **그달 마케팅비가 한참 적게** 집계됐다. 오타 하나가 판단을 뒤집는다
- 소액 건이 건수의 대부분인데 금액은 얼마 안 된다 — 소액이 시간을 다 먹는다

## 2. 누가 언제 쓰나요?

**사장 둘**이 쓴다 — 집에서 정산 작업하는 나, 홀에서 확인·추가하는 남편. 동시에 작업하지는 않는다. 직원은 열지 않는다.

- 나: 월말 정산할 때 (월 1회, 집 노트북)
- 남편: 정산 뒤 확인하거나 빠진 걸 추가할 때, 중간에 손익 궁금할 때 (홀)
- v1은 이 노트북에서만 열리므로, 둘이 각자 기기에서 보는 건 v2(Supabase)에서
- 세무사에게는 결과만 전달 (v2에서 파일로)

## 3. 지금은 어떻게 하고 있나요?

1. 카드사 홈페이지에서 내역 받아 구글시트에 붙여넣기
2. 계정과목을 한 줄씩 손으로 타이핑
3. 전부 훑어보며 분류
4. 고정비를 매달 다시 입력
5. 수식으로 소계 계산 — 틀려도 모름
6. 지난달과 비교하려면 탭을 왔다갔다

## 4. 도구를 쓰면 어떤 일이 달라지나요?

**카드 CSV 한 달치를 올리면** → 카드사 형식이 달라도 자동으로 읽히고 → 거래처로 자동 분류돼서 → **검수 필요한 건만** 뜨고 → [매장]/[집] 정하고 고정비 복사하고 매출 넣고 마감 누르면 → **매출·비용·영업이익·프라임코스트가 전월 대비와 함께 뜬다.**

한 건 기준: `07-03 식자재 도매A 1,200,000`(예시) 한 줄이 들어오면 → `식자재비` 로 자동 분류 → 식자재비 합계와 식재료비율이 바로 움직인다.

## 5. v1에서 만들 것 — 오늘(9/17) 안에 되는 것만

- 기능 1 — **카드 파일 불러오기**: 카드사별 CSV를 머리글 이름으로 찾아 읽음. EUC-KR, 줄바꿈 머리글, 취소 건, 할부, `######` 깨진 금액 처리. 파일 안 합계와 대조
- 기능 2 — **자동 분류 · 검수**: 거래처→계정 매핑, 3만원 미만 접기, 쿠팡·세븐일레븐·배민은 [매장]/[집] 묻기, `거래처 기억`으로 다음 달 자동 적용
- 기능 3 — **고정비 템플릿 · 매출 입력**: 전월 복사 후 달라진 금액만 수정, 채널별 매출액·입금액, 수수료 자동 계산
- 기능 4 — **월 요약**: 매출·비용·영업이익, 프라임코스트·식재료비율·인건비율·임차료율, 전월 대비 %p, 누락·이상값 경고
- 기능 5 — **연간 대시보드**: 누적 KPI, 월별 매출·비용 막대, 연간 비용 구성
- 기능 6 — **설정**: 계정과목·소분류, 고정비 템플릿, 인건비 소분류별 고정·변동 플래그
- **이번에 하지 않을 것:** 인터넷 배포(Vercel·Supabase) · CSV/엑셀 내보내기 · 손익관리 심화 · 거래처 검색 · 홀 매출 끌어오기 · 할부 월 안분 · 알바 스케줄러 연동(인건비) → v2 / 범용화 → 나중

## 6. 완성됐다는 걸 어떻게 확인하나요?

- 시연할 예시 입력: 가짜 거래로 만든 카드 CSV 한 달치 (30건 안팎, 쿠팡·세븐일레븐 포함)
- 기대하는 결과: 올리면 전부 미분류로 들어옴 → 자동 분류 → 쿠팡·세븐일레븐만 검수에 뜸 → [매장]/[집] 지정 → 고정비 복사 → 매출 입력 → 마감 → 월 요약에 매출·비용·영업이익·프라임코스트가 뜸
- 잘못 입력했을 때:
  - 같은 파일 두 번 올림 → 승인일+승인번호로 걸러져 건수가 안 늘어남
  - 금액이 `######`인 줄 → 0이 아니라 "확인 필요"로 따로 표시
  - 머리글을 못 찾는 파일 → 열을 직접 고르는 화면이 뜸
  - 지난달 있던 고정비가 없음 → 막지 않고 경고만
- 다시 열었을 때 남아 있어야 할 것: 올린 거래 · 분류 결과 · 거래처 규칙 · 고정비 템플릿 · 마감된 달의 손익 (브라우저 localStorage, 규칙은 `mappings.json`으로 내보내 보관)
- **검증 방식**: 숫자가 맞는지가 아니라 **기존 시트의 오류를 툴이 잡아내는지**. 7월 실데이터로 대조해 시트의 문제 4가지(변동비 소계 누락, 세금 소계 라벨 중복, 대출이자·기부 소계 행 없음, 날짜가 거의 안 적힘)를 찾아냈다

## 7. v2에서 더할 것 (10/17까지 · API·외부 데이터 등)

- 다음에 추가할 기능 하나: **인터넷에서 열기** — Vercel 배포 + Supabase 저장. 지금은 이 노트북에서만 돌아간다
- 필요한 데이터나 외부 연결: Supabase 프로젝트 (키는 저장소에 올리지 않음), Vercel·GitHub 연결, CSV·엑셀 내보내기
- 사람이 직접 판단·확인해야 할 부분: 홀 매출을 t'order·POS에서 끌어올 수 있는지 · 손익을 어디까지 더 자세히 볼지 · 소분류 축 정리는 두세 달 더 쌓은 뒤

## 8. 절대 자동화하면 안 되는 것

- **급여 확정** — 계산은 보조할 수 있어도 "이 금액으로 지급"은 사람이. 주휴수당·최저임금은 노무 확인 필요
- **세무 신고** — 계정과목 분류는 도와도 신고 자체는 세무사
- **쿠팡·세븐일레븐·배민 건의 [매장]/[집] 판단** — 같은 가맹점에서 둘 다 나오므로 기계가 정할 수 없음
- **마감 버튼** — 자동으로 마감하지 않는다. 사람이 확인하고 누른다
