# 발표자료 이미지 — 시연 장면 3개 (데모판, 가상 자료)

장면마다 **전(누르기 전) → 중(입력 중) → 후(누른 뒤)** 를 폰(가로 390)과 패드(가로 820)로 찍었고, 같은 흐름을 10~12초 GIF로도 만들었습니다.

| 장면 | 화면 | 파일 |
|---|---|---|
| 1 | 업무 › 할 일 — 체크 → 이름 → "어떻게 했나요" | `장면1_전·중·후_폰.png` · `장면1_전·중·후_패드.png` · `장면1_폰.gif` · `장면1_패드.gif` |
| 2 | 업무 › 수조 관리표 — 폐사 3일 사용 기한 → 사용 완료 | `장면2_*` |
| 3 | 홈 › 테스트 안내 — 오류 신고 → 접수 목록 | `장면3_*` |

캡처는 헤드리스 크롬으로 자동 생성(https://haemonic-demo.vercel.app). 이름·숫자는 전부 가상입니다.
