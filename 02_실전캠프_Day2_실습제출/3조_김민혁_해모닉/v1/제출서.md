# v1 제출서 — 해모닉 / 김민혁

## 만든 것

- 도구 이름: **해모닉 운영 ERP v1**
- 한 줄 설명: 두 매장(안산·안양)의 할 일 · 수조 · 근무표 · 근로계약서 · 이슈 · 레시피 · 원가에 **회계(매출 입력 · 매출 분석 · 월 손익 · 인건비)** 를 붙여, 매장 운영과 돈 흐름을 앱 하나에서 기록하고 보는 도구
- 프로젝트 폴더: `v1/프로젝트/` (만든 폴더 통째로. 코드 · 시연용 샘플 CSV · 사용 설명서)
- 실행 방법:
  1. `v1/프로젝트/index.html` 을 크롬이나 엣지로 **더블클릭**해 엽니다. 설치 · 서버 · 인터넷이 필요 없습니다. (맥은 `실행하기.command`, 윈도우는 `start.bat` 을 눌러도 됩니다)
  2. 왼쪽 위 **안양점** 버튼을 누르고, 왼쪽 메뉴 **회계 › 매출 입력 › CSV 가져오기** 에서 `v1/프로젝트/샘플/매출_샘플.csv` 를 고르면 1년치 가짜 매출이 들어갑니다.
  3. **회계 › 매출 분석 · 월 손익 · 인건비** 를 차례로 엽니다. 기록은 브라우저 안에 자동 저장됩니다(저장 버튼 없음).
- 첫 화면 스크린샷: `결과물/첫화면.png` (할 일 화면)
- 다른 스크린샷: `결과물/매출분석.jpg` · `결과물/월손익.jpg` · `결과물/인건비.jpg`
- 영상이 있으면 링크로 (파일은 올리지 않습니다): 없음
- PRD 아티팩트 링크 (사전 과제로 만든 웹페이지, 있으면): 없음 (기획안은 `PRD_전체.md` · `v1/PRD.md` · `v2/PRD.md`)

## 이번 버전에서 되는 것

- **매출 입력** — 마감 루틴 "포스 마감·매출 정산"을 완료할 때 총주문 · 매장/배달/포장 매출 · 대게/킹크랩/랍스터 kg · 주류를 입력. 회계 › 매출 입력에서 날짜별 표(미입력 표시) · 수정 · 삭제. 같은 날 덮어쓰기 확인. 음수·글자는 저장 안 됨
- **CSV 가져오기** — 엑셀에서 변환한 `sales_daily.csv` 형식 그대로. 열 이름 검사 → 몇 건 들어가는지 미리 보여준 뒤 확인. 빈 줄 · 미래 날짜는 건너뜀
- **매출 분석** — 이번 달 · 지난 달 · 최근 90일 · 직접 지정. 총매출 · 일평균 · 객단가 · 총 kg, 일별 막대, 요일별 평균, 매장/배달/포장 비중, 품종별 kg
- **월 손익** — 매출 − 원가(매입) − 인건비 − 고정비 = 남는 돈. 원가율 45% · 인건비율 30% 경고, 지난달 비교, "근무표 없음" · "고정비 미설정" 안내
- **인건비** — 근무표 구간 시간 × 시급, 주 15시간 이상 주휴수당, 4대보험 사업주 부담 어림, 최저임금 경고. **이달 급여 확정**은 사장님만. 확정 뒤 근무표가 바뀌면 경고
- **설정** — 고정비(항목 · 금액 · 적용 시작 월), 4대보험 비율, 주휴수당 자동 계산 켜고 끄기. **직원 명단**에 급여 형태 · 금액 · 이메일
- 기존 운영 OS 전부 — 할 일 40개 루틴 · 완료자 기록 · 수조 관리표 · 월간 근무표 · 전자 근로계약서 · 공지사항 · 이슈 노트 · 레시피 · 원가 관리 · 백업
- 시연 확인: 9월 매출 3일(6,000,000원) + 매입 2건(1,000,000원) + 직원 2명 시급 10,320원 5일×8시간 + 임대료 2,500,000원 → 월 손익 **남는 돈 1,410,208원** (손으로 계산한 값과 일치)
