# 해모닉 업무 체크리스트

가게 PC에서 도는 시간대별 업무 체크리스트. 서버도 인터넷도 필요 없습니다.

## 실행

### 맥

`실행하기.command` 를 **더블클릭**하세요. 검은 창이 하나 뜨고 브라우저가 열립니다.

> 처음 한 번은 macOS가 "확인되지 않은 개발자" 라며 막을 수 있습니다.
> 그때는 파일을 **우클릭 → 열기 → 열기** 를 누르면 됩니다. 이후로는 더블클릭으로 열립니다.

**검은 창은 영업 중에 닫지 마세요.** 닫으면 앱이 꺼집니다. 브라우저 탭도 열어두세요 — 알림은 탭이 열려 있을 때만 갑니다.

바탕화면에 두고 쓰려면 `실행하기.command` 의 **가상본을 만들어**(우클릭 → 가상본 만들기) 바탕화면으로 옮기세요.

### 윈도우

`start.bat` 을 **더블클릭**하세요. 파이썬이 깔려 있으면 자동으로 서버를 띄우고, 없으면 파일을 바로 엽니다. **둘 다 정상 동작합니다.**

파이썬 없이 열렸을 때 앱 맨 위에 **빨간 경고**가 뜨면 그 브라우저가 저장을 막는 경우입니다. 크롬이나 엣지로 열어보세요. 경고가 없으면 그대로 쓰시면 됩니다.

바탕화면에 두려면 `실행하기.bat` 우클릭 → **바로 가기 만들기** 후 바탕화면으로 옮기세요.

> 윈도우 SmartScreen이 막으면 **추가 정보 → 실행**을 누르세요.

**BAT 파일이 안 보인다면** 둘 중 하나입니다.
>
> 1. 윈도우가 확장자를 숨겨서 이름이 **`start`** 로만 보입니다. 그게 맞는 파일입니다.
> 2. 맥에서 압축한 한글 파일명이 깨졌습니다. `실행하기.bat` 대신 **`start.bat`** 을 쓰세요 — 영문 이름이라 안 깨집니다.
>
> 그래도 없으면 **`index.html` 을 더블클릭**하세요. BAT 없이도 앱은 똑같이 돌아갑니다. BAT는 편의용일 뿐입니다.

### 리눅스 / 그 밖

`index.html` 을 브라우저로 열면 됩니다.

## 다른 PC로 옮기기

### 옮길 것 — `app` 폴더 통째로

폴더 안 5개 파일이 **같은 폴더에** 있어야 합니다. 하나라도 빠지면 안 열립니다.

```
index.html   style.css   data.js   store.js   app.js
```

여기에 실행 스크립트를 더합니다. 윈도우면 `start.bat`, 맥이면 `start-mac.command`.

USB, 카톡 나에게 보내기, 메일 첨부 — 아무거나 됩니다. 인터넷 연결도, 설치도 필요 없습니다.

> **맥에서 압축해 윈도우로 보낼 때는 한글 파일명이 깨집니다.** 맥 Finder의 "압축"은 한글 이름을 윈도우가 못 읽는 방식으로 저장합니다. 그래서 영문 이름 `start.bat` 을 같이 넣어뒀습니다. 압축을 푼 뒤 이름이 `?????` 처럼 깨진 파일이 있으면 그냥 지우고 `start.bat` 을 쓰시면 됩니다.

### ⚠️ 기록은 파일에 안 따라갑니다

**중요합니다.** 체크한 기록은 파일이 아니라 **그 PC 브라우저 안에** 있습니다. 파일만 옮기면 새 PC에서는 빈 상태로 열립니다.

기록까지 옮기려면:

1. **옛 PC** — 설정 탭 → `파일로 내보내기` → JSON 파일이 하나 받아집니다
2. 그 파일을 새 PC로 옮깁니다
3. **새 PC** — 앱을 열고 설정 탭 → `가져오기` → 그 파일 선택

루틴 수정 내역, 직원 목록, 지난 체크 기록이 전부 그대로 넘어갑니다.

## 처음 한 번만 할 일

1. **설정** 탭 → 직원 이름을 실제 이름으로 바꾸고, 인원을 추가합니다.
2. **설정** 탭 → 알림 **허용하기**를 누릅니다. 이걸 안 하면 알림이 안 옵니다.
3. **월간 근무표** → `빈 날 자동 채우기` 로 이번 달 편성을 한 번에 넣습니다.

## 매장 두 곳 (안산점 · 안양점)

사이드바 맨 위 버튼으로 매장을 전환합니다. **모든 화면 제목 옆에 지금 보고 있는 매장이 표시**됩니다.

매장 이름은 **안산점 · 안양점으로 고정**되어 있습니다.

**직원 명단은 매장마다 따로입니다.** 설정 탭 → 직원 → `안산점 직원` / `안양점 직원` 탭을 눌러 각 매장 직원을 입력합니다. 매장을 전환하지 않아도 한 화면에서 두 매장 직원을 다 관리할 수 있고, 편성·완료자 선택·마감 리포트에는 지금 매장의 직원만 나옵니다.

**직원·루틴·기록·원가·공지·이슈·레시피가 매장별로 완전히 분리**됩니다. 기존에 쓰던 기록은 안산점으로 자동 승계됩니다.

> 두 매장 PC의 데이터는 서로 자동으로 합쳐지지 않습니다. **매장 간 공유는 텔레그램 방**으로 합니다 — 공지·이슈를 등록할 때 "텔레그램에 공유"를 켜면 다른 매장 직원도 폰으로 바로 봅니다. 마감 리포트에도 매장 이름이 붙어 나갑니다.

### 휴대폰·태블릿에서 보기

같은 와이파이라면 PC에서 **`폰에서보기.command`**(윈도우는 `폰에서보기.bat`)로 켜세요. 검은 창에 `http://192.168.x.x:8777` 같은 주소가 찍히는데, 그 주소를 폰 브라우저에 그대로 입력하면 됩니다. 폰 홈 화면에 추가해 두면 앱처럼 열립니다.

- 처음 켤 때 방화벽 허용 창이 뜨면 **허용**을 누릅니다.
- 폰에서 체크한 기록은 **그 폰에만** 남습니다. PC 기록과 합쳐지지 않으니, 실제 체크는 한 기기에서만 하고 나머지는 보기용으로 쓰세요.
- 매장 밖(다른 와이파이·데이터)에서는 열리지 않습니다. 밖에서도 봐야 하면 `haemonic-app.html` 파일 하나를 카톡 '나에게 보내기'로 폰에 옮겨 여세요. 보기는 되고, 저장은 폰 브라우저에 따라 막힐 수 있습니다(막히면 화면 위에 빨간 안내가 뜹니다).

백업(설정 → 파일로 내보내기)은 이제 **두 매장을 한 파일**에 담습니다.

| 🔁 루틴 / 📊 기록 | 루틴 관리 · 완료율 통계 |

| 📖 레시피 관리 | 메뉴별 재료·조리 순서 |

| 📢 월간 공지 | 이번 달 공유사항, 📌 고정 |
| 📝 트러블시트 | 두 매장 공용 트러블 기록·해결 공유 |

## 할 일 — 시간별 작업

사장님 검토본(2026-09) 기준 **오픈 15 · 미들 10 · 마감 15 = 40개**가 들어 있습니다.
미들에 **15:00 휴식**(고객 없을 경우)이 한 칸 있습니다. 업무가 아니라서 **완료율 분모에 넣지 않고 알림도 울리지 않습니다.** 점선 카드로 표시됩니다.

- 맨 위 **오픈 / 미들 / 마감** 탭으로 시간대를 고릅니다. 각 탭에 그 시간대 완료 수가 보입니다.
- 그 아래 **진행률**, 역할 필터(전체/점장/홀/주방).
- 담당이 **`공통`** 인 업무(음식 맛 체크, 화장실 청소)는 그날 있는 사람이 하는 일이라 **역할 필터를 무엇으로 놓아도 항상 보입니다.** 근무 편성에서도 담당을 따지지 않습니다.
- 필터 줄 오른쪽 끝의 **`2인 기준` / `3인 기준`** 은 그날 담당이 어떻게 정해졌는지 알려줍니다.
  - 그날 **근무 편성이 있으면 편성 인원**을 따라갑니다 (3명 이상 → 3인 기준).
  - 편성 전에는 **매장 기본값**을 씁니다 — **안산점은 3인, 안양점은 2인**으로 설정돼 있습니다. `설정 → 인원 기준`에서 매장마다 바꿀 수 있습니다.
  - 칩을 누르면 편성 화면으로 갑니다.
- 2인일 때는 점장이 홀을 겸해 일이 몰리므로, 주방이 비는 시간대의 **홀 청소 4건(11:05 · 11:10 · 16:20 · 16:30)을 주방이 맡습니다.**
- 화면이 **좌우 두 칸**으로 나뉩니다. **왼쪽 `해야 할 일`** 은 시간 배지(11:00, 11:05 …)로 묶여 순서대로, **오른쪽 `완료`** 는 최근 완료한 것이 위로 쌓입니다.
- 왼쪽에서 네모를 누르면 오른쪽으로 넘어가고, 오른쪽에서 다시 누르면 왼쪽으로 돌아옵니다.
- 화면이 좁으면(태블릿·휴대폰) 두 칸이 위아래로 자동 배치됩니다.
- 카드를 누르면 **세부 안내·담당·보조·마감 시각**이 펼쳐집니다. 왼쪽 네모를 누르면 완료 처리됩니다.
- **중요 항목이 지나면** 시간대와 상관없이 맨 위 `지연` 묶음으로 올라옵니다.
- 맨 아래 **기본 운영 룰**이 접혀 있습니다. 맨 위에 사장님 **운영 방침 안내문**, 그 아래 **공통** 룰 8개, 그리고 보고 있는 매장의 **전용 룰**이 따로 나옵니다 (안양점 2개, 안산점은 아직 없음).

## 월간 근무표

- 달력에서 **날짜를 누르면 오른쪽 패널**에서 그날 편성을 바로 고칩니다 (근무자 추가, 역할 지정, 평일·주말 프리셋, 전날 복사).
- 각 날짜 칸에 근무자 이름과 상태가 보입니다 — `✓ 충족` / `! 홀 없음`(담당 빠짐) / `편성 없음`.
- **`빈 날 자동 채우기`** 를 누르면 오늘부터 월말까지 빈 날을 월~금 평일 프리셋, 토·일 주말 프리셋으로 한 번에 채웁니다. 이미 편성한 날과 지난 날은 건드리지 않습니다.
- 지난 날짜 칸에는 그날 완료율(예: 36/40)이 같이 표시되고, 날짜 상세의 `할 일 보기`로 그날 체크리스트로 바로 갑니다.
- 마감 리포트의 "근무" 줄과 담당 없는 역할 경고는 이 편성을 그대로 씁니다.

## 회계 — 매출 입력 · 매출 분석 · 월 손익 · 인건비 (2026-09-17 추가)

왼쪽 메뉴 **회계**. 매장마다 따로 기록됩니다.

- **매출 입력** — 마감 루틴 "포스 마감·매출 정산"을 완료할 때 뜨는 창에 총주문 · 매장/배달/포장 매출 · 대게/킹크랩/랍스터 kg · 주류를 넣으면 여기에 쌓입니다. 빠진 날은 표에서 줄을 눌러 채우고, 같은 날을 다시 넣으면 덮어쓸지 묻습니다. 빈칸은 0이 아니라 "미입력"입니다.
- **CSV 가져오기** — 엑셀을 변환한 `sales_daily.csv` 형식(열 이름 `날짜, 총매출` 필수, 나머지는 있으면 같이)을 읽습니다. 몇 건이 들어가는지 먼저 보여주고 확인을 받습니다. 시연용 가짜 파일이 `샘플/매출_샘플.csv`에 있습니다.
- **매출 분석** — 이번 달 · 지난 달 · 최근 90일 · 직접 지정. 총매출 · 일평균 · 객단가 · 총 kg, 일별 막대, 요일별 평균, 매장/배달/포장 비중, 품종별 kg.
- **월 손익** — 매출 − 원가(원가 관리의 매입) − 인건비 − 고정비 = 이달 남는 돈. 원가율 45% · 인건비율 30%를 넘으면 붉게. 고정비는 **설정 › 고정비**에 항목별 월 금액과 적용 시작 월을 한 번 적어두면 됩니다.
- **인건비** — 직원 명단에 급여 형태(시급/월급)와 금액을 넣으면, 근무표의 구간 시간을 더해 사람별 예상 급여가 나옵니다. 주 15시간 이상이면 주휴수당을 더하고, 4대보험 사업주 부담은 설정의 비율(기본 10%)로 어림합니다. **"이달 급여 확정"은 사장님이 직접** 누르며, 확정 뒤 근무표가 바뀌면 경고가 뜹니다. 휴게 시간과 "10시출근" 같은 시간 메모는 계산에 넣지 않으니 실제 지급 전에 확인하세요.

## 원가 관리

- 입고될 때마다 `+ 매입 입력` — 날짜·분류·품목·수량·금액·거래처. **직원 누구나** 입력하고, 누가 적었는지 남습니다.
- 월 상단에 **매입 총액 / 매출(마감 정산 입력분) / 원가율**이 자동 계산됩니다. 원가율이 45%를 넘으면 붉게 표시됩니다.
- 분류별 매입 막대로 어디에 돈이 나가는지 한눈에 보입니다. 내역을 누르면 수정·삭제.

## 갑각류 매입 인사이트 (운영)

원가 관리의 매입 기록(분류 대게·킹크랩·랍스터, kg 단위)으로 계산합니다. 거래처 원장이 있으면 원가 관리 › **CSV 가져오기**로 한 번에 넣으세요(형식은 `샘플/매입_샘플.csv`).

- **지금 단가 신호** — 최근 30일 평균 단가를 12개월 평균·작년 같은 시기와 비교해 저가/보통/고가.
- **다음 수요 일정** — 설·추석·가정의달·연말(+ 직접 추가한 일정) 앞 8주 단가 패턴을 과거 여러 해 평균해서, **보관 가능 일수**(화면 위, 기본 28일 = 3~4주) 안에서 가장 쌌던 주를 권장 매입 구간으로. 필요량은 지난 같은 일정 앞뒤 3일 판매 kg(없으면 그 주 매입 kg), 절감액은 필요량 × (일정 주간 단가 − 권장 주 단가).
- **월별 단가 표**(해별 나란히, 초록 = 중간값보다 15% 이상 쌈 · 빨강 = 15% 이상 비쌈), **주간 막대**(2년), **품목별 표**.
- 예측이 아니라 과거 평균입니다. 시세와 수조 상태를 보고 결정하세요.

## 트러블시트 (구 이슈 노트) — 안산점·안양점 공용

크고 작은 일을 그날 바로 적고, **어떻게 해결했는지까지** 남기는 곳입니다. **두 매장이 같은 목록을 봅니다.** 매장을 바꿔도 그대로 보이고, 카드마다 어느 매장 일인지 표시됩니다.

- 등록: 분류(고객 컴플레인/서비스/시설·장비/수조·상품/직원·교육/기타) + 상황 설명. "텔레그램에 공유"를 켜면 다른 매장도 봅니다.
- 누구나 **덧글**로 해본 것·알게 된 것을 보탭니다.
- **개선 완료**로 넘기려면 어떻게 개선했는지 한 줄을 반드시 남겨야 합니다 — 그게 남아야 다음 사람이 배웁니다. 완료된 이슈는 ✅ 개선 내용과 함께 보관됩니다.
- 잘잘못을 따지는 곳이 아니라 **다음에 어떻게 할지**를 남기는 곳입니다. 이 원칙이 지켜져야 직원들이 솔직하게 적습니다.

## 마감 리포트 — 매일 21:30 텔레그램 자동 전송

매일 **21:30**이 되면 하루 결과가 **텔레그램 단체방으로 자동 전송**됩니다. 사장님과 직원 모두 휴대폰으로 받습니다.

```
🦀 해모닉 8/28(금) 마감 리포트

전체 44/49  90%
중요 8/9  ⚠️ 미완료 1건

⚠️ 중요 미완료
· 수조 최종 점검 (점장)

⏳ 이후 예정 3건 — 포스 마감·매출 정산, 전원·문잠금 외

폐사 3마리 · 매출 1,250,000원
근무 김점장(점장·홀) 박주방(주방)
```

- 21:30 이후에 할 업무(마감 정산·문잠금 등)는 **"이후 예정"으로 따로 표시**되고 완료율에서 빠집니다. 아직 할 시간이 안 된 일로 점수가 깎이지 않습니다.
- 전송에 실패하면 **30초마다 자동 재시도**하고, 화면에 알림과 함께 복사용 문구가 떠서 수동으로도 보낼 수 있습니다.
- 조건: 21:30에 앱(브라우저 탭)이 열려 있고 인터넷이 연결되어 있어야 합니다. PC는 22:00에 꺼도 됩니다.

### 처음 설정 (약 5분, 한 번만)

1. 사장님·직원 모두 휴대폰에 **텔레그램** 앱 설치
2. 텔레그램에서 **@BotFather** 검색 → **/newbot** 전송 → 봇 이름 정하면 **토큰**이 나옴
3. 앱 설정 탭 → 마감 리포트 → **토큰 붙여넣기**
4. 사장님·직원 **단체방을 만들고 봇을 초대** → 그 방에 아무 메시지나 하나 올림
5. 설정 탭 → **대화방 찾기** → 단체방 선택 → **연결 테스트** → 휴대폰에 메시지 오면 끝

토큰은 이 PC에만 저장됩니다.

### 왜 카카오톡이 아닌가

카카오톡은 개인 앱이 자동으로 메시지를 보내는 걸 허용하지 않습니다 (사업자 알림톡은 업체 계약·건당 과금). 텔레그램은 이런 용도로 봇을 공식 지원하고 무료이며, 만료되는 것이 없어 한 번 설정하면 계속 갑니다.

### 21:30에 앱이 닫혀 있을까 봐

폴더의 스크립트를 **한 번만** 실행해 두면 매일 **21:25**에 앱이 자동으로 열립니다.

## 완료자 기록 방식 두 가지

설정 탭 → **완료자 기록** 에서 고릅니다.

| | 꺼짐 (기본) | 켜짐 |
|---|---|---|
| 방식 | 상단에서 **한 번** 고른 이름으로 계속 기록 | **체크할 때마다** 이름을 고름 |
| 장점 | 빠릅니다 | 기록이 정확합니다 |
| 단점 | 다른 사람이 체크해도 그 이름으로 남습니다 | 탭이 한 번 더 듭니다 |

**한 대의 PC를 둘이 나눠 쓰신다면 켜두시는 걸 권합니다.** 안 그러면 아침에 이름을 고른 사람 앞으로 하루치가 전부 기록됩니다.

켜두면 증빙이 없는 항목은 **이름만 누르면 바로 완료**됩니다. 확인 버튼을 거치지 않아 탭 한 번이면 끝입니다.

### 나중에 고치기

완료된 항목의 **⋯** → `완료자 바꾸기` 에서 언제든 바꿀 수 있습니다. 지난 날짜도 됩니다.

## 날짜 바꾸기

**오늘** 탭 맨 위의 날짜 칸을 누르면 달력이 열립니다. `‹` `›` 로 하루씩 옮길 수도 있고, `오늘로` 를 누르면 바로 돌아옵니다.

- **지난 날짜** — 빠뜨린 항목을 지금 채워 넣을 수 있습니다. 마감 업무를 다음 날 아침에 정리할 때 쓰세요. 안 한 항목엔 `미완료` 표시가 붙습니다.
- **앞으로의 날짜** — 그날 어떤 업무가 잡혀 있는지 미리 볼 수 있습니다(2주까지). 미리 체크할 수는 없습니다.
- **기록** 탭의 날짜 줄을 눌러도 그날로 바로 갑니다.

편성 탭도 보고 있는 날짜를 따라갑니다. 지난 날짜의 근무 편성을 나중에 고칠 수 있습니다.

> 날짜를 옮겨도 **알림은 항상 실제 오늘 기준**으로 갑니다. 지난 날짜를 열어둔 채로 있어도 그날 알림을 놓치지 않습니다.
>
> 앱을 새로 열면 항상 오늘·전체 보기로 시작합니다.

## 저장은 자동입니다

**저장 버튼은 없습니다.** 체크하는 순간 바로 저장됩니다. 지난 날짜를 열어 채워 넣은 것도 똑같이 즉시 저장됩니다. 창을 그냥 닫아도 됩니다.

아래 백업은 "저장"이 아니라 **다른 곳에 사본을 하나 떠두는 것**입니다. 성격이 다릅니다.

## ⚠️ 백업 — 이것만은 꼭

기록은 이 PC의 브라우저 안에만 있습니다. **브라우저 데이터(방문 기록·쿠키·사이트 데이터)를 지우면 전부 사라집니다.**

**주 1회, 설정 탭 → `파일로 내보내기`** 를 누르세요. 다운로드 폴더에 파일 하나가 생깁니다. 그 파일만 있으면 새 PC에서도 그대로 복원됩니다.

7일 넘게 백업을 안 하면 오늘 탭 맨 위에 안내가 뜹니다.

- 오른쪽 `⋯` → 이름·메모·담당 수정, **반복 주기 변경**(매일 ↔ 요일 지정), 사용 안 함으로 끄기

## 폐사 마릿수 — 어종별 입력

갑각류 체크 4곳(상태 확인·중간체크 2회·수조 최종 점검)을 완료할 때 **대게 / 킹크랩 / 랍스터** 세 칸에 나눠 입력합니다. 없으면 0 그대로 두면 됩니다.

- 항목에는 `폐사 대게 2 · 랍스터 1` 처럼 남고, 0이면 `폐사 없음`으로 표시됩니다.
- 마감 리포트에는 `폐사 3마리 (대게 2 · 랍스터 1)` 로 나갑니다.
- 기록 탭에 어종별 30일 합계가 표로 나옵니다. 특정 어종만 올라가면 그 수조를 의심하세요.
- 어종을 바꾸려면 `data.js` 맨 위 `SPECIES` 목록만 고치면 됩니다. 예전 기록(총 마릿수만 적던 것)도 그대로 집계에 포함됩니다.
