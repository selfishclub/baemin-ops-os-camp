## 10/9 가상 QA — 데모판 (https://haemonic-demo.vercel.app)

- 페르소나: 첫 주차 신입 홀 직원. 매장 포스(1024×768)에서 미들 시간에 처음 엶. 목표: 내 담당 할 일 하나 끝내고, 이상한 점 신고하기
- 해 본 것: 업무 › 할 일 › 미들 → "룸 벽면·오염 구역 청소" 체크 → 이름 고르기 → "어떻게 했나요" 입력 → 완료 칸으로 이동 확인 / 카드 ⋯ 메뉴 / 테스트 안내 › 오류 신고 쓰기 → 익명 저장 → 접수 목록 확인
- 잘 된 것: 이름·메모를 안 넣으면 완료가 안 됨(의도대로). 완료 카드에 이름·시각·메모가 바로 보임. 직원 잠금 상태에서 ⋯ 메뉴는 "오늘만 건너뛰기 · 오늘 메모"만 보임. 저장한 신고가 양식 바로 아래 목록 맨 위에 남음
- 막힌 것 → 고침(836aedc): ① 데모판에서 신고 저장 뒤 "텔레그램 전송 실패" 빨간 안내 → 데모에서는 "데모라 보내지 않습니다" 안내로 ② 양식을 그대로 둔 줄("매장 아이패드 / 내 폰")이 목록 요약으로 나옴 → 손대지 않은 양식 줄은 요약에서 뺌 ③ 벽 청소에도 메모 예시가 "수조 3번 온도 1도 내림" → 수조·갑각류 업무가 아니면 청소·정리 예시로
- 실제 직원에게 물어볼 것: 완료할 때마다 메모를 쓰는 게 바쁜 시간에 부담인지 / 이름 고르기 버튼이 손가락으로 누르기 충분히 큰지 / 테스트 안내 페이지를 하루에 몇 번 여는지
