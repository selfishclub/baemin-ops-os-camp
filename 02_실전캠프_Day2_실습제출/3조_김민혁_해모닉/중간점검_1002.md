# 10/2 온라인 중간 점검 — 결과물과 만든 과정 공유 — 해모닉 / 김민혁

**v2 완성과 1~5번은 10/1(목) 밤 11시 59분까지** push합니다. 점검 때 이 파일을 화면에 띄우고 5분 동안 결과물과 만든 과정을 공유합니다.
6번은 점검 당일, 피드백을 주고받은 뒤 채웁니다. 아직 안 된 것은 '아직 안 됨'이라고 적으면 됩니다.

- 내 도구 이름 / 누가 언제 쓰나요?: **해모닉 업무 체크리스트 (매장 운영 ERP)** — 안산점·안양점 직원이 매일 오픈~마감 시간대마다 아이패드로 할 일을 체크하고, 사장님은 폰 텔레그램으로 즉시 알림과 21:30 리포트를 받습니다. 사장님은 PC·폰에서 근무표·교육·회계를 봅니다.
- 해결하려는 문제 / 내 가게에서 바라는 변화 (한 문장): 사장님이 매장에 없어도 **중요 업무(갑각류 상태·수조·마감 정산)가 됐는지 바로 알고**, 직원은 **묻지 않고도 오늘 할 일과 순서를 알며**, 두 매장이 같은 기준으로 돌아가게 하는 것.

## 0. 이 도구로 지금 실제로 할 수 있는 것

**직원이 매일 (아이패드·폰)**
- 오픈·미들·마감 시간대별 오늘 할 일을 보고 체크한다. 담당(갑각류 관리자·홀·주방)은 그날 근무 인원에 맞춰 자동으로 정해진다
- 중요 업무(갑각류 상태 확인·염도·수조·마감 정산 등 9건)는 시간이 지나면 지연으로 뜨고, 완료할 때 폐사 마릿수·매출 같은 수치를 함께 적는다
- 누가 했는지 이름을 고르고, 오늘만 할 일을 추가하고, 못 한 일은 사유와 함께 건너뛴다
- 수조 관리표에 해수 교체·청소·입고를 기록하고 주기가 지난 칸을 색으로 본다
- 공지사항 필독·월간 공지를 읽고, 트러블(컴플레인·시설·수조 문제)을 등록해 두 매장이 같이 본다
- 교육 영상을 코스 순서대로 보고(여정 맵으로 내 위치 확인), 보고 나서 "내일 적용할 것 한 줄"을 적어 개인 미션으로 만들고, 해내면 "해냈어요"를 누른다
- 레시피를 찾아본다

**사장님이 (폰·PC)**
- 텔레그램으로 중요 업무 완료·지연 알림을 즉시 받고, 매일 21:30 마감 리포트(완료율·중요 미완료·폐사·매출)를 받는다 — 매장 PC가 꺼져 있어도
- 기록 화면에서 날짜별 완료율·시간대별·누가 몇 건·중요 업무 지연·폐사 추이를 본다
- 할 일 순서·시각·이름을 PIN을 풀고 바꾼다. 업무를 공통/안산점만/안양점만으로 나누고 새 업무를 만든다. 바꾼 것은 모든 기기·내일부터 적용된다
- 월간 근무표를 오전·오후 조 요일 패턴으로 한 달 채우고 예외(병원·대체·명절)만 고친다. 인쇄용 보기, 변경 이력
- 직원 명단·근로계약서(작성·전자 서명·보관)·급여명세서(4대보험 요율 반영)·보건증 기한·위생교육 일정을 관리한다
- 직원별 교육 진행률·배지와 개인 미션을 보고, 확인 대기 미션을 승인한다. 승인·월간 달성은 텔레그램 방에 공유된다
- 매출을 입력하거나 CSV로 가져오고(매장·배달·포장 매출, 품종별 매장 kg·배달 kg), 매출 분석·월 손익·인건비를 본다
- 갑각류 매입 인사이트에서 과거 매입·매출로 명절 전 매입 시기와 양을 가늠한다
- 원가 관리에 고정비를 넣고 손익을 본다
- 설정에서 서버 연결·텔레그램·알림 예산·인원 기준·오후 조 시작 시각·백업(내보내기/가져오기)을 관리한다

**시스템이 알아서**
- 모든 기기가 같은 기록을 실시간으로 본다. 처음 연결하는 기기의 기록은 서버와 합쳐진다
- 주 n회 업무는 해당 없는 요일에 자동 완료로 처리된다
- 루틴이 새 판으로 올라가도 사장님이 고친 이름·메모·순서·시각·매장 구분은 유지된다

## 2. 만든 과정 — 다른 사장님이 따라 할 수 있게

1. 계획을 어떻게 고쳤나요?
   - v2 PRD는 "Cloudflare + 공용 비밀번호 + Supabase"였는데, 이미 쓰던 Vercel은 그대로 두고 **저장 층만 Supabase**로 바꿨습니다. 카페24 서버도 검토했지만 실시간 동기화·무료·관리 부담에서 Supabase가 맞았습니다.
   - 사용메모에서 "낮 2명·저녁 3명" 문제가 나와서, 계획에 없던 **오전·오후 조 근무표**를 알림보다 먼저 끝냈습니다.
   - 교육은 "영상 목록"에서 **코스 + 개인 미션**으로 방향을 바꿨습니다. 봤는지 확인하는 방법을 묻다가 퀴즈 대신 "적용할 것 한 줄"로 정했습니다.
2. 만든 순서 (세 줄 안팎):
   - 서버(Supabase 표·실시간·첫 연결 합치기) → 텔레그램 알림을 서버가 보내게(SQL·cron) → 두 매장 텔레그램 연결·전체 시험
   - 근무표 오전·오후 조 → 시간대별 인원 기준 → 할 일 순서 잠금·시각·이름 편집 → 매장별 업무 구분
   - 교육 세분화 → 학습 코스 → 재생 확인 + 개인 미션
3. **AI에게 한 말 중 결과를 크게 바꾼 것** (원문 그대로):
   > "웹에서 실시간으로 보는 형식으로 하고 싶어."
   > "낮에 2명, 저녁에 3명인 경우가 있는데 현재 작성한 건 낮에도 3명인 경우로 되어 있거든. 어떻게 하면 좋을까?"
   > "퀴즈 대신 '내일 매장에서 적용할 것 한 가지'를 한 줄 적기 … 직원별 월간미션 형태로 … 교육과 연계해서 개인미션이라는것 만들어줘"
4. 막혔다가 푼 것과 푼 방법:
   - 서버 로그인이 "비밀번호가 틀렸다"고만 나옴 → 원인은 비밀번호가 아니라 **브라우저가 외부 라이브러리(CDN)를 막은 것** → 라이브러리를 사이트 안(vendor/)에 포함
   - 텔레그램 "대화방 찾기"가 안 됨 → 봇 **프라이버시 모드** 때문에 단체방의 `/hello`가 봇에 안 감 → `/hello@봇이름`처럼 봇을 지목해 보내고, 찾기 자체를 서버 경유로
   - 서버 리포트 SQL이 "malformed array literal" 오류 → 문자열을 배열에 붙일 때 `array_append`로 명시
   - 안산점 토큰 칸에 Supabase 키를 잘못 붙여 넣어 "Not Found" → 두 값의 모양을 비교해 찾아냄
