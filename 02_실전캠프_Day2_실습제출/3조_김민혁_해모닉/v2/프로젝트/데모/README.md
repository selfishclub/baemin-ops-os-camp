- 되돌리기: 맨 위 보라색 줄의 **🔄 데모 데이터 다시 채우기** (저장소를 지우고 오늘 날짜 기준으로 새로 만듦). 날짜가 바뀌어 처음 열어도 자동으로 다시 채움.

## 파일

| 파일 | 역할 |
|---|---|
| `demo.js` | **자료를 만드는 코드 전부.** 위쪽 `HM_DEMO_CFG` 가 숫자·이름·기간·일부러 넣은 일, 아래 `HM_DEMO_SEED` 가 그걸로 두 매장 자료를 만든다. 앱(app.js)은 `demoSeed()` 에서 이 함수를 부르고 저장만 한다 |
| `build_demo.py` | 실제 앱 파일을 복사하고 `demo.js` 한 줄을 끼워 `dist/` 를 만든다 |
| `dist/` | 빌드 결과. **자기 git 저장소**(GitHub `SUSANOO123/haemonic-demo`) → Vercel 프로젝트 `haemonic-demo` 가 push 때마다 자동 배포 |

## 숫자 바꾸고 올리기

```bash
# 1) 데모/demo.js 의 HM_DEMO_CFG 를 고친다 (직원 이름·매출 크기·요일 배율·공휴일·일부러 넣은 일·시연 장면)
# 2) 빌드 → 커밋 → push (Vercel 이 1분 안에 반영)
python3 데모/build_demo.py && cd 데모/dist && git add -A && git commit -m "데모 갱신" && git push
```

앱 코드(app.js 등)를 고친 뒤에도 같은 명령으로 데모판이 따라간다. `index.html` 의 `?v=` 판 번호를 올려야 캐시가 갱신된다.
