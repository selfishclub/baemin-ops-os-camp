## 이번 버전에서 되는 것

**직원 (매장 포스·아이패드)**
- **할 일** — 오픈·미들·마감 시간대별 체크. 완료할 때마다 **이름 고르기 + "어떻게 했나요" 메모(필수)**. 담당은 그날 근무표 인원대로 자동(안양점 2인은 관리자·주방 반반, 힘든 일 💪은 관리자). 주 n회 업무는 해당 요일에만. 다른 기기 저장이 와도 보던 시간대 탭 유지.
- **수조 관리표** — 해수 교체·청소 주기, **폐사 기록과 3일 사용 기한 표시·사용 완료**.
- **테스트 안내** — 테스트 기간 행동 요령, 오류·건의 양식, **접수 목록(전체·접수·처리 완료·오류·건의 필터, 전체 이력)**. 건의는 팀원과 상의 필수.
- **공유 게시판** — 두 매장 공용, 익명 글·덧글, 텔레그램 공유.
- **매출 입력** — 매장·배달 주문 건 분리(총주문 자동), 매장·배달·포장 매출로 총매출 자동, 주류는 "그중 주류".
- **원가 관리(식자재)** — 직원이 실제 매입하는 식자재·소모품만(갑각류 제외).
- **교육 자료** — 66편·5개 코스, 영상 90% 재생 → O/X 퀴즈 → 개인 미션. 등록 안 된 개인 폰에서도 교육 자료는 열림.

**사장님**
- **대시보드** — 안산·안양 나란히 점수판(원형 게이지, 중요 지연·일반 지연·수조·미션), 시간대별 진행, 7일 완료율, 수조·폐사, 오늘 근무, 교육·미션, 이달 랭킹. 포스 1024×768에 맞춤, 왼쪽 메뉴 자동 숨김.
- **텔레그램** — 중요 업무 완료·지연 즉시, 공지·게시판 공유, **매일 21:50 마감 리포트 + 오늘 평가**(🟢🟡🔴 등급, 7일 평균 비교, 잘한 것·아쉬운 것, 내일 한 가지, 사람별 완료 수). 서버(pg_cron)가 보내서 매장 PC가 꺼져 있어도 감.
- **보안** — **기기 등록제**(등록한 기기만 기록이 보임, 열쇠를 세 곳에 저장 + 기기 전용 주소로 자동 복구), **사장님 비밀번호 하나**(해시만 저장, 5분 무사용 자동 잠김), **직원 잠금**(직원은 체크·메모만, 업무 추가·수정·삭제 불가).
- **인사관리** — 직원 명단, 월간 근무표(오전·오후 조 패턴, 이름 눌러 넣기), 근로계약서 전자 서명, 급여명세서, 보건증·위생교육.
- **운영·회계** — 총원가(갑각류 + 식자재), 갑각류 매입 인사이트, 매출 분석, 월 손익, 인건비.
- **데모판** — 서버 없이 가짜 두 매장 자료로 도는 공유회용 주소.
