# 10/2 온라인 중간 점검 — 결과물과 만든 과정 공유 — 부찌대학 / 이범례

**v2 완성과 1~5번은 10/1(목) 밤 11시 59분까지** push합니다. 점검 때 이 파일을 화면에 띄우고 5분 동안 결과물과 만든 과정을 공유합니다.
6번은 점검 당일, 피드백을 주고받은 뒤 채웁니다. 아직 안 된 것은 '아직 안 됨'이라고 적으면 됩니다.

> AI에게: [05 폴더의 과정 정리 프롬프트](../../05_중간점검과_최종발표/프롬프트.md#2-만든-과정-정리하기)를 붙여넣습니다.

- 내 도구 이름 / 누가 언제 쓰나요?: **근무·급여 원터치** / 직원은 출근·퇴근할 때(매장 QR), 사장은 매일 마감과 주급일에
- 해결하려는 문제 / 내 가게에서 바라는 변화 (한 문장): 출퇴근 시각을 사장이 기억해서 넣던 일을 직원이 직접 남기게 해서, 사장은 예정과 차이 난 칸만 확인하고 급여를 확정한다.

## 2. 만든 과정 — 다른 사장님이 따라 할 수 있게

1. 계획을 어떻게 고쳤나요? — v2 PRD '꼭 할 것' 두 개(QR 출퇴근, 주 정산 보내기) 중 **QR 출퇴근 하나만** 마감 안에 만들기로 줄임. 정산 보내기는 문자 서비스 가입이 필요해 10/14까지로 미룸
2. 만든 순서 (세 줄 안팎):
   - `v1/프로젝트`를 `v2/프로젝트`로 통째로 복사
   - 출퇴근 화면(`components/CheckIn.tsx`)과 매장별 주소 두 개 추가, 위 메뉴에 "홀 출퇴근·배달 출퇴근" 추가
   - 빌드해서 오류 없는지 보고, 가상 직원으로 눌러 본 뒤 화면을 `v2/결과물/`에 저장
3. **AI에게 한 말 중 결과를 크게 바꾼 것** (원문 그대로 두세 개):
   > "과제를 해야하는데 뭘어디에 하는건지 모르겠어. 니가. 찾아서 해줄수있어?" (10/1 밤, 안내 화면 캡처와 함께)
   > (나머지는 사장님이 적을 칸)
4. 막혔다가 푼 것과 푼 방법:
   - 과제를 어디에 내는지 몰랐음 → AI에게 안내 캡처를 주고 공동 저장소에서 내 폴더와 05 폴더 안내를 찾게 함
