# 전체 기획안(PRD) — 근무·급여 원터치

- 가게 / 이름: 부찌대학 / 이범례

- 한 줄 목표: 사장님 두 분이 매장 마감 때 예정과 다른 출퇴근만 넣으면, 주급·월급 직원별·사업장별 세전 급여가 한 화면에 나오는 도구

## 1. 배경 — 최근 실제로 있었던 한 장면

- 장면: 가장 최근 주급 계산일. ① 종이 근무표(예정 시간만 적혀 있음)와 수첩을 펴고 → ② 직원 한 명 한 명과 카톡으로 "그날 몇 시에 왔고 몇 시에 갔는지"를 서로 맞추고(크로스체크) → ③ 직원별로 근무시간 − 휴게시간을 계산기로 더하고, 주 15시간 넘는지 봐서 주휴수당을 따로 계산하고 → ④ 종이에 금액을 적어 사진으로 찍어 카톡으로 세무사에게 전달. ②와 ③ 둘 다 시간이 많이 든다.
- 얼마나 자주: **주급 직원 7~8명은 매주**, 월급 직원 3~4명은 매월. 직원은 모두 11명 안팎.
- 한 번에 걸리는 시간: 주급 한 번에 30분~1시간 (카톡 맞추기 + 계산기 + 종이 정리)
- 실수·빠뜨림: 급여를 준 뒤 직원이 "그날 더 일했는데요"라고 말해 줘서 다시 계산한 적 있음. 시급제라 출퇴근 시각에 따라 급여가 매번 달라지는데, 그 차이가 어디에도 정리돼 있지 않은 게 원인.
- 앞으로: 홀 매장과 배달전문 매장을 사업자로 나눔 → 급여도 사업장별로 따로 관리해야 함. 두 매장은 이미 장소가 다르고 기기도 따로 있음.

## 7. 예외 — 잘못 넣거나 평소와 다를 때

- 퇴근이 출근보다 빠르면 → "시간을 다시 확인해 주세요", 계산하지 않음
- 휴게시간이 근무시간보다 길면 → 경고
- 시급이 최저시급보다 낮으면 → 빨간 경고 (저장은 되지만 눈에 띄게)
- 출근·퇴근·휴게 중 하나라도 빈칸이면 → 0시간으로 계산하지 않고 "미입력"으로 표시
- 그 주에 결근이 있으면 → 주휴수당 0원
- 실제 시각이 예정과 10분 이상 다르면 → 노란 표시, 사장님이 인정/조정할 때까지 "확인 필요"
- 조정을 골랐는데 사유가 비어 있으면 → 저장하지 않고 사유 요청

## 9. 성공 기준 — 숫자로

- 지금: 주급 계산 매주 30분~1시간 + 급여 뒤 다시 계산하는 일 가끔
- 목표: 매일 마감 입력 1~2분 + 주급일 확인 10분 이내, 급여 뒤 다시 계산 0건
- 시연할 예시 입력 → 기대하는 결과 (가상 직원, 시급 10,320원 = 2026년 최저시급):
  - A (홀·오전 설거지·주급): 월~금 09:00~16:00, 휴게 30분 → 주 32.5시간, 주휴 67,080원, **주 402,480원**
  - B (배달·저녁 포장·주급): 월~금 17:00~22:00, 휴게 30분 → 주 22.5시간, 주휴 46,440원, **주 278,640원**
  - C (배달·학생·주급): 금 5시간, 휴게 30분 → 주 4.5시간, 주휴 없음, **주 46,440원**
  - A 수요일 결근 → 주 26시간, **주휴수당 0원**
  - A 화 실제 퇴근 16:20(+20분 인정) · 목 실제 출근 09:10(−10분) → 주 32시간 40분, 기본급 337,120원 + 주휴 67,080원 = **404,200원**, 화면에 "예정 대비 +10분 / +1,720원"
  - 월 정산표: 홀 합계 = A, 배달 합계 = B + C 로 나뉘어 표시

## 11. 아직 정하지 못한 것

- 일찍 출근·늦게 퇴근한 시간을 어디까지 근로시간으로 인정할지 → 노무사 확인 후 근로계약서·안내문에 적기
- 5인 미만/이상 판단과 가산수당 적용 여부 → 노무사 확인
- 월 경계에 걸친 주의 주휴수당을 어느 달에 넣을지 → 노무사·세무사와 기준 정하기
- 결원 대체를 실제로 누구에게 부탁할지
- `[가정]` 주의 시작은 월요일, 끝은 일요일 (주휴수당·주 정산표 기준) → 다르면 설정에서 바꿈
- `[가정]` 주급 지급일은 그 주가 끝난 뒤 월요일 → 실제 지급 요일 확인
- `[가정]` 자정을 넘기는 근무는 드물어 v1에서는 같은 날 안에서만 계산 → 있으면 v2에서 처리
- `[가정]` QR을 찍고 다른 사람 이름을 고르는 걸 막는 방법(직원별 4자리 번호 등)은 v2 만들 때 정하기
