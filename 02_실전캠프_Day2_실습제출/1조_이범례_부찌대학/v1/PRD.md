# 기획안(PRD) — 근무·급여 원터치 · v1

- 가게 / 이름: 부찌대학 / 이범례
- 조 주제: 직원 급여 산정표 (조 주제: 직원 스케줄 / 원가 / 대시보드)
- 이 버전의 목표 한 줄: **사장님이 급여날 아침에 근무 기록만 확인하면, 직원별·사업장별 세전 급여가 한 화면에 나오는 도구**

> 한 줄로: **계산은 도구가, 확인과 확정은 사장님이.**
> ※ 공개 저장소라 실제 직원 이름·시급·매출은 넣지 않았습니다. 예시는 모두 가상입니다.

---

## 1. 무엇을 왜 만들고 싶나요?

- 급여날마다 근무표를 펴 놓고 직원별로 계산기를 두드립니다. 직원이 11명 안팎이라 시간이 꽤 걸립니다.
- 결원·휴가 대체가 생기면 원래 근무표와 실제 근무가 달라집니다. 이걸 기억에 의존해 고치다 보니 빠뜨릴까 걱정됩니다.
- 휴게시간 무급 공제, 주 15시간 이상일 때 주휴수당, 짧게 일하는 학생 직원처럼 **사람마다 계산 규칙이 조금씩 달라** 헷갈립니다.
- **가장 큰 문제: 시급제라 급여가 고정이 아닙니다.** 같은 직원도 그날 몇 시에 출근·퇴근했느냐에 따라 금액이 달라집니다. 5분 일찍 온 날, 20분 늦게 끝난 날, 10분 지각한 날이 쌓이는데 이게 어디에도 정리돼 있지 않습니다.
- 앞으로 **홀 매장과 배달전문 매장을 사업자로 나눕니다.** 급여도 사업장별로 따로 관리해야 해서, 손 계산으로는 더 복잡해집니다.

## 2. 누가 언제 쓰나요?

| 누가 | 언제 | 무엇을 |
|---|---|---|
| 사장님(홀·마케팅 총괄) | 매주 월요일 아침 | 지난주 실제 근무를 확인·수정 |
| 사장님 | 급여 정산일 | 월 합계 확인 → 세무사 전달용 표 내려받기 |
| 사장님(주방 총괄) | 필요할 때 | 배달매장 근무 기록 확인 |
| 직원 | v1에서는 쓰지 않음 | (v2에서 본인 근무 기록 확인) |

v1은 **사장님 둘만 쓰는 도구**입니다. 두 분이 각자 매장(홀·배달)의 카운터 PC·태블릿에서 열고, **같은 기록**을 봅니다(Supabase 데이터 창고).

## 3. 지금은 어떻게 하고 있나요?

1. 주간 근무표(엑셀·종이)를 기준으로 봅니다.
2. 결원·대체·조퇴는 카톡과 기억으로 챙깁니다.
3. 직원별로 하루 근무시간 − 휴게시간을 계산기로 더합니다.
4. 주 15시간이 넘는지 보고 주휴수당을 따로 계산합니다.
5. 월 합계를 정리해 세무사에게 넘깁니다.

**문제:** 3~4번이 매번 손 계산이고, 2번이 기록으로 남지 않습니다.

## 4. 도구를 쓰면 어떤 일이 달라지나요?

**넣는 것 → 나오는 것 (직원 1명, 1주 기준)**

- 넣는 것: 사업장(홀/배달) · 자리(예: 오전 주방) · 시급 · 요일별 출근·퇴근·휴게시간
- 나오는 것:
  - 하루 실근무시간 (휴게시간 자동 공제)
  - 주 합계 시간
  - 주휴수당 발생 여부와 금액
  - 그 주 세전 급여
  - 최저시급보다 낮게 입력됐으면 빨간 경고

**한 달이 끝나면** 직원별 월 세전 합계 + 사업장별(홀/배달) 인건비 합계가 한 표로 나옵니다.

## 5. v1에서 만들 것 — 오늘(9/17) 안에 되는 것만

- **기능 1: 직원 명단 + 기본 근무표**
  - 직원마다 사업장(홀/배달), 자리, 시급, **지급 주기(주급/월급)**, 요일별 기본 출퇴근·휴게시간을 한 번 입력
  - 주가 바뀌면 기본 근무표가 자동으로 채워짐 → 달라진 날만 고치면 됨
- **기능 2: 예정 vs 실제 출퇴근 + 자동 계산** ← 시급제 변동 해결
  - 하루 칸이 두 줄: **예정**(기본 근무표) / **실제**(찍힌 출퇴근 시각)
  - 실제 시각을 넣으면 예정과의 차이가 분 단위로 뜸 (예: +20분, −10분)
  - 차이가 10분 이상이면 노란 표시 → 사장님이 **인정 / 조정** 중 선택, 조정하면 사유 메모 필수
  - 급여는 **인정된 실제 시간 × 1분 단위**로 계산 (15분·30분 단위 내림 안 함)
  - 결원·대체·조퇴·결근도 그날 칸에서 수정 (수정한 칸은 색으로 표시)
  - 실근무시간 = 인정 퇴근 − 인정 출근 − 휴게시간(무급)
  - 주 합계 옆에 **"예정 대비 +○분 / +○원"** 표시 → 이번 주 급여가 왜 달라졌는지 한눈에
  - 주휴수당 = 주 15시간 이상 + 그 주 결근 없음일 때만 계산
    `(주 소정근로시간 ÷ 40) × 8시간 × 시급` (최대 8시간분)
    - 주휴수당은 **예정(소정) 시간 기준**이라, 몇 분 더 일해도 주휴수당은 그대로 → 변동은 기본급 쪽에서만 생김
- **기능 3: 주 정산표 + 월 정산표 + 내려받기**
  - 주 정산표: 주급 직원(7~8명)의 그 주 세전 급여(기본급 + 주휴수당)를 한 표로 → 매주 주급일에 봄
  - 직원별 월 세전 합계, 홀/배달 사업장별 합계
  - CSV(엑셀로 열림) 내려받기 → 세무사 전달용
  - 입력한 내용은 Supabase 데이터 창고에 저장 → 홀·배달 두 매장 기기에서 같은 기록을 봄 (가입·열쇠 붙이기는 사장님 직접)
- **실제 출퇴근 시각은 어떻게 넣나 (v1):** 사장님이 하루 마감 때 **예정과 다른 사람만** 입력. 다 예정대로면 "오늘 예정대로" 한 번에 확정
- **이번에 하지 않을 것:**
  - 4대보험·소득세 공제, 실수령액 계산 (세무사 몫)
  - 연장·야간·휴일 가산수당 (사업자 분리 후 두 곳 모두 5인 미만 예정. 적용 여부는 노무사 확인 후 v2에서 설정으로 추가)
  - 연차수당, 퇴직금 계산
  - 직원 로그인, 직원이 직접 찍는 출퇴근(매장 QR)
  - 주 정산 확인을 직원에게 카톡·문자로 보내기
  - 근무표 자동 생성·결원 대체 추천

## 6. 완성됐다는 걸 어떻게 확인하나요?

- **시연할 예시 입력 (가상 직원, 시급 10,320원 = 2026년 최저시급):**
  - 가상 직원 A (홀 · 오전 설거지): 월~금 09:00~16:00, 휴게 30분 무급
  - 가상 직원 B (배달 · 저녁 포장): 월~금 17:00~22:00, 휴게 30분 무급
  - 가상 직원 C (배달 · 학생): 금 1일 5시간, 휴게 30분
- **기대하는 결과:**
  | | 하루 | 주 합계 | 주휴수당 | 주 세전 합계 |
  |---|---|---|---|---|
  | A | 6.5시간 | 32.5시간 | 6.5시간분 67,080원 | **402,480원** |
  | B | 4.5시간 | 22.5시간 | 4.5시간분 46,440원 | **278,640원** |
  | C | 4.5시간 | 4.5시간 | 없음 (15시간 미만) | **46,440원** |
  - A가 수요일 결근으로 수정되면 → 주 26시간, **주휴수당 0원**으로 바뀜
  - **출퇴근 변동 예시 (A, 결근 없는 주):** 화요일 실제 퇴근 16:20(+20분, 사장님 인정), 목요일 실제 출근 09:10(−10분)
    → 주 32시간 40분, 기본급 337,120원 + 주휴수당 67,080원(그대로) = **404,200원**
    → 화면에 "예정 대비 +10분 / +1,720원" 표시
- **잘못 입력했을 때:**
  - 퇴근이 출근보다 빠르면 → "시간을 다시 확인해 주세요" 표시, 계산 안 함
  - 휴게시간이 근무시간보다 길면 → 경고
  - 시급이 최저시급보다 낮으면 → 빨간 경고 (저장은 되지만 눈에 띄게)
  - 빈칸은 0시간으로 계산하지 않고 "미입력"으로 표시
- **주 정산표·월 정산표:** A·B·C 모두 주급이면 주 정산표에 세 명, 월 정산표는 홀 합계 = A, 배달 합계 = B + C 로 나뉘어 표시
- **다시 열었을 때 남아 있어야 할 것 (다른 매장 기기에서 열어도 똑같이):**
  - 직원 명단과 기본 근무표, 이번 달 수정 내역, 최저시급 설정값

## 7. v2에서 더할 것 (10/17까지 · API·외부 데이터 등)

- **꼭 할 것 1: 매장 QR 출퇴근** — 매장에 붙인 QR을 직원 폰으로 찍으면 본인 이름을 고르고 출근/퇴근 → 시각 자동 기록. 사장님은 차이 난 칸만 인정/조정 (지금의 카톡 맞추기를 없앰)
- **꼭 할 것 2: 주 정산 확인 보내기** — 주급 직원에게 본인 주 정산을 카톡·문자로. 보내기 버튼은 사장님이
- **여유 있으면:** 결원 대체 추천 — 결원이 생기면 아래 순서로 후보를 보여줌
  1. 그날 나올 수 있는가
  2. 그 자리를 할 줄 아는가
  3. 지쳐 있지 않은가 (주 40시간 넘으면 뒤로, 연속 5일 넘으면 제외)
  4. 인건비 (주휴수당이 새로 생기는지)
  - 홀↔배달 직원은 섞지 않음 (사업자·장소 분리)
- **여유 있으면 2: 직원 본인 기록 보기** — QR 화면에서 본인 출퇴근·본인 주 정산만 확인 (다른 직원 시급·급여는 못 봄)
- **그 밖에 v2 후보**
  - 월급제 전환 계산기 — 근무가 일정한 직원은 `(주 소정시간 + 주휴시간) × 4.345주 × 시급`으로 고정 월급을 미리 계산해 보기 (전환은 노무사 확인 후)
  - (Supabase 저장은 v1로 옮김) 사장님 폰에서도 열어 보기
  - 직원별 근로계약 만료일 알림 (기간제 계약 만료 한 달 전)
  - 사업장별 설정: 5인 이상/미만에 따라 가산수당·연차 켜고 끄기
  - 퇴직금 대상(1년 이상·주 15시간 이상) 표시
  - 월 인건비 추이 그래프 (홀/배달 비교)
- **필요한 데이터나 외부 연결:** Supabase(저장), 매년 최저시급 값(직접 입력), 공휴일 달력
- **사람이 직접 판단·확인해야 할 부분:**
  - 일찍 출근·늦게 퇴근한 시간을 어디까지 근로시간으로 인정할지 기준 → 노무사 확인 후 근로계약서·안내문에 적어 두기
  - 5인 미만/이상 판단과 가산수당 적용 여부 → 노무사 확인
  - 월 경계에 걸친 주의 주휴수당을 어느 달에 넣을지 → 노무사·세무사와 기준 정하기
  - 결원 대체를 실제로 누구에게 부탁할지

## 8. 절대 자동화하면 안 되는 것

- **급여 금액 확정** — 도구는 "계산안"까지만, 확정은 사장님 확인 후
- **급여 이체**
- **직원에게 급여명세서·메시지 자동 발송**
- **결원 대체 확정 통보** — 추천까지만, 연락은 사장님이 직접
- **근로계약서 내용 변경, 시급 변경**
- **세무사에게 자동 전송** — 내려받기까지만
