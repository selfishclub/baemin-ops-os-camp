## 만든 것

- 도구 이름: **근무·급여 원터치**
- 한 줄 설명: 매장 마감 때 예정과 다른 출퇴근만 넣으면, 주휴수당까지 계산된 직원별·사업장(홀/배달)별 세전 급여가 한 화면에 나오는 도구. 계산은 도구가, 확인과 확정은 사장님이.
- 프로젝트 폴더: `v1/프로젝트/` (Next.js 16 + Supabase. 만든 폴더 통째로)
- 실행 방법:
  1. `v1/프로젝트` 폴더에서 `npm install`
  2. `.env.local`에 Supabase 주소·anon 열쇠 두 줄을 넣음 (없으면 브라우저 임시 저장으로 돌아감)
  3. `npm run dev` → http://localhost:3000 (홀 매장 `/hall`, 배달 매장 `/delivery`, 정산 `/`)
- 첫 화면 스크린샷: `결과물/첫화면.png` (홀 매장 — 오늘 마감 + 주간 근무표)
- 다른 스크린샷: `결과물/정산.png` (주 정산표 + 월 정산표)
- 영상이 있으면 링크로 (파일은 올리지 않습니다):

## 이번 버전에서 되는 것

- 직원 명단: 별칭·사업장(홀/배달)·자리·시급·주급/월급·요일별 기본 출퇴근·휴게를 한 번 입력 → 매주 자동으로 채워짐
- 오늘 마감 (매장별 주소): 예정과 다른 사람만 "다르게"로 고치고, 나머지는 "예정대로 확정" 버튼 하나. 결근·대체 근무도 여기서
- 주간 근무표: 예정/실제 두 줄, 분 단위 차이, 10분 이상 차이면 노란 표시 → 사장님이 인정/조정(조정은 사유 필수). 인정 전에는 급여에 안 들어감
- 자동 계산: 실근무(휴게 공제, 1분 단위) · 주 합계 · 주휴수당(주 15시간 이상 + 결근 없음, 소정시간 기준) · 주 세전 · "예정 대비 +○분/+○원"
- 주 정산표(주급 직원) · 월 정산표(전체, 홀/배달 사업장별 합계) · CSV 내려받기(엑셀로 열림, 세무사 전달용)
- 설정: 최저시급(미만이면 빨간 경고), 시연 데이터로 되돌리기
- 예외: 퇴근<출근 · 휴게>근무 · 빈칸=미입력 · 조정인데 사유 없음 → 저장 안 하고 안내
- 저장: Supabase 데이터 창고 → 홀 매장 기기와 배달 매장 기기가 같은 기록을 봄 (내 컴퓨터에서 연결 확인 완료. 배포 주소는 Vercel 환경변수 등록 전이라 지금은 각 브라우저에 저장)
- 시연 확인: PRD 6번 기대값과 일치 — 가상 직원 A 402,480원 / B 278,640원 / C 46,440원, A 화 +20분·목 −10분 인정 시 404,200원(+10분/+1,720원)
