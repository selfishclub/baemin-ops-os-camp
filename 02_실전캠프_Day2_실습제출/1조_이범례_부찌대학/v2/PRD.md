# 기획안(PRD) — 근무·급여 원터치 · v2

> 초안 — v1을 써 본 뒤 고칩니다

- 가게 / 이름: 부찌대학 / 이범례
- 조 주제: 직원 급여 산정표 (조 주제: 직원 스케줄 / 원가 / 대시보드)
- 이 버전의 목표 한 줄: **직원이 매장 QR을 찍어 출퇴근을 스스로 남기고, 사장님은 차이 난 칸만 확인한 뒤 주 정산을 직원에게 보내는 도구**

> 전체 그림은 `../PRD_전체.md` 4번 표의 [v2] 꼬리표. 여기는 그중 v2에서 만들 것만.

## 1. 무엇을 왜 만들고 싶나요?

v1이 되어도 두 가지가 남습니다.

- 실제 출퇴근 시각을 **사장님이 마감 때 직접** 넣어야 합니다. 지금 직원과 카톡으로 맞추던 일이 "사장님이 기억해서 입력"으로 바뀐 것뿐입니다.
- 주급을 준 뒤 직원이 "그날 더 일했는데요"라고 나중에 말해 주면 다시 계산합니다. 주기 **전에** 직원이 확인할 길이 없습니다.

## 2. 누가 언제 쓰나요?

| 누가 | 언제 | 무엇을 |
|---|---|---|
| 직원 (11명 안팎) | 출근할 때·퇴근할 때 | 매장에 붙인 QR을 본인 폰으로 찍고 이름 고르고 출근/퇴근 |
| 사장님 (홀 / 주방 각각) | 매일 마감 · 월요일 아침 | 예정과 차이 난 칸만 인정/조정 |
| 사장님 | 주급일 | 주 정산표 확인 → "보내기" 버튼 → 직원에게 카톡·문자 |

직원은 **본인 기록만** 봅니다. 다른 직원의 시급·급여, 사업장 합계, 조정 사유는 보이지 않습니다.

## 3. 지금은 어떻게 하고 있나요? (v1을 쓴 뒤 기준)

1. 사장님이 마감 때 예정과 다른 사람만 실제 시각 입력
2. 월요일 아침 주간 근무표에서 노란 칸 인정/조정
3. 주 정산표를 보고 직원에게 따로 카톡

## 4. 도구를 쓰면 어떤 일이 달라지나요?

직원이 QR 찍기(출근·퇴근) → 시각이 자동으로 주간 근무표 "실제" 줄에 들어감 → 예정과 10분 이상 차이면 노란 표시 → 사장님이 인정/조정 → 주 정산표 → **보내기 버튼** → 직원 폰으로 "이번 주 ○시간, ○원" 확인 메시지 → 직원이 이의 있으면 사장님께 말함

## 5. 이번 버전에서 만들 것

**꼭 할 것**
- 기능 1: **매장 QR 출퇴근** — 매장(홀·배달 각각)에 붙인 QR을 찍으면 출퇴근 화면이 열림. 본인 이름 고르기 → 출근 또는 퇴근 버튼 → 지금 시각 기록. 방금 찍힌 시각이 화면에 보임
- 기능 2: **주 정산 확인 보내기** — 주급 직원별 주 정산 내용을 문자(또는 카톡)로. 보내기 전 미리보기, 버튼은 사장님이 누름, 언제 누구에게 보냈는지 기록

**여유 있으면**
- 결원 대체 추천 — 결원이 생기면 ① 그날 가능 ② 자리 가능 ③ 지치지 않음(주 40시간 넘으면 뒤로, 연속 5일 넘으면 제외) ④ 인건비(주휴수당 새로 생기는지) 순. 홀↔배달 섞지 않음
- 직원 본인 기록 보기 — QR 화면에서 본인 출퇴근·본인 주 정산만
- 사업장별 설정 — 5인 이상/미만에 따라 가산수당·연차 켜고 끄기 (노무사 확인 후)
- 월급제 전환 계산기 — `(주 소정시간 + 주휴시간) × 4.345주 × 시급`
- 근로계약 만료 한 달 전 표시 · 퇴직금 대상(1년 이상·주 15시간 이상) 표시
- 월 인건비 추이 그래프(홀/배달) · 공휴일 달력 연결

**준비물**
- 매장 QR 이미지: 무료 QR 생성 도구로 만들어 인쇄 → 홀·배달 매장에 각각 붙이기
- 문자 보내기: 문자 발송 서비스 가입(사장님 직접) → 열쇠(API 키)는 사장님이 직접 붙임. 카카오 알림톡은 채널 심사가 오래 걸려 **문자부터** `[가정]`
- 직원 폰에서 인터넷이 되어야 함

**이번에 하지 않을 것:** 연장·야간·휴일 가산수당 · 4대보험·소득세 공제·실수령액 · 연차수당·퇴직금 금액 계산 · 배민 매출과 인건비 비교 · 급여 이체

## 6. 완성됐다는 걸 어떻게 확인하나요?

- **시연할 예시 입력:** 가상 직원 A가 폰으로 매장 QR을 찍고 이름 고르고 화요일 09:00 출근 → 16:20 퇴근
- **기대하는 결과:** 주간 근무표 화요일 "실제" 줄에 09:00 / 16:20 자동 반영, +20분 노란 표시 → 사장님 인정 → 주 정산표 A 404,200원 → 보내기 버튼 → 미리보기 "이번 주 32시간 40분, 404,200원" → 사장님 확인 후 발송 → 발송 기록에 날짜·받는 사람 남음
- **잘못 입력했을 때:**
  - 출근을 두 번 연속 찍으면 → "이미 출근 중이에요" 안내, 두 번째는 기록하지 않음
  - 퇴근을 안 찍고 다음 날이 되면 → 그날 "퇴근 미입력" 표시, 사장님이 마감 화면에서 입력
  - 다른 사람 이름으로 찍으면 → 사장님이 조정(사유 메모)으로 바로잡음 `[가정]` 막는 방법은 만들 때 정함
  - 보내기 전에 정산이 "확인 필요"(노란 칸 남음) 상태면 → 보내기 버튼 잠금
- **다시 열었을 때 남아 있어야 할 것:** QR 출퇴근 기록, 발송 기록(언제·누구에게·무슨 내용)

## 7. 다음 버전에서 더할 것

- 다음에 추가할 기능 하나: 사업장별 5인 이상/미만 설정에 따른 가산수당 (노무사 확인 후)
- 필요한 데이터나 외부 연결: 공휴일 달력, (필요가 확실해지면) 배민 매출 데이터
- 사람이 직접 판단·확인해야 할 부분:
  - 일찍 출근·늦게 퇴근을 어디까지 근로시간으로 인정할지 → 노무사 확인 후 근로계약서·안내문에 적기
  - 5인 미만/이상 판단과 가산수당 적용 → 노무사
  - 월 경계에 걸친 주의 주휴수당을 어느 달에 넣을지 → 노무사·세무사
  - 결원 대체를 실제로 누구에게 부탁할지

## 8. 절대 자동화하면 안 되는 것

- 급여 금액 확정 · 급여 이체
- 직원에게 확인 메시지·명세서 **자동** 발송 — 반드시 사장님이 미리보기 보고 버튼
- 결원 대체 확정 통보
- 근로계약·시급 변경
- 세무사에게 전송 (내려받기까지만)
