- 도구 이름: **부찌대학 오늘근무** (10/2까지의 이름은 영업 근무 출근부 · 근무·급여 원터치 v2)
- 한 줄 설명: 매장 폰에서 직원이 자기 이름을 눌러 출근·퇴근을 찍으면, 사장은 관리자 모드에서 기록을 보고 주급을 계산해 명세서를 직원에게 보내는 도구
- 실제 사용본: Claude 아티팩트로 만들어 매장에서 사용 중. **실제 직원 이름·시급이 들어 있어 주소와 코드는 이 공개 저장소에 올리지 않았습니다.** 10/2 점검 때 화면으로 보여 드립니다
- 프로젝트 폴더: `v2/프로젝트/` — 가상 직원으로 만든 **공개용 시연판**(v1 + 이름 눌러 출퇴근 화면 `/checkin/hall` · `/checkin/delivery`). 실제 사용본과는 다른 코드입니다
- 시연판 실행 방법:
  1. `v2/프로젝트` 폴더에서 `npm install`
  2. `.env.local`에 Supabase 주소·anon 열쇠 두 줄 (없으면 브라우저 임시 저장)
  3. `npm run dev` → http://localhost:3000

## 이번 버전에서 되는 것 (실제 사용본 기준)

- 단말 모드: 직원이 자기 이름을 누르고 PIN 4자리로 출근, 다시 눌러 퇴근. 찍은 시각이 출근부에 바로 기록
- 관리자 모드(PIN 잠금): 배달 영업 / 홀 영업 달력에서 사람별 출근·지각·조퇴·결근 확인, 편성과 10분 넘게 다르면 '확인' 표시
- 편성표 수정, 하루만 근무자 바꾸기, 기간 결근 등록, 공휴일 단축 영업
- 이번 주 지급: 주급·주휴 계산 → 사람별 명세서 → 복사·공유로 문자 전달 → 지급 완료 체크
- 월급 정산, 월간 출근 집계
- (10/10 최종) 맨 위 "오늘 한눈에" — 두 매장 출근 현황·챙길 일·이번 달 인건비 / 10월부터 월급제 반영과 월 단위 임금명세서 / 특근 칸 / 근무표 인쇄·주간 근무표 문구·이 달 기록 내려받기
