# 처음 AI에게 준 근무표 (이름만 바꿈)

출근부를 만들 때 맨 처음 AI에게 준 것은 **이런 근무 편성표 한 장**이었습니다.
표의 모양·영업시간·자리·근무시간은 그대로이고, **직원 이름만 "직원 A~L"로 바꿨습니다.** (시연용 출근부의 직원 A~K와 같은 사람입니다.)
아래는 2026년 9월 운영 기준 표입니다. 실제로 처음 올린 것은 같은 형식의 10월 표 사진이었습니다.
