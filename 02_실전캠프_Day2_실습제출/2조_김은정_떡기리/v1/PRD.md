# 기획안(PRD) — 떡기리 직원 교육 온라인 북 · v1

- 가게 / 이름: 떡기리 / 김은정
- 조 주제: 직원 교육 매뉴얼 온라인 북
- 이 버전의 목표 한 줄: **새로 온 직원이** **첫 출근~첫 주에 궁금할 때마다** **폰으로 열어 오픈·포장·응대 순서를 스스로 찾아보는** 온라인 북

## 1. 무엇을 왜 만들고 싶나요?

떡기리는 3대째 내려오는 방앗간에서 시작한 무방부제·무색소·무첨가물 프리미엄 떡카페입니다.
그래서 일반 카페보다 직원이 알아야 할 게 많습니다. 떡은 당일 생산이라 진열·보관 시간이 정해져 있고, 종류마다 포장 방법이 다르고, "첨가물 없나요?", "냉동해도 되나요?" 같은 손님 질문이 매일 나옵니다.

지금은 신입이 올 때마다 사장이 처음부터 말로 설명하고, 며칠 뒤 같은 걸 또 물어보면 또 설명합니다. 바쁜 시간에 물어보면 대답을 못 해 주고, 그 사이 직원이 자기 방식대로 포장하거나 잘못 안내하는 일이 생깁니다.
"한 번 정리해 두고, 물어보는 대신 여기서 찾아봐"라고 할 수 있는 **떡기리 업무 안내서**를 만들고 싶습니다.

## 2. 누가 언제 쓰나요?

- **주로 쓰는 사람**: 신입 직원(아르바이트 포함). 첫 출근일부터 익숙해질 때까지 약 1~2주.
- **여는 순간**: 출근해서 오픈 준비 시작할 때, 손님 질문에 막혔을 때, 마감 전 체크할 때. 매장 카운터 뒤에서 **본인 폰으로** 봅니다.
- **관리하는 사람**: 사장(김은정). 내용이 바뀌면 사장이 고칩니다.
- 사장과 직원이 같은 화면을 봅니다. 로그인 없이 링크만 알면 열립니다.

## 3. 지금은 어떻게 하고 있나요?

1. 신입 첫날 사장이 옆에 붙어서 말로 설명
2. 중요한 건 카톡으로 사진과 함께 보내 둠 → 나중에 카톡 위로 올려 찾아야 해서 잘 안 봄
3. 일부는 종이에 써서 카운터 아래 붙여 둠 → 찢어지거나 최신 내용이 아님
4. 결국 직원이 사장에게 다시 물어봄

쓰는 도구: 말, 카톡, 종이 메모. 한곳에 모여 있는 문서는 없음.

## 4. 도구를 쓰면 어떤 일이 달라지나요?

한 건 기준:
- **넣는 것**: 직원이 폰으로 링크를 열고, 목차에서 "포장" 또는 검색창에 "인절미"를 침
- **나오는 것**: 인절미 포장 순서(사진 자리 포함), 보관 온도, 손님에게 안내할 문장이 한 화면에 나옴
- **달라지는 것**: 사장에게 묻지 않고 30초 안에 확인. 직원마다 다른 방식으로 하던 게 하나로 맞춰짐. 사장은 같은 설명을 반복하지 않음.

## 5. v1에서 만들 것 — 오늘(9/17) 안에 되는 것만

- 기능 1: **목차가 있는 온라인 북 화면** — 챕터를 누르면 그 내용이 열림. 폰에서 잘 보이는 화면.
  - 챕터(초안): ① 떡기리 소개와 우리 원칙(무방부제·무색소·무첨가물) ② 오픈 준비 ③ 떡 진열·보관 시간 ④ 포장 방법(떡 종류별) ⑤ 손님 자주 묻는 질문과 답변 ⑥ 마감 체크
- 기능 2: **검색** — 단어를 치면 해당하는 챕터·항목이 바로 나옴
- 기능 3: **오픈·마감 체크리스트** — 항목을 하나씩 체크하며 진행. 화면을 닫아도 오늘 체크 상태는 그 폰에 남음
- **이번에 하지 않을 것:**
  - 직원 로그인 / 누가 읽었는지 확인
  - 사진·영상 업로드 (v1은 텍스트 + 사진 자리만)
  - 사장이 화면에서 직접 내용 수정하는 관리자 기능 (v1은 사장이 파일을 고쳐서 다시 올림)
  - 퀴즈·교육 이수 기록

## 6. 완성됐다는 걸 어떻게 확인하나요?

- 시연할 예시 입력: 폰으로 Vercel 주소를 열고 → 목차에서 "포장 방법" 클릭 → 검색창에 "냉동" 입력
- 기대하는 결과: 포장 방법 챕터가 열리고, "냉동" 검색 시 보관 관련 항목(예: 냉동 보관 가능 여부와 해동 안내)이 나옴
- 잘못 입력했을 때: 없는 단어를 검색하면 "찾는 내용이 없어요. 사장님께 물어보세요" 문구가 나오고 화면이 깨지지 않음
- 다시 열었을 때 남아 있어야 할 것: 같은 폰에서 오늘 체크한 오픈 체크리스트 상태. (내용 자체는 파일에 있으니 항상 그대로)

## 7. v2에서 더할 것 (10/17까지 · API·외부 데이터 등)

- 다음에 추가할 기능 하나: **사장이 폰에서 바로 내용을 고치고 사진을 올리는 관리 화면** (Supabase에 내용 저장)
- 필요한 데이터나 외부 연결 (API, 배민 데이터, 날씨 등):
  - Supabase — 매뉴얼 내용·사진 저장, 직원별 체크리스트 기록
  - AI(Claude API) — 손님 질문을 치면 매뉴얼 내용을 바탕으로 안내 문장 초안을 만들어 줌
  - 명절 시즌 안내(선물세트 포장·예약 접수 순서) 챕터를 시즌별로 켜고 끄기
- 사람이 직접 판단·확인해야 할 부분: AI가 만든 안내 문장은 사장이 확인한 뒤에만 매뉴얼에 반영. 알레르기·보관 기한 등 안전과 관련된 내용은 사장이 직접 씀.

## 8. 절대 자동화하면 안 되는 것

- 손님에게 직접 보내는 메시지·답변 전송 (직원이 보고 말하는 것까지만)
- 알레르기·유통기한·보관 기한 같은 안전 정보의 자동 생성 (사장이 확인한 내용만)
- 직원 근무·급여와 관련된 판단 (이 도구는 교육용으로만)
