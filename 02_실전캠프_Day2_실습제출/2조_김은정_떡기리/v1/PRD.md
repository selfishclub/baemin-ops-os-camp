# 기획안(PRD) — 떡기리 신입직원 교육 온라인 북 · v1

- 가게 / 이름: 떡기리 / 김은정
- 조 주제: 직원 교육 매뉴얼 온라인 북
- 이 버전의 목표 한 줄: **매장 직원(특히 신입)이** **오픈·마감·손님 응대 중 막히는 순간에** **폰으로 열어 12장 매뉴얼을 찾아보고 오픈·마감을 체크하며 스스로 일하는** 온라인 북

> 전체 그림은 `../PRD_전체.md`에 있습니다. 이 문서는 그중 [v1]만 옮긴 것입니다.
> 재료: 과제 1에서 만든 `떡기리_신입직원_교육_온라인북.md` (12장 + 별도 출력물 4개). 내용을 새로 쓰지 않고 화면으로 옮깁니다.

## 1. 무엇을 왜 만들고 싶나요?

떡기리는 3대째 내려오는 방앗간에서 시작한 무방부제·무색소·무첨가물 프리미엄 떡카페입니다.
그래서 일반 카페보다 직원이 알아야 할 게 많습니다. 떡은 당일 생산이라 진열·보관 시간이 정해져 있고, 종류마다 포장 방법이 다르고, "첨가물 없나요?", "냉동해도 되나요?" 같은 손님 질문이 매일 나옵니다.

매뉴얼은 PDF 10개로 이미 있었지만 흩어져 있어 아무도 열지 않았고, 신입이 올 때마다 사장이 처음부터 말로 설명하고, 며칠 뒤 같은 걸 또 물어보면 또 설명합니다. 한 달쯤 전 신입 첫날에도 그랬습니다. 직원 질문은 매장 3곳 합쳐 주 5~10번, 한 번에 5분쯤. 물어보지 않고 자기 방식대로 해서 틀리는 일이 한 달에 1~2번인데, 제일 아까운 건 오픈·마감 항목을 빠뜨리는 것입니다.
과제 1에서 PDF 10개를 12장 온라인북(.md)으로 합쳤습니다. 이제 그걸 **직원 폰에서 찾아보고 체크할 수 있는 화면**으로 만들고 싶습니다.

## 2. 누가 언제 쓰나요?

- **주로 쓰는 사람**: 매장 3곳의 직원(정직원 4명 + 파트 10명 이상, 매장당 2~4명 근무). 특히 신입은 첫 출근~7일차에 집중.
- **여는 순간**: 출근해서 오픈 준비 시작할 때, 손님 질문에 막혔을 때, 마감 전 체크할 때, 신입이 그날 교육표를 따라갈 때. 매장 카운터 뒤에서 **본인 폰으로** 봅니다.
- **관리하는 사람**: 사장(김은정). 내용이 바뀌면 v1에서는 사장이 파일을 고쳐서 다시 올립니다. "확인 필요" 목록을 보고 채웁니다.
- 사장과 직원이 같은 화면을 봅니다. 로그인 없이 링크만 알면 열립니다. 세 매장이 같은 북 하나를 씁니다.

## 3. 지금은 어떻게 하고 있나요?

1. 신입 첫날 사장이 옆에 붙어서 말로 설명
2. 중요한 건 카톡으로 사진과 함께 보내 둠 → 나중에 카톡 위로 올려 찾아야 해서 잘 안 봄
3. 매뉴얼 PDF 10개는 있지만 어떤 상황에 어떤 문서를 봐야 할지 몰라 안 봄. 일부는 종이에 써서 카운터 아래 붙여 둠 → 찢어지거나 최신 내용이 아님
4. 오픈·마감은 기억에 의존 → 한 달에 1~2번 항목 빠뜨림
5. 결국 직원이 사장에게 다시 물어봄

쓰는 도구: 말, 카톡, PDF, 종이 메모, 재고발주추천툴 엑셀(마감 때 폐기수량 입력). 한곳에 모여 있는 화면은 없음.

## 4. 도구를 쓰면 어떤 일이 달라지나요?

한 건 기준:
- **넣는 것**: 직원이 폰으로 링크를 열고, 목차에서 "8장 위생·청소"를 누르거나 검색창에 "라벨"을 침
- **나오는 것**: 그 장의 체크박스 형식 설명(해야 할 일 → 방법 → 완료 기준 → 자주 하는 실수 → 대처)이 한 화면에 나옴. 오픈·마감 때는 체크리스트를 눌러 가며 "5/7 완료"를 봄
- **달라지는 것**: 사장에게 묻지 않고 30초 안에 확인. 직원마다 다른 방식으로 하던 게 하나로 맞춰짐. 오픈·마감 빠뜨림이 보임. 사장은 같은 설명을 반복하지 않음.

## 5. v1에서 만들 것 — 오늘(9/17) 안에 되는 것만

- 기능 1: **12장 목차가 있는 온라인 북 화면** — 과제 1 온라인북 .md의 내용을 그대로 옮김. 장을 누르면 그 내용이 열림. 폰에서 잘 보이는 화면. "확인 필요"는 눈에 띄게 표시.
  - 12장: ① 우리 가게 이해하기 ② 첫 출근 가이드 ③ 기본 근무수칙 ④ 오픈 매뉴얼 ⑤ 영업 중 매뉴얼 ⑥ 상품·서비스 매뉴얼 ⑦ 고객응대 매뉴얼 ⑧ 위생·청소 매뉴얼 ⑨ 재고·발주·폐기 관리 ⑩ 마감 매뉴얼 ⑪ 컴플레인·돌발상황 대응 ⑫ 신입직원 교육 체크리스트
- 기능 2: **검색** — 단어를 치면 해당하는 장·항목이 바로 나옴
- 기능 3: **오픈·마감 체크리스트** — 별도 출력물 ②③(오픈 7항목·마감 6항목)을 항목 하나씩 체크하며 진행. "5/7 완료" 표시. 화면을 닫아도 오늘 체크 상태는 그 폰에 남고, 다음 날 새로 시작
- 기능 4: **신입 1·3·7일차 교육표 + "읽었어요" 체크** — 12장 표를 화면으로. 그날 읽을 장으로 바로 이동, 읽으면 체크(그 폰에 남음)
- 기능 5: **"확인 필요" 모아 보기** — 온라인북에 남은 "확인 필요" 8곳을 한 화면 목록으로. 누르면 그 자리로
- **이번에 하지 않을 것 (v2 또는 나중):**
  - 사장이 화면에서 직접 내용 수정·사진 업로드하는 관리 화면 (v1은 사장이 파일을 고쳐서 다시 올림)
  - 직원별 체크·교육 기록을 한곳에 모으는 것과 사장용 점검표 (v1은 그 폰에만 남음)
  - 재고 엑셀 툴 연결(오늘 추천 해동수량 표시), 결제·주문관리 장, 돌발상황·팝업 부록, AI 응대 문장 초안, 명절 시즌 장
  - 직원 로그인, 퀴즈·교육 이수 시험, 매장별 표시

## 6. 완성됐다는 걸 어떻게 확인하나요?

- 시연할 예시 입력: 폰으로 주소를 열고 → 목차에서 "8장 위생·청소" 클릭 → 검색창에 "라벨" 입력 → 오픈 체크리스트에서 3개 체크 → 신입 교육표에서 1일차 "읽었어요" 체크 → "확인 필요" 목록 열기
- 기대하는 결과: 8장이 열리고 기기별 세척 주기 표가 보임. "라벨" 검색 시 6장 라벨링 항목(품목명/제조일/담당자/사용기한)이 나옴. 오픈 체크리스트가 "3/7 완료"로 보임. "확인 필요" 목록에 8개가 보이고 누르면 그 자리로 이동
- 잘못 입력했을 때: 없는 단어를 검색하면 "찾는 내용이 없어요. 사수나 사장님께 물어보세요" 문구가 나오고 화면이 깨지지 않음. "확인 필요" 항목을 직원이 열면 "아직 기준이 정해지지 않았어요. 사수에게 확인하세요"
- 다시 열었을 때 남아 있어야 할 것: 같은 폰에서 오늘 체크한 오픈·마감 체크리스트 상태와 교육표 "읽었어요" 상태. 내용 자체는 파일에 있으니 항상 그대로. 하루가 지나면 체크리스트는 새로 시작

## 7. v2에서 더할 것 (10/17까지 · API·외부 데이터 등)

- 다음에 추가할 기능 하나: **사장 관리 화면** — 사장이 폰에서 바로 내용을 고치고 "확인 필요"를 채우고 사진을 올림 (Supabase에 저장). 그다음은 **직원별 체크·교육 기록 → 사장 점검표**
- 필요한 데이터나 외부 연결 (API, 배민 데이터, 날씨 등):
  - Supabase — 매뉴얼 내용·사진 저장, 직원별 체크·교육 기록
  - 재고발주추천툴 엑셀 — 오픈 4장에 오늘 추천 해동수량 표시
  - AI(Claude API) — 손님 질문을 치면 7장 고객응대 매뉴얼을 바탕으로 안내 문장 초안
  - 결제·주문관리 장(OK포스·키오스크·배달앱 4개), 돌발상황·팝업 부록, 명절 시즌 장 켜고 끄기
- 사람이 직접 판단·확인해야 할 부분: AI가 만든 안내 문장은 사장이 확인한 뒤에만 매뉴얼에 반영. 알레르기·보관 기한·위생 온도 등 안전과 관련된 내용과 "확인 필요" 항목은 사장이 직접 씀. 신입 교육 "관리자 확인"은 사수가 직접 누름.

## 8. 절대 자동화하면 안 되는 것

- 손님에게 직접 보내는 메시지·답변 전송 (직원이 보고 말하는 것까지만)
- 알레르기·유통기한·보관 기한·위생 온도 같은 안전 정보의 자동 생성 (사장이 확인한 내용만)
- "확인 필요" 항목 채우기 (법률·노무·식품위생 관련은 임의로 단정하지 않음)
- 신입 교육 "관리자 확인" 버튼 (사수·사장이 직접 보고 누름)
- 직원 근무·급여와 관련된 판단 (이 도구는 교육용으로만. 급여 지급일·금액은 넣지 않음)
