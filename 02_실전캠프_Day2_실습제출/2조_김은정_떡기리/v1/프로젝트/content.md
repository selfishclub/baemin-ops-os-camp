# 떡기리 신입직원 교육 온라인북

*이 문서는 스마트폰으로 근무 중 빠르게 찾아볼 수 있도록 만들어졌습니다. 체크박스는 실제로 체크하면서 사용하세요.*

---

## 1장. 우리 가게 이해하기

**브랜드 소개 — "정성을 빚어낸 한 입의 행복"**

떡기리는 1972년 파주 장단정미소에서 시작된 전통 방앗간의 뿌리를 이어온 브랜드입니다. 3대째 이어온 장인의 손맛과 정성을 현대적으로 재해석하여, 전통과 트렌드를 잇는 프리미엄 떡 디저트 카페로 성장하고 있습니다.

- 건강한 원재료와 정직한 손맛 고집
- **3무 원칙: 무방부제·무색소·무첨가**
- 단순한 간식이 아니라 "선물로 나눌 수 있는 품격 / 가족이 함께 즐길 수 있는 따뜻함 / 건강을 지키는 가치"를 담음

**우리가 중요하게 생각하는 서비스 기준 — "따뜻하게 맞이하고, 정직하게 설명하며, 정성껏 담아드립니다"**
- [ ] **따뜻하게 맞이하기**: 손님이 들어오면 3초 안에 미소와 인사 (7장 ① 기준)
- [ ] **정직하게 설명하기**: 원재료·첨가물·보관 기한은 아는 대로만 안내. 모르면 "확인해 드릴게요" 하고 사수에게 확인 후 답하기
- [ ] **정성껏 담아드리기**: 포장은 6장 기준대로, 전달할 때 "흔들림 주의" 멘트까지 (7장 ③ 기준)

---

## 2장. 첫 출근 가이드

- [ ] 유니폼·앞치마·네임택 착용 (브랜드를 대표한다는 마음으로)
- [ ] 손톱 짧게, 긴 머리는 묶기, 강한 향수·화장품 금지 *(8장 위생 기준과 동일)*
- [ ] 출근 시간: **정해진 출근 시간을 지킨다** (근무 매장의 시간표 기준). 늦을 것 같으면 3장 지각·결근 기준대로 미리 연락
- [ ] 교대(인수인계) 시 다음 근무자에게 **재고 · 예약 · 폐기 · 매장 특이사항** 4가지를 정확히 전달한다
- [ ] 필요한 내용은 **인수인계 노트에 반드시 기록**한다 (말로만 전달하지 않기)
- [ ] 급여 지급일·방식: 매장마다 다름 (근무 매장의 기준을 첫날 안내받기)
- [ ] 첫날 담당 사수: 매니저 또는 점주
- [ ] 첫날 목표: 이 온라인북의 1~4장(가게 이해·근무수칙·오픈)까지 훑어보기

## 3장. 기본 근무수칙

- [ ] 손님이 없어도 POS 앞 대기, 주방에서 대기하지 않기
- [ ] 2~3인 근무 시 한 명은 항상 카운터 상주
- [ ] 휴대폰 사용·개인 용무는 교대 후에 진행
- [ ] 점심·휴식 시간은 교대제로 준수
- [ ] 매출·재고 관리 기록(v1 엑셀 툴 입력 등) 철저히 작성

**인수인계·보고 체계**
- [ ] 교대 시 주요 업무·재고·예약·특이사항을 다음 근무자에게 정확히 인계한다 (2장 인수인계 노트 기준)
- [ ] 문제가 생기면 **즉시 관리자(매니저·점주)에게 보고**한다

**지각·결근 처리 기준**
- [ ] 지각이나 결근이 예상되면 가능한 한 **사전에 관리자에게 직접 연락**한다
- [ ] **무단 지각·무단 결근은 금지**

## 4장. 오픈 매뉴얼

> 목표: 출근 후 약 20분 이내 완료 | 담당: 오픈조 직원

**① POS·기기 세팅**
- [ ] POS 전원 켜기 → 날짜·시간, 인터넷 연결 확인
- [ ] 카드 단말기 정상 작동 확인
- [ ] 배달앱(배민·쿠팡이츠·요기요·땡겨요), 키오스크 로그인 확인
- [ ] 음악: 지정된 태블릿에서 **매장 플레이리스트** 재생. 볼륨은 **고객 대화에 방해되지 않는 정도**로
- [ ] 조명: **매장 메인 조명 → 입구·홀 조명 → 쇼케이스 조명** 순서로 켜기
- [ ] 영업 시작 전 꺼진 조명이 없는지 한 바퀴 확인
- 태블릿 위치, 권장 볼륨 단계, 조명 스위치 위치는 **매장마다 다름** → 첫날 사수에게 안내받고 매장 표시를 따른다
- [ ] 에어컨/난방기 켜고 계절별 설정 온도 확인

**② 매장 청소·정돈**
- [ ] 바닥 청소, 테이블·의자 정돈
- [ ] 입구 유리문·간판 먼지 제거, 외부 간판·배너 상태 확인
- [ ] 화장실 청소 + 소모품 보충

**③ 재고·재료 준비 (v1 엑셀 툴 연동)**
- [ ] 어제 마감 시 폐기수량이 엑셀에 입력되어 있는지 확인
- [ ] **[추천결과] 시트에서 오늘 제품별 추천 해동수량 확인 후 그대로 해동**
- [ ] 전날 꺼내둔 떡 상태 확인
- [ ] 시럽·분말·우유·베이스·토핑류 재고·유통기한 확인 및 보충
- [ ] 완료 기준: 모든 제품이 추천수량만큼 준비됨

**④ 위생 점검**
- [ ] 전날 세척 여부(커피머신·행주·식기세척기) 확인
- [ ] 냉장 2~5℃ / 냉동 -18℃ 이하 확인
- [ ] 손 씻기(30초 이상) → 위생장갑 착용
- [ ] 유니폼·개인위생 점검

**⑤ 기기 예열·점검**
- [ ] 커피머신 30분 이상 예열, 그라인더 테스트
- [ ] 시럽펌프·퓨레병, 얼음머신, 빙수기 상태 확인

**⑥ 디스플레이 세팅**
- [ ] 진열대 정리, 시그니처 메뉴 강조 배치
- [ ] 컵·홀더·빨대·티슈 등 소모품 채우기

**⑦ 오픈 전 최종 점검**
- [ ] 예약·단체 주문, 이벤트·프로모션 확인
- [ ] 직원 역할 분담, 첫 손님 맞이 준비

**자주 하는 실수**: 재고를 감으로 꺼내다 폐기 발생 → 엑셀 추천값을 그대로 따르면 해결
**관리자 보고 기준**: 기기·POS·배달앱 로그인 오류 발생 시

## 5장. 영업 중 매뉴얼

- [ ] 손님 응대는 7장 고객응대 매뉴얼 기준을 따름
- [ ] 진열 상품은 수시로 정돈, 빈 진열대는 즉시 보충
**피크타임 대응 (주말·공휴일, 주문이 몰리는 시간)** — 역할을 명확하게 나눈다
- [ ] **2명 근무**: 1명 주문·결제 + 포장 / 1명 음료·메뉴 제조
- [ ] **3명 이상 근무**: 주문·결제 / 제조 / 포장·진열·재고 보충
- [ ] 대기 손님이 많아지면 **주문 전에 예상 대기시간을 먼저 안내**: "현재 주문이 많아 약 10분 정도 소요될 수 있습니다. 최대한 빠르게 준비해 드리겠습니다."
- 실제 피크타임 시간대는 매장별 매출 데이터 기준으로 매장마다 정한다 (사수에게 확인)

## 6장. 상품·서비스 매뉴얼

- [ ] 라벨링 필수 항목: **품목명 / 제조일(YYYY-MM-DD) / 담당자 / 사용기한(해동일+48시간)**
- [ ] 라벨 부착 위치: 각 용기·통 전면, 직원이 쉽게 확인 가능한 위치
- [ ] 원칙: 선입선출(FIFO) 철저히 준수
- [ ] 라떼·음료 제조 시 정해진 레시피 준수, 임의 변경 금지
- [ ] 빙수·떡류는 위생장갑 착용 후 세팅
- [ ] 대표 메뉴(흑임자 라떼, 흑임자 빙수 등)는 표준화된 플레이팅 유지

**상품별 상세 레시피** — 배합비는 온라인북이 아니라 **매장 레시피북**으로 관리한다
- [ ] 상품별 정확한 재료량·배합비·제조 순서는 **매장 레시피북**을 기준으로 한다
- [ ] 이 온라인북에는 대표 메뉴의 기본 제조 순서와 완성 기준만 안내한다. **세부 배합량은 최신 레시피북을 반드시 확인**
- [ ] 레시피 임의 변경, 개인 방식 제조 금지

## 7장. 고객응대 매뉴얼

**① 고객 입장 시**
- [ ] 3초 안에 미소 + 인사: **"안녕하세요? 떡기리입니다."**
- [ ] 눈 마주치고 가볍게 목례, 혼잡 시에도 시선으로 인사 전달

**② 주문 응대**
- [ ] 메뉴판 건네며 시그니처 메뉴 추천 (예: "저희 인기 메뉴는 흑임자 라떼와 흑임자 빙수예요.")
- [ ] 대기 5분 이상 예상 시 안내: "현재 주문이 많아 7분 정도 소요됩니다. 괜찮으실까요?"
- [ ] 견과류 포함 제품은 알레르기 안내: "이 제품에는 호두·피칸이 들어가 있어요. 혹시 견과류 알레르기는 없으실까요?"

**③ 대기·서빙**
- [ ] 트레이 사용, 컵·접시 외부 깨끗한지 확인 후 전달
- [ ] 전달 멘트: "주문하신 ○○ 나왔습니다. 맛있게 드세요."
- [ ] 포장 시 "흔들림 주의" 멘트 전달

**④ 테이블 관리**
- [ ] 고객 퇴점 후 2분 이내 테이블 정리, 소독 티슈로 닦기

**⑤ 단골 고객 관리**
- [ ] 재방문 고객: "다시 찾아주셔서 감사합니다."
- [ ] 생일 등 특별한 날 서비스 제공은 점장 승인 필요 (예: 떡 1pc)

**⑥ 전화 응대**
- [ ] 첫 멘트: "네, 떡기리 ○○점입니다. 무엇을 도와드릴까요?"
- [ ] 예약 문의: 성함·방문 시간 확인 / 불만 접수: "불편을 끼쳐드려 죄송합니다. 담당자에게 바로 전달드리겠습니다."
- [ ] 종료: "전화 주셔서 감사합니다. 좋은 하루 되세요."

**⑦ 상황별 멘트**
| 상황 | 멘트 |
|---|---|
| 제품 지연 | "죄송합니다. 조금 더 기다려 주시면 바로 준비해드리겠습니다." |
| 제품 불만 | "불편을 드려 정말 죄송합니다. 바로 교환해드리겠습니다." |
| 계산 오류 | "확인 후 바로 처리해드리겠습니다. 잠시만 기다려주세요." |
| 대기석 부족 | "잠시만 기다려주시면 자리를 바로 준비해드리겠습니다." |
| 리뷰 요청 | "네이버에서 '떡기리 ○○점' 검색하시고 리뷰 남겨주시면 감사하겠습니다." |
| 퇴점 인사 | "감사합니다, 좋은 하루 되세요." |

## 8장. 위생·청소 매뉴얼

**8-1. 개인 위생 (매일, 출근 시)**
- [ ] 손톱 짧게, 머리 묶기, 강한 향수·화장품 금지
- [ ] 손 씻기 30초 이상 (근무 전/식사 후/화장실 후)
- [ ] POS 주문 시 라텍스 장갑 금지 / 조리 시 전용 위생장갑만 사용

**8-2. 식재료 위생**
- [ ] 선입선출(FIFO) 준수
- [ ] 라벨 부착 (품목명/제조일/담당자/사용기한)
- [ ] 해동 떡은 당일 소진 원칙, 남은 떡은 시식·빙수용 전환 후 폐기
- [ ] 냉장 2~5℃ / 냉동 -18℃ 이하 유지

**8-3. 조리·제조 위생**
- [ ] 칼·도마·스푼 등 용도별 분리 사용 (교차오염 방지)
- [ ] 베이스·라떼크림 등은 혼합 금지, 7일 이내 사용
- [ ] 이상 냄새·맛 발생 시 즉시 전량 폐기

**8-4. 기기별 세척 주기**

| 기기 | 매일 | 주 1회 | 월 1회 |
|---|---|---|---|
| 커피머신 | 포터필터·헤드·트레이·스팀노즐 세척 | 심층 세척(커피오일 제거), 노즐 분해 | 정수필터·보일러 점검, 전문 엔지니어 의뢰 |
| 빙수기·제빙기 | 분리 세척, 얼음 색·냄새 확인 | 내부 얼음 폐기 후 세척, 고무패킹 세척 | 필터·배수라인 청소, 응축기 먼지 제거 |
| 냉장고 | - | - | 2주 1회 전체 세척 |
| 행주 | 세탁·건조 | 살균소독제 사용 | - |

**8-5. 안전 관리**
- [ ] 전기·가스 사용 후 전원 차단, 튀김기 기름기 잔여 제거
- [ ] 바닥 물기 즉시 제거, 소화기 위치·사용법 숙지(월 1회 점검)
- [ ] 비상구·뒷문 폐쇄 금지

**관리자 보고 기준**: 냉장·냉동고 온도 이탈 / 이상 냄새·맛으로 폐기 발생 / 기기 고장 발견 시

## 9장. 재고·발주·폐기 관리

> 이 챕터는 **떡기리_재고발주추천툴.xlsx (v1)** 로 실제 운영됩니다.

- [ ] 매일 마감 시 [일별데이터입력]에 날짜·매장·제품·해동/판매/폐기수량 입력
- [ ] 매일 오픈 전 [추천결과]에서 내일 추천 해동수량 확인
- [ ] 판매량 기준: 동일요일 최근 3주 평균 → 부족하면 확보된 동일요일 평균 → 그마저 없으면 최근 14일 평균 (자동 계산)
- [ ] 최근 3일 연속 폐기율 15% 이상 → 20% 감량 추천 / 최근 3일 연속 완판 → 10% 증량 추천
- [ ] 최소진열수량 밑으로는 내려가지 않음
- [ ] 원재료 발주: 현재재고 입력 → 소진예상일수 확인 → 🚨 알림 뜨면 발주 준비

**완료 기준**: 매일 데이터 입력 누락 없이 기록되고, 다음날 해동수량이 추천값과 일치
**관리자 보고 기준**: ⚠️ 폐기주의 표시가 반복되는 제품 발생 시

## 10장. 마감 매뉴얼

> 시작 기준: 저녁 20:30경, 손님이 줄어들면 마감 시작

**① 뒷카운터 정리**
- [ ] 퓨레류 냉장 보관, 집기통·얼음스쿱 세척, 시럽판 밑 청소

**② 주방 정리**
- [ ] 튀김기 주변·설탕통·스텐 집기 세척
- [ ] 견과류 등 냉장 보관
- [ ] **오늘 폐기수량을 v1 엑셀에 입력**
- [ ] 떡 날짜 표기, 싱크대 설거지·음식물 처리

**③ 앞카운터 정리**
- [ ] 그라인더 주위 정리
- [ ] 커피머신 마감 세척(포터필터 교체→세척→헤드 찌꺼기 제거→트레이 세척→건조)

**④ 홀 정리 + 마지막 정리**
- [ ] 식기세척기 마감, 행주 세탁
- [ ] 테이블·의자 정돈, 태블릿 충전, 에어컨·불 끄기, TV·음악 끄기

**⑤ 포스기 마감**
- [ ] 영업관리 → 마감정산 → 현금 확인·입력 → 정산서 출력·보관 → 초기 금액 확인 → 시스템 종료

**⑥ 최종 퇴실**
- [ ] 뒷문·앞문·주방 뒷문 잠금 확인

**예외 상황**: 이미 마감했는데 늦은 주문 발생 시 재세척하지 않고 최소한으로 대응, 순서(①→⑥)는 그대로 유지
**관리자 보고 기준**: 현금 시재 불일치 / 마감 후 기기 이상 발견 시

## 11장. 컴플레인·돌발상황 대응

**클레임 응대 3단계**
1. **경청**: 고객 말 끊지 않고 끝까지 듣기
2. **공감**: "많이 불편하셨겠어요. 죄송합니다."
3. **해결**: 즉시 교환/환불, 점장 승인 필요 시 신속 보고

**직원 선에서 처리 vs 매니저 호출 기준**
- 직원이 매뉴얼(7장 상황별 멘트, 클레임 3단계)대로 시도해보고, 그래도 해결이 안 되면 **그때 매니저를 호출**한다.

**돌발상황 대응** (정전, 화재, 손님 부상, 심각한 시설 고장 등): *확인 필요 — 아직 정리된 매뉴얼이 없어 임의로 작성하지 않았습니다. 각 상황별 1차 대응(예: 전원 차단 위치, 응급 연락처, 대피 동선)을 알려주시면 채워드릴게요.*
