# 떡기리 신입직원 교육 온라인북 · v1 앱

빌드 도구 없이 동작하는 정적 웹앱입니다. `index.html`을 폰이나 PC 브라우저로 열면 바로 됩니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대 |
| `style.css` | 폰에서 보기 좋은 스타일 |
| `app.js` | 목차·검색·체크리스트·교육표·확인 필요 화면 |
| `content.md` | **매뉴얼 내용 (12장 + 별도 출력물)** — 사장님이 고치는 파일 |
| `content.js` | `content.md`를 앱이 읽는 형태로 바꾼 것 (자동 생성) |
| `make-content.sh` | `content.md` → `content.js` 변환 |

## 실행

- 그냥 열기: `index.html` 더블클릭
- 인터넷 주소로: Vercel에 이 폴더를 그대로 올리면 됩니다 (프레임워크 없음, 빌드 명령 없음, 출력 폴더 `.`)

## 내용 고치기

1. `content.md`를 고칩니다. 규칙은 지금 파일과 같게: `## 4장. 오픈 매뉴얼` 처럼 장 제목, `- [ ] ` 로 체크 항목, 아직 정하지 못한 건 `확인 필요`라고 씁니다.
2. `bash make-content.sh` 를 실행합니다. (Claude에게 "content.md 고쳤어, content.js 다시 만들어 줘"라고 해도 됩니다)
3. 커밋·push 합니다.

## 저장되는 것

- 체크 상태는 그 폰(브라우저)에만 남습니다. 오픈·마감 체크리스트와 각 장의 체크는 날짜가 바뀌면 새로 시작합니다.
- 교육표의 "읽었어요"는 날짜가 바뀌어도 남습니다.
- 서버·데이터 창고 없음. 여러 폰의 기록을 모으는 것은 v2에서 Supabase로 합니다.
