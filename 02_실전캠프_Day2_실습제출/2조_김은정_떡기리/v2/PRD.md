# 기획안(PRD) — 떡기리 신입직원 교육 온라인 북 · v2

> 초안 — v1을 써 본 뒤 고칩니다

- 가게 / 이름: 떡기리 / 김은정
- 조 주제: 직원 교육 매뉴얼 온라인 북
- 이 버전의 목표 한 줄: **사장과 사수가** **내용이 바뀌거나 신입이 들어올 때** **폰에서 바로 매뉴얼을 고치고, 직원별 오픈·마감 체크와 교육 진행을 한눈에 보는** 온라인 북

> 전체 그림은 `../PRD_전체.md`에 있습니다. 이 문서는 그중 [v2]만 옮긴 초안입니다.
> v1을 써 본 기록(`../v1/사용메모.md`)을 보고 10/2 중간 점검에서 다시 정합니다.

## 1. 무엇을 왜 만들고 싶나요?

v1은 12장 매뉴얼을 직원 폰에서 찾아보고 오픈·마감을 체크하는 것까지입니다. 그런데 v1에서는 내용을 고치려면 사장이 파일을 고쳐 다시 올려야 하고, 체크 기록이 그 폰에만 남아 사장은 누가 오픈·마감을 제대로 했는지, 신입 교육이 어디까지 됐는지 여전히 물어봐야 합니다. 온라인북에 남은 "확인 필요" 8곳도 채워 넣을 화면이 없습니다.

## 2. 누가 언제 쓰나요?

- **사장**: 내용이 바뀔 때, "확인 필요"를 채울 때, 사진을 올릴 때 → 관리 화면. 신입별 교육 진행과 매장별 오픈·마감 기록을 볼 때 → 점검표 화면
- **담당 사수(매니저·점주)**: 신입 1·3·7일차 교육을 확인하고 "관리자 확인"을 누를 때
- **직원**: v1과 같음. 다만 체크할 때 자기 별칭을 고른다 (실명·로그인 없음)

## 3. 지금은 어떻게 하고 있나요?

v1을 쓰고 있다고 가정하면: 내용 수정은 사장이 파일을 고쳐 올림. 체크·교육 기록은 각자 폰에만 남음. 사장은 "오늘 마감 다 했어?", "3일차 교육 봤어?"를 카톡으로 물어봄. 오픈 때 추천 해동수량은 엑셀을 따로 열어 확인.

## 4. 도구를 쓰면 어떤 일이 달라지나요?

한 건 기준:
- **넣는 것**: 사장이 관리 화면에서 8장 세척 주기 표 한 줄을 고치고 사진 1장을 올림 / 직원이 별칭 "알바 A"를 고르고 마감 체크리스트 6개를 체크함
- **나오는 것**: 세 매장 직원 폰에 바로 바뀐 내용이 보임 / 사장 점검표에 "알바 A · 9/20 마감 · 6/6 완료"가 뜸. 신입별로 1·3·7일차 진행과 사수 확인 여부가 표로 보임
- **달라지는 것**: 파일을 다시 올리지 않아도 됨. "다 했어?"라고 묻지 않아도 됨. 별도 출력물 ④(교육 완료 점검표)가 종이 대신 화면이 됨

## 5. v2에서 만들 것 — 10/17까지 (API 연동·외부 데이터 등 v1에서 미룬 것)

**꼭 할 것**
- 기능 1: **사장 관리 화면** — 장·항목 편집, "확인 필요" 채우기, 사진 업로드. 내용은 Supabase(데이터 창고)에 저장. 간단 비밀번호(PIN)로 잠금
- 기능 2: **직원별 체크·교육 기록 → 사장 점검표** — 직원이 별칭을 고르고 체크하면 누가 언제 오픈·마감을 했는지, 신입별 1·3·7일차 진행과 사수 "관리자 확인"이 한 화면에 (Supabase)

**여유 있으면**
- 기능 3: **재고 엑셀 툴 연결** — 재고발주추천툴 엑셀을 올리면 오픈 4장에 오늘 제품별 추천 해동수량 표시
- 기능 4: **결제·주문관리 장 추가** — OK포스·키오스크·배달앱 4개(배민·쿠팡이츠·요기요·땡겨요) 처리 순서 (내용은 사장이 앱별 화면을 확인해 줌)
- 기능 5: **돌발상황 대응·팝업 매장 부록** — "확인 필요"로 남은 기준을 사장이 정한 뒤 장으로 추가
- 기능 6: **AI 손님 응대 문장 초안** — 손님 질문을 치면 7장을 바탕으로 초안 (Claude API). 사장이 확인 후 "매뉴얼에 넣기"
- 기능 7: **명절 시즌 장 켜고 끄기** — 선물세트 포장·예약 접수 순서를 시즌에만

**준비물**
- Supabase 가입·로그인과 열쇠(Project URL, anon 키) 붙여넣기는 사장이 직접. 프로젝트·테이블·RLS는 Claude가 Claude in Chrome으로
- Claude API 키 발급과 사용 비용 확인 (기능 6을 할 때만)
- 재고발주추천툴 엑셀의 시트·열 이름 확인, 시연용 가짜 수량 파일 (기능 3을 할 때만)

- **이번에 하지 않을 것:** 직원 로그인(별칭으로 충분한지 먼저 봄), 퀴즈·교육 이수 시험, 매장별 표시, 카톡 알림 발송

## 6. 완성됐다는 걸 어떻게 확인하나요?

- 시연할 예시 입력: 사장이 PIN 입력 → 8장 세척 주기 표 한 줄 수정 + 사진 1장 업로드 → 다른 폰에서 8장 열기 / 직원 폰에서 별칭 "알바 A" 고르고 마감 체크리스트 6개 체크 → 사장 점검표 열기
- 기대하는 결과: 다른 폰에서 바뀐 내용과 사진이 보임. 점검표에 "알바 A · 오늘 마감 · 6/6 완료"가 보이고, 신입별 1·3·7일차 진행 표에서 사수가 "관리자 확인"을 누르면 확인일이 남음
- 잘못 입력했을 때: 틀린 PIN이면 관리 화면이 열리지 않음. 별칭을 고르지 않고 체크하면 "누구인지 골라 주세요" 안내. (기능 3) 엑셀 열 이름이 다르면 읽지 않고 "파일 형식이 달라요"
- 다시 열었을 때 남아 있어야 할 것: 수정한 내용·사진, 모든 직원의 체크·교육 기록 (다른 폰·다른 브라우저에서 열어도 동일)

## 7. 그 다음에 더하고 싶은 것

- 다음에 추가할 기능 하나: 매장별 표시 (세 매장 내용이 달라지면), 직원 로그인 (별칭으로 부족하면)
- 필요한 데이터나 외부 연결 (API, 배민 데이터, 날씨 등): 카톡 알림(오늘 마감 안 한 매장 알림) — 알림톡 심사가 필요해 [나중]
- 사람이 직접 판단·확인해야 할 부분: 알림을 보낼지 말지는 사장이 누름

## 8. 절대 자동화하면 안 되는 것

- 손님에게 직접 보내는 메시지·답변 전송
- 알레르기·유통기한·보관 기한·위생 온도 같은 안전 정보의 자동 생성. AI 초안은 사장이 확인 후에만 반영
- "확인 필요" 항목 채우기 (법률·노무·식품위생 관련은 사장이 확인해서 씀)
- 신입 교육 "관리자 확인" 버튼 (사수·사장이 직접 보고 누름)
- 직원 근무·급여와 관련된 판단 (교육용으로만)
