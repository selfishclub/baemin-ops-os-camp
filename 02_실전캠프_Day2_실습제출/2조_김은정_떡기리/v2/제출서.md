## 만든 것

- 도구 이름: 떡기리 신입직원 교육 온라인북 v2
- 한 줄 설명: 12장 매뉴얼은 v1 그대로, 오픈·마감 체크를 "이름 → 체크(즉시 저장) → 완료 제출"로 서버에 남기고, 사장은 점검표에서 날짜별 완료 여부·담당자·미완료 항목·특이사항을 봄
- 프로젝트 폴더: `v2/프로젝트/` (만든 폴더 통째로. 코드·SQL·설정 스크립트·문서 전부)
- 실행 방법:
  1. 인터넷 주소를 폰으로 열면 바로 됩니다. 로그인 없음. 처음 한 번 이름을 고르거나 적습니다.
  2. 사장 점검표는 첫 화면 맨 아래 "사장 점검표" → 숫자 4자리(PIN). 거기서 "매장·이름 목록 고치기"로 매장·직원 이름을 등록합니다.
  3. 내 컴퓨터에서 열려면 `열쇠_예시.txt`대로 `.env.local`을 만들고 `node make-config.js` 후 `index.html`을 엽니다. 자세한 건 `v2/프로젝트/README.md`.
- 첫 화면 스크린샷: `결과물/첫화면.png`
- 다른 스크린샷: `결과물/체크리스트.png`(마감 체크리스트·특이사항), `결과물/사장점검표.png`(날짜별 담당자·완료시간·상태·미완료 항목·특이사항)
- 영상이 있으면 링크로 (파일은 올리지 않습니다):
- PRD 아티팩트 링크 (사전 과제로 만든 웹페이지, 있으면): https://claude.ai/code/artifact/02c8b0fc-06d7-49aa-97c4-300e8937794c

## 이번 버전에서 되는 것

- 체크리스트 시작 때 이름 고르기(매장이 2곳 이상 등록돼 있으면 매장도). 폰이 기억함
- 항목을 누르는 즉시 서버(Supabase)에 저장. 어느 폰·어느 브라우저(카톡 안 브라우저 포함)로 열어도 같은 상태
- 특이사항 입력칸 (재고 부족, 기기 이상 등) — 쓰는 즉시 저장
- "완료 제출" 버튼 → 담당자 이름·완료 시각 기록. 빠진 항목이 있으면 확인 후 제출
- 사장 점검표(PIN): 날짜별 매장 × 오픈·마감 완료/진행 중/미완료 표 + 기록마다 담당자·완료시간·체크 수·미완료 항목·특이사항 카드. 전날·다음날 이동, 과거 기록은 서버에 계속 보존
- 사장님 번호(PIN) 바꾸기: 점검표 → 목록 화면에서 새 번호 설정(서버에 해시로 저장). 처음 값은 Vercel 환경변수 OWNER_PIN(0000)
- 매장·이름 목록 등록 화면 (코드에 지점명이 박혀 있지 않음. 등록한 것만 보임)
- 서버 연결이 없거나 저장이 실패하면 빨간 안내 + 폰에 임시 보관
- v1 기능(12장 매뉴얼·검색·교육표·확인 필요)은 그대로
