# 떡기리 직원 온라인북 · 점주님 시작 안내

> 본사에서 지점을 등록하면 이 안내문이 **링크·점주 번호(PIN)가 채워진 상태**로 자동 생성됩니다(본사 화면 → 지점 등록 → "점주 안내문 복사"). 아래는 그 안내문의 원본입니다. 5분이면 끝나요.

```text
[떡기리 직원 온라인북 · {지점명} 점주님 안내]

1) 우리 지점 직원용 링크
{직원용 링크}

2) 점주 화면 들어가기
위 링크를 열고 → 맨 아래 "점주 화면" → 점주 번호(PIN) {6자리} 입력
※ 처음 들어가면 설정 → "점주 번호 바꾸기"에서 번호를 꼭 바꿔 주세요 (숫자 6자리)

3) 직원 이름 등록
점주 화면 → 직원관리 → 이름 적고 "추가" (입사일은 선택)

4) 직원에게 링크 보내기
점주 화면 → 설정 → "직원용 안내문 복사" → 직원 단톡방에 붙여넣기 (QR 저장·인쇄도 가능)
직원은 링크를 열고 본인 이름만 고르면 끝이에요. 번호·코드는 필요 없어요.

5) 오픈·마감 확인
점주 화면 → 오늘 점검: 담당자 · 완료시간 · 빠진 항목 · 특이사항

6) 우리 지점만의 내용 덧붙이기
점주 화면 → 우리 지점 추가사항 → 장과 소제목을 고르고 내용 저장. 직원 화면에 바로 보여요.

문제가 생기면: 본사(떡기리)에 연락 주세요. 번호를 잊으면 본사에서 새로 받을 수 있어요.
```

## 자주 묻는 것
| 상황 | 하는 법 |
|---|---|
| 직원이 "내 이름이 없어요" | 점주 화면 → 직원관리에서 이름 추가. 직원은 링크를 닫았다 다시 열면 보여요 |
| 직원이 그만뒀어요 | 직원관리 → 그 직원 "퇴사". 목록에서 빠지고 과거 기록은 남아요. "복귀"로 되돌릴 수 있어요 |
| 점주 번호를 잊었어요 | 본사에 연락 → 본사 화면 "PIN 초기화"로 새 번호를 받아요 |
| 번호를 5번 틀렸어요 | 10분 뒤 다시 넣으면 돼요 |
| 공통 매뉴얼 내용을 고치고 싶어요 | 공통 매뉴얼은 본사만 고칩니다. 우리 지점만의 내용은 "우리 지점 추가사항"에 적어요 |
| 체크가 저장 안 돼요 | 직원 폰의 인터넷을 확인하고 다시 눌러요. 화면 위 "✓ 서버에 저장됨"이 나오면 된 거예요 |
| 다른 지점이 우리 기록을 볼 수 있나요 | 아니요. 지점 링크·점주 번호가 다르면 서로의 직원·기록·추가사항을 볼 수 없어요. 본사만 전체를 봅니다 |
