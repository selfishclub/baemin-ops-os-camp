# 직원 단톡방 안내문 (점주가 그대로 복사해 보내는 글)

점주 화면 → 설정 → "직원용 안내문 복사"를 누르면 아래 글이 **우리 지점 링크가 채워진 채로** 복사됩니다. 직원은 번호도 지점 코드도 몰라도 됩니다.

```text
[{지점명} 직원 온라인북]
이 링크는 우리 지점 직원교육 온라인북이에요.
링크를 열고 본인 이름을 고른 뒤 오픈·마감 체크와 업무 매뉴얼을 확인해 주세요.
{직원용 링크}
(번호나 코드는 없어요. 홈 화면에 추가해 두면 앱처럼 쓸 수 있어요)
```

## 직원이 하는 일 (3단계)
① 링크 열기 (카톡에서 열려도 되고, "브라우저로 열기"를 누르면 더 편해요)
② 본인 이름 고르기 — 한 번 고르면 폰이 기억해요
③ 오픈·마감 체크리스트 누르기 → 항목 체크 → 맨 아래 "완료 제출"

## 직원이 알아 둘 것
- 체크는 누를 때마다 바로 저장돼요 (화면 위 "✓ 서버에 저장됨")
- 마감 때는 "오늘 폐기"를 꼭 적어요. 없으면 "오늘 폐기 없음"
- 이상한 게 있으면 "특이사항"에 적으면 점주님 화면에 바로 보여요
- 📍 "우리 지점 추가사항" 상자는 우리 지점에서만 적용되는 내용이에요
- 내 이름이 목록에 없으면 점주님께 말해요
