# 떡기리 직원 온라인북 · v3 (다점포)

v2 와 같은 정적 웹앱(빌드 도구 없음)입니다. 달라진 점:

- 직원은 **지점 전용 링크** `https://<주소>/#/s/<지점코드>` 로 들어옵니다. 코드는 링크 안에 있어 직원이 입력하지 않습니다. 한 번 열면 폰이 기억합니다.
- 앱은 Supabase 표를 직접 읽지 않고 **지점 코드를 받는 서버 함수**(`v3/db/05_functions_staff.sql`)만 부릅니다. 다른 지점 데이터는 받을 수 없습니다.
- 매뉴얼 = 본사 공통(`manual_pages`) + 우리 지점 추가사항(`store_manual_notes`). 소제목 아래 "📍 우리 지점 추가사항" 상자로 이어서 보입니다. DB가 비어 있으면 `content.js` 로 보여 줍니다.
- 점주·본사 화면은 3·4단계에서 추가됩니다. 그때까지 점주 점검은 v2 주소의 사장 점검표를 그대로 씁니다(기록이 양쪽에 똑같이 보임).

## 실행
`열쇠_예시.txt` 대로 `.env.local` 을 만들고 `node make-config.js` → `index.html` 을 열고 `#/s/<코드>` 로 들어갑니다. Vercel 은 환경변수 SUPABASE_URL, SUPABASE_ANON_KEY(Publishable key) 만 있으면 됩니다.
