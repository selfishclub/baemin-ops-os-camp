# 기획안(PRD) — 배달 리뷰 한눈에 + 답글 도우미 · v2
> 초안 — v1을 써 본 뒤 고칩니다

- 가게 / 이름: 마선생얼큰국밥 / 유승균
- 조 주제: 직원 스케줄 관리 / 메뉴 원가 분석 / 배민 데이터 분석 대시보드
- 이 버전의 목표 한 줄: 리뷰는 알아서 들어오고, 사장님은 초안을 고르기만 하면 배민·쿠팡이츠에 답글이 바로 등록되는 도구

> 전체 그림은 [`../PRD_전체.md`](../PRD_전체.md)에 있습니다. 이 문서는 그중 [v2]만 담았습니다.

## 1. 무엇을 왜 만들고 싶나요?

v1에서도 리뷰를 붙여넣고, 고른 초안을 복사해 배민 앱에 붙여넣는 손일이 남는다. 사장님이 바란 것은 "선택 한 번으로 작성까지 완료"다.

## 2. 누가 언제 쓰나요?

사장님 혼자. 폰으로 리뷰를 보고 초안을 고른다. 등록과 수집은 노트북 크롬(사장님 사이트 로그인 유지)에서 돈다.

## 3. 지금은 어떻게 하고 있나요?

(v1 기준) 리뷰 붙여넣기 → 초안 고르기 → 복사 → 배민 앱에 붙여넣고 등록 → 답글 완료 체크.
v1 사용메모를 모아 채운다.

## 4. 도구를 쓰면 어떤 일이 달라지나요?

새 리뷰가 자동으로 들어옴 → 초안 하나 고르기 → 배민·쿠팡이츠에 바로 등록되고 "답글 완료"로 바뀜.

## 5. v2에서 만들 것

**꼭 할 것**
- 답글 바로 등록 — 초안을 고르면 배민·쿠팡이츠 사장님 사이트에 등록 (기존 배달 리뷰 자동답글 크롬 확장 활용)
- 리뷰 자동 불러오기 — 배민·쿠팡이츠 새 리뷰가 알아서 들어옴 (기존 수집기 활용)

**여유 있으면**
- AI 답글 초안 — 사장님 말투·리뷰 내용을 살린 초안
- 리뷰 목록 거르기 — 불만/단골/칭찬·플랫폼·메뉴·완료 여부
- 분석 화면 — 주간 유형별 건수(누락·식음 반복 여부), 메뉴별 칭찬·불만
- 네이버 방문자 리뷰 함께 보기

**준비물**
- 노트북 크롬에 배민·쿠팡이츠 사장님 사이트 로그인 (비밀번호는 사장님이 직접)
- 크롬 확장과 도구를 잇는 연결 토큰 (`.env`에만 보관)
- (AI 초안 시) AI 키 발급 — `.env`에만 보관

- **이번에 하지 않을 것:** 불만 리뷰 알림 ([나중] — 알림 방식 미정, 카톡 알림톡은 심사 필요)

## 6. 완성됐다는 걸 어떻게 확인하나요?

- 시연할 예시 입력: 시연용 매장 계정(또는 가짜 데이터)에 새 리뷰 1건
- 기대하는 결과: 리뷰가 자동으로 들어오고, 초안을 고르면 사장님 사이트에 답글이 등록되고 도구에서 "답글 완료"로 바뀜
- 잘못 입력했을 때: 등록 실패(로그인 풀림·사이트 개편) 시 "등록 못 했어요, 복사해서 직접 올려 주세요"로 v1 방식으로 돌아감
- 다시 열었을 때 남아 있어야 할 것: v1 항목 + 자동으로 들어온 리뷰의 원래 번호(중복 방지)

## 7. 그다음에 더할 것

- 불만 리뷰 알림 (방식 정한 뒤)

## 8. 절대 자동화하면 안 되는 것

- 답글 등록은 사장님이 초안을 **고른 뒤에만**. 고르지 않은 리뷰를 한꺼번에 자동 등록하지 않는다.
