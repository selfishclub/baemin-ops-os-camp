# 전체 기획안(PRD) — 배달 리뷰 한눈에 + 답글 도우미

- 가게 / 이름: 마선생얼큰국밥 / 유승균
- 조 주제: 직원 스케줄 관리 / 메뉴 원가 분석 / 배민 데이터 분석 대시보드
- 한 줄 목표: 사장님이 주 2~3번 몰아서 리뷰를 챙길 때, 폰에서 불만·단골 리뷰를 먼저 보고 답글 초안을 골라 바로 끝내는 도구
- 마지막 수정: 2026-09-17

> **이 문서는 "다 만들었을 때의 모습"입니다.** 먼저 여기에 전체를 그린 뒤, 4번 기능 목록에 꼬리표를 붙여
> 오늘 만들 것은 `v1/PRD.md`로, 나중에 더할 것은 `v2/PRD.md`로 나눕니다.
> v1을 써 본 뒤에는 `v1/사용메모.md`를 보고 이 문서와 v2를 다시 고칩니다.
>
> 참고: 사장님이 이미 만든 개인 도구(배달 리뷰 자동답글 크롬 확장, 「리뷰 콘텐츠 스튜디오」의 리뷰 수집·분류)를 운영 도구로 다시 정리한 기획입니다.

## 1. 배경 — 최근 실제로 있었던 한 장면

- 장면: 배민 앱에서 단골 손님 리뷰("긴말 안 합니다, 최근 5번째 주문")를 봤다. 노트북을 켜서 배민 사장님 사이트에 들어가 답글을 직접 타이핑했다. 따로 모아 둔 리뷰(개인 앱)는 열어 보지 않았다.
  - 막힌 곳 — 답글 쓰기 전부: 단골을 알아봐 주는 문장이 매번 비슷해짐 · "긴말 안 한다"는 짧은 리뷰라 뭘 짚을지 막막함 · 노트북에서 한 글자씩 치는 데 오래 걸림 · 이런 리뷰가 여러 개 쌓여 있음
- 얼마나 자주: 리뷰는 하루 4~10개(배민·쿠팡이츠), 답글은 주 2~3번 몰아서
- 한 번에 걸리는 시간: 한 번 앉으면 30분~1시간 (주 1~3시간)
- 실수·빠뜨림: 불만 리뷰를 일주일 넘게 늦게 발견한 적이 있음 → 그사이 같은 문제(누락·식음 등)가 또 생김

## 2. 쓰는 사람과 역할

| 누가 | 언제 여나 | 무엇을 보나 | 무엇을 누르나 | 어떤 기기로 |
|---|---|---|---|---|
| 사장 (혼자 담당, 매장 1곳) | 주 2~3번 답글 챙길 때 · 틈틈이 불만 확인 | 불만 리뷰 먼저, 답글 안 단 리뷰 수, 이번 주 리뷰 수·평균 별점 | 리뷰 넣기, 초안 고르기, 답글 완료, 불만 대응 메모 | 사장님 폰 |

직원은 쓰지 않는다.

## 3. 흐름 — 지금 vs 도구를 쓰면

| 단계 | 지금 (쓰는 앱·파일) | 도구를 쓰면 |
|---|---|---|
| 1 | 배민 앱에서 리뷰를 보고 기억해 둔다 | 리뷰를 도구에 넣는다 (v2부터는 자동으로 들어옴) |
| 2 | 노트북을 켜고 배민 사장님 사이트에서 그 리뷰를 다시 찾는다 | 폰 첫 화면에 불만 리뷰가 맨 위, 단골·칭찬은 표시가 붙어 보인다 |
| 3 | 답글 문장을 생각해서 직접 타이핑한다 | 리뷰를 누르면 사장님 말투 초안 2~3개가 나오고 하나를 고른다 |
| 4 | 등록 버튼을 누른다 | (v1) 복사해서 배민 앱에 붙여넣고 등록 → (v2) 고르면 바로 등록 |
| 5 | 불만 원인은 머릿속에만 남는다 | "답글 완료"와 불만 대응 메모가 남고, 같은 불만이 반복되는지 보인다 |

## 7. 예외 — 잘못 넣거나 평소와 다를 때

- 같은 리뷰를 두 번 넣으면 → 새로 만들지 않고 "이미 있는 리뷰예요" 안내
- 별점이나 메뉴가 빠진 리뷰면 → 저장하되 "정보 부족" 표시
- 초안이 리뷰 내용과 안 맞으면 (메뉴를 잘못 말함 등) → "다시 만들기" 버튼
- 이미 답글을 단 리뷰면 → 초안 버튼을 막고 "완료됨" 표시

## 8. 사람이 꼭 직접 해야 하는 것 (자동화 금지)

- 답글 등록은 사장님이 초안을 **고른 뒤에만**. 고르지 않은 리뷰를 한꺼번에 자동 등록하지 않는다.

## 9. 성공 기준 — 숫자로

- 지금: 답글에 주 1~3시간 (한 번 30분~1시간 × 주 2~3번), 불만 리뷰를 일주일 넘게 늦게 발견한 적 있음
- 목표: [가정] 한 번 앉는 시간 15분 이하, 불만 리뷰는 들어온 뒤 다음 확인 때(최대 3일) 반드시 처리
- 시연할 예시 입력 → 기대하는 결과: 가짜 리뷰 5개(단골 칭찬 1·불만 누락 1·일반 칭찬 3) 붙여넣기 → 첫 화면 맨 위에 불만 1건 → 단골 리뷰를 누르면 "5번째 주문"을 짚는 초안 2~3개 → 하나 고르고 복사 → 답글 완료로 바뀌고 다시 열어도 남아 있음
