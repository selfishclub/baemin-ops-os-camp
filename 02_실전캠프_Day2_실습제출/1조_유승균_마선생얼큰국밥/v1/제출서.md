## 만든 것

- 도구 이름: 배달 리뷰 한눈에 + 답글 도우미
- 한 줄 설명: 폰에서 불만 리뷰를 먼저 보고, 리뷰마다 답글 초안 2~3개 중 하나를 골라 복사해 배민·쿠팡이츠 답글을 빨리 끝내는 도구
- 프로젝트 폴더: `v1/프로젝트/` (만든 폴더 통째로. 코드·프롬프트 기록·이미지·문서 전부. 10/2까지 여기)
- 실행 방법 (AI에게 "실행 방법을 제출서에 세 줄로 적어 줘"):
  1. `v1/프로젝트/index.html`을 더블클릭합니다 (설치할 것 없음).
  2. 시연용 리뷰로 보려면 「리뷰 넣기」 → "시연용 가짜 리뷰 5개 넣기"를 누릅니다.
  3. 「오늘 할 일」에서 리뷰를 누르고 초안을 골라 복사 → 배민 앱에 붙여넣어 직접 등록 → "답글 완료"를 누릅니다.
- 첫 화면 스크린샷: `결과물/첫화면.png` (구경하기 표에 올라갑니다)
- 다른 스크린샷: `결과물/답글초안.png` (단골 리뷰 초안 고르기) · `결과물/불만리뷰.png` (불만 리뷰 초안·대응 메모) · `결과물/리뷰넣기.png`

## 이번 버전에서 되는 것

- 리뷰 넣기 (플랫폼·날짜·별점·메뉴·몇 번째 주문·내용) — 같은 리뷰는 "이미 있는 리뷰예요", 별점·메뉴가 비면 "정보 부족" 표시
- 불만 / 단골 / 칭찬 자동 표시와 유형(누락·식음·맛·양·배달 등)
- 오늘 할 일: 답글 안 단 리뷰 수, 이번 주 리뷰 수·별점, 불만 리뷰가 맨 위
- 답글 초안 2~3개 고르기 → 복사 · 다시 만들기 · 답글 완료 (완료된 리뷰는 초안이 막힘), AI 키 없이 규칙으로 만듦
- 불만 리뷰에 "무엇을 고쳤나" 메모
- 다시 열어도 남음 (이 폰·브라우저 안에 저장)
