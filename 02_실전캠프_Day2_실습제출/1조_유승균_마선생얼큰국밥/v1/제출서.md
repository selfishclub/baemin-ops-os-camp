# v1 제출서 — 마선생얼큰국밥 / 유승균

## 만든 것

- 도구 이름: 리뷰 콘텐츠 스튜디오
- 한 줄 설명: 배민·쿠팡이츠·네이버 리뷰를 모아 맛·양·포장·배달·불만 등으로 자동 분류해 한눈에 보고, 리뷰 하나로 인스타 캐러셀·릴스 대본·새소식 문구를 AI가 만들어 주는 웹앱
- 프로젝트 폴더: `v1/프로젝트/` (만든 폴더 통째로. 코드·프롬프트 기록·이미지·문서 전부. 10/2까지 여기)
  - 비밀 키(`.env.local`), 실제 리뷰가 든 데이터 파일(`data/`), 로그인 정보는 빼고 올렸습니다.
- 실행 방법 (AI에게 "실행 방법을 제출서에 세 줄로 적어 줘"):
  1. `v1/프로젝트/` 폴더에서 `npm install --legacy-peer-deps` 를 한 번 실행합니다. (Node 22.13 이상)
  2. 같은 폴더에 `.env.local` 파일을 만들고 `ANTHROPIC_API_KEY=` 또는 `OPENAI_API_KEY=` 뒤에 AI 키를 넣습니다. (키는 올리지 않습니다)
  3. `npm run dev` → 브라우저에서 `http://localhost:3400` → 설정에서 가게 정보 저장 → 「배민 수집」 또는 크롬 확장으로 리뷰 넣기 → 리뷰 카드의 「콘텐츠 만들기」
- 첫 화면 스크린샷: `결과물/첫화면.png` (구경하기 표에 올라갑니다 · 시연용 가짜 리뷰)
- 다른 스크린샷: `결과물/답글도우미_시안/` — PRD대로 먼저 만든 「배달 리뷰 한눈에 + 답글 도우미」 화면 (코드는 `v1/답글도우미_시안/`)
- 영상이 있으면 링크로 (파일은 올리지 않습니다):
- PRD 아티팩트 링크 (사전 과제로 만든 웹페이지, 있으면):
- Vercel 배포 주소 (오늘은 있으면. 만드는 법 → [부록](../../../03_인터넷에서_접근가능하게_만들기/부록_CLI로_바로_올리기.md)): https://review-content-studio.vercel.app/ (접속 비밀번호가 걸려 있습니다)

## 이번 버전에서 되는 것

- 배민·쿠팡이츠 리뷰 자동 수집 (노트북 크롬, 로그인 유지), 네이버 방문자 리뷰 수집, 크롬 확장(배달 리뷰 자동답글 도우미)에서 리뷰 받기
- 리뷰 자동 분류: 맛·양·포장·배달·서비스·가격·재주문·사진·불만 태그, 긍정/부정, 콘텐츠 소재 점수
- 리뷰 대시보드(전체·이번 주 리뷰 수, 검색·플랫폼·감정·태그 거르기), 좋은 리뷰를 모아 두는 리뷰 수집함
- 주간 베스트: 지난주 리뷰 요약 + 콘텐츠 소재 Top 5 (AI)
- 리뷰 하나로 인스타 캐러셀 · 릴스/쇼츠 대본 · 네이버/당근 새소식 문구 한 번에 만들기 (AI, 리뷰에 없는 내용은 쓰지 않음, 손님 닉네임은 가림)
- 인터넷 주소(Vercel) + 클라우드 저장(Turso), 접속 비밀번호

## 아직 안 되는 것 / 다음에 할 것

- 수집은 노트북에서만 됩니다 (인터넷 서버는 크롬을 열 수 없음)
- 배민·쿠팡 사이트가 바뀌면 수집이 멈출 수 있음
- 답글 도우미 시안(불만 리뷰 먼저 보기 · 답글 초안 고르기)을 스튜디오에 합치기
- PRD를 스튜디오 기준으로 맞추기 (운영진 확인 후)
