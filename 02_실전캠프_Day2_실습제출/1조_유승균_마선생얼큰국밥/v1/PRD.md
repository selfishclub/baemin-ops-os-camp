# 기획안(PRD) — 배달 리뷰 한눈에 + 답글 도우미 · v1

- 가게 / 이름: 마선생얼큰국밥 / 유승균
- 조 주제: 직원 스케줄 관리 / 메뉴 원가 분석 / 배민 데이터 분석 대시보드
- 이 버전의 목표 한 줄: 사장님이 주 2~3번 리뷰를 챙길 때, 폰에서 불만 리뷰를 먼저 보고 답글 초안을 골라 복사해 끝내는 도구

> 전체 그림은 [`../PRD_전체.md`](../PRD_전체.md)에 있습니다. 이 문서는 그중 [v1]만 담았습니다.

## 1. 무엇을 왜 만들고 싶나요?

배민 앱에서 단골 손님 리뷰("긴말 안 합니다, 최근 5번째 주문")를 보고, 노트북을 켜서 사장님 사이트에서 답글을 직접 타이핑했다. 단골을 알아봐 주는 문장이 매번 비슷해지고, 짧은 리뷰라 뭘 짚을지 막막하고, 치는 데 오래 걸리고, 이런 리뷰가 쌓여 있었다.
불만 리뷰를 일주일 넘게 늦게 발견해, 그사이 같은 문제(누락·식음 등)가 또 생긴 적도 있다.

## 2. 누가 언제 쓰나요?

사장님 혼자(매장 1곳). 주 2~3번 몰아서 답글을 챙길 때와 틈틈이 불만 리뷰를 확인할 때, **사장님 폰**으로 연다. 직원은 쓰지 않는다.

## 3. 지금은 어떻게 하고 있나요?

배민 앱에서 리뷰 확인 → 노트북으로 배민 사장님 사이트 접속 → 그 리뷰를 다시 찾아 답글을 직접 타이핑 → 등록.
리뷰는 하루 4~10개(배민·쿠팡이츠), 한 번 앉으면 30분~1시간, 주 1~3시간. 불만 원인은 따로 기록하지 않는다.

## 4. 도구를 쓰면 어떤 일이 달라지나요?

리뷰 한 건(플랫폼·날짜·별점·메뉴·내용·몇 번째 주문)을 붙여넣으면
→ 불만 / 단골 / 칭찬 표시가 자동으로 붙고, 불만은 첫 화면 맨 위로 온다
→ 리뷰를 누르면 답글 초안 2~3개가 나오고, 하나 골라 **복사** → 배민 앱에 붙여넣어 등록
→ "답글 완료"와 단 답글이 남고, 불만이면 "무엇을 고쳤나" 메모가 남는다.

## 5. v1에서 만들 것 — 오늘(9/17) 안에 되는 것만

- 기능 1: **리뷰 넣기** — 붙여넣기로 저장 (플랫폼·날짜·별점·메뉴·내용·몇 번째 주문). 같은 리뷰는 "이미 있는 리뷰예요", 별점·메뉴가 빠지면 "정보 부족" 표시
- 기능 2: **자동 표시** — 불만 / 단골(몇 번째 주문 기준) / 칭찬, 그리고 맛·양·포장·배달 등 유형 (정해 둔 단어 규칙)
- 기능 3: **오늘 할 일 화면** (첫 화면) — 불만 리뷰 맨 위, 답글 안 단 리뷰 수, 이번 주 리뷰 수·평균 별점
- 기능 4: **답글 초안 고르기** — 리뷰 하나에 초안 2~3개 (AI 없이 규칙·문장 틀: 단골이면 "N번째 주문" 감사, 리뷰의 칭찬·불만 포인트를 짚음) → 하나 고르기 → 복사 · 다시 만들기 · 답글 완료 체크. 이미 완료된 리뷰는 초안 버튼을 막고 "완료됨"
- 기능 5: **불만 대응 메모** — 불만 리뷰에 "무엇을 고쳤나" 한 줄
- 화면: ① 오늘 할 일 · ③ 리뷰 상세 · ④ 리뷰 넣기 (폰에서 보기 좋게)
- 데이터 창고: Supabase
- **이번에 하지 않을 것:** 답글 바로 등록 · 리뷰 자동 불러오기 · AI 답글 초안 · 리뷰 목록 거르기 · 분석 화면 · 네이버 리뷰 ([v2]) / 불만 리뷰 알림 ([나중]) / 캐러셀·릴스 등 홍보 콘텐츠 만들기 (범위 밖)

## 6. 완성됐다는 걸 어떻게 확인하나요?

- 시연할 예시 입력: 가짜 리뷰 5개 — 단골 칭찬 1개("긴말 안 합니다. 또 시켰어요", 5번째 주문) · 불만 1개(누락) · 일반 칭찬 3개
- 기대하는 결과: 첫 화면 맨 위에 불만 1건, 답글 안 단 리뷰 5 → 단골 리뷰를 누르면 "5번째 주문"을 짚는 초안 2~3개 → 하나 고르고 복사 → 답글 완료로 바뀌고 안 단 리뷰가 4로 줄어듦
- 잘못 입력했을 때: 같은 리뷰를 다시 넣으면 "이미 있는 리뷰예요" · 별점·메뉴가 빠지면 저장하되 "정보 부족" · 초안이 안 맞으면 "다시 만들기" · 완료된 리뷰는 초안 버튼이 막힘
- 다시 열었을 때 남아 있어야 할 것: 리뷰 기본 정보, 몇 번째 주문, 표시, 답글 완료 여부·단 답글·날짜, 불만 대응 메모

## 7. v2에서 더할 것 (10/14까지 · API·외부 데이터 등)

- 다음에 추가할 기능 하나: **초안을 고르면 배민·쿠팡이츠에 답글 바로 등록** (+ 리뷰 자동 불러오기)
- 필요한 데이터나 외부 연결 (API, 배민 데이터, 날씨 등): 배민·쿠팡이츠 사장님 사이트(기존 크롬 확장·수집기 활용), 여유 있으면 AI 초안·네이버 리뷰
- 사람이 직접 판단·확인해야 할 부분: 어떤 초안으로 등록할지 고르기

## 8. 절대 자동화하면 안 되는 것

- 답글 등록은 사장님이 초안을 **고른 뒤에만**. 고르지 않은 리뷰를 한꺼번에 자동 등록하지 않는다.
