# 배달 리뷰 한눈에 + 답글 도우미 (v1)

마선생얼큰국밥 사장님이 폰에서 **불만 리뷰를 먼저 보고**, 리뷰마다 **답글 초안 2~3개 중 하나를 골라 복사**하는 도구입니다.
기획: [`../PRD.md`](../PRD.md)

## 여는 방법

- **내 컴퓨터:** 이 폴더의 `index.html`을 더블클릭합니다. (설치할 것 없음)
- **시연용 리뷰로 바로 보기:** 이 폴더에서 `python -m http.server 3500` 실행 → 브라우저에서 `http://localhost:3500/?demo` (리뷰가 비어 있을 때 가짜 리뷰 5개를 채웁니다)
- **폰:** Vercel에 올린 주소로 엽니다. (이 폴더를 그대로 올리면 됩니다)

## 화면

| 화면 | 하는 일 |
|---|---|
| 오늘 할 일 | 답글 안 단 리뷰 수 · 이번 주 리뷰 수·별점, 🔴 불만 리뷰가 맨 위 |
| 리뷰 상세 | 초안 2~3개 중 고르기 → 복사 · 다시 만들기 · 답글 완료, 불만이면 "무엇을 고쳤나" 메모 |
| 리뷰 넣기 | 플랫폼·날짜·별점·메뉴·몇 번째 주문·내용. 같은 리뷰는 "이미 있는 리뷰예요", 별점·메뉴가 비면 "정보 부족" |

## 만든 방식

- HTML·CSS·JavaScript만 씁니다. 설치(`npm install`)가 필요 없습니다.
- 저장: 이 브라우저(폰) 안(localStorage). 다른 기기와는 공유되지 않습니다. → v2에서 Supabase로 옮길 때 `js/store.js`만 바꿉니다.
- 답글 초안: AI 없이 정해 둔 단어·문장 틀(`js/rules.js`). 불만·단골·칭찬 단어나 문장을 고치려면 이 파일을 고칩니다.
- 답글 등록은 사장님이 배민·쿠팡이츠 앱에서 **직접** 합니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 틀 |
| `style.css` | 디자인 (폰 기준) |
| `js/store.js` | 리뷰 저장·중복 확인 |
| `js/rules.js` | 불만·단골·칭찬 표시, 답글 초안 규칙 |
| `js/app.js` | 화면 3개와 버튼 동작, 시연용 리뷰 |

손님 이름은 저장하지 않습니다. 시연 데이터는 모두 가짜입니다.
