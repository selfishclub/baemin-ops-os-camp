# v1 제출서 — 빈숲카페 / 양진서

## 만든 것

- 도구 이름: 빈숲 레시피OS (레시피북 v1)
- 한 줄 설명: 직원이 메뉴를 검색하면 정량·제조 순서·주의사항·최종 수정일이 바로 나오고, 버튼 하나로 교육 영상용 프롬프트를 만들어 주는 레시피북
- 프로젝트 폴더: `v1/프로젝트/` (만든 폴더 통째로. 코드·프롬프트 기록·이미지·문서 전부)
- 실행 방법:
  1. `v1/프로젝트` 폴더에서 `npm install` (Node 22 이상)
  2. `npm run dev`
  3. 브라우저에서 http://localhost:3000 열기
- 첫 화면 스크린샷: `결과물/첫화면.png` (구경하기 표에 올라갑니다)
- 다른 스크린샷: `결과물/폰화면.png` (휴대폰 폭에서 본 첫 화면)
- 영상이 있으면 링크로 (파일은 올리지 않습니다): 없음
- PRD 아티팩트 링크 (사전 과제로 만든 웹페이지, 있으면): 없음

## 이번 버전에서 되는 것

- 카테고리별 레시피 목록, 메뉴명·재료 검색, 즐겨찾기·최근 본 메뉴
- 레시피 상세: ICE/HOT/SIZE UP별 정량, 층 쌓는 순서, 제조 순서, 제조 주의사항, 손님 안내, 사진·영상 자리
- 상세 화면 머리에 버전과 최종 수정일 표시 (직원이 자기 기억이 아니라 화면을 최신으로 믿게)
- "프롬프트 생성" 버튼: 그 레시피의 정량·순서·주의사항을 정해진 문장 틀에 끼워 넣어 교육 영상 프롬프트 생성 + 복사 (외부 API 없음). 레시피가 비어 있으면 만들지 않고 안내
- 없는 메뉴를 검색하면 "일치하는 레시피가 없습니다" 안내
- 시연 데이터: "테스트 ○○"로 표시된 가짜 레시피 10개. 실제 레시피 값은 넣지 않았습니다

## 아직 안 되는 것 / 다음에 할 것

- 직원 로그인·권한 (로그인한 직원만 보기, 퇴사자 차단) → v2 꼭
- 사장 편집 화면은 코드에 들어 있지만 ChatGPT 계정 연동 기준으로 만들어져 있어, 이 저장소에서는 로그인 없이 시연만 됨 → v2에서 데이터 창고(Supabase) 로그인으로 바꿈
- 바뀐 레시피 읽음 확인 + 포스기 빈숲OS 알림 → v2 꼭
- 신입 체크리스트·퀴즈, 영상·사진 워터마크, 챗봇 → v2 여유 있으면 (자세한 순서는 `../v2/PRD.md`)
