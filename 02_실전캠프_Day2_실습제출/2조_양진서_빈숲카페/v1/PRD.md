# 기획안(PRD) — 빈숲 레시피북 · v1

- 가게 / 이름: 빈숲카페 / 양진서
- 조 주제: 직원 교육 매뉴얼 온라인 북 — 레시피북
- 이 버전의 목표 한 줄: 직원이 메뉴 레시피를 검색하는 순간, 재료·비율·순서를 바로 찾고 영상 프롬프트까지 받는 도구

> 아래 칸을 채우기 어려우면 AI에게 이렇게 말하세요.
> "내가 하는 일은 ○○인데 매번 ○○이 힘들어. 이 PRD.md 양식대로 v1과 v2를 나눠서 기획안을 써 줘."

## 1. 무엇을 왜 만들고 싶나요?

레시피가 카톡·엑셀·사진으로 흩어져 있어서, 직원마다 참고하는 버전이 다릅니다. 더 큰 문제는 직원이 헷갈려도 찾아보지 않고 본인이 외운(잘못된) 방식대로 만들고, 그걸 신입에게 그대로 전달하는 것입니다(한 달에 2~3번 발견). 사람이 바뀌어도 같은 기준으로 음료·메뉴를 만들 수 있게 "최신 레시피가 여기 하나"로 정리하고 싶습니다.

## 2. 누가 언제 쓰나요?

빈숲카페(매장 1곳, 정직원 3명 + 파트타임 4명) 직원이, 근무 중 메뉴를 만들다가 재료 비율이나 순서가 헷갈릴 때 매장 태블릿·휴대폰으로 바로 열어봅니다. 사장은 PC에서 레시피를 등록·수정합니다.

## 3. 지금은 어떻게 하고 있나요?

카톡·엑셀·사진으로 레시피를 공유하고 있습니다. 표준 문서가 없어 버전이 여러 개로 섞여 있고, 직원이 다시 찾아보는 건 주 1~2회·1분 이내로 짧지만 그만큼 "안 찾아보고 그냥 만드는" 일이 많습니다.

## 4. 도구를 쓰면 어떤 일이 달라지나요?

메뉴 이름을 검색하면 해당 레시피(재료·비율·순서)가 바로 나오고, 상세 페이지에서 버튼을 누르면 그 레시피 내용이 반영된 영상 프롬프트 문장이 만들어집니다.

## 5. v1에서 만들 것 — 오늘(9/17) 안에 되는 것만

- 기능 1: 메뉴별 레시피(재료·비율·순서)를 카테고리로 정리한 레시피북 웹페이지
- 기능 2: 메뉴 이름으로 검색/필터
- 기능 3: 레시피 상세 페이지의 "AI 영상 프롬프트 생성" 버튼 — 정해진 문장 틀에 그 레시피의 재료·순서를 끼워 넣어 프롬프트 텍스트 조합 (외부 API 호출 없음)
- 기능 4: 레시피 상세 페이지에 "최종 수정일" 표시 — 직원이 자기 기억이 아니라 화면을 최신으로 믿게
- **이번에 하지 않을 것:** 실제 영상 생성, 진짜 AI 챗봇 응답, 로그인/직원별 권한

## 6. 완성됐다는 걸 어떻게 확인하나요?

- 시연할 예시 입력: "아메리카노" 검색
- 기대하는 결과: 레시피 상세(재료·비율·순서·최종 수정일) 표시 + 프롬프트 버튼 클릭 시 해당 레시피 내용이 반영된 영상 프롬프트 문장 생성
- 잘못 입력했을 때: 없는 메뉴 검색 시 "레시피를 찾을 수 없습니다" 안내
- 다시 열었을 때 남아 있어야 할 것: 등록해 둔 레시피 데이터 전체

## 7. v2에서 더할 것 (10/14까지 · API·외부 데이터 등)

- 다음에 추가할 기능 하나: 직원 로그인 + 사장 편집 화면 + 바뀐 레시피 읽음 확인 — 사장이 고치면 포스기 빈숲OS에 "바뀐 레시피 N건", 직원 7명 중 누가 안 봤는지 표시. 레시피 유출 방지를 위해 로그인한 직원만 봄 (챗봇은 그다음 "여유 있으면"으로)
- 필요한 데이터나 외부 연결 (API, 배민 데이터, 날씨 등): 데이터 창고(Supabase) — 로그인·레시피·읽음 기록 저장. 빈숲OS HTML에 배지 한 줄
- 사람이 직접 판단·확인해야 할 부분: "직원 확인 필요" 체크 여부, 직원 계정 만들기·끄기

## 8. 절대 자동화하면 안 되는 것

- 레시피 원가·판매가 확정
- 실제 영상 파일 생성·게시
- 직원에게 보내는 메시지 발송
