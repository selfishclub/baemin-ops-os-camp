## 2. 만든 과정 — 다른 사장님이 따라 할 수 있게

1. 계획을 어떻게 고쳤나요?: v1은 "레시피북"이었는데, 쓰다 보니 레시피보다 "누가 봤나·바뀐 걸 아나·오픈마감을 했나"가 더 급해서 v2 PRD를 "빈숲 OS 포털"로 넓혔다. 유출 걱정이 커서 "로그인 없이는 아무것도 안 보이게"를 꼭 할 것 1번으로.
2. 만든 순서 (세 줄 안팎):
   - 로그인·권한 → 바뀐 레시피 확인 → 교육 체크·퀴즈 → 워터마크 → 포털(매뉴얼 8영역·응대북·교육 경로·공지·가져오기·시험·오늘 체크) → 미리보기(직원 눈/사장 눈)
   - 공개 시연판 고정(9/22) → 비공개 버전 분리 → 유출 방지 1차(열람 기록·자동 로그아웃·매장 밖·파일 워터마크·앱 안 계정)
   - 다른 사장님 저장소 보고 재미·경쟁 장치(점수판 → 퀘스트 → 칭찬 → 인수인계 → 체크 고도화) → 시연판에 가짜 데이터로 다시 올림(10/6)
3. **AI에게 한 말 중 결과를 크게 바꾼 것** (원문 그대로 두세 개):
   > "외부 유출이 완전 싫거든" → 로그인 없이는 메뉴 이름도 안 보이게, 워터마크, 열람 기록, 자동 로그아웃
   > "레시피북에 퀘스트처럼… 문제가 너무 다 공개되어 있으면 안 돼. 각자 자기가 퀘스트를 얼만큼 깼는지 볼 수 있고, 사람마다 문제도 다 달랐으면 좋겠거든" → 직원 ID+주 씨앗으로 사람마다 다른 퀘스트, 정답은 서버에만
   > "나중에 나만의 레시피를 엑셀이나 이런 식으로 주면, 네가 알아서 그 자리에 맞게 다 넣어줄 거지?" → 가져오기 탭
4. 막혔다가 푼 것과 푼 방법:
   - 문서 1장만 고쳐 게시해도 알림이 26건 나감 → 창고(jsonb)가 항목 순서를 바꿔서 "다르다"고 본 것. 순서와 무관하게 비교하도록 고치고 되풀이 검사 추가
   - 컴퓨터 이름이 한글이라 Vercel 배포가 죽음 → 이름을 가짜로 바꿔 주는 한 줄 패치를 앞에 붙여 실행
   - 공개 시연판에 실제 데이터를 넣을 수 없음 → 원본은 비공개 폴더, 시연판은 가짜 데이터만 복사해 올리는 구조
