# 전체 기획안(PRD) — 빈숲 레시피북

- 가게 / 이름: 빈숲카페 / 양진서
- 조 주제: 직원 교육 매뉴얼 온라인 북 — 레시피북
- 한 줄 목표: 직원이 근무 중 궁금할 때 메뉴 레시피를 바로 찾거나 물어보고, 레시피 기반 영상 프롬프트까지 받는 도구
- 마지막 수정: 2026-09-17

> **이 문서는 "다 만들었을 때의 모습"입니다.** 먼저 여기에 전체를 그린 뒤, 4번 기능 목록에 꼬리표를 붙여

> v1을 써 본 뒤에는 `v1/사용메모.md`를 보고 이 문서와 v2를 다시 고칩니다.

## 1. 배경 — 최근 실제로 있었던 한 장면

- 장면: 새로 온 직원이 아메리카노 비율을 몰라서 카톡방을 뒤지다가, 예전 버전 레시피 사진을 보고 잘못 만듦. 더 큰 문제는 직원이 헷갈릴 때 찾아보지 않고 **본인이 외운(잘못된) 방식대로 그냥 만들고, 그걸 신입에게도 그대로 전달**하는 것
- 얼마나 자주: 레시피를 다시 찾아보는 건 직원당 주 1~2회. "잘못된 자기 방식대로" 만드는 게 발견되는 건 한 달에 2~3번
- 한 번에 걸리는 시간: 찾아볼 때는 1분 이내(짧게 확인하고 넘어감) — 그래서 안 찾아보고 그냥 만드는 게 더 문제
- 실수·빠뜨림: 잘못된 레시피가 신입에게 그대로 전달돼 굳어지는 것이 핵심 리스크

## 2. 쓰는 사람과 역할

- 매장 1곳 · 정직원 3명 + 파트타임 4명

| 누가 | 언제 여나 | 무엇을 보나 | 무엇을 누르나 | 어떤 기기로 |

| 직원(정직원·파트타임) | 근무 중 메뉴 제조가 헷갈릴 때 | 레시피 검색·상세 화면 | 검색, 프롬프트 생성 버튼 | 매장 태블릿·휴대폰 |

## 3. 흐름 — 지금 vs 도구를 쓰면

| 단계 | 지금 (쓰는 앱·파일) | 도구를 쓰면 |
|---|---|---|
| 1 | 카톡방·엑셀·사진에서 레시피 찾기 | 레시피북 웹페이지에서 메뉴 이름 검색 |
| 2 | 여러 버전 중 어떤 게 최신인지 헷갈림 | 하나로 정리된 최신 레시피(재료·비율·순서) 확인 |
| 3 | (레시피 영상은 직접 기획·촬영) | 레시피 상세에서 영상 프롬프트 자동 생성 → v2에서는 챗봇에게 물어서 바로 답 받기 |

## 7. 예외 — 잘못 넣거나 평소와 다를 때

- 없는 메뉴를 검색하면 → "레시피를 찾을 수 없습니다" 안내
- 레시피북에 없는 메뉴를 챗봇에 물으면(v2) → 임의로 답하지 않고 "레시피북에 없는 메뉴입니다"라고 답변
- 레시피 데이터가 비어 있는 상태로 프롬프트 생성 버튼을 누르면 → 생성하지 않고 안내

## 8. 사람이 꼭 직접 해야 하는 것 (자동화 금지)

- 레시피 원가·판매가 확정
- 실제 영상 파일 생성·게시
- 직원에게 보내는 메시지 발송

## 9. 성공 기준 — 숫자로

- 지금: 레시피를 찾아보는 것 자체는 1분 이내로 짧지만, 안 찾아보고 "외운 대로" 잘못 만드는 경우가 한 달에 2~3번
- 목표: 검색·최종 수정일 확인으로 30초 이내에 최신 레시피 확인, "자기 방식대로" 잘못 만들어 신입에게 전달되는 사례 0건
- 시연할 예시 입력 → 기대하는 결과: "아메리카노" 검색 → 재료·비율·순서 표시, 프롬프트 버튼 클릭 → 해당 레시피 기반 영상 프롬프트 문장 생성
