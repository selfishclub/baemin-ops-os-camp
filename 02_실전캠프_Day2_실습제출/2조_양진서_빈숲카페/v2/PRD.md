# 기획안(PRD) — 빈숲 레시피북 · v2

> 초안 — v1을 써 본 뒤 고칩니다

- 가게 / 이름: 빈숲카페 / 양진서
- 조 주제: 직원 교육 매뉴얼 온라인 북 — 레시피북
- 이 버전의 목표 한 줄: 직원이 자연어로 레시피를 물어보면, AI가 레시피북 내용을 바탕으로 바로 답해주는 도구

> 아래 칸을 채우기 어려우면 AI에게 이렇게 말하세요.
> "내가 하는 일은 ○○인데 매번 ○○이 힘들어. 이 PRD.md 양식대로 v1과 v2를 나눠서 기획안을 써 줘."

## 1. 무엇을 왜 만들고 싶나요?

v1의 검색형 레시피북은 정확한 메뉴 이름을 알아야 찾을 수 있습니다. 직원이 "아메리카노 뜨거운 거 비율 얼마야?"처럼 편하게 물어봐도 답을 찾을 수 있게 하고 싶습니다.

## 2. 누가 언제 쓰나요?

빈숲카페 직원이, 근무 중 메뉴를 만들다가 궁금한 게 생겼을 때 바로 챗봇에게 물어봅니다.

## 3. 지금은 어떻게 하고 있나요?

v1에서 만든 레시피북 웹페이지를 메뉴 이름으로 검색해서 확인하고 있습니다.

## 4. 도구를 쓰면 어떤 일이 달라지나요?

직원이 자연어로 질문을 입력하면, AI가 레시피북 데이터 안에서 관련 레시피를 찾아 재료·비율·순서를 답변으로 정리해서 보여줍니다.

## 5. v2에서 만들 것 — 10/17까지 (API 연동·외부 데이터 등 v1에서 미룬 것)

**꼭 할 것**
- 기능 1: 레시피북 웹페이지에 챗봇 UI(대화창) 추가
- 기능 2: AI 응답 API 연동 — v1 레시피북 데이터를 근거로 자연어 질문에 답변. 레시피북에 없는 메뉴는 "없는 메뉴입니다"라고만 답함

**여유 있으면**
- 기능 3: 답변에 참고한 원본 레시피 페이지로 바로 이동하는 링크 제공
- 기능 4: 답변에 그 레시피의 최종 수정일도 같이 표시 (v1의 "최신 버전" 신뢰를 챗봇에서도 유지)

**준비물:** AI 응답 API 키 발급 (사장님이 직접 발급, 키 값은 PRD·채팅에 적지 않음)

- **이번에 하지 않을 것:** 레시피북에 없는 메뉴에 대한 AI 임의 답변, 영상 실제 생성

## 6. 완성됐다는 걸 어떻게 확인하나요?

- 시연할 예시 입력: "아메리카노 비율 알려줘"
- 기대하는 결과: 아메리카노 레시피(재료·비율·순서)를 바탕으로 한 답변 + 원본 페이지 링크
- 잘못 입력했을 때: 레시피북에 없는 메뉴를 물으면 "레시피북에 없는 메뉴입니다"라고 답변 (임의로 지어내지 않음)
- 다시 열었을 때 남아 있어야 할 것: v1의 레시피 데이터와 챗봇 UI 설정

## 7. 그 다음에 더하고 싶은 것

- 다음에 추가할 기능 하나: 영상 프롬프트를 실제 영상 생성 API에 연결해서 프롬프트뿐 아니라 영상 초안까지 만들기
- 필요한 데이터나 외부 연결 (API, 배민 데이터, 날씨 등): 영상 생성 API
- 사람이 직접 판단·확인해야 할 부분: 생성된 영상이 실제 레시피와 맞는지, 직원 교육용으로 써도 되는 품질인지 확인

## 8. 절대 자동화하면 안 되는 것

- 레시피 원가·판매가 확정
- 실제 영상 파일 생성·게시 (v2까지는 프롬프트 생성까지만)
- 직원에게 보내는 메시지 발송
