## 이번 버전에서 되는 것 (9/20 기준)

- **빈숲 OS 홈(포털)**: 주소를 열면 내용이 아니라 영역별 큰 버튼이 먼저 보임. 레시피·신입 교육 체크·사장용 관리는 "열기", 운영 매뉴얼 8개 영역도 "열기", 시험·인증과 공지는 자리만 잡은 "준비 중". 레시피는 `/recipes`
- **운영 매뉴얼 (문서형 영역 8개)**: 홈의 빈숲의 기준 · 오픈 · 미들 · 마감 · 고객응대·주문·결제 · 위생·안전 · 바리스타 기초 · 기기·시설이 열림(`/manual/영역`). 모든 문서가 같은 틀 — 왜 하나요 · 준비물 · 순서 · 완료 기준 · 하면 안 되는 것 · 이럴 땐 바로 보고. 공개용 버전이라 안에는 **가짜 예시(○○ 빈 양식)**만 있음. 사장은 관리자 편집의 "매뉴얼" 탭에서 문서를 추가·수정하고 레시피처럼 초안 저장 → 공식 게시. 영역 잠금이 그대로 적용됨. 시험·인증, 공지는 아직 준비 중
- **응대북 (응대 카드)**: 고객응대 영역(`/manual/service`)은 상황별 카드 — 어떤 상황인가요 · 이렇게 말해요 · 이렇게는 말하지 않아요 · 직원이 혼자 해도 되는 범위 · 이럴 땐 책임자를 불러요. 묶음 7개(기본 흐름, 주문 상황, 결제, 불만, 매장 이용 안내, 배달·포장·전화, 어려운 상황)에 가짜 예시 17장. "손님이 환불해 달라고 하면 뭐라고 해?"처럼 물으면 챗봇이 카드를 찾아 답함. 관리자 편집 "매뉴얼" 탭에서 "+ 새 응대 카드"
- **신입 교육 경로**: `/recipes/training` 위쪽에 단계별 경로(예시: 1일차 · 1주차 · 2주차 · 30일차). 단계마다 익힐 매뉴얼 문서·응대 카드·메뉴가 묶여 있고, 직원이 문서는 "읽었어요", 메뉴는 "만들어 봤음"을 누르면 사장이 직접 보고 "확인함". 단계별 "n / m 확인", 사장 교육 현황에 직원별 문서 읽음·확인 수. 퀴즈는 레시피 + 매뉴얼(하면 안 되는 것 / 보고 기준) 문제가 섞여 나옴. 관리자 편집 "교육 경로" 탭에서 단계와 내용을 고침
- **공지 · 변경 이력**: 매뉴얼 문서·응대 카드도 고쳐 게시하면 바뀐 것마다 알림이 생김. 홈의 "공지 · 변경 이력"(`/notices`)에 레시피·매뉴얼 변경이 모이고 "보기"·"확인했어요", 홈 버튼에 "확인할 것 n". 바뀐 문서를 열면 그 자리에서도 확인 가능. 사장 확인 현황(`/recipes/changes`)에 매뉴얼도 함께 표시
- **엑셀·표에서 가져오기**: 관리자 편집의 "가져오기" 탭. 엑셀에서 복사한 표를 붙여 넣으면 어떻게 읽었는지(메뉴·구분·정량·단계 수, 건너뛴 줄, 확인할 점)를 먼저 보여 주고, 확인을 눌러야 초안에 들어감. 레시피 표와 매뉴얼·응대 카드 표. 열 이름이 조금 달라도 알아보고, HOT·ICE 줄을 한 메뉴로 합침. "예시 표 넣어 보기"로 바로 체험 가능
- **물어보기(챗봇)가 매뉴얼도 답함**: 홈·레시피·매뉴얼 화면 오른쪽 아래. "마감 순서 알려줘", "기기 고장 나면 누구한테 보고해?" → 문서 내용 + "문서 열기". 잠긴 영역의 내용은 답하지 않음. 외부 AI 없음
- **메뉴 잠금 설정**: 관리자 화면(`/manage/menus`)에서 큰 메뉴마다 직원에게 열림/잠김을 정함(준비 중인 메뉴도 미리 지정 가능). 잠기면 직원에게는 "잠김"으로만 보이고, 주소를 직접 열거나 챗봇으로 물어도 열리지 않음. 사장은 항상 들어감. 지금은 전부 열림
- **미리보기 (직원 눈으로 / 사장 눈으로)**: 지금처럼 로그인을 꺼 둔 둘러보기 모드에서는 전체 흐름을 로그인 없이 눌러 볼 수 있음. 홈·레시피·각 화면의 노란 단추로 **직원 눈 / 사장 눈**을 바꿈. 사장 눈: 관리자 편집(`/recipes/admin`: 레시피 고치기 · 영상 프롬프트 지침 · 공식 게시 · 버전 복구), 메뉴 잠금 설정(`/manage/menus`), 직원 교육 현황, 확인 현황(`/recipes/changes`), 직원 계정 관리(`/recipes/staff`). 직원 눈: 사장 메뉴가 사라지고, 바뀐 레시피 "확인했어요", 내 체크리스트 "만들어 봤음", 퀴즈. 사장 눈으로 게시한 변경이 직원 눈에 알림으로 뜨고, 직원이 확인하면 사장 확인 현황에 표시됨. 가짜 사람(미리보기 사장, 직원 A·B·C)만 나오고 고친 내용은 **그 브라우저에만** 저장 — 실제 데이터와 다른 사람 화면은 바뀌지 않음. "처음 상태로"로 되돌림. 사진·영상 올리기는 미리보기에서 안 됨
- **직원 로그인·권한** (꼭 할 것 1): 아이디·비밀번호 로그인. 로그인 없이는 메뉴 이름도 안 보임. 사장(owner)만 편집·게시·직원 관리, 직원(staff)은 보기만. 첫 계정이 자동으로 사장. 직원 계정 관리 화면(`/recipes/staff`)에서 퇴사 직원을 중지하면 그 순간부터 로그인 차단
- **데이터 창고(Supabase) 연결**: 레시피·버전·기록·사진이 Supabase에 저장되고 잠금(RLS)으로 로그인한 재직 직원만 읽음. ChatGPT 계정 연동과 Cloudflare 저장은 걷어냄
- **바뀐 레시피 읽음 확인** (꼭 할 것 2): 사장이 게시할 때 "직원 확인 필요"를 켜 두면(기본), 이전 공식본과 비교해 실제로 바뀐 메뉴마다 알림이 생김. 직원 첫 화면에 "바뀐 레시피" 목록 + "보기"·"확인했어요", 헤더에 안 읽은 건수. 사장 화면 **확인 현황**(`/recipes/changes`)에서 메뉴별로 확인한 사람 / 안 본 사람. 오타 수정은 체크를 끄면 알림 없이 게시
- **빈숲OS 배지**: 포스기 빈숲OS HTML에 `<script src="https://beansoop-recipe-os.vercel.app/badge.js" defer></script>` 한 줄을 넣으면 "바뀐 레시피 N건 · 확인하기" 배지가 뜸. 건수만 공개(메뉴 이름 안 나감). 방법은 `프로젝트/docs/빈숲OS_배지.md`
- **신입 메뉴 체크리스트 + 레시피 퀴즈** (여유 1순위): `/recipes/training`. 직원은 메뉴마다 "만들어 봤음", 사장은 직원별 체크리스트에서 "확인함"(직원이 스스로 못 누르게 창고에서 막음). 퀴즈는 레시피 정량·순서로 10문제 자동 생성, 점수는 기록되고 사장 교육 현황에 직원별로 보임
- **워터마크 + 자주 틀리는 포인트** (여유 2순위): 레시피 사진·영상 위에 "빈숲카페 · 보는 직원 이름 · 날짜"가 반투명으로 깔림(스크린샷으로 새면 누가 찍었는지 남음). 사진 드래그·우클릭 저장 막기, 직접 올린 영상은 다운로드 버튼 숨김. 레시피마다 "자주 틀리는 포인트"가 상세 화면 맨 위에 눈에 띄게 보이고, 영상 프롬프트에도 들어감
- **유출 금지 안내**: 모든 페이지 맨 아래 "레시피 등 카페 정보 유출 금지" 버튼을 누르면 전문이 펼쳐짐(모든 권리는 빈숲카페에 있음 · 촬영/복사/반출/외부 전송 금지 · 워터마크로 보는 사람 표시 · 위반 시 계정 중지와 민·형사상 책임). 인쇄물 하단에도 표시. 저장소에 `NOTICE.md`(권리 고지)
- **종류별 영상 프롬프트 지침서**: 관리자 편집의 "영상 프롬프트 지침" 탭에 음료·베이커리(커팅·포장·매장 제공)·기타 지침서를 저장해 두고, 레시피 상세의 "프롬프트 생성"이 그 메뉴 종류에 맞는 지침서를 불러와 빈칸({메뉴명}·{정량}·{제조순서} 등)을 채움. 카테고리로 자동 선택되고 화면에서 다른 지침으로 바꿔 다시 만들 수 있음. 베이커리는 매장·플레이팅 / 포장으로 나눠 적음. 외부 API 없음
- **변경 이력 보기** (여유 3순위): 레시피 상세의 "변경 이력"에서 버전마다 "액체 10ml → 170ml"처럼 이전 값과 지금 값을 나란히 봄
- **레시피 물어보기(챗봇) 1단계** (여유 4순위): 화면 오른쪽 아래 버튼. 외부 AI 없이 레시피북 데이터만으로 답하는 규칙 답변기. "카페라떼 핫 액체 얼마야?" → 정량 + 최종 수정일 + 레시피 열기. 레시피북에 없는 메뉴는 "없는 메뉴입니다"라고만 답하고 비슷한 메뉴를 제안. AI 응답 API는 맨 마지막에 `app/api/chat/route.ts` 한 곳에만 연결
- **Vercel 배포**: 위 주소. 열쇠가 없는 컴퓨터에서 `npm run dev`로 열면 시연 모드(가짜 레시피, 편집은 그 브라우저에만 저장되는 미리보기)
- 단면도 색 자동 지정: 층 이름에 딸기·말차·초코·카라멜·자몽·레몬·블루베리·민트·홍차 등 재료가 들어가면 16가지 팔레트에서 색이 자동으로 정해짐. 편집할 때 목록에서 바꿀 수 있고, 목록에 없는 재료는 "직접 고른 색"으로 지정
- 얼음층에 얼음 조각 표시 (튀지 않게 연한 파란 테두리)
- 단면도는 잔 아래(1층)부터 넣는 순서대로 쌓이고, 층마다 번호 표시. 관리자 화면 입력 설명도 "첫 줄이 맨 아래"로 통일
