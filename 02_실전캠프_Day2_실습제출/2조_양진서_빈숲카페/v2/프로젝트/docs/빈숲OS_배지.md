# 빈숲OS(포스기 화면)에 "바뀐 레시피 N건" 배지 붙이기

레시피북에서 사장이 레시피를 고쳐 게시하면, 포스기의 빈숲OS 첫 화면 오른쪽 아래에 **"바뀐 레시피 N건 · 확인하기"** 배지가 떠요. 누르면 레시피북(로그인 화면)이 열려요. 카톡·문자는 쓰지 않아요.

## 붙이는 방법 — 한 줄

빈숲OS HTML 파일의 `</body>` 바로 앞에 이 한 줄을 넣고 저장·업로드하면 끝이에요.

```html
<script src="https://beansoop-recipe-os.vercel.app/badge.js" defer></script>
```

## 어떻게 동작하나

- 5분마다 `https://beansoop-recipe-os.vercel.app/api/badge`에서 **최근 14일 안에 바뀐 레시피 건수**만 가져와요.
- 건수만 나가고 메뉴 이름·내용은 나가지 않아요. 빈숲OS가 공개 페이지여도 레시피가 새지 않아요.
- 0건이면 배지가 안 보여요.
- "누가 아직 안 봤는지"는 로그인이 필요해서 배지에는 안 나오고, 레시피북 사장 화면 **확인 현황**(`/recipes/changes`)에서 봐요.

## 배지가 안 뜰 때

- 빈숲OS 파일에 스크립트 한 줄이 들어갔는지, 업로드가 됐는지 확인
- 브라우저 주소창에 `https://beansoop-recipe-os.vercel.app/api/badge` 를 열어 `{"count":N,"days":14}` 가 나오는지 확인
- 최근 14일 안에 "직원 확인 필요"로 게시한 게 없으면 원래 0건이라 안 보여요
