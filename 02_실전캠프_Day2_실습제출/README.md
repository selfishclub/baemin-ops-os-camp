## 만든 폴더를 통째로 올립니다 — 왜, 어떻게

**왜.** 만들면서 **서로 힌트를 얻기 위해서**입니다. 12명이 한 저장소에 두면 "저런 것도 구현이 되는구나"를 폴더를 열어 바로 볼 수 있고, 필요한 부분은 끌어다 쓸 수 있습니다. 같은 조가 같은 주제를 만드니 더 그렇습니다. 코드만이 아니라 **프롬프트 기록, 아티팩트, 이미지, 문서**도 같이 올려야 "어떻게 만들었나"까지 보입니다.
**써 보는 건 폴더가 아니라 Vercel 주소로 합니다.** 오늘은 시간이 되면 [임시 주소](../03_인터넷에서_접근가능하게_만들기/부록_CLI로_바로_올리기.md)를 만들고, 10/2에 개인 저장소를 만들면서 정식 주소를 만듭니다.
**10/2 중간 점검 때** 각자 개인 저장소(Public)로 옮기고 GitHub·Vercel을 연결합니다. 그 뒤로는 개인 저장소에서 작업하고, 여기에는 링크와 제출서만 갱신합니다. 방법은 [03 폴더](../03_인터넷에서_접근가능하게_만들기/README.md)에 있습니다.

**어떻게.** 규칙 일곱 개면 됩니다.

| 규칙 | AI에게 이렇게 |
|---|---|
| 프로젝트는 **내 폴더 `v1/프로젝트/` 안**에 만든다 | "`02_실전캠프_Day2_실습제출/[내폴더]/v1/프로젝트` 폴더 안에 만들어 줘" |
| 내 폴더 안에서 **`git init`을 하지 않는다** (이미 저장소 안) | "이 폴더는 이미 GitHub 저장소 안이니 git init은 하지 마" |
| `node_modules`·`.env`는 올리지 않는다 (`.gitignore`가 자동으로 뺀다) | "올리기 전에 node_modules와 .env가 빠지는지 확인해 줘" |
| **자주 pull, 자주 push** — 남의 것도 받아 오고 내 것도 올린다 | 시작할 때 "pull해 줘", 한 기능 될 때마다 "커밋하고 push해 줘" |
| 남의 것은 **읽고 복사만**, 그 폴더는 고치지 않는다 | "[2조_양진서_빈숲카페]/v1/프로젝트를 읽고 [메뉴 카드 화면]을 내 것에 맞게 가져와 줘. 그 폴더는 고치지 마" |
| 다른 곳에서 만든 걸 가져올 땐 **`.git` 폴더는 빼고** 복사한다 | "[~/Downloads/내앱] 폴더를 내 폴더 v1/프로젝트로 복사해 줘. .git, node_modules, .env는 빼고" |
| **영상은 올리지 않는다** — 링크로 적는다 (GitHub 한도) | 제출서에 유튜브·드라이브 링크 |

폴더 이름을 이미 `앱/`으로 만드신 분은 그대로 두셔도 됩니다. 구경하기 표는 두 이름을 다 알아봅니다.
이름이 같은 파일(예: `package.json`)이 사장님마다 있어도 됩니다. 폴더가 다르면 서로 부딪히지 않습니다.
복사해 온 폴더 안에 `.git`이 남아 있으면 GitHub에 내용이 안 올라가고 빈 칸만 생깁니다. "v1/프로젝트 안의 .git 폴더를 지우고 다시 추가해 줘"라고 하면 됩니다.

## v1과 v2

| | v1 | v2 |
|---|---|---|
| 언제 | **9/17** | **10/1(목) 밤 11시 59분까지 완성·push** → 10/2 점검에서 공유·피드백 → 개선해 **10/10 (금) 최종 제출** |
| 범위 | 오늘 안에 되는 것만. 외부 연결 없이 (데이터 저장용 Supabase는 가능) | API 연동, 배민 데이터, 날씨 등 외부 데이터·고도화 |
| 어디 | `내폴더/v1/` (코드는 `v1/프로젝트/`) | 10/2까지 `내폴더/v2/` (코드는 `v2/프로젝트/`, v1/프로젝트를 복사해 이어 만듦) · **10/2부터 내 개인 저장소** |

전체 PRD에서 [v2] 꼬리표를 붙인 것이 v2의 시작점입니다. v2는 **v1을 써 본 뒤 바뀌는 게 정상**입니다. 그래서 오늘 쓰는 `v2/PRD.md`는 초안입니다.

**v1이 오늘 안에 끝난 분은 바로 v2를 시작해서 올려도 됩니다.** 10/2 마감을 기다릴 필요 없습니다. `v1/프로젝트`를 `v2/프로젝트`로 복사해 이어 만들고, v2 제출서를 채우면 됩니다. 나중에 써 보고 바뀌면 그때 또 고치면 됩니다.

## 실습 ② — AI에게 시켜서 올리기

Claude에게 순서대로 말합니다. `[ ]` 부분만 바꿉니다.

   > https://github.com/selfishclub/baemin-ops-os-camp 저장소를 내 컴퓨터에 처음 가져와 줘. 홈 폴더 아래에 받아 줘.

2. 내 폴더 확인
   > `02_실전캠프_Day2_실습제출` 안에서 내 폴더 `[1조_이범례_부찌대학]`을 열어 줘. 안에 뭐가 있는지 알려 줘.

3. 전체 PRD → v1·v2 나누기 (스킬 `baemin-ops-prd`가 있으면 그걸로. 없으면 아래)
   > `PRD_전체.md`를 나와 인터뷰하면서 채워 줘. 질문은 한 번에 하나씩, 내가 짧게 답하면 예를 들어 달라고 다시 물어봐 줘. 다 채우면 기능마다 [v1]/[v2]/[나중]을 붙이고, [v1]은 `v1/PRD.md`에, [v2]는 `v2/PRD.md`에 초안으로 옮겨 줘.

   (사전 과제 PRD가 있을 때 — 먼저 붙여넣기)
   > 내가 붙여넣는 기획안으로 `PRD_전체.md`를 먼저 채우고, 빈칸만 나한테 물어봐 줘. 그다음 v1·v2로 나눠 줘. [기획안 붙여넣기]

4. 올리기
   > 내 폴더 안의 파일만 바뀌었는지 확인하고, 비밀번호나 키가 없는지 본 다음, "전체 PRD·v1 PRD 작성"이라고 커밋하고 push해 줘.

5. 확인
   > GitHub 웹에서 내 폴더를 열어 `PRD_전체.md`와 `v1/PRD.md`가 채워져 있으면 완료입니다.
