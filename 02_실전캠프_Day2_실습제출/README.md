# 실전 캠프 Day 2 실습 제출

여기가 **제출하는 곳**입니다. 사장님마다 폴더가 하나씩 있고, 그 안에 `PRD_전체.md`와 `v1/`·`v2/`가 있습니다.

**기획은 크게 그린 뒤 나눕니다.** `PRD_전체.md`에 다 만들었을 때의 모습을 먼저 그리고, 오늘 만들 것은 `v1/PRD.md`로, 나머지는 `v2/PRD.md`(초안)로 나눕니다. v2는 v1을 써 본 뒤 다시 고칩니다.

```
전체 PRD ──나누기──▶ v1 PRD ──만들기──▶ v1 써 보기(사용메모) ──▶ 10/2 중간 점검 ──▶ v2 PRD 고치기 ──▶ v2 만들기
            └──────▶ v2 PRD (초안) ─────────────────────────────────────────┘
```

## 무엇을 제출하나 — 네 가지

| 무엇 | 어디에 | 설명 |
|---|---|---|
| ① **전체 기획안 `PRD_전체.md`** | `내폴더/PRD_전체.md` | 다 만들었을 때의 모습. 기능마다 [v1]·[v2]·[나중] 꼬리표 |
| ② **v1 기획안 `PRD.md`** | `내폴더/v1/PRD.md` | 전체에서 오늘 만들 것만. 사전 과제로 쓴 PRD가 있으면 그 내용부터 옮깁니다 |
| ③ **제출서 `제출서.md`** | `내폴더/v1/제출서.md` | **내 개인 GitHub 저장소 링크(Public)** + **Vercel 인터넷 주소** + 아티팩트 링크 |
| ④ **스크린샷** | `내폴더/v1/결과물/` | 만든 화면 사진 1~3장 |

**코드는 여기에 올리지 않습니다.** 코드는 내 개인 GitHub 저장소(공개)에 두고, Vercel이 그걸 읽어 인터넷 주소를 만듭니다. 여기에는 그 **링크**를 적습니다.
왜 그렇게 하는지와 방법은 [03_인터넷에서_접근가능하게_만들기](../03_인터넷에서_접근가능하게_만들기/README.md)에 있습니다.

## v1과 v2

| | v1 | v2 |
|---|---|---|
| 언제 | **9/17 오늘** 안 | **10/17(금)**까지 (10/2 온라인 중간 점검) |
| 범위 | 오늘 안에 되는 것만. 외부 연결 없이 (데이터 저장용 Supabase는 가능) | API 연동, 배민 데이터, 날씨 등 외부 데이터·고도화 |
| 어디 | `내폴더/v1/` | `내폴더/v2/` |

전체 PRD에서 [v2] 꼬리표를 붙인 것이 v2의 시작점입니다. v2는 **v1을 써 본 뒤 바뀌는 게 정상**입니다. 그래서 오늘 쓰는 `v2/PRD.md`는 초안입니다.

| v1과 v2 사이에 | 어디에 | 언제 |
|---|---|---|
| v1을 쓸 때마다 한 줄 적기 | `내폴더/v1/사용메모.md` | v1 완성 직후부터 |
| 사용메모를 모아 v2 변경안 정리 | `내폴더/중간점검_1002.md` | 10/2 점검 전날까지 |
| 변경안을 반영해 v2 확정 | `PRD_전체.md` 4·12번 + `v2/PRD.md` | 10/2 점검 뒤 |

## 실습 ② — AI에게 시켜서 올리기

Claude에게 순서대로 말합니다. `[ ]` 부분만 바꿉니다.

1. 처음 가져오기
   > https://github.com/selfishclub/baemin-ops-os-camp 저장소를 내 컴퓨터에 처음 가져와 줘. 홈 폴더 아래에 받아 줘.

2. 내 폴더 확인
   > `02_실전캠프_Day2_실습제출` 안에서 내 폴더 `[1조_이범례_부찌대학]`을 열어 줘. 안에 뭐가 있는지 알려 줘.

3. 전체 PRD → v1·v2 나누기
   > `PRD_전체.md`를 나와 인터뷰하면서 채워 줘. 질문은 한 번에 하나씩, 내가 짧게 답하면 예를 들어 달라고 다시 물어봐 줘. 다 채우면 기능마다 [v1]/[v2]/[나중]을 붙이고, [v1]은 `v1/PRD.md`에, [v2]는 `v2/PRD.md`에 초안으로 옮겨 줘.

   (사전 과제 PRD가 있을 때 — 먼저 붙여넣기)
   > 내가 붙여넣는 기획안으로 `PRD_전체.md`를 먼저 채우고, 빈칸만 나한테 물어봐 줘. 그다음 v1·v2로 나눠 줘. [기획안 붙여넣기]

4. 올리기
   > 내 폴더 안의 파일만 바뀌었는지 확인하고, 비밀번호나 키가 없는지 본 다음, "전체 PRD·v1 PRD 작성"이라고 커밋하고 push해 줘.

5. 확인
   > GitHub 웹에서 내 폴더를 열어 `PRD_전체.md`와 `v1/PRD.md`가 채워져 있으면 완료입니다.
